# 백과 카드의 그림

이야기 속 이름(사람·장소·세력·세상)을 누르면 나오는 카드의 그림을 여기에 둔다.
파일 이름은 카드 id의 뒤쪽 — 예:

| 카드 | 파일 |
|---|---|
| 브람 (npc:npc_bram) | `npc_bram.png` |
| 배급 막사 '절름발이 수탉' (loc:gf_rooster) | `gf_rooster.png` |
| 바알카르 (node:baalkar) | `baalkar.png` |
| 바르그 노예사냥 조합 (fac:fac_barg) | `fac_barg.png` |
| 인간 (gl:gl_human) | `gl_human.png` |

webp · png · jpg · svg 가운데 하나. 세로 4:5 비율(예: 800×1000)이 카드에 잘 맞는다. 그림이 없으면 이름 첫 글자를 새긴 판이 대신 나온다.
