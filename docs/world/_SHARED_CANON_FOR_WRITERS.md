# 세계관 작가 공통 규칙 (병렬 작성용 고정 정보)

## 반드시 지킬 것
1. 정본은 `docs/world/WORLD_BIBLE.md`. 먼저 전부 읽고, 이름·연도·관계를 절대 바꾸지 말 것.
2. 시스템 문서 `docs/systems/01_STATS_AND_CHECKS.md`, `docs/systems/02_ITEMS_AND_CHOICES.md`를 읽고 수치·태그·스킬 이름을 그대로 쓸 것.
3. 한국어로, 그림다크 + 인간 찬가 톤. 현대 윤리로 세계를 판단하지 말 것 (WORLD_BIBLE §0.2~0.3).
4. 플레이어는 항상 **잔향(주인공)** 이 깃든 인간(또는 인간 혼혈)이다. **특별한 것은 주인공뿐이다.** 평범한 인간은 아무 힘도, 회귀도 없고, 이식을 받으면 거의 죽고, 진명을 거의 쓰지 못한다 (WORLD_BIBLE §1.3, §1.3.1).
5. 맡은 파일 하나만 작성. 다른 파일은 수정하지 말 것. git commit 하지 말 것.
6. 새로 만든 고유명사는 자유롭게 만들되, 아래 고정 명단과 충돌하지 말 것.
7. 게임 데이터로 옮기기 쉽게 표·일관된 항목 형식을 쓸 것. 모호한 수식어보다 구체적 사실(숫자, 장소, 이름, 사건)을 쓸 것.
8. 모든 항목에 "이야기 씨앗(플레이어가 엮일 수 있는 갈등)"을 넣을 것.

## 고정 명단 B — 재능 포인트 시스템 (06 문서가 정본)
- 첫 시대 기본 재능 포인트(TP) 10. 업적으로 영구 증가, 최대 40. 업적으로 늘어난 TP는 **회귀할 때** 영혼의 재능을 깨우는 데만 쓴다 (06 §2.1).
- 재능: 9개 분야(무예·몸·감각·그림자·사회·생존·기술·지식·신비·영혼) 119개. 등급 **소질 / 수재 / 천재 / 신재** (큰 재능 누적 2/4/7/12 TP, 작은 재능 1/2/4). 신재는 시대당 1개, 천재는 3개까지. 비기·오의, 신재만 넘는 경지(100+). 숨은 재능 2~3개는 플레이로만 드러난다.
- **회귀 규칙**: 기술은 기억, 몸은 재단련. 스킬 수치·영혼의 재능은 남고, 몸 관련 스킬은 **몸의 상한**에 묶인다 (06 §4).
- 몸의 특질(혈통, **주인공(잔향)만**): **용심(드래곤 하트)**, 거인의 뼈, 엘다르의 눈, 바르그의 피, 나가의 비늘살, 그롬의 분노샘, 두르강의 돌심장, 아에리의 깃뼈, 녹테른의 갈증, 페이의 그림자, 잔향의 눈(잿빛 고리). 혈통은 몸과 함께 회귀점으로 돌아가므로 남는다. **회차 중에 받은 이식은 회귀하면 사라진다.**
- 결점(TP 환급, 최대 +8): 노예 낙인, 외눈, 절름발이, 말더듬, 허약 체질, 겁쟁이, 원수의 피, 주인의 빚, 저주받은 이름, 재오염, 짙은 잔향
- 몸의 특질은 **사냥당할 이유**도 된다(예: 용심 보유자는 용족이 직접 처단).

## 고정 명단 C — 회귀 (WORLD_BIBLE §1.3.1이 정본)
- 주인공은 죽으면 **자기 몸으로** 회귀점(AS 312 낙엽월 1일 저녁 6시, 회색여울 배급 줄)에 돌아간다. 다른 몸으로 옮겨가지 않는다. 아기로 다시 태어나지 않는다.
- 남는 것: 기억(지식 카드·지도·비밀·단어·진명), 스킬, 영혼의 재능, 맹세의 기억. 돌아가는 것: 몸·물건·돈·모든 관계·평판·영역·가문. 사랑한 사람도, 낳은 아이도 주인공을 기억하지 못하고, 아이는 다시 태어나지 않는다.
- 용어: **회차**(한 번의 흐름), **시대**(한 잔향자의 모든 회차), **회차 기록**, **시대 연대기**. 주인공에게 '생애'·'전생'을 쓰지 말 것 (NPC의 일생은 '생애'로 써도 된다).
- 시간의 표류: 큰 사건·고정 날짜는 같고, 작은 일은 회차마다 어긋난다. 회귀의 대가: 젖은 재 냄새(회차가 쌓일수록 짙음), 엘다르·바르스카르·잿빛 탑의 기시감, 쌓이는 죽음의 기억.
- 진짜 죽음은 넷뿐: 바르스카르의 불, 엘다르의 시간의 그물, 재의 황무지의 시간의 상처, 잿빛 탑의 시간 유리 칼(세 자루). 그러면 시대가 끝나고 다른 출신의 새 잔향자로 새 시대가 시작된다.
