# 세계관 작가 공통 규칙 (병렬 작성용 고정 정보)

## 반드시 지킬 것
1. 정본은 `docs/world/WORLD_BIBLE.md`. 먼저 전부 읽고, 이름·연도·관계를 절대 바꾸지 말 것.
2. 시스템 문서 `docs/systems/01_STATS_AND_CHECKS.md`, `docs/systems/02_ITEMS_AND_CHOICES.md`를 읽고 수치·태그·스킬 이름을 그대로 쓸 것.
3. 한국어로, 그림다크 + 인간 찬가 톤. 표현 수위 원칙(WORLD_BIBLE §0.2) 준수.
4. 플레이어는 항상 **인간**(또는 인간 혼혈: 반용·반엘다르 등)이다.
5. 맡은 파일 하나만 작성. 다른 파일은 수정하지 말 것. git commit 하지 말 것.
6. 새로 만든 고유명사는 자유롭게 만들되, 아래 고정 명단과 충돌하지 말 것.
7. 게임 데이터로 옮기기 쉽게 표·일관된 항목 형식을 쓸 것. 모호한 수식어보다 구체적 사실(숫자, 장소, 이름, 사건)을 쓸 것.
8. 모든 항목에 "이야기 씨앗(플레이어가 엮일 수 있는 갈등)"을 넣을 것.
