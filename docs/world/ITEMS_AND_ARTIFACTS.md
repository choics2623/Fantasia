# 아이템과 유물 — 『무혈자의 찬가』 물건의 세계

> **정본 관계**: 이 문서는 [WORLD_BIBLE.md](WORLD_BIBLE.md)를 따르며, 데이터 형식은
> [02_ITEMS_AND_CHOICES.md](../systems/02_ITEMS_AND_CHOICES.md), 판정 수치는
> [01_STATS_AND_CHECKS.md](../systems/01_STATS_AND_CHECKS.md), 회귀와 가보의 메아리는
> [03_ROGUELITE_AND_LEGACY.md](../systems/03_ROGUELITE_AND_LEGACY.md)를 그대로 쓴다.
> **회귀 원칙 (정본 개정)**: 물건은 회차를 건너지 못한다. 주인공이 죽어 회귀점(AS 312 낙엽월 1일 저녁, 회색여울 배급 줄)으로 돌아가면 **모든 물건은 그 저녁의 자리와 주인에게** 돌아간다 — 훔친 칼, 모은 돈, 몸에 꿰맨 용심까지.
> 회차를 건너는 것은 물건이 아니라 **물건에 대한 앎**이다: 어디에 있고, 누가 지키고, 어떻게 얻는가(§6.0 **물건의 기억**). 시대를 건너는 물건은 진짜 죽음 때의 **가보의 메아리** 하나뿐이다(§6).
> 02 문서 예시의 `성광교`·`발도르`는 구판 이름이다. 이 문서는 정본 이름(`순종의빛`, `용제국`)을 쓴다.

> **이 문서의 한 줄**: 인간에게 물건은 **도구이기 전에 죄목**이다.
> 낫은 수확월엔 일감이고 수확이 끝나면 반역의 증거다. 숯 한 토막은 불쏘시개이거나, 글자를 쓴 사형수의 손이다.

## 0. 데이터 규약

### 0.1 YAML 형식 (02 문서 §1 그대로 + 이 문서의 확장 필드)

```yaml
id: sickle_iron
name: 쇠낫
tags: [무기, 날붙이, 한손, 베기, 농기구, 즉석무기]
slot: 무기_주
weight: 0.6
bulk: 1
quality: 보통          # 조악 / 보통 / 좋음 / 명품 / 걸작 → 장비보정 -5/0/+3/+6/+10
condition: 70
value: { 발톱: 2 }       # 비늘 / 발톱 / 못
visibility: 보임
provenance:
  - { owner: npc_bran, how: 제작, year: 305 }
  - { owner: raven_keep, how: 지급, year: 312 }
legal: { 용제국: 작업중, 세렌: 합법, 카즈둠: 합법, 그롬마르: 합법, 루멘: 금지 }
# --- 이 문서의 확장 필드 ---
human_legal: 작        # 합 / 작 / 허 / 불 / 사  (§1.5)
conceal: null          # 소매 / 부츠 / 솔기 / 이중바닥 / null
mods: { 단검: -2, 베기_대상: +10 }
unique: false          # true면 고유 물건 — 가보의 메아리 후보 (§6). 회귀하면 물건은 제자리로, 물건의 기억(지식 카드)만 영혼에
```

### 0.2 표 읽는 법
- **장비보정**은 01 문서 §2.1 공식의 `장비보정` 항에 들어가는 값이다. 품질 보정(-5~+10)은 별도로 더한다.
- **무게kg / 부피**: 부피는 배낭 칸(기본 배낭 12칸). 0은 "주머니에 들어감".
- **가격**은 용제국 평년 기본가(품질 보통, 내구 100). `—`는 정상 거래 불가(암시장·물물교환만).
- **인간 소지 합법성**은 용제국 기준 코드 + 괄호 안에 예외 지역(§1.5 약어).

## 1. 아이템 설계 규칙 요약

### 1.1 품질 등급

| 품질 | 장비보정 | 가격 배수 | 내구 감소 배율 | 만들 수 있는 자 (제작 스킬) | 인간 사회에서의 의미 |
|------|----------|-----------|----------------|-----------------------------|----------------------|
| 조악 | −5 | ×0.4 | ×1.5 | 누구나 (0~9) | 노예의 물건. 누구도 훔쳐 가지 않는다 |
| 보통 | 0 | ×1 | ×1.0 | 초보 이상 (10~24) | 평민 용인·크릭 감독관의 물건 |
| 좋음 | +3 | ×1.8 | ×0.8 | 숙련 (25~44) | 인간이 지니면 "어디서 났느냐"가 첫 질문 |
| 명품 | +6 | ×4 | ×0.6 | 전문가 (45~64) | 출처가 기록되는 물건. 소유 이력 추적 확률 ×2 |
| 걸작 | +10 | ×12 | ×0.4 | 명인 이상 (65+) + 좋은 재료 | 이름이 붙는다. 주인이 바뀌면 소문이 난다 |

- 인간 장인 브란(회색여울 대장간 노예)의 최고 작품은 '좋음'이다. 인간이 '명품' 이상을 만들면 그 물건은 **장인 본인의 위험**이 된다(용인 귀족이 "노예가 이런 것을?" 하고 의심 → 장인 몰수 또는 승격 이벤트).

### 1.2 내구도 (condition 0~100)

| 원인 | 감소량 | 비고 |
|------|--------|------|
| 전투 1합 (무기) | −1 (조악 −2) | 대실패 시 추가 −10 |
| 피격 1회 (갑옷·방패) | −2 ~ −5 | 둔기 피격 ×1.5 |
| 비·바닷물에 노출된 철 (하루) | −1 | 기름칠하면 무시 |
| 즉석무기 (깨진 병·뼈 칼) | 전투 후 −30 | 깨진 병은 첫 합 후 0 |
| 도구 사용 (자물쇠따개·지렛대) | 대실패 시 −20 또는 부러짐 | |
| 음식 | 하루 −10 (말린 것 −2, 절인 것 −1) | 0 = 썩음, 먹으면 체질 판정(D 30) |
| 문서 | 젖음 −40, 불 0 | 30 이하면 글자가 번져 검문에서 의심 +15 |

- **20 이하**: 품질 한 단계 하락 ("칼날이 이가 빠져 있다"). **0**: 파손 → `잔해` 태그만 남음(쇠붙이는 재료로 쓸 수 있음).
- **수리**: 숫돌·바늘실로 현장 수리 최대 70까지(제작 D 15). 대장간·작업대에서는 100까지(제작 D 30, 명품 이상 D 45).
- 인간이 대장간을 쓰려면 브란 같은 노예 장인과의 관계(신뢰 40+)가 필요하다. 작업 기록이 남지 않게 하는 것이 진짜 비용이다.

### 1.3 가격 공식

```
최종가 = 기본가 × 품질배수 × 내구계수 × 지역계수 × 계절계수 × 법률할증 × 흥정보정

내구계수   = 0.3 + 0.7 × (내구도 / 100)
지역계수   = 산지 0.7 / 일반 1.0 / 먼 지역 1.5 / 봉쇄·전쟁 지역 2.0
계절계수   = 음식: 수확월 0.7 / 굶주림월 3.0 / 흉년 3~5
법률할증   = 구매자가 인간이고 물건이 '불' → ×2 (암시장), '사' → ×4, 촉매·금서 ×6
흥정보정   = 1 − (내 흥정 − 상대 흥정) / 200        (0.7 ~ 1.3로 제한)

매각가     = 최종가 × 0.4                     (일반 상인 매입)
           × 0.6 (인간 판매자 할인 — 상인은 "훔친 것"이라 가정한다)
           × 0.3~0.5 (장물로 알려진 경우, 장물아비에게만)
```

- **인간과 돈**: 인간은 법적으로 화폐를 가질 수 없다(세렌 계약민 제외). 인간이 지닌 동전은 기본 `장물` 추정.
  수색에서 1발톱 이상이 나오면 절도 심문, 1비늘 이상이면 "주인을 죽였느냐"로 시작한다.
- 인간끼리의 거래는 물물교환이 기본이며, **잿빛 표**(§2.8 `grey_ticket`)는 이름 없는 자들 안에서만 신용으로 통한다.
- 화폐 환산: 1비늘 = 20발톱 = 240못. 세렌 두카트 = 1.1비늘. 두르강 각인 철괴 = 3발톱(카즈둠 안에서 3.5).

### 1.4 소유 이력과 장물
- 모든 `좋음` 이상 물건과 모든 `문장:*`·`고유` 물건은 provenance를 기록한다.
- 원래 마을에서 장물을 팔면 상인의 알아봄 확률 = 10% (보통) / 25% (좋음) / 50% (명품) / 90% (걸작·문장).
- 죽은 자의 물건은 그 친족·원수·채권자를 끌어온다. 이 문서의 전설 유물은 모두 provenance를 3~6건 갖는다(§5).
- **회귀와 provenance**: 회귀하면 세계 안의 provenance는 회귀점의 상태로 돌아간다 — 주인공이 남긴 줄은 지워진다. 주인공의 기억에만 남는 이력은 §6.0의 「물건의 기억」 카드에 적는다.

### 1.5 인간 소지 합법성 코드

| 코드 | 의미 | 발각 시 결과 (용제국 기준) |
|------|------|-----------------------------|
| **합** | 합법 | 없음 |
| **작** | 작업 중·주인 지급일 때만 합법 (주인 표식·감독관 확인 필요) | 작업 밖에서 들고 있으면 압수 + 태형, 감독관 의심 +10 |
| **허** | 허가 문서가 있을 때만 합법 (통행증·순례 허가·조합 허가) | 문서 없으면 '불'과 같음 |
| **불** | **불법:인간** | 압수, 태형 또는 벌금(주인에게), 소문 "그 노예가 ○○을 숨겼다", 재범 시 매각 |
| **사** | **사형:인간** — 무기·글·진명 | 즉결 처형 또는 화형. 목격자가 고대 종족이면 판정 없이 처형 장면으로 |

녹 = 녹테른 / 그 = 그롬마르 / 흐 = 흐로스가르드 / 모 = 모르바 / 탑 = 아르카스 탑섬 / 초 = 하르칸 초원 / 첨 = 바람첨탑 / 가 = 가시안개 숲 / 황 = 재의 황무지

### 1.7 숨기기 규칙

| 은닉 위치 | 허용 태그 | 수용량 | 수색자 보정 | 비고 |
|-----------|-----------|--------|-------------|------|
| 숨김:소매 (슬롯) | `숨길수있음:소매` | 1개 | 0 | 02 문서 슬롯 |
| 숨김:부츠 (슬롯) | `숨길수있음:부츠` | 1개 | +5 (신발을 벗기면 끝) | 맨발 노예는 이 칸이 없다 |
| 솔기 (의복 확장) | `숨길수있음:솔기` — 납작한 것 (문서·잿빛 표·동전 3개 이하) | 의복 1벌당 1 | −5 | 꿰매는 데 제작(재봉) D 15, 1시간 |
| 이중바닥 (용기 확장) | `숨길수있음:이중바닥` | 부피 2 | −15 | `double_bottom_pack` 등 |
| 성표 고리 안 (`은닉칸:성표` 물건) | `숨길수있음:성표` | 1 (가는 것) | −10 (신앙심 있는 경비는 성표를 만지지 않는다) | 이름 없는 자들의 고전 수법 |

```
숨기는 쪽 S = (은신 + 손재주)/2 + 민첩보정 + 은닉위치 보정 + 크기보정(부피0 +10, 부피1 0)
수색하는 쪽 D = 수색자 통찰 + 감각보정 + 수색 강도 (툭툭 털기 0 / 몸수색 +10 / 옷을 벗기는 수색 +25)
                + 수색자의 사전 의심 (밀고 받음 +15, 목줄단 지목 +20)
```
- `은닉칸:*` 태그는 그 물건이 해당 은닉 위치를 **제공**한다는 뜻이다(노역 장화 → 부츠 칸, 성표 → 성표 고리 안).
- 개(추적견)와 바르그는 냄새로 찾는다: 음식·피·기름·약초 계열은 수색 D +15. 늪진흙 반죽(§2.7)으로 상쇄.

### 2.10 마법 촉매·룬석 (27)

> 01 §3.5: 시전 S에 `촉매 품질`이 더해진다 (조악 −5 ~ 걸작 +10, 아래 '장비보정'은 품질과 별개 추가값).
> **정본 (개정)**: 8근원 전부를 배우고 진명을 말해도 살아남는 것은 **잔향 — 주인공의 영혼 하나뿐**이다(빈 그릇). 타 종족은 자기 혈명 근원만.
> **보통 인간은 진명을 안전하게 말할 수 없다** — 한 단어가 그 사람의 생명을 태운다. 늪 마녀 회합이 이어 온 것은 진짜 마법이 아니라
> **'빌린 피의 주술'(빌린 혈명)** 이다: 훔친 고대 종족의 피·비늘·깃·이를 촉매로 삼아 **그 종족의 혈명을 잠시 빌려** 작은 주술을 건다.
> 그 대가로 시전자는 **수명을 잃는다**(아래 §2.10.1). **촉매 소지 = 인간에게 화형.**

## 4. 이식 재료 — 빈 그릇에 담는 다른 피

> **정본 (개정)**: 보통 인간은 진짜 무혈자다. **다른 종족의 피·심장·눈을 이식받은 보통 인간은 약 99%가 죽는다.**
> 살아남는 그릇은 단 하나 — 에오르의 마지막 말이 깃든 사람, **잔향자(주인공)** 다. 이식은 주인공만의 길이며, 그래서 이식의 성공 자체가 **주인공을 드러내는 징후**가 된다.
> 시대의 시작에 재능 포인트로 고르는 '신체 특질'은 **회귀점 이전에 이 몸에 누군가 이 시술을 했고, 그 몸이 살아남은 결과**다(실험실에서 수백 명 중 유일한 생존자, 늪 노파의 절박한 도박, 혈목장의 의식). 회귀점의 몸이 이미 지닌 것이므로 **시대 내내 남는다**(06 §7).
> 회차 중에도 아래 재료를 구해 시술받을 수 있다. 그러나 회차 중의 이식은 **몸에 붙인 것**이라 회귀하면 사라진다 — 재료도, 꿰맨 자국도, 거부 반응도. 매 회차 다시 재료를 구하고 다시 수술대에 올라야 한다(06 §4.4, 이식 친화 재능).
> 남는 것은 앎이다: 누가 재료를 갖고 있는지, 어느 시술자가 손이 떨리는지, 내 몸이 어느 재료를 어떻게 거부했는지. 단, 이식은 언제나 **누군가의 몸에서 떼어 낸 것**이다 — 그 대가는 재료의 주인 종족이 기억한다. 회차가 바뀌면 그 주인은 다시 살아 있다.
> **멜리산드 은비늘의 실험이 수천 명을 죽이는 이유**도 여기 있다: 그녀는 살아남는 단 하나의 그릇을 찾고 있다. 이식에 성공한 인간의 소문은 곧 그녀의 귀에 들어간다.

### 4.0 공통 시술 규칙

```
① 시술 판정 (시술자)
   S = 시술자 약학 (또는 마법:생명) + 지능보정 + 재료 품질보정 + 시설보정
       (시설: 늪 오두막 −10 / 은신처 0 / 잿빛 탑·멜리산드 실험실 +15)
   D = 재료별 시술 난이도 (아래 표)

② 수용 판정 (환자 — 플레이어)
   S = 체질보정 × 2 + 의지보정 + 지구력/2 + 시술 판정 결과 보너스(대성공 +15 / 성공 +5 / 부분 성공 −5)
   D = 재료별 거부 강도

결과 (수용 판정 기준, 01 §2.3 다섯 단계)
   대성공   특질 완전 발현, 부작용 1개 경감
   성공     특질 발현, 회복 기간 후 정상
   부분 성공 특질 발현, 부작용 하나 추가 강화 또는 흉터 (가릴 수 없음 — 이번 회차 내내)
   실패     재료 손실, 중상 1 + 통증 60, 30일 요양
   대실패   체질 D 50 사망 판정(죽으면 회귀). 살아남으면 재료 손실 + 능력치 −1 (이번 회차의 몸)

※ 회귀: 회차 중의 이식 특질·흉터·능력치 손실은 모두 회귀점의 몸으로 돌아간다.
   남는 것: 지식 카드 `시술_기록_{재료}` — 시술자·재료 출처·거부 양상. 같은 재료의 다음 시술에서 수용 판정 +5 (몸이 아니라 '견디는 법'을 기억한다).

※ 보통 인간 NPC (동료·제자·자녀 포함 — 주인공에게 배운 자도 잔향의 선물은 얻지 못한다)
   수용 판정 없음. d100 = 1일 때만 생존(1%), 생존해도 특질 효과 절반 + 부작용 2배.
   NPC에게 이식을 권하거나 강요하는 선택지는 자비 −10, 그 NPC와 친한 모든 이의 신뢰 −20.
```
- **징후**: 주인공의 이식 성공이 목격·소문으로 퍼지면 '잔향 징후 보고'로 기록된다 — 잿빛 탑과 멜리산드의 추적 클락 +1, 그리고 그 지역에서 **무고한 '징후자' 색출**이 시작될 수 있다.
- **회복 기간**: 재료별 10~60일. 이 기간 동안 모든 신체 판정 −15, 시술 흔적 발견 시 즉시 '이식자' 소문.
- **이식 한도**: 이식 특질은 **최대 2개**. 세 번째부터는 수용 판정 D +40, 성공해도 스트레스 최대치가 70으로 고정된다("그릇이 넘친다").
- **표식**: 모든 이식자는 시술 자리에 흔적이 남는다. 옷을 벗기는 수색(§1.7 +25)에서 통찰 D 30이면 발견된다.
- **TP 비용·효과·대가는 06_CHARACTER_CREATION §4가 정본이다.** 아래 각 항목의 '효과'는 06과 같고, '부작용'은 06의 대가를 먼저 적은 뒤 그 재료의 혈명 굴레에서 오는 서사적 부작용을 덧붙인 것이다. TP로 고른 특질이든 회차 중 이식이든 효과는 같다. 다른 점은 회귀했을 때 남느냐뿐이다.

## 5. 전설의 유물 (33)

### 5.0 유물 공통 규칙
- 모든 유물은 태그 `유물`, `고유`, `전설`을 갖고, provenance가 3~6건 기록되어 있다. 같은 유물은 한 세계에 하나뿐이다.
- **감정**: 유물인지 알아보려면 학식 D 45 (관련 지식이 있으면 D 25). 실패하면 "오래된 물건"으로만 보인다 — 흥정 실패의 가장 흔한 이유.
- **잔향 공명**: 앞선 잔향자(아스테리온, 붉은 손 다라, 그리고 이름 없는 아이들)가 지녔던 유물은 주인공이 처음 손에 쥘 때 **그 사람의 기억 조각** 1개를 준다(지식 획득 + 스트레스 +10, 목소리(15)와 연결). 동시에 잔향 징후 판정(감각 D 30을 가진 목격자가 있으면 소문). 공명은 **시대에 한 번** — 회귀해서 다시 쥐어도 같은 조각은 다시 오지 않는다.
- **회귀와 유물**: 유물도 회귀하면 회귀점의 자리와 주인에게 돌아간다. 한 회차에 손에 넣은 유물은 그 회차의 것이다. 공명으로 얻은 지식, 흡수해 익힌 진명처럼 **영혼에 새긴 것**만 남는다. '회차당 1회' 효과는 회귀하면 다시 쓸 수 있다 — 물건을 다시 얻는다면.
- **회귀를 끊는 물건**: 유물 가운데 회귀를 끊을 수 있는 것은 **시간 유리 칼**(L33) 하나뿐이다. 나머지 셋(바르스카르의 불, 엘다르의 시간의 그물, 재의 황무지의 시간의 상처)은 물건이 아니다(§5.33 표).
- **인간 소지**: 모든 유물은 인간에게 최소 '불', 대부분 '사'. 유물을 가진 노예는 "어디서 훔쳤느냐"가 아니라 "누가 시켰느냐"로 심문받는다.
- 힘의 수치는 품질 보정에 **더해지는** 장비보정이다. 유물은 내구도가 없거나(파괴 불가) 별도 조건으로만 파괴된다.

| 소유 이력 | ① 황무지의 학자들이 모은 시간 유리 → 잿빛 탑 (AS 201 설립 시 인계, AS 214 첫 칼) → ② '첫 침묵'은 AS 214~300 사이 이름 없는 아이들에게 여러 번 쓰였다 — 날에 머리카락 같은 금이 일곱 줄 → ③ '정오'는 탑의 **시간 측정관**에게 지급, 징후 보고가 몰리는 곳으로 옮겨진다 (AS 268~) → ④ '마지막 금'은 한 번도 쓰이지 않았다. 이레네가 몸에 지닌다 (AS 305~) |
| 현재 위치 | **아르카스 탑섬** — '첫 침묵'은 봉인 금고 제1실(신살의 창 조각 L03과 같은 층) / '정오'는 측정관과 함께 이동(회차가 쌓이면 회색여울 방면 — 03 기시감 45~69) / '마지막 금'은 탑주 집무실, 이레네의 허리 |
| 찾는 방법·시나리오 | 피험자 탈출 시나리오(금고 제1실), 측정관 습격('정오'), 이레네와의 거래('마지막 금' — 그녀는 칼보다 렌즈 L22를 믿는다). 어느 쪽이든 손에 넣는 것은 **그 회차뿐**이다. 회차를 건너 남는 것은 「물건의 기억」: 세 자루가 각각 어디에, 몇 번째 날에, 누구의 손에 있는가 — 그리고 시간의 표류로 그 날짜가 조금씩 어긋난다는 것 |
| 소문 | **진실**: 탑은 세 자루밖에 만들지 못했다. **진실**: 칼에 죽은 아이들은 "또 꿈이야?" 하고 묻지 못했다. **거짓**: 칼로 찌르면 잔향이 칼 속에 갇힌다 — 잔향은 갇히지 않는다. 그 시대를 떠나 찢어진 시간의 다른 갈래로 간다. **확정되지 않음**: 네 번째 칼이 될 유리가 이미 깎이고 있다 |
| 이야기 씨앗 | '마지막 금'은 아직 아무도 베지 않았다. 이레네는 그것을 처음 쓸 상대가 누구일지 안다고 일기에 적었다 — 그리고 회차가 쌓일수록 그 일기의 날짜가 점점 앞당겨진다 |

### 5.33 회귀를 끊는 넷 — 물건과 장소의 연결

회귀를 끊는 수단은 넷뿐이고(바이블 §1.3.1, 03 §4.5), 그중 **물건은 시간 유리 칼 하나**다. 나머지는 이 문서의 유물과 아래처럼 닿아 있다.

| 단절의 수단 | 물건인가 | 닿아 있는 유물 | 예고 |
|-------------|----------|----------------|------|
| **용황 바르스카르의 불** | 아니다 — 시간의 상처를 입은 용의 숨결 | L04 용황의 첫 비늘(같은 상처가 번져 있다), L27 멈춘 모래시계(그 불이 의식을 덮친 순간) | 숨결 전, 공기가 늙는다 |
| **엘다르의 시간의 그물** | 아니다 — 영원 여왕과 존속파가 영혼 정원에서 짜는 의식 | L12 첫 아침의 수정(그물을 짜는 중심 온실에 놓여 있다) | 정원의 노래가 박자를 잃는다 |
| **시간의 상처** | 아니다 — 재의 황무지 중심, 찢어진 시간 그 자체 | L32 증언하는 비늘(상처 가장자리 '유리 광장'), L33의 원료 유리 | 화면 가장자리가 바랜다 |
| **잿빛 탑의 시간 유리 칼** | **그렇다** — 세 자루 (L33) | L22 볼드의 잔향 측정경(칼을 들 상대를 고르는 눈) | 목소리들의 침묵 |

## 6. 물건과 회귀 — 물건의 기억, 그리고 가보의 메아리

> **정본 (개정, 03·06 문서)**: 물건은 **회차를 건너지 못한다.** 회귀하면 모든 물건은 회귀점(AS 312 낙엽월 1일 저녁)의 자리와 주인에게 돌아간다.
> 회차를 건너는 것은 물건에 대한 **앎**뿐이다 — 이것을 **「물건의 기억」** 이라 부른다(§6.0).
> 물건이 건너는 경우는 단 하나, **시대**가 진짜 죽음으로 끝날 때다: 그때 잔향자가 오래 지닌 고유 물건 하나가 **다음 시대의 세계에 '전설의 물건'으로** 나타난다. 이것이 **가보의 메아리**다(§6.1~). 시대를 건너는 유일한 물건이고, 공짜가 아니다 — 새 시대의 세계 안에서 찾아야 한다.
> 위 §5의 ● 표시 유물(L01·L02·L10·L11·L27·L32)이 바로 그렇게 생겨난 것이라고 이름 없는 자들의 일부는 믿는다: **앞선 잔향자들의 가보의 메아리.** 아스테리온의 깃펜은 그보다 앞선 시대 누군가의 깃펜이었을지도 모른다.

### 6.0 물건의 기억 — 회차를 건너는 앎

| 항목 | 내용 |
|------|------|
| 무엇인가 | 지식 카드의 한 종류 `물건의기억_{id}`. 주인공이 한 회차에 손에 넣었거나, 보았거나, 얻는 길을 알아낸 물건에 대해 영혼에 남는 기록 |
| 담기는 것 | ① **자리**: 회귀점 무렵 그 물건이 있는 곳과 주인 ② **길**: 얻는 법 — 누구의 신뢰, 어느 열쇠, 몇 번째 날 밤, 어느 경비 교대 ③ **함정**: 지난 회차에 무엇이 잘못됐는가 ④ **쓰임**: 그 물건이 무엇을 할 수 있었는가 (공명으로 얻은 지식 포함) |
| 남지 않는 것 | 물건 그 자체, 품질·내구도, 세계 안의 provenance(주인공이 남긴 줄), 붙인 이름과 소문 — 회귀하면 아무도 그 낫을 「굶주린 겨울의 낫」이라 부르지 않는다. 주인공만 그렇게 부른다 |
| 시간의 표류 | 큰 물건(유물, 금고, 보물고)은 매 회차 같은 자리에 있다. 작은 물건(장터의 칼, 떠돌이 상인의 약, 누가 주머니에 넣고 다니는 것)은 회차 시드에 따라 **조금씩 어긋난다** — 카드의 '자리'에 확신도(□ 확실 / ◇ 아마도)가 붙는다 |
| 흐려짐 | 다른 지식 카드와 같다(03 §4.4): 5회차 동안 다시 확인하지 않으면 세부가 흐려진다 |
| 게임 효과 | 그 물건을 다시 얻는 판정에 **앎 보정** +5~+15 (카드의 세부 수준), 처음 보는 척을 못 하면 '앎의 흔적' 징후 판정(03 §4.3 — "처음 가는 길을 앎") |

- **회귀의 아침 소지품**: 회귀점의 주인공이 가진 것은 언제나 같다 — 배급 그릇, 해진 옷, 그 몸이 지닌 것. 첫 회차에 숨긴 돈은 숨기기 전으로 돌아가 있다.
- **이식 재료도 물건이다**: 회차 중에 몸에 꿰맨 용심은 회귀하면 다시 멜리산드의 실험실 유리병 안에 있다(§4). 남는 것은 그 유리병이 몇 번째 선반에 있는지에 대한 기억이다.
- 그래서 회귀자의 소지품은 지도에 있다. 열 번째 회차의 주인공은 빈손으로 배급 줄에 서 있지만, 사흘 안에 무엇을 어디서 가져올지 안다.

### 6.1 가보의 메아리 — 후보 자격

| 조건 | 내용 |
|------|------|
| 고유화 | 일반 아이템은 `unique: false`. 한 회차 안에서 **내력 점수 20 이상**이 되면 이름이 붙으며 `고유` 태그 획득. 회귀하면 세계 안의 이름은 사라지지만, 물건의 기억 카드에 이름과 점수가 남는다 |
| 메아리 자격 (정본, 03·06) | **같은 시대에서 그 물건을 합계 1년 이상 지님** — 회차를 넘어 다시 손에 넣은 기간도 합산한다. 진짜 죽음의 순간 지니고 있던 고유 물건 중 1개 |
| 예외 | 진짜 죽음의 순간 지니고 있던 §5 유물은 보유 기간과 무관하게 후보가 된다. 새 시대의 세계에서 그 유물은 원래 이력 + 그 잔향자의 이력이 합쳐진 상태로 나타난다 |
| 불가 | 소모품(음식·약·화살), 화폐, `일회용` 태그, 시간 유리 칼(L33 — 진짜 죽음을 준 칼은 그 시대에 남는다). 단 소모품을 담은 **용기**(약병, 씨앗 주머니)는 가능 |

### 6.2 내력이 자라는 방식 (내력 점수)

물건의 provenance에 아래 사건이 기록될 때마다 내력 점수가 쌓인다. 세계 안의 기록은 회귀하면 지워지지만, **점수는 물건의 기억 카드에 누적된다** — 같은 낫을 다섯 회차에 걸쳐 다시 쥐었다면, 다섯 회차의 이야기가 한 낫에 쌓인다.

| 사건 | 점수 | provenance 기록 예 |
|------|------|--------------------|
| 이름 있는 NPC의 목숨을 구하는 데 쓰임 | +5 | `{ event: 구함, npc: 사라, year: 312, loop: 3 }` |
| 고대 종족 개체를 쓰러뜨리거나 굴복시킴 | +10 | `{ event: 쓰러뜨림, target: 바르그 사냥꾼, loop: 4 }` |
| 월드 클락 분기를 바꾼 장면에서 사용·소지 | +15 | `{ event: 분기, clock: 북방대탈주 }` |
| 빼앗겼다가 되찾음 | +8 | `{ event: 되찾음 }` |
| 회귀한 뒤 다시 찾아 손에 넣음 | +3 (회차마다, 최대 +15) | `{ event: 다시찾음, loop: 6 }` — 같은 물건을 거듭 찾는 것도 이야기다 |
| 다른 인간에게 물려주었다가 다시 돌아옴 (같은 회차 안) | +5 | |
| 제자에게 이것으로 무언가를 가르침 (읽고쓰기·검술 등) | +5 (최대 +20) | |
| 사람들이 이 물건에 별명을 붙임 (평판 시스템) | +10 | `{ event: 이름붙음, name: "굶주린 겨울의 낫" }` |
| 주인공의 죽음 순간에 지니고 있었음 | +10 (회귀하는 죽음 포함, 최대 +20) | |
| 사용 중 대실패로 부서졌다가 수리됨 | +3 | 흉터가 이야기가 된다 |
| 무고한 자의 죽음에 쓰임 | +10, 그리고 '저주' 표식 | 메아리가 되면 대가·저주 칸이 생긴다 |

| 단계 | 내력 점수 | 효과 (그 회차의 세계 안에서) |
|------|-----------|------|
| 무명 | 0~19 | 일반 물건 |
| **사연 있는 물건** | 20~49 | 이름이 붙음, 관련 NPC가 알아봄(장물 알아봄 확률 +30%) |
| **이야기** | 50~99 | 소문 시스템에 실림, '내력 보정' +2 (품질 보정에 더함) |
| **전설** | 100+ | 내력 보정 +4. 메아리가 되면 새 시대에서 이 단계로 나타난다 |

- 회귀하면 세계는 그 물건의 이야기를 잊는다. 다시 쥔 회차에는 **이번 회차에 쌓은 사건만** 소문과 알아봄에 쓰인다(단계 효과). 누적 점수는 메아리 자격과 새 시대의 모습을 정할 때만 쓴다.

### 6.3 이름 짓기 규칙
- 자동 생성: `[가장 점수가 큰 사건의 장소·계절]의 [물건 종류]` 또는 `[소유자 별명]의 [물건 종류]`.
  - 예: 「굶주린 겨울의 낫」, 「여울 건너기의 족쇄」, 「리사의 글자판」, 「아홉 아이의 성표 칼」
- 플레이어가 직접 이름을 지을 수 있다 — 단, 인간에게 성이 금지된 세계에서 **물건에 이름을 붙이는 것** 자체가 작은 반역이다(목격 시 소문 "그 노예는 낫에 이름을 붙였다").
- 회귀한 뒤에도 주인공은 그 이름으로 부른다. 처음 보는 낫을 이름으로 부르는 노예를 본 사람은 고개를 갸웃한다(앎의 흔적, 심각도 1).

### 6.4 새 시대에서 메아리가 나타나는 곳

진짜 죽음의 장면이 물건의 새 위치를 정한다. 새 시대는 **찢어진 시간의 다른 갈래**다 — 그 갈래에서 물건은 "이미 오래전부터 있어 온 것"으로 나타나고, 앞선 잔향자는 "옛날 한 노예"로만 전해진다.

| 진짜 죽음 때 물건의 최후 | 새 시대의 세계에서의 위치 | 찾는 방법 |
|--------------------------|---------------------------|-----------|
| 잔향자와 함께 묻힘 | 그 지역의 오래된 무덤 — 앞선 잔향자의 무덤, 도굴꾼이 노린다 | 앞선 잔향자의 꿈(목소리)으로 무덤 위치 단서 |
| 살해자가 가져감 (불·그물·칼의 주인) | 살해자 종족의 전리품관·보물고 — 바르스카르의 보고, 영혼 정원, 잿빛 탑 금고 | 해당 종족 거점 잠입 |
| 동료·제자에게 맡김 | 그 갈래의 어느 인간 가문이 몇 대째 지켜 온 숨겨진 가보 (성 없는 가문의 '말로 전하는 이름'). 그 가문은 잔향자의 핏줄이 아니다 — 같은 물건을 지켜 왔을 뿐이다 | 그 가문 후손 NPC와 신뢰 |
| 압수당함 | 잿빛 탑 금고 또는 루멘 침묵의 서고 | 피험자·서기·사제 루트 |
| 잃어버림 (황무지·늪·바다) | 재의 황무지 / 모르바 늪 / 남해 바닥 — 유물 사냥꾼 소문 | 유물 사냥꾼 동행 |
| 이름 없는 자들에게 맡김 | 잿빛 실의 성유물로 숨겨짐 | 이름 없는 자들 서열 상승 |

- 새 시대의 메아리는 **원래 장비보정 + 내력 보정(+4)** 을 갖고, 앞선 시대의 provenance는 **소문**(진실 2 + 거짓 1)으로 변환된다.
- **잔향 공명**: 새 잔향자가 메아리를 처음 쥐면 앞선 잔향자의 기억 조각 1개(목소리, 15 문서) + 스트레스 +10 + 징후 판정. 메아리는 주인공을 강하게 하지만, 동시에 **주인공을 드러낸다.**
- 메아리 물건을 다른 인물(보통 인간)이 쓰면 내력 보정만 적용되고 공명은 없다.
- 새 시대 안에서도 메아리는 다른 물건과 같다: **회귀하면 제자리로 돌아간다.** 한 번 찾은 뒤에는 물건의 기억이 길을 안다.

### 6.5 데이터 예시 — 물건의 기억과 가보의 메아리

```yaml
# 회차를 건너는 앎 — 지식 카드 (영혼)
id: 물건의기억_sickle_iron_grey_barn
item: sickle_iron
```

### 6.7 설계 원칙
- **더 강하게 시작하지 않는다** (03 문서): 회귀의 아침에도, 새 시대의 첫날에도 물건은 손에 없다. 물건의 기억은 **찾는 시간**을 줄여 줄 뿐이고, 메아리는 반드시 **새 시대의 세계 안에서 찾아야** 한다. 찾는 과정이 그 시대의 첫 목표가 될 수 있다.
- **회차 안의 물건은 그래서 더 소중하다**: 30년 걸려 모은 것이 한 번의 죽음으로 제자리에 돌아간다. 회차가 길수록 잃는 것도 크다.
- 메아리 하나당 시대 하나. 같은 물건이 여러 시대를 건너면 내력 점수는 누적되고, 소문은 점점 거짓이 많아진다(시대마다 진실 1개가 거짓으로 바뀜) — **전설은 그렇게 만들어진다.**
- 보통 인간 동료·제자는 회차 안에서 주인공의 물건을 물려받아 쓸 수 있다. 잔향의 선물은 얻지 못하지만, 물건과 함께 **이야기**를 물려받는다. 회귀하면 그 물려줌은 없던 일이 된다 — 다시 물려줄지는 다시 정해야 한다. 무혈자의 찬가는 그렇게, 한 회차 안에서 퍼진다.
