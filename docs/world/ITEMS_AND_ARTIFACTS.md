# 아이템과 유물 — 『무혈자의 찬가』 물건의 세계

> **정본 관계**: 이 문서는 [WORLD_BIBLE.md](WORLD_BIBLE.md)를 따르며, 데이터 형식은
> [02_ITEMS_AND_CHOICES.md](../systems/02_ITEMS_AND_CHOICES.md), 판정 수치는
> [01_STATS_AND_CHECKS.md](../systems/01_STATS_AND_CHECKS.md), 가보 계승은
> [03_ROGUELITE_AND_LEGACY.md](../systems/03_ROGUELITE_AND_LEGACY.md)를 그대로 쓴다.
> 02 문서 예시의 `성광교`·`발도르`는 구판 이름이다. 이 문서는 정본 이름(`순종의빛`, `용제국`)을 쓴다.

> **이 문서의 한 줄**: 인간에게 물건은 **도구이기 전에 죄목**이다.
> 낫은 수확월엔 일감이고 수확이 끝나면 반역의 증거다. 숯 한 토막은 불쏘시개이거나, 글자를 쓴 사형수의 손이다.

## 0. 데이터 규약

### 0.1 YAML 형식 (02 문서 §1 그대로 + 이 문서의 확장 필드)

```yaml
id: sickle_iron
name: 쇠낫
tags: [무기, 날붙이, 한손, 베기, 농기구, 즉석무기]
slot: 무기_주
weight: 0.6
bulk: 1
quality: 보통          # 조악 / 보통 / 좋음 / 명품 / 걸작 → 장비보정 -5/0/+3/+6/+10
condition: 70
value: { 발톱: 2 }       # 비늘 / 발톱 / 못
visibility: 보임
provenance:
  - { owner: npc_brann_smith, how: 제작, year: 305 }
  - { owner: reyburn_manor, how: 지급, year: 312 }
legal: { 용제국: 작업중, 세렌: 합법, 카즈둠: 합법, 그롬마르: 합법, 루멘: 금지 }
# --- 이 문서의 확장 필드 ---
human_legal: 작        # 합 / 작 / 허 / 불 / 사  (§1.5)
conceal: null          # 소매 / 부츠 / 솔기 / 이중바닥 / null
mods: { 단검: -2, 베기_대상: +10 }
unique: false          # true면 고유 물건 — 가보의 메아리 후보 (§9)
```

### 0.2 표 읽는 법
- **장비보정**은 01 문서 §2.1 공식의 `장비보정` 항에 들어가는 값이다. 품질 보정(-5~+10)은 별도로 더한다.
- **무게kg / 부피**: 부피는 배낭 칸(기본 배낭 12칸). 0은 "주머니에 들어감".
- **가격**은 용제국 평년 기본가(품질 보통, 내구 100). `—`는 정상 거래 불가(암시장·물물교환만).
- **인간 소지 합법성**은 용제국 기준 코드 + 괄호 안에 예외 지역(§1.5 약어).

## 1. 아이템 설계 규칙 요약

### 1.1 품질 등급

| 품질 | 장비보정 | 가격 배수 | 내구 감소 배율 | 만들 수 있는 자 (제작 스킬) | 인간 사회에서의 의미 |
|------|----------|-----------|----------------|-----------------------------|----------------------|
| 조악 | −5 | ×0.4 | ×1.5 | 누구나 (0~9) | 노예의 물건. 누구도 훔쳐 가지 않는다 |
| 보통 | 0 | ×1 | ×1.0 | 초보 이상 (10~24) | 평민 용인·크릭 감독관의 물건 |
| 좋음 | +3 | ×1.8 | ×0.8 | 숙련 (25~44) | 인간이 지니면 "어디서 났느냐"가 첫 질문 |
| 명품 | +6 | ×4 | ×0.6 | 전문가 (45~64) | 출처가 기록되는 물건. 소유 이력 추적 확률 ×2 |
| 걸작 | +10 | ×12 | ×0.4 | 명인 이상 (65+) + 좋은 재료 | 이름이 붙는다. 주인이 바뀌면 소문이 난다 |

- 인간 장인 브란(회색여울 대장간 노예)의 최고 작품은 '좋음'이다. 인간이 '명품' 이상을 만들면 그 물건은 **장인 본인의 위험**이 된다(용인 귀족이 "노예가 이런 것을?" 하고 의심 → 장인 몰수 또는 승격 이벤트).

### 1.2 내구도 (condition 0~100)

| 원인 | 감소량 | 비고 |
|------|--------|------|
| 전투 1합 (무기) | −1 (조악 −2) | 대실패 시 추가 −10 |
| 피격 1회 (갑옷·방패) | −2 ~ −5 | 둔기 피격 ×1.5 |
| 비·바닷물에 노출된 철 (하루) | −1 | 기름칠하면 무시 |
| 즉석무기 (깨진 병·뼈 칼) | 전투 후 −30 | 깨진 병은 첫 합 후 0 |
| 도구 사용 (자물쇠따개·지렛대) | 대실패 시 −20 또는 부러짐 | |
| 음식 | 하루 −10 (말린 것 −2, 절인 것 −1) | 0 = 썩음, 먹으면 체질 판정(D 30) |
| 문서 | 젖음 −40, 불 0 | 30 이하면 글자가 번져 검문에서 의심 +15 |

- **20 이하**: 품질 한 단계 하락 ("칼날이 이가 빠져 있다"). **0**: 파손 → `잔해` 태그만 남음(쇠붙이는 재료로 쓸 수 있음).
- **수리**: 숫돌·바늘실로 현장 수리 최대 70까지(제작 D 15). 대장간·작업대에서는 100까지(제작 D 30, 명품 이상 D 45).
- 인간이 대장간을 쓰려면 브란 같은 노예 장인과의 관계(신뢰 40+)가 필요하다. 작업 기록이 남지 않게 하는 것이 진짜 비용이다.

### 1.3 가격 공식

```
최종가 = 기본가 × 품질배수 × 내구계수 × 지역계수 × 계절계수 × 법률할증 × 흥정보정

내구계수   = 0.3 + 0.7 × (내구도 / 100)
지역계수   = 산지 0.7 / 일반 1.0 / 먼 지역 1.5 / 봉쇄·전쟁 지역 2.0
계절계수   = 음식: 수확월 0.7 / 굶주림월 3.0 / 흉년 3~5
법률할증   = 구매자가 인간이고 물건이 '불' → ×2 (암시장), '사' → ×4, 촉매·금서 ×6
흥정보정   = 1 − (내 흥정 − 상대 흥정) / 200        (0.7 ~ 1.3로 제한)

매각가     = 최종가 × 0.4                     (일반 상인 매입)
           × 0.6 (인간 판매자 할인 — 상인은 "훔친 것"이라 가정한다)
           × 0.3~0.5 (장물로 알려진 경우, 장물아비에게만)
```

- **인간과 돈**: 인간은 법적으로 화폐를 가질 수 없다(세렌 계약민 제외). 인간이 지닌 동전은 기본 `장물` 추정.
  수색에서 1발톱 이상이 나오면 절도 심문, 1비늘 이상이면 "주인을 죽였느냐"로 시작한다.
- 인간끼리의 거래는 물물교환이 기본이며, **잿빛 표**(§2.8 `grey_ticket`)는 이름 없는 자들 안에서만 신용으로 통한다.
- 화폐 환산: 1비늘 = 20발톱 = 240못. 세렌 두카트 = 1.1비늘. 두르강 각인 철괴 = 3발톱(카즈둠 안에서 3.5).

### 1.4 소유 이력과 장물
- 모든 `좋음` 이상 물건과 모든 `문장:*`·`고유` 물건은 provenance를 기록한다.
- 원래 마을에서 장물을 팔면 상인의 알아봄 확률 = 10% (보통) / 25% (좋음) / 50% (명품) / 90% (걸작·문장).
- 죽은 자의 물건은 그 친족·원수·채권자를 끌어온다. 이 문서의 전설 유물은 모두 provenance를 3~6건 갖는다(§8).

### 1.5 인간 소지 합법성 코드

| 코드 | 의미 | 발각 시 결과 (용제국 기준) |
|------|------|-----------------------------|
| **합** | 합법 | 없음 |
| **작** | 작업 중·주인 지급일 때만 합법 (주인 표식·감독관 확인 필요) | 작업 밖에서 들고 있으면 압수 + 태형, 감독관 의심 +10 |
| **허** | 허가 문서가 있을 때만 합법 (통행증·순례 허가·조합 허가) | 문서 없으면 '불'과 같음 |
| **불** | **불법:인간** | 압수, 태형 또는 벌금(주인에게), 소문 "그 노예가 ○○을 숨겼다", 재범 시 매각 |
| **사** | **사형:인간** — 무기·글·진명 | 즉결 처형 또는 화형. 목격자가 고대 종족이면 판정 없이 처형 장면으로 |

### 1.7 숨기기 규칙

| 은닉 위치 | 허용 태그 | 수용량 | 수색자 보정 | 비고 |
|-----------|-----------|--------|-------------|------|
| 숨김:소매 (슬롯) | `숨길수있음:소매` | 1개 | 0 | 02 문서 슬롯 |
| 숨김:부츠 (슬롯) | `숨길수있음:부츠` | 1개 | +5 (신발을 벗기면 끝) | 맨발 노예는 이 칸이 없다 |
| 솔기 (의복 확장) | `숨길수있음:솔기` — 납작한 것 (문서·잿빛 표·동전 3개 이하) | 의복 1벌당 1 | −5 | 꿰매는 데 제작(재봉) D 15, 1시간 |

| 성표 고리 안 | `숨길수있음:성표` | 1 (가는 것) | −10 (신앙심 있는 경비는 성표를 만지지 않는다) | 이름 없는 자들의 고전 수법 |

```
숨기는 쪽 S = (은신 + 손재주)/2 + 민첩보정 + 은닉위치 보정 + 크기보정(부피0 +10, 부피1 0)

                + 수색자의 사전 의심 (밀고 받음 +15, 목줄단 지목 +20)
```
- 개(추적견)와 바르그는 냄새로 찾는다: 음식·피·기름·약초 계열은 수색 D +15. 늪진흙 반죽(§2.7)으로 상쇄.

## 4. 이식 재료 — 빈 그릇에 담는 다른 피

> 정본(§1.3 '빈 그릇'): 인간은 정해진 혈명이 없기에 **다른 종족의 피·심장·눈을 이식받아 그 힘을 품을 수 있다.**
> 재능 포인트로 시작 시 고르는 '신체 특질'은 **이미 누군가가 이 시술을 해 준 결과**다(부모의 선택, 실험실, 늪의 노파).
> 생애 중에도 아래 재료를 구해 시술받을 수 있다. 단, 이식은 언제나 **누군가의 몸에서 떼어 낸 것**이다 — 그 대가는 재료의 주인 종족이 기억한다.

### 4.0 공통 시술 규칙

```
① 시술 판정 (시술자)
   S = 시술자 약학 (또는 마법:생명) + 지능보정 + 재료 품질보정 + 시설보정
       (시설: 늪 오두막 −10 / 은신처 0 / 잿빛 탑·멜리산드 실험실 +15)
   D = 재료별 시술 난이도 (아래 표)

② 수용 판정 (환자 — 플레이어)
   S = 체질보정 × 2 + 의지보정 + 지구력/2 + 시술 판정 결과 보너스(대성공 +15 / 성공 +5 / 부분 성공 −5)
   D = 재료별 거부 강도

결과 (수용 판정 기준, 01 §2.3 다섯 단계)
   대성공   특질 완전 발현, 부작용 1개 경감
   성공     특질 발현, 회복 기간 후 정상
   부분 성공 특질 발현, 부작용 하나 추가 강화 또는 영구 흉터 (가릴 수 없음)
   실패     재료 손실, 중상 1 + 통증 60, 30일 요양
   대실패   체질 D 50 사망 판정. 살아남으면 재료 손실 + 능력치 −1 영구
```
- **회복 기간**: 재료별 10~60일. 이 기간 동안 모든 신체 판정 −15, 시술 흔적 발견 시 즉시 '이식자' 소문.
- **이식 한도**: 이식 특질은 **최대 2개**. 세 번째부터는 수용 판정 D +40, 성공해도 스트레스 최대치가 70으로 고정된다("그릇이 넘친다").
- **표식**: 모든 이식자는 시술 자리에 흔적이 남는다. 옷을 벗기는 수색(§1.7 +25)에서 통찰 D 30이면 발견된다.
- 재능 포인트 비용은 권장값이며, 재능 시스템 문서가 확정되면 그쪽을 따른다.
