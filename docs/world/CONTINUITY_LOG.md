# 연속성 로그 (Continuity Log)

> 작성: 연속성 편집 1차 패스 (AS 312 낙엽월 1일 기준 문서 전체).
> 2차 패스: 1차에서 열어 둔 A~G를 디자이너 결정대로 해결하고 17_NEMESIS 바르그 나이를 고쳤다(§2). 14_FIRST_HOURS·15_INNER_VOICES는 손대지 않았다.
> 원칙: **WORLD_BIBLE.md가 정본**이며 모든 충돌에서 이긴다. 정본이 정하지 않은 충돌은 ① 기계 파싱되는 데이터(REGIONS §17 노드 id·좌표, CHARACTERS npc id·관계 튜플)를 가진 쪽, ② 더 많은 문서가 따르는 쪽, ③ 다른 사실과 덜 부딪치는 쪽 순으로 골랐다.
> 바이블은 비정본 문서끼리의 충돌을 해소한 결과를 **기록**할 때와 내부 모순을 고칠 때만 손댔다 (아래 표에 [바이블 기록]으로 표시).
> 수정은 문서 구조를 바꾸지 않는 최소 편집으로 했다. CHARACTERS의 관계 튜플 형식과 REGIONS §17 표는 건드리지 않았다(튜플 수 477 → 477 유지).
