# 14. 첫 시간들: 첫 죽음이 곧 튜토리얼이다

> 몰입 아이디어 #1. **기본 출신 「회색여울 농노의 자식」(SCENARIOS O-01)의 첫 회차를 하나의 설계된 미끼로 만든다.**
> 첫 회차는 실제 플레이 60~120분이다. 거의 모든 플레이어가 이 안에서 죽는다. 그 죽음은 컷신이 아니다. 시스템이 깔아 둔 자리에서
> 플레이어의 선택으로 일어난다. 그리고 죽은 바로 그 숨에서, 플레이어는 **빵 냄새**를 맡는다. 게임의 첫 화면이 한 글자도 다르지 않게 다시 펼쳐진다.
> 낙엽월 1일 저녁, 절름발이 수탉 앞 배급 줄. 자기 몸으로. 키트가 허리띠를 쥐고 있고, 사라가 소매를 당긴다. 그녀가 무슨 말을 할지, 이제 안다.
> 이 게임이 무엇인지를 이 순간 처음 알게 된다. 설명문은 한 줄도 없다.
>
> 정본: WORLD_BIBLE §0.2~0.3·**§1.3.1(잔향과 회귀)**·§2·§8·§11, SCENARIOS O-01·§0.4, CHARACTERS R02, REGIONS §2. 수치·용어는 01·02·03·05·06·07·08을 따른다.
> 인접 문서: 15 내면의 목소리 · 16 메아리와 맹세 · 17 숙적 · 18 이야기 연출가 · 19 연출 · 20 애착과 상실. 이 문서는 **"언제·무엇이 처음 열리는가"** 와 **첫 죽음에서 두 번째 회차의 첫 시간까지**를 정하고, 장치들의 내부 규칙은 각 문서에 맡긴다.
>
> **용어**: **회차(回次)** = 회귀점에서 다음 죽음까지 한 번의 흐름. 주인공에 관해서는 '생애'를 쓰지 않는다. **회귀점** = AS 312 낙엽월 1일 저녁 6시(18:00), 회색여울 절름발이 수탉 앞 배급 줄. **회차 기록** = 한 회차가 죽음으로 끝날 때 쓰이는 연대기 (§6.6).

## 2. 핵심 결정 네 가지

1. **회귀점이 곧 게임의 첫 화면이다.** 게임은 AS 312 낙엽월 1일 저녁 6시, 배급 줄의 빵 냄새로 시작한다. **진짜 이름도 이 첫 화면에서, 줄 뒤에서 부르는 어머니의 입으로 정해진다** — 그리고 모든 회차에 어머니는 같은 순간에 그 이름을 부른다 (20 R6). 잔향이 깨어나는 순간이 바로 그때이므로(WORLD_BIBLE §1.3.1), 회귀는 언제나 **플레이어가 이미 본 첫 화면**으로 돌아온다. 아침의 일(사라가 명단을 엿들은 것, 헨릭이 명단을 적은 것)은 회귀점 이전이라 바꿀 수 없는 과거다. **이 저녁보다 앞으로는 절대 돌아갈 수 없다.** 첫 회차도 이 저녁에서 시작하므로, 그날 아침은 어느 회차에서도 플레이하지 않는다 — 모든 회차가 같은 첫 화면을 공유한다.
2. **첫 죽음은 강요하지 않고, 설계된 자리에 놓는다.** 시스템이 93일 안에 세 갈래의 치명적 자리를 깐다. 하겐의 배신(C), 볼크의 사냥(B), 굶주림월 3일 2차 매각(A). 각각 경고가 둘 이상 앞서고 빠져나갈 길이 있다. 첫 회차 연출 프로파일이 우연한 사망은 한 번 감쇄하고, 치명적 자리는 실제 20분마다 하나씩 연다. 결과는 판정이 정한다.
3. **첫 죽음 뒤에는 아무것도 묻지 않는다.** 고를 몸도, 누를 버튼도 없다. 순서는 **죽음 → 회차 기록 → 시간이 접힌다 → 배급 줄**: 세 줄짜리 짧은 회차 기록이 저절로 재가 되고, 날짜가 거꾸로 흐르고, 정적, 신의 한 마디, 그리고 빵 냄새와 "나는 — 이 냄새를 안다." 전체 회차 기록 카드(§6.6)는 두 번째 회차의 첫 잠자리에서 "잠들기 전, 너는 센다"로 펼쳐진다. 두 번째 죽음부터는 전체 카드가 죽음 시퀀스의 ③ 자리에 들어간다.
4. **시스템은 이야기가 필요로 할 때 열린다. 열리지 않으면 늦어도 정해진 때 열린다.** 해금마다 허구의 계기와 대체 시한이 있다 (§8). 한 번 열린 것은 **잔향에 남아**, 회차가 바뀌어도 닫히지 않고, 두 번째 시대부터는 처음부터 전부 열려 있다.

## 3. 첫 회차의 설계

### 3.1 뼈대: 93일을 60~120분에

첫 회차의 시계는 AS 312 낙엽월 1일 18:00(회귀점)에 시작해 굶주림월 3일(2차 매각 호송)에 끝나도록 짜여 있다. 그 사이 정본 사건 일정(REGIONS §2.14)이 그대로 흐른다.

- 4일차 이후의 "몰아서 보내기"는 03 문서 그대로다. 사건이 생기면 멈춘다. 연출가는 첫 회차 동안 **멈춤 지점 간격을 실제 4~6분**으로 맞춘다.
- 첫 회차의 모든 일지 줄(18 §5.2 ④)은 **회차 기록**의 재료이고, 죽음 시퀀스의 짧은 회차 기록과 접힘(§4.1 ③·④)에 그대로 쓰인다.

### 3.2 세 갈래 죽음의 자리

> **치명적 자리(Lethal Setup)**: 세계 상태가 조건을 채우면 열리고, 그 안의 선택지 일부가 사망 결과를 가진 스토리렛 묶음. 들어서지 않으면 아무 일도 없다.
> 자리는 세계의 일이므로 **모든 회차에 다시 깔린다.** 첫 회차 프로파일은 자리를 여는 **빈도와 경고 시점**만 조절한다. 두 번째 회차부터 플레이어는 기억으로 자리를 피하거나, 일부러 들어선다.

| A1 | 사슬을 끊는다 | 70% | 50% (경비의 자리를 기억) | 사라 탈출, 고드릭의 보복 10명 처형 (마르타가 고른다) |
| A2 | 금고를 연다 | 50% (발각 시 사망 90%) | 30% (발각 경로를 기억) | 명단 소각 → 세렌 사본으로 30일 지연 |

- 각 경로의 원인 사슬에는 **플레이어 선택이 3개 이상** 들어가도록 스토리렛을 짠다 (§3.3 규칙의 2개보다 여유 있게).
- 비율은 플레이테스트 목표다. 연출가가 직접 맞추지 않는다. 자리의 빈도와 경고 시점만 조절한다. 두 번째 회차의 목표치는 **기억이 논거 보정(01 §3.1)으로 들어간 결과**일 뿐, 별도 보정이 아니다.

### 3.3 첫 회차 연출 프로파일 (18 문서의 선택 불가 프로파일 `first_loop`)

| 항목 | 값 | 이유 |
|------|----|------|
| 안전한 날 | 1~3일 | 첫 저녁과 사흘의 VS 스토리렛에는 치명적 결과가 없다. 예외는 플레이어가 고른 명시적 공격(용인·크릭)뿐이고, 법대로 죽는다 (체감 "무모하다" + "매우 위험해 보인다") |
| 무작위 사망 감쇄 | 첫 회차 1회 | 원인 사슬에 플레이어 선택이 2개 미만인 사망(질병·추위·우연한 짐승·대실패 연쇄)은 **빈사**로 바뀐다: 부상 중상 + 3일 누움 + 스트레스 +20. 두 번째는 그대로 죽는다. **첫 회귀는 플레이어가 고른 길의 끝에서 와야 한다** |
| 치명적 자리 간격 | 4일차부터 실제 20분마다 1개 이상 열려 있음 | 죽음이 너무 늦게 오면 미끼가 늦게 문다 |
| 동시에 열린 자리 | 최대 1개 (+예약 1개) | 두 경로가 겹치면 원인이 흐려진다. 회차 기록의 원인 사슬이 한 문장이어야 한다 |
| 예고 | 발동 전 실제 10분 안에 경고 2개 이상 | 소문 / NPC 대사 / 체감 문구 / 냄새·시야 묘사 중 서로 다른 종류. **경고는 두 번째 회차의 기억 카드가 된다** |
| 정보 보정 | 수집한 경고 1개당 관련 판정 +10 (논거 보정, 01 §3.1) | 경고를 모은 플레이어는 "무모하다"를 "반반이다"로 바꿀 수 있다 |
| 판정 보정 | 없음 | 첫 회차라고 주사위를 굴려 주지 않는다 |
| 종료 | 굶주림월 4일 00시 또는 첫 죽음 | 사건 `director.unlock` 발행 → 18 문서가 플레이어가 고른 화자로 전환 (회차 2는 18 §6.3 재진입 「되감김」부터) |

### 3.4 죽지 않는 플레이어: 대체 경로

굶주림월 4일을 살아서 넘긴 플레이어는 정상 진행한다. 미끼는 **첫 자연스러운 죽음**에서 문다. §4 시퀀스는 언제 죽든 똑같다 (되감기 길이만 다르다). 그 사이 다음 장치가 '같은 날을 다시 사는 것'의 냄새를 흘린다.

| 시점 | 장치 | 내용 |
|------|------|------|
| 굶주림월 4일~ | 앞선 잔향자의 꿈 빈도 | 주 1회에서 3일에 1회로. **붉은 손 다라의 꿈**: 잿불 광산의 같은 새벽에 다라가 아홉 번 눈을 뜬다. 같은 감독관이 같은 채찍을 들고, 같은 말을 한다. 꿈마다 다라는 한 걸음씩 다르게 움직인다 (15 문서 목소리 ⟨다라⟩의 첫 조각) |
| 굶주림월 10일 | 엘사가 먼저 다가온다 | 정본 사건 "마르타가 수탉 지하의 냄새를 알아챈다"와 같은 날. 엘사: "너는 꿈을 꾸지? 같은 아침을 아홉 번 사는 여자 꿈." (CHARACTERS R02-14 이야기 씨앗) |
| 재의 날 3일 밤 | 옛 돌 고리 잔상 | 붉은 길의 처형 잔상. 다라의 얼굴이 한순간 플레이어의 얼굴이 된다. 다라가 입 모양으로 말한다: "또 와." |
| 실제 3시간 | 연출가 정상 압력 | 18 문서 기본 성격. 클락 사건이 플레이어를 찾아온다 |
| 볼크에게 팔려 간 경우 | 이탈 분기 | 바알카르 송곳니 회관의 우리. VS 범위 밖이므로 VS 빌드에선 우리 안 탈출 스토리렛 1개 후 **사망(→ 회귀) 또는 회색여울 귀환**으로 수렴 |
| 자원해서 팔려 간 경우 | 이탈 분기 | 1차(서리월 9일) 또는 2차 호송에 스스로 오름. VS 빌드에선 용주 역참 밤 스토리렛 1개(탈출 판정)로 수렴, 1.0에선 세렌 계약민의 회차로 이어짐 |

### 4.1 화면 시퀀스 (첫 죽음)

- **게임 오버·메뉴·업적·TP 화면은 이 자리에 나오지 않는다.** 첫 죽음의 ③은 읽을거리가 아니라 **닫히는 소리**다: 세 줄, 버튼 없음, 저절로 재가 됨. 전체 회차 기록 카드는 두 번째 회차의 첫 잠자리(§6.6 "잠들기 전, 너는 센다")에서, 또는 기억 메뉴에서 펼쳐진다.
- ⑦의 속마음 줄 *"나는 — 이 냄새를 안다."* 는 이 게임에서 드물게 쓰는 **1인칭 속마음**이다 (§10.2의 속마음 힌트와 같은 서체). 본문 2인칭이 돌아오기 전, 주인공이 처음으로 스스로에게 말한다. 회귀할 때마다 같은 줄이다.
- 되감기의 날짜 단위는 회차 길이에 따른다: 60일 이하 = 날, 61일~2년 = 달("굶주림월 · 긴밤월 · 서리월 · 낙엽월"), 2년 초과 = 해("315년 · 314년 · 313년 · 312년 낙엽월 1일"). 어느 경우든 마지막 줄은 **"낙엽월 1일"** 이다.
- 첫 회차가 굶주림월 4일을 넘겨 길어졌다면 되감기가 길어질 뿐, 시퀀스는 같다.

### 4.2 햅틱 악보

> 19 원칙 "몸의 감각만 진동한다"를 따른다. 죽음과 첫 숨은 몸의 감각이다. 되감기의 틱은 몸의 감각이 아니지만 **시간이 몸을 지나가는 감각**으로 예외 인정 (19와 맞출 것). 설정의 '진동 끔'은 모두 끈다.

| ID | 이름 | 모양 (지속 ms · 세기 0~1) | 쓰이는 곳 |
|----|------|---------------------------|-----------|
| **H1** | 마지막 감각 | 경로별. **C 물**: 180·0.6 → 120 쉼 → 140·0.45 → 160 쉼 → 100·0.3 (가라앉는 세 번) / **B 이빨**: 90·0.9 → 60 쉼 → 90·0.9 (짧고 날카로운 두 번) / **A1 창**: 260·0.85 한 번 (들어왔다 나간다) / **A2 들보**: 450·0.7, 끝 100ms 동안 0으로 줄어듦 / **B2 창끝**: 60·1.0 한 번 / 그 밖: 450·0.8 | ① 끊김 |
| **H2** | 되감기 틱 | 25·0.3, 간격 220 → 40ms 지수 감속(가속) | ④ 접힘 |
| **H3** | 심장 | 60·0.35 → 140 쉼 → 80·0.5 | ⑦ "빵 냄새." |
| **H4** | 유령 진동 | 그 회차의 H1을 세기 ×0.3으로 한 번 | 새 회차에서 죽음의 흔적(§4.4)의 방아쇠를 **처음** 만났을 때. 회차마다 방아쇠당 1회 |
| **H5** | 기억과 다름 | 40·0.25 한 번 | ◇ 기억과 다름 표지가 뜰 때 (§7.5). 회차마다 처음 3회만 |

- H1이 경로마다 다른 것은, 두 번째 회차의 H4가 **어떤 죽음이 깨어났는지**를 손바닥으로 알려 주기 때문이다. 하겐의 웃음 앞에서 가라앉는 세 번이 희미하게 오면, 플레이어는 물을 기억한다.
- 소리 (요약, 19 소관): ① 장면 소리가 그대로 뚝 끊김 → ②~④ 무음 → ⑥ 장작 타는 소리와 줄의 웅성거림이 0.8초 페이드 인. 음악 없음.

### 4.3 무엇이 남고 무엇이 돌아가는가: 회귀 정산

죽음이 확정되면 엔진은 **회귀 정산**을 한다 (WORLD_BIBLE §1.3.1 표의 데이터판). 세계 상태는 회귀점 스냅샷 `snapshot.loop_origin`으로 통째로 되돌아가고, 아래 '남는 것'만 잔향에 실려 새 회차의 주인공에게 다시 얹힌다.

### 4.4 죽음의 흔적: 쌓이는 죽음

> WORLD_BIBLE §1.3.1 "죽는 방식이 잔혹할수록 회귀한 뒤에도 남는 것이 있다." 흔적은 **영혼의 기억**이라 몸이 바뀌어도(=돌아가도) 남는다.
> 흔적은 벌이 아니다. 그 죽음을 다시 만났을 때 손이 떨리는 것이다. 그리고 극복할 수 있다.

| 경로 | 흔적 | 방아쇠 (H4 유령 진동이 오는 자리) | 효과 | 극복 |
|------|------|-----------------------------------|------|------|
| C | 「물의 기억」 | 하겐의 얼굴 · 강물에 몸이 잠기는 장면 · 등 뒤에서 노 젓는 소리 | 물에 들어가는 판정 −5, 하겐과 같은 장면 첫 화면에 스트레스 +5 | 같은 회차에 물굽이를 산 채로 건넌다 / 하겐을 심판대에 세운다 |
| B1 | 「목덜미」 | 볼크의 목소리 · 개 짖는 소리가 세 번 · 바르그의 냄새 묘사 | 바르그·사냥개 앞 공포 판정 −5 | 볼크 앞에서 공포 판정 성공 2회 |
| B2 | 「가시덤불」 | 시그리드의 창 · 늑대굴 입구 | 시그리드와의 첫 대화 기만 판정 −5 (손이 먼저 떤다) | 시그리드 신뢰 50 (그녀는 왜 당신이 떠는지 모른다) |
| A1 | 「옆구리」 | 용인 경비의 창 · 눈 위에 눕는 장면 | 창 든 상대와의 전투 첫 합 −5 | 같은 굽이를 산 채로 지난다 |
| A2 | 「손톱」 | 성채 지하실 · 헨릭의 목소리 · 들보 | 심문의 의지 판정 **+5**(이미 견뎌 봤다), 그러나 성채 마당 장면마다 스트레스 +5 | 없음 (흔적이 두 얼굴을 다 가진다) |
| 무작위 | 「빈 숨」 | 같은 원인 | 그 원인 앞 판정 −3 | 1회 회피 |

- 같은 흔적을 두 번 얻으면 단계가 오른다 (−5 → −10, 유령 진동 세기 ×0.5). 세 번째부터는 15 문서 목소리가 그 자리에서 한 마디를 한다 (⟨군데⟩ "같은 강에 세 번 들어가는 놈은 처음 본다.").
- 흔적은 인물 수첩·상태 띠에 숫자로 보이지 않는다. 판정 근거 미리보기(01)에 한 줄로만: "▼ 물이 차다. 너는 그걸 안다."

### 4.5 회귀 변형 지도: 어떤 죽음이 깨어나는가

회귀점은 하나다. 그러나 두 번째 회차의 첫 화면은 **어떻게 죽었는가**에 따라 다르게 읽힌다. 문장은 같고, 기억 잉크(┊)와 유령 진동과 첫 ◈ 선택지가 다르다. 골격은 §6.5에 하나만 쓰고, 경로 변수로 바꾼다.

| 죽음 | 장면 ID | 첫 화면에서 깨어나는 것 | 첫 ◈ 선택지 (대표) | 이 회차의 첫 질문 |
|------|---------|--------------------------|----------------------|--------------------|
| **C** 북쪽 길 | `loop_return_c` | 기침(물). 하겐의 웃음 위에 가슴의 발. 페인의 손 = 노를 젓던 손 | ◈ 페인의 손을 잡아 처마에서 끌어내린다: "하겐 따라가지 마." | 페인을 하겐에게서 떼어 낼 수 있나. 그리고 그 아이는 왜 나를 처음 보는 얼굴로 보나 |
| **B1** 송곳니 불 | `loop_return_b1` | 목덜미가 가렵다. 수탉 뒤 개 짖는 소리 세 번에 손이 굳는다 (H4). 페인의 손 = 바위 위에서 "왼쪽!" 하던 손 | ◈ 브람에게: "무두장 가죽, 지금 얼마나 남았어요?" | 9.25까지 늑대굴을 옮길 수 있나 |
| **B2** 안내 | `loop_return_b2` | 손이 떨린다. 사라를 보면 마르타가, 마르타를 생각하면 덤불이 떠오른다 | ◈ 마르타가 오기 전에 수탉 지하로 내려간다 | 이번엔 누구를 팔지 않을 수 있나 |
| **A1** 소금 나루 | `loop_return_a1` | 옆구리가 시리다. 사라가 소매를 당기는 손이, 눈 위에서 머리를 받쳐 주던 손이다 | ◈ 사라에게: "네 이름도 있어. 둘째 명단에." | 사라에게 석 달을 어떻게 말하나 (그녀는 아직 자기 이름이 없는 명단만 안다) |
| **A2** 성채 금고 | `loop_return_a2` | 손톱이 아리다. 헨릭의 목소리에 몸이 먼저 굳는다 (H4) | ◈ 헨릭에게 머리를 조아린다. 그의 장부 마지막 장을 안다 | 마르타는 또 열쇠를 잃어버려 줄까 |
| 첫 회차 생존 후 죽음 | `loop_return_late` | 되감기가 길다. 많은 것이 깨어난다. 기억 잉크 상한(§7.5)이 먼저 걸린다 | 가장 무거운 기억 하나 (18이 고름) | 길게 살았던 사람들이 아무도 나를 모른다 |

- 경로 변수: `{death.route}`, `{death.date}`, `{kit.status_at_death}`, `{fayne.trust_at_death}`, `{word.harbek.known}`. 다섯 변형은 §6.5 골격의 **줄 단위 치환**으로 만든다 (새 장면 다섯 개를 쓰지 않는다).

## 6. 장면 원고

> 2인칭 현재형 (SCENARIOS §0.1). `{player.형누나}`는 키트가 부르는 호칭. 선택지 옆 체감 문구는 O-01 시작 수치(지구력 20 · 농사 20 · 운동 12 · 야외생존 10 · 은신 8 · 노예말 30, 나머지 0, 능력치 9~12)와 01 §4.2 과신 편향을 적용한 **표시값**이다.
> 이 절의 문장은 **모든 회차에 글자 그대로 반복된다.** 회차마다 바뀌는 것은 ◈ 선택지, ┊ 기억 잉크, ◇ 표지, 그리고 표류(§7.1)가 고른 작은 것들뿐이다. 그래서 첫 화면의 문장은 외워질 각오로 쓴다.

### 6.1 여는 장면 = 회귀점

> 15 §11 장면 3·20 §9 R6과 같은 순간이다: **저녁 6시, 빵 냄새, 이 빠진 그릇, 즈닉의 국자, 줄 뒤에서 이름을 부르는 어머니.** 이 절은 그 순간의 **첫 회차판**과 공통 골격을 정한다. 두 번째 회차부터의 변형은 §6.5, 어머니 장면의 회차별 변주는 20 R6이 맡는다.

### 6.5 두 번째 회차의 첫 화면

> **기억 잉크 표기**: 주인공 자신의 지난 회차 기억은 `┊` 가는 점선 막대가 붙은 흐린 잉크(회색 기울임)로 쓴다. 본문과 같은 2인칭 현재형이지만 **현재형이 아니라 과거형**이다 — 그 일은 이제 일어나지 않은 일이기 때문이다.
> **기시감 렌더링**: 지난 회차에 이미 읽은 본문 줄은 먼저 흐린 잉크로 떠올랐다가 0.3초 뒤 본문 잉크로 굳는다 (19). 처음 읽는 줄은 평소처럼 나온다. 플레이어는 설명 없이 **"이 줄을 읽은 적이 있다"** 를 눈으로 느낀다.
> 문장에 "당신은 돌아왔다", "회귀했다", "시간이 되돌아갔다" 같은 설명은 쓰지 않는다.

| 헨릭에게 담보 | 낱말 `harbek` | 논거 보정 +10 (지식) → "무모하다"가 "어렵다"로. 헨릭이 처음으로 너를 숫자 이외의 것으로 본다: "…말보다 싼 것이 그 말을 어디서 주워들었지?" 성공: 키트 대신 다른 이름 (토비) — 2번 선택지와 같은 결과를 동화 1못으로. 실패: 헨릭 의심 +20, 헨릭이 사라를 의심한다 (사라가 그 말을 들을 수 있는 유일한 하녀) |
| 브람에게 벽 | `fact_bram_hides_refugees` + 첫 회차에서 벽 소리를 들음 | 브람이 국자를 내려놓는다. 긴 침묵. "…누가 보냈냐." 브람 신뢰 +10, 의심 +15. 그날 밤 브람이 벽을 다시 바른다 → 16 M2 「수탉 아래에서 온 말」의 뿌리가 **지난 회차의 기억**으로 바뀐다 |

- ◈는 한 화면에 최대 3개 (§7.5). 우선순위는 18 연출가가 정한다 (지난 죽음의 경로 > 실타래 위험도 > 최근 획득).
- ◈ 선택지는 **말투로 보이지 않는다.** 다른 선택지와 같은 모양, 앞의 ◈ 하나가 다를 뿐이다.

**첫 회차의 끝 자극 → 두 번째 회차의 첫 밤** (세션 경계)

│ 02:30 · 강변 움막 12호             │
│ ──────────────────────────────── │

│ 이마가 따뜻하다. 물에 젖지 않았다.   │
│ 송곳니 불 쪽은 조용하다. 아직 볼크가 │
│ 오지 않았으니까. 열사흘 뒤에 온다.   │
│ 너는 그것을 안다.                   │
│ 잠들기 전, 너는 센다.               │
│                  [ 센다 ▸ ]        │
└────────────────────────────────┘
```

- "열사흘 뒤에 온다. 너는 그것을 안다."는 플레이어가 그 날짜를 지난 회차에 **알았을 때만** 나온다 (`known_by`). 아니면 그 두 줄은 빠진다.
- [센다 ▸]를 누르면 첫 회차의 회차 기록이 펼쳐진다 (§6.6).

### 6.6 회차 기록 `loop_record`

> 한 회차가 죽음으로 끝날 때 쓰이는 연대기. **자기 무덤은 없다.** 주인공은 이 세계에서 죽지 않았다 — 그 회차가 없어졌을 뿐이다.
> 보이는 때: 모든 죽음의 시퀀스 ③ (§4.1). 첫 죽음은 **짧은 판**(기간 한 줄 + 원인 사슬 한 문장 + 가져가는 것 한 줄, 저절로 재가 됨)이고, 전체 카드는 두 번째 회차의 첫 잠자리("잠들기 전, 너는 센다")에서 펼쳐진다. 두 번째 죽음부터는 시퀀스 ③'에 전체 카드. 그 뒤로는 언제든 기억 메뉴 → 「회차 기록」 보관함.

```
┌────────────────────────────────┐
│ 첫 번째 저녁부터                   │
│ 낙엽월 1일 — 낙엽월 21일 (스무하루) │
│ ──────────────────────────────── │
│ "너는 하겐의 배에 올랐다. 그 배를    │
│  알려 준 것은 페인이었고, 페인에게   │
│  길을 물은 것은 첫날 저녁 배급       │
│  줄에서였다."                       │
│ ── 가져온 것 ──                    │
│  기억   비밀 4 · 날짜 7 · 낱말 2     │
│         (하르벡 · 낫 세 번)          │
│         지도 9곳                    │
│  기술   은신 8→14 · 노예말 30→34     │
│  죽음   물이 차다                    │
│ ── 두고 온 것 ──                    │
│  페인   갈대 속에서 살아남았다.       │
│         그 밤은 이제 없다.           │
│  키트   송곳니 불의 우리 안이었다.    │
│         그 밤도 없다.                │
│  사라   우물가에서 너에게 낱말을       │
│         알려 주었다. 기억하지 못한다. │
│  너     손바닥의 물집 · 동화 1못      │
└────────────────────────────────┘
```

| 줄 | 규칙 |
|----|------|
| 머리 | 회차 번호는 숫자 대신 **"첫 번째 저녁부터 / 두 번째 저녁부터 …"**. 열 번째부터는 "열한 번째 저녁". 기간 = 회귀점 ~ 죽은 날, 괄호에 고유어 날수 |
| 원인 사슬 문장 | 16 메아리 형식(평가어 금지)으로 한 문장. 원인 사슬의 플레이어 선택 3개를 거꾸로: "너는 X했다. 그 X를 Y한 것은 Z였고, Z에게 W한 것은 V에서였다." |
| 가져온 것 | 그 회차에 **새로** 얻은 것만. 기억은 범주별 개수 + 대표 2개 이름, 기술은 변한 스킬 최대 3개, 죽음은 흔적 이름(§4.4)을 세계 안의 말로 ("물이 차다", "목덜미", "옆구리", "손톱") |
| 두고 온 것 | 그 회차에 관계가 ±20 이상 변한 사람 최대 4명, **한 줄씩**: 그 회차에 그 사람에게 일어난 일 + "기억하지 못한다" / "그 밤은 이제 없다". 마지막 줄 "너"는 몸에 생겼던 것(흉터·물건·돈)이 돌아갔다는 것 |
| 길이 | 카드 1장, 18줄 이하. 회차가 1년을 넘으면 카드 2장(두 번째: 「그 회차에 세운 것」 — 영역·가문·아이들. 아이들은 다시 태어나지 않는다) |
| 공유 | 연대기 공유 이미지(03)와 같은 형식으로 저장 가능 |

**"그 밤에 지켜진 사람"**: 치명적 자리의 `beneficiaries`(§3.2)는 회차 기록의 "두고 온 것" 첫 줄로 간다. 지켜 낸 것이 그대로 무효가 된다는 것을 숫자 없이 보여 준다. 회차 기록에 TP나 업적 알림은 붙지 않는다 — 업적은 잔향에 조용히 새겨지고 기억 메뉴에서만 보인다.

**회차가 긴 경우** (1년 이상, 「그 회차에 세운 것」 예)

```
│ ── 그 회차에 세운 것 ──            │
│  늑대굴   숨은 마을, 백마흔 명.      │
│           아무도 그곳을 모른다.      │
│           아직 아무도 거기 없다.     │
│  미나     너에게 글자 서른한 개를     │
│           배웠다. 다시 글을 모른다.  │
│  아이     봄에 태어났다. 이름은       │
│           너와 시그리드만 알았다.    │
│           다시 태어나지 않는다.      │
```

## 7. 같은 저녁, 다른 회차 — 고정 회귀점의 변주

> 회귀점은 옮겨지지 않는다. 그러므로 다양성은 세 가지에서 나온다: **① 시간의 표류**(세계가 조금씩 어긋난다) · **② 첫 선택의 갈래**(플레이어가 다르게 한다) · **③ 아무도 기억하지 않는다**(같은 사람을 다른 순서로 처음 만난다). 그리고 반복을 줄이는 장치 하나: **아는 날을 접는다**(18).

### 7.1 시간의 표류 — 네 등급

회차마다 `loop.seed`가 새로 굴러간다 (시뮬레이션 난수 스트림의 회차 시드. 판정 난수·연출 난수와 별개, 18 §7.1). 모든 세계 요소는 표류 등급을 가진다.

| 등급 | 뜻 | 회색여울 첫 사흘 예 | 회차마다 |
|------|-----|---------------------|----------|
| **고정** | 월드 클락·REGIONS §2.14 확정 사건, 회귀점 이전의 모든 일 | 18:00 즈닉의 국자 · 어머니가 이름을 부르는 것 · 사라가 아침에 엿들은 명단 · 헨릭의 "하르벡" · 9.3 세베로 사자 · 9.14 볼크 도착 · 9.25 대수색 · 10.9 1차 호송 | 같다 |
| **단단함** | 성격·목표가 정하는 NPC 선택. 플레이어가 같게 하면 90% 이상 같다 | 하겐이 빵을 들고 오는 것 · 페인의 손바닥과 첫 대사 · 2일 19:40 마르타의 포섭 · 게르다가 이름 뒤에 하는 말 ("키트 빵까지 받아") · 이르마의 9.24 신고 | 거의 같다. 플레이어가 다르게 하면 반응이 다르다 (그것은 표류가 아니라 인과다) |
| **흔들림** | 일정의 작은 폭, 경로, 순서 | 스니의 순회 01:20~02:30 · 점호 수색 대상 셋 · 엘사의 갈대배 시각 · 사라의 옷차림 줄 · 첫 비 오는 날(9.6~9.11) · 하겐의 세 소나무 매듭 날(9.4~9.6) · 미카의 꿈(60%) | 시드에 따라 폭 안에서 |
| **흩어짐** | 우연 | 배급 줄 앞뒤의 C등급 인물 · 들일 위치 · 날씨의 세부 · 소문 운반자 · 고요한 날 소품의 순서 | 매번 새로 |

- **표류는 공정하다**: 표류는 플레이어 행동과 무관하게 굴러가고, 플레이어의 선택이 만든 차이는 표류가 아니라 **인과**다 (16 메아리가 그것을 말한다).
- **표류는 회차가 쌓여도 커지지 않는다.** 찢어진 시간의 폭은 일정하다. 회차가 쌓이면 커지는 것은 냄새와 기시감뿐이다 (§7.4).
- **기억의 신뢰도**: 지식 카드는 그 내용이 가리키는 요소의 표류 등급을 물려받는다. 카드에 등급이 숫자로 보이지는 않는다. 다만 '흔들림' 이상의 카드에 기댄 ◈ 선택지는 결과가 어긋날 수 있고, 어긋나면 ◇가 뜬다. 플레이어는 몇 회차 만에 **어떤 기억이 단단한지**를 배운다. 이것이 이 게임의 숙련이다.
- **표류 전용 스토리렛**: '흔들림·흩어짐' 요소가 특정 값으로 떨어졌을 때만 나오는 작은 장면 (예: 9.7에 비가 오면 `rain_on_hut12` — 지붕 새는 자리에서 키트가 옛 노래를 흥얼거린다). 회색여울 첫 사흘에 12개 (§13). 이것이 같은 저녁을 다르게 만드는 가장 싼 방법이다.

### 7.2 첫 선택의 갈래 — 첫 저녁의 ◈

첫 저녁(1일 18:00~2일 04:30)은 모든 회차가 지나는 길목이다. 여기서 열리는 ◈ 선택지는 **지난 회차들에서 얻은 기억의 합**에 따라 늘어난다.

| ◈ 선택지 | 요구 기억 | 무엇이 달라지나 |
|-----------|-----------|------------------|
| 사라보다 먼저 "스물여섯째 줄" | 첫 회차 그 자체 (항상) | 사라와의 첫 매듭이 '소식'에서 '의심'으로. 정오 우물 약속 |
| 헨릭에게 담보 | 낱말 `harbek` | 키트 명단 제외를 첫날 저녁에 시도 (토비가 대신 간다 — 16 M11 「되풀이」의 씨앗) |
| 페인의 손을 잡는다 | 하겐의 정체 | 페인 `stranger_warned_me`. C창이 열리기 어려워진다 |
| 브람에게 벽 | 수탉 지하 | 에길 일가 보호가 2일 대신 1일 밤부터. 16 M2의 뿌리 |
| 하겐의 빵을 받으며 '안내인'의 이름을 묻는다 | 하겐이 안내인이 없다는 것 | 하겐 의심 +20. 그가 처음으로 너를 '물건'이 아니라 '위험'으로 본다 → 하겐이 볼크에게 너를 먼저 판다 (9.14, 새로운 치명적 자리 — 기억이 위험을 만든다) |
| 키트를 데리고 바로 엘사에게 (통금 전) | 엘사 = 잿빛 실 연락책 | 첫 밤의 잠꼬대 장면이 엘사의 갈대배 안에서 일어난다. 숯 원은 없다 |
| 어머니가 부르기 전에 돌아본다: "엄마." | 첫 회차 그 자체 | 게르다가 굳는다. "…불렀니, 내가?" 20 R6의 세 선택지와 별개의 ◈. 게르다 `player_speech_changed`(15) 판정 +10 |
| 오스릭에게 "빛의 서신, 저에게 맡기지 마세요" | 오스릭의 조각 | 서신 조각이 다른 사람(미카의 어머니)에게 간다 → 6일 압수, 처형 (기억으로 피한 위험이 남에게 간다) |

- 첫 저녁에 동시에 보이는 ◈는 최대 3개. 나머지는 그 장면의 "⋯ 기억 더" 접힌 줄에 있다 (§7.5).
- 같은 ◈를 세 회차 연속 고르면 그 ◈는 선택지 목록에서 **일반 선택지처럼** 보인다 (◈가 빠진다). 더 이상 '기억'이 아니라 '습관'이기 때문이다. 15 문서 목소리 ⟨아스테리온⟩이 이때 처음 한 마디를 한다 (조건: 그 시대 회차 5 이상): "백 번째쯤엔, 이 저녁의 냄새가 싫어질 거다. 그래도 맡아."

### 7.3 아무도 기억하지 않는다

| 규칙 | 내용 |
|------|------|
| 기억 없음 | 회귀 뒤 NPC는 **어떤 경우에도** 지난 회차를 기억하지 않는다. 기억 태그·신뢰·애정·맹세 증인 기억이 모두 시작값 |
| 같은 상태, 같은 말 | 세계 상태가 같으면 NPC의 대사는 **글자 그대로 같다** (05 대사 규칙의 결정성). 플레이어가 대사를 외울 수 있어야 반복이 무기가 되고, 반복이 슬픔이 된다 |
| 지나치게 아는 낯선 사람 | 플레이어가 지난 회차의 지식을 입 밖에 내면 05 개념 `과하게_앎` 대사: "너 그걸 어떻게 알아?" / "누가 보냈냐." / "…처음 보는데." 해당 NPC 의심 +10~25, 잔향 징후 노출 판정 +3~5 |
| 인물 수첩의 두 겹 | 지난 회차에 쓴 매듭과 메모는 **지난 회차 잉크**(흐린 회색)로 남는다. 이번 회차의 매듭은 진한 잉크. 이번 회차에 처음 만나면 그 사람의 얼굴에 작은 표지 "처음 보는 얼굴" (상대가 너를). 08 §5 확신도 표지와 겹치지 않게 19가 설계 |
| 재회 | 사랑한 사람·가까웠던 사람을 새 회차에서 처음 만나는 장면은 20 문서 「나를 처음 보는 사람」 규칙을 따른다. 첫 시간들의 재회는 셋: 페인(배급 줄 처마), 사라(배급 줄), 게르다(어둠 속 이름) |
| 진짜 이름 | 지난 회차에 진짜 이름을 알려 준 사람은 그것을 잊는다. 이름의 위험도 함께 잊힌다. 이름을 다시 말할지는 다시 고른다 |

### 7.4 기시감 — 시간에 민감한 것들 (회색여울에서)

> WORLD_BIBLE §1.3.1 회귀의 대가 (a)(b). 아무도 기억하지 않는다. 그러나 **시간에 닿은 것들은 낌새를 느낀다.** 첫 시간들에서 그것은 셋이다.

| 무엇 | 회차가 쌓이면 | 회색여울 첫 사흘~첫 달의 모습 | 소관 |
|------|----------------|-------------------------------|------|
| **젖은 재의 냄새** (주인공) | `loop.count`에 따라 짙어진다 | 1회차: 볼크가 B1 죽음 순간에만 맡음 · 2~3회차: 9.14 냄새 판정(D45) 난이도 −5/회차 · 4회차~: 죽음 시퀀스 ⑥에 "그 밑에, 젖은 재." · 6회차~: 송곳니 불의 사냥개가 첫날 수탉 앞에서 운다 | 17 (수치) |
| **잿빛 탑의 관측** → 이졸 | 탑이 기시감을 느낀다 → 이졸이 더 일찍, 더 오래 | 이졸 도착 9.18 → `loop.count ≥ 3`부터 회차당 하루씩 이르게 (최대 9.12) · 응시 3초 → 회차당 +0.5초 (최대 6초) · 판정 −2/회차 (최대 −10) | 17·SCENARIOS |
| **엘사** (늪 마녀, 빌린 혈명) | 기시감이 아니라 **눈치** — 그녀는 같은 날을 두 번 산 얼굴을 안다 | 엘사의 "같은 날을 두 번 산 얼굴" 대사는 회차와 무관하게 오지만, 그녀가 먼저 다가오는 날은 `loop.count`가 클수록 이르다 (3일 → 2일 → 1일 밤) | 이 문서 |

- 바르스카르·엘다르의 기시감은 첫 시간들에 닿지 않는다 (먼 곳의 일). 단, 15 목소리 ⟨아스테리온⟩은 회차가 쌓일수록 "그 늙은 용이 꿈을 꾼다"는 말을 한다.

### 7.5 기억 표지 — ◈ · ┊ · ◇

| 표지 | 뜻 | 규칙 |
|------|----|------|
| **◈ 기억 선택지** | 지난 회차의 지식이 있어야 열리는 선택지 | 한 화면 최대 3개. 넘치면 "⋯ 기억 더" 접힌 줄. 길게 누르면 그 기억의 출처 (회차·날짜·사람) — 판정 근거 미리보기와 같은 제스처. 세 회차 연속 고르면 ◈가 빠진다 (§7.2) |
| **┊ 기억 잉크** | 지난 회차에 일어났던 일 (이제 일어나지 않은 일) | 과거형. 한 화면 최대 2줄. 같은 방아쇠에 회차당 1번. 설정 「기억 잉크: 많이 / 보통 / 적게」 (적게 = 죽음의 흔적 방아쇠만) |
| **◇ 기억과 다름** | 표류로 기억과 결과가 어긋남 | 기억 잉크 한 줄로 어긋남만 말한다: "┊ 두 시가 아니었다." H5 진동은 회차마다 처음 3번. ◇ 자체는 결과 문장 끝에 붙는 작은 기호 |
| 기시감 렌더링 | 이미 읽은 본문 줄 | 0.3초 흐림 → 굳음. 회차당 첫 등장 줄만. 같은 회차 안에서 다시 읽는 줄은 평소대로 |

- ◈·┊·◇는 **두 번째 회차가 시작되는 순간** 처음 보인다 (§8 #17). 첫 회차에는 존재하지 않는다.

- 15번 영역은 "숨긴 곳" 카드 하나로 시작한다. 인구·식량·노출 세 수치만 보인다. 09 문서의 나머지 수치(방어·은폐·사기·문해율·질서·재화)는 인구 6명 이상(비밀 거점)이 되면 열린다.
- 19~25번은 **회귀가 처음 일어나야만** 열린다. 죽지 않고 굶주림월 4일을 넘긴 플레이어에게 이 일곱 개는 해금표의 회색 칸으로만 남는다 (이름만, 계기는 숨김 — §14 '해금이 깊이를 숨김').

## 9. 첫 세션 리텐션

### 9.1 세션 지도 (첫 3시간 ≈ 15분 세션 열두 번)

| 세션 | 실제 시간 | 끝나는 자리 | 열린 질문 (다음에 돌아올 이유) |
|------|-----------|-------------|--------------------------------|
| 1 | 0:00~0:14 | 문설주의 숯 원 | 누가 알아챘나. 키트까지 38일 |
| 2 | 0:14~0:35 | 페인: "어제 마르타 아줌마랑 무슨 얘기 했어?" | 그가 본 것을 누구에게 말할까 |
| 3 | 0:35~0:50 | 나루의 결과 + "며칠을 보낸다" | 키트의 이름은 남았나 |
| 4 | 0:50~1:04 | 옛 돌 고리에서 돌아오는 길, 어머니의 기침이 멎어 있다 | 약이 늦었나 (다음 장면에서 게르다는 잠들어 있을 뿐이다) |
| 5 | 1:04~T | 볼크의 코 / 이졸의 눈 / 하겐의 배 → 죽음 | (경로별) |
| 6 | T~T+15 | **두 번째 회차의 첫 밤: "잠들기 전, 너는 센다."** | 무엇을 가져왔나. 열사흘 뒤 볼크가 온다는 것을 안다 |
| 7 | T+15~T+35 | 마르타의 값 — 이번엔 셋째 길 | 기억으로 바꾼 것은 무엇을 부를까 |
| 8 | T+35~T+52 | 엘사: "같은 날을 두 번 산 얼굴" → 「기억대로 보낸다」 첫 제안 | 어디까지 접을까. 어디서 다르게 할까 |
| 9~12 | T+52~3:00 | 지난 회차 사망일로 다가감 → **넘어섬** | 어제의 나는 여기까지였다. 그 너머는 모른다 |

- 세션의 끝은 언제나 **잠 · 몰아서 보내기 · 장면 전환** 경계다. 앱을 닫으면 그 경계까지 자동 저장된다 (03 그림다크 자동 저장).
- **죽음은 세션의 끝이 아니다.** 죽음 시퀀스는 반드시 두 번째 회차의 첫 화면까지 이어진다. 죽음 시퀀스 도중 앱이 닫히면, 다시 열 때 ⑦ "빵 냄새."부터 시작한다 (전체 회차 기록은 첫 잠자리에서 그대로).
- 하루 요약 카드는 숫자 대신 **매듭 변화**를 보여 준다: "매듭 +3 · 풀린 매듭 1 · 들은 말 +2". 시한(키트 38일, 사라 93일)은 사라나 키트의 매듭에 붙은 작은 눈금으로만 보인다. 플레이어가 그 시한을 알게 된 경우에만 보인다. 두 번째 회차부터는 **지난 회차 사망일**이 플레이어 자신의 매듭에 눈금으로 붙는다 (아무도 모르는 시한).

### 9.2 세션 1의 15분 설계 원칙

15분 안에 순서대로 다섯 가지를 준다. **위험한 이름 하나**(0~1분, 줄 뒤에서 어머니가 부르는 진짜 이름) → **지킬 사람과 시한**(1~2분, "명단에 키트가 있어") → **위험한 사람들이 웃고 있다**(1~3분, 헨릭의 손가락·하겐의 빵·페인의 손바닥 — 두 번째 회차에서 모두 다르게 읽힐 세 얼굴) → **이 몸이 이상하다**(2~3분, 읽을 수 없는 글자를 읽는다) → **내 비밀이 이미 새어 나갔는데, 누군가 덮어 주었다**(10~14분, 첫 밤과 숯 원). 15분 안에는 전투·메뉴 설명·지도·재능 숫자·"잔향"·"회차"라는 단어를 넣지 않는다.

> 첫 화면의 세 얼굴(헨릭·하겐·페인)은 **두 번째 회차를 위한 투자**다. 첫 회차의 플레이어는 그들을 배경으로 본다. 두 번째 회차의 플레이어는 그들을 다시 보며 자기가 무엇을 아는지 깨닫는다. 그러려면 첫 화면이 짧고, 정확하고, 외워질 만해야 한다.

### 9.3 첫 회차의 끝 자극

첫 회차의 마지막 화면은 죽음이 아니라 **두 번째 회차의 첫 밤**이다 (§6.5 끝). 그 화면의 마지막 줄은 셋 중 둘 이상을 담는다: **이미 아는 위협**("열사흘 뒤에 온다") · **아무것도 모르는 사람**(등에 이마를 댄 키트) · **센다**(가져온 것을 세는 손).

| 지난 죽음 | 아는 위협 (기억) | 모르는 사람 | 가져온 것 (대표) |
|-----------|------------------|-------------|------------------|
| C | 하겐의 배 (9.21) | 페인 — 처마의 손 | 물이 차다 · 하겐의 은니 |
| B1 | 볼크의 개들은 오른쪽 비탈로 | 페인 — 바위 위의 "왼쪽!" | 목덜미 · 무두장 냄새 |
| B2 | 시그리드의 창 | 마르타 — 내일 19:40의 털모자 | 가시덤불 · 늑대굴 입구 |
| A1 | 굶주림월 3일 습지 굽이 | 사라 — 이름을 물었던 손 | 옆구리 · 둘째 명단 |
| A2 | 성채 지하실 | 마르타 — 한 시간 잃어버린 열쇠 | 손톱 · 금고의 위치 |

### 9.4 다시 열었을 때

8시간 이상 닫았다 열면 **마지막 장면의 마지막 두 줄**과 **가장 최근에 바뀐 매듭 하나**만 보여 주고 선택지로 돌아간다. 줄거리 요약문은 쓰지 않는다. 회차가 바뀐 뒤 처음 여는 경우는 18 §5.4 「지난 이야기」에 **"몇 번째 저녁인지"** 한 줄이 붙는다.

### 10.2 허용되는 화면 힌트 (게임 전체에 세 번)

설명 팝업·화살표·"탭하세요"는 쓰지 않는다. 단 세 번, **캐릭터의 속마음 한 줄**로 조작을 암시한다. 한 번 보이면 다시 보이지 않는다 (회귀해도). 회귀 자체에는 힌트를 쓰지 않는다 — ◈ 선택지의 길게 누르기는 ①과 같은 제스처라서 따로 가르칠 필요가 없다.

| # | 계기 | 속마음 한 줄 | 암시하는 조작 |
|---|------|--------------|---------------|
| ① | 체감 "해볼 만하다" 이상에서 첫 실패 | *다음엔 덤비기 전에 따져 보자. (선택지를 꾹 누르고 있으면…)* | 길게 누르기 → 판정 근거 |
| ② | 지도 첫 해금 직후 | *저기, 둔덕 너머. 손가락으로 짚어 보면 얼마나 걸릴지 알 것 같다.* | 노드 탭 |
| ③ | 인물 수첩에 모순 매듭이 처음 생김 | *둘 중 하나는 거짓말을 하고 있다. 잊지 않게 매듭을 지어 두자.* | 수첩 메모 |

  warnings: { id: string; kind: 'rumor' | 'line' | 'feel' | 'scent' | 'sight' }[];  // 다음 회차의 기억 카드가 됨
  lethalChoiceIds: string[]; exits: string[];
  beneficiaries: NpcRef[];                         // 회차 기록 "두고 온 것" 첫 줄
  targetDeathRate: { firstLoop: number; remembered: number };   // 플레이테스트 목표 (런타임 미사용)
  deathTrace: DeathTraceId;
}
// 사망의 원인·뿌리는 16 §6.1의 `CauseRef`(같은 회차 안의 직접 원인)와 `RootRef`(플레이어 뿌리 — `loop` 필드 포함)를 쓴다. 회차 기록·16 메아리 공용 (옛 `CauseLink`는 폐기)
interface DeathTrace {                             // §4.4
  id: DeathTraceId; name: string;                  // 세계 안의 말: "물이 차다"
  triggers: Criterion[]; effects: Effect[]; overcome: Criterion[];
  haptic: HapticPatternId; stage: 1 | 2 | 3;
}
interface RegressionEvent {                        // 사건 `loop.regressed`
  fromLoop: number; died: { at: GameTime; route?: LethalRoute; causes: CauseRef[]; roots: RootRef[] };
  carry: { memory: MemoryCard[]; skills: Record<SkillId, number>; talents: TalentId[];
           stress: number; traces: DeathTraceId[]; oaths: OathId[] };   // 오스 = 16 기억 속 맹세
  record: LoopRecord;
  sequence: { firstOfEra: boolean; rewindUnit: 'day' | 'month' | 'year'; showRecordInline: boolean };
}
interface LoopRecord {                             // §6.6
  loop: number; from: GameTime; to: GameTime; days: number;
  causeSentence: string;                           // 원인 사슬 → 16 문장 규칙
  carried: { counts: Record<'secret' | 'date' | 'word' | 'map', number>; samples: string[];
             skills: { id: SkillId; from: number; to: number }[]; trace?: DeathTraceId };
  leftBehind: { npc?: NpcRef; line: string }[];    // ≤ 4 + "너"
  built?: { line: string }[];                      // 1년 이상 회차의 2장
  tensionGraphRef?: string;                        // 18 §6.5
}
interface DriftRule { id: string; target: string; grade: DriftGrade; variants?: string[]; window?: [GameTime, GameTime]; p?: number }
```

- `first_loop` 프로파일 값은 18 문서의 `StorytellerProfile` 형식에 §3.3 표를 그대로 넣는다 (이 문서에 별도 타입을 두지 않는다).
- 회귀점 스냅샷 `origin.snapshot`은 시대 시작 때 한 번 만들어지고, **`loop.seed`만 바꿔** 매 회차 다시 쓴다. '흔들림·흩어짐' 요소는 스냅샷 로드 직후 `loop.seed`로 다시 굴린다.

| **해금이 깊이를 숨김** | 숙련자가 "이 게임은 얕다"고 오해 | 해금표 전체가 설정 메뉴 '기록'에 회색 칸으로 보인다 (이름만, 계기는 숨김). 두 번째 시대부터 전부 열림 |
| **첫 15분 텍스트 피로** | 모바일에서 긴 글 | 장면당 모바일 화면 1~2장 + 선택지. 첫 15분 동안 한 화면 18줄 이하 |
