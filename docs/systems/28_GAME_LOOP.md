# 28. 진행 루프 — 엔진들을 한 판으로

> 위치(24), 목표 행동(26), 반응 층(27), 카드(22), LLM(21)은 따로 검사만 돌던 부품이었다. 이 문서는 그것들을 **플레이할 수 있는 한 판**으로 묶는 규칙이다.
> 첫 판: 회색여울, 회귀점 AS 312 낙엽월 1일 18:30 절름발이 수탉.

- 엔진: `engine/game/game.mjs`(규칙), `prompts.mjs`(LLM 프롬프트·검증), `session.mjs`(한 판 = 엔진 + LLM + 저장), `reveal.mjs`(숨긴 사실의 공개 조건), `engine/llm/provider.mjs`(구독 CLI·API·가짜, 스트리밍)
- 실행: `prototypes/greyford/` (PC 서버 + 폰 화면)
- 검사: `node engine/game/test_game.mjs` (규칙), `node engine/game/test_session.mjs` (LLM 붙인 한 판, 가짜 LLM)

## 1. 저장 = 시드 + 행동 기록 (검토 #1 해결)
| 무엇 | 어떻게 |
|------|--------|
| 저장 | `{seed, loop, journal[], carry}` — 플레이어가 고른 행동과, LLM이 만든 것 중 엔진이 받아들인 기억만 |
| 불러오기 | 회귀점부터 기록을 **다시 재생**한다. 세계 상태(클로저·Map·덮어쓰기)를 직렬화할 일이 없다 |
| LLM 실패 되돌리기 | 마지막 기록을 빼고 재생. 판정도 시간도 흐르지 않은 것이 된다 |
| 주사위 | `hash(시드, 회차, 기록 번호)` — 다시 시도해도 같은 주사위. 재시도로 이득을 보지 못한다 |
| 회귀 | `carry`(수첩, 알게 된 사실 = 다음 회차의 '미래 기억', 죽음의 기록)만 넘기고 새 기록으로 |
| 비용 | 재생은 빠르다 (첫 달 기준 1초 미만). 길어지면 하루 단위 스냅숏을 둔다 (다음) |

## 2. 진실은 한 곳에 (검토 #2 해결)
| 전에는 | 이제 |
|--------|------|
| 브람의 돈 = 목표 행동 변수 `bram_coin`, 반응 층에는 따로 지갑 | **하나의 지갑** `state.purse` (못 단위). 목표 행동의 `coin`·`pay`, 시체 털기, 플레이어의 거래가 모두 같은 지갑. 헨릭이 받은 입막음 값은 실제로 헨릭의 지갑에 쌓인다 |
| 목격·소문은 반응 층 안에만 | 믿음은 세계 상태(`state.beliefs`). 목표 행동은 `believes npc kind 대상` 조건으로, LLM 장면은 "셋째에 대해 믿는 것"으로 같은 것을 읽는다 |
| LLM 기억의 인상은 대화 화면에만 | 받아들인 인상이 관계 수치로 → 반응 층이 "고발할까 침묵할까"를 정할 때 쓴다 |
| 공개 조건은 글 | 엔진이 판정하는 조건(§4) |

## 3. 시간이 흐르는 법 (검토 #4 해결)
| 행동 | 시간 |
|------|------|
| 말 걸기 1분, 대화 한 박자 5분, 물건 보이기 2분, 팔기 3분 | |
| 걷기 | 실제 거리 ÷ 80m/분 (24) |
| 뒤지기 10분, 시체 뒤지기 5분, 시체 숨기기 20분 | |
| 기다리기 60분, 자기 | 다음 04:40까지 → 점호 날이면 막사 사람들과 광장으로 끌려 나간다 |

시간이 흐르는 동안 30분마다 세계가 돈다 (목표 행동 → 반응 층). 그 사이 시각에 걸린 규칙:
- **점호** (05:00, 안식일 제외): 광장에 없으면 즈닉의 명단에 빈칸.
- **통금 순찰** (21:00·23:00·02:00): 막사 밖이면 은신 판정, 걸리면 몽둥이(아픔 +15)와 막사로 끌려감.
- **배고픔**: 하루에 한 칸.
- **수배 3 이상**: 낮에는 사람을 풀어 찾는다 — 막사·광장처럼 뻔한 곳은 금방, 비밀 장소·마을 밖은 느리게 (숨는 것이 길이다). 쫓는 윗선과 같은 자리에 있으면 붙잡힌다.
- 플레이어가 아는 것: 그 자리에서 일어난 공개 기록, 그리고 자기에 대한 것만.

## 4. 할 수 있는 것 (어포던스)
**장면**: 그 자리에 실제로 있는 사람에게 말 걸기 · 덤벼들기(자는 사람은 +20, 칼이 있으면 +10, 무장한 상대 −8) · 시체 뒤지기·숨기기 · 뒤져 보기(숨긴 물건) · 챙기기 · 다른 곳으로(출입 규칙: 공용·농노는 그냥, 주인·일꾼·닫힌 시간·비밀 장소는 **몰래** = 은신 판정, 실패하면 반응 층의 '숨어듦' 자극) · 기다리기 · 자기.
**대화**: 잡담(마음이 열리면 들은 소문 하나) · 주제를 묻기(플레이어가 **아는 이름만** 주제가 된다) · 숨긴 것을 들먹이기(위압) · 돈 건네기 · 물건 보이기 · 팔기 · 끝내기. 인내가 다하거나 화가 차면 상대가 끝낸다.
**자유 입력**: LLM이 위 행동 중 하나 + 논거 태그로 옮긴다 (21 §7). 판정은 엔진.

### 숨긴 사실의 공개 조건 (검토 #3)
카드의 `reveal_when`(사람이 쓴 글) 옆에 `reveal:`(엔진 조건)을 둔다. 대안(OR)들의 목록이고, 대안 하나 안의 항목은 모두 참이어야 한다.

| 항목 | 뜻 | 예 (글 → 조건) |
|------|----|----------------|
| `trust` / `like` | 신뢰·호감 이상 ("충성 아크 N" = 호감 N) | "신뢰 40 이상" → `{trust: 40}` |
| `tier` | 그 판정의 등급 | "판정 대성공(신뢰 10 이상)" → `{tier: 대성공, trust: 10}` |
| `dead` / `told_by` | 그 사람이 죽은 뒤 / 그 사람이 먼저 말해 준 뒤 | "헨릭이 죽거나 실각한 뒤" → `{dead: npc_henrik}` |
| `gift` | 건넨 돈(못) | "뇌물 은화 3닢" → `{gift: 36}` |
| `deja_vu` / `echo_known` | 시간에 민감한 존재의 기시감(회차마다 +10) / 잔향임을 눈치챔 | |
| `named` | 플레이어가 그 이름을 주제로 꺼냄 | "베라의 이름이 직접 나왔을 때" |
| `scene` / `player_offer` | 특정 장면 / 플레이어의 제안 | |
| `self` / `never` | 그가 스스로 꺼낸다 / 말로는 열리지 않는다(물건·장소·증언으로만) — 물어서는 열리지 않음 | |
| `flag: trial` / `flag: story` | 은자 시험 통과, 이야기의 한 장면 — 장면·목표 행동이 `vars["trial:<npc>"]`·`vars["story:<사실>"]`를 세운다 | |

`node tools/write_reveals.mjs` 가 글을 조건으로 옮겨 카드에 적는다 (이미 있으면 건드리지 않는다 — 사람이 고친 것이 정본). 지금 647개 중 **561개는 대화로 열리고**, 54개는 이야기 장면이 여는 열쇠(`story`), 13개는 말로는 열리지 않는다(`never`·`self`). `--check`로 목록을 본다.

## 5. LLM — 부르는 때와 아끼는 법 (검토 #5·6·7)
| | |
|--|--|
| 한 턴 | 서술 + 다음 선택지를 **한 번에**. 형식: `<서술>…</서술><선택지>{json}</선택지>` |
| 스트리밍 | 서술이 오는 대로 화면에 흐른다 (CLI `stream-json`, API stream → 서버 SSE). 체감 대기가 5~10초에서 1~2초로 |
| 부르지 않는 때 | 아무도 없는 곳으로 걷기, 아무 일 없이 기다리기·자기 → 엔진의 짧은 문장 |
| 선택지 문장 | 대화·말 걸기·덤비기만 LLM이 다듬는다. 이동·시간은 엔진 문장 (토큰 절약) |
| 카드 자르기 | 대화 상대만: 말투(셋째에게), 말버릇, 쓰는·안 쓰는 말, **장면에 맞는 견본 3개**, 마음, 셋째에 대해 믿는 것, 털어놓은 것, 숨긴 것의 **얼버무림만**, 기억 6개. 나머지 사람은 한 줄 |
| 검증 | 아직 모르는 이름이 서술에 나오면 다시 생성(2번), 선택지면 엔진 문장으로. 확률·수치 언급 금지 |
| 실패 | 기록을 되돌린다 — LLM이 없으면 게임은 진행되지 않는다 (21 §1) |

## 6. 대화 결과를 세계에 넣는 법 — 대화 에이전트와 기록관 (2026-10 결정)
- **대화(서술) 에이전트**: 빠르게, 문장과 선택지만. 플레이어가 기다리는 유일한 호출.
- **기록관 에이전트** (`session.mjs`의 기록관, `prompts.mjs`의 `recorderPrompt`): 대화가 끝난 뒤 **뒤에서** 돈다 — 플레이어는 기다리지 않는다. 대화를 *제안*으로 옮긴다: 기억·인상, 약속("내일 정오 방앗간"), 플레이어가 한 거짓말, NPC가 새로 안 것. 엔진이 대화 기록에서 근거를 확인하고 기록(journal)에 넣는다. 여러 대화를 묶어 한 번에, 더 싼 모델로.
- **세계선 에이전트는 두지 않는다.** LLM이 세계를 직접 바꾸면 같은 회차가 같게 흐르지 않아 회귀자의 기억이 쓸모없어지고, 재생 저장이 깨진다. 기록관의 제안이 **규칙을 통해서** 세계에 닿는다: 약속 → 그 NPC의 일정(덮어쓰기), 거짓말 → 반응 층의 믿음 → 소문으로 퍼짐, 새로 안 것 → 그 NPC의 지식.
- 기록관의 결과는 **턴과 턴 사이에만** 기록에 들어간다 — 진행 중인 턴이 실패해 되돌릴 때 섞이지 않게. 실패하면 2초·4초 뒤 다시, 세 번 실패하면 버린다 (게임은 멈추지 않는다 — 서술과 달리 기록관은 필수가 아니다).
- 약속 장소는 장소 이름과 별칭(`aka`)으로 찾는다 ("방앗간" → 물레방아간). 시각은 "오늘 밤·내일 정오·모레 새벽 다섯 시" 같은 말을 엔진이 읽는다. 못 읽으면 기억으로만 남는다.
- 검사: 근거 없는 제안은 버림, 약속 → 브람이 다음 날 정오 실제로 방앗간에 있음, 믿은 주장 → 이틀 안에 페인·게르다·즈닉에게 퍼짐, 플레이어가 모르는 사실을 '말해 주었다'는 제안은 버림.

## 6b. 살아남기 — 먹고, 숨기고, 수색을 넘긴다
| 규칙 | 내용 |
|------|------|
| 배고픔 | 하루에 한 칸 (0~4). 바닥(4)이면 날마다 아픔 +15, 아픔 100이면 죽는다 — **아무것도 먹지 않으면 열흘 안에 죽는다** |
| 저녁 배급 | 18:30~20:30 수탉, 브람이 있을 때 하루 한 번 (배고픔 −1) |
| 사기 | 상점 NPC와 대화 중 `buy` (content/base/economy). 값 = 기본 × 흥정(호감·신뢰 ±20%) × 굶주림월 먹을 것 ×3 × 장물 ×2. 장물아비(하겐·헨릭)만 칼·위조 통행증을 판다 — 그리고 당신이 무엇을 샀는지 안다(협박의 씨앗) |
| 쓰기·먹기 | 소지품의 `eat`·`use` (빵, 쑥 찜질약…) |
| 점호 몸수색 | 첫 회차 둘째 날 아침은 반드시 플레이어, 그 뒤는 셋 중 하나. 숨길 수 있는 것은 손재주 판정. 은화(동화 12닢 이상)는 절도 의심으로 빼앗기고 채찍, **무기·위조 문서는 수배 3** (WORLD_BIBLE §7.1) |
| 숨기기 | `stash` — 물건·동전을 그 장소 어딘가에 묻어 둔다. 몸에 지니지 않으면 수색에 걸리지 않는다. 숨긴 곳을 조사하는 사람이 찾을 수도 있다 |

검사에서 나온 장면: 하겐을 죽이고 칼과 동전을 지닌 채 잠들면, 다음 날 아침 점호에서 몸수색에 걸려 즈닉에게 붙잡힌다. 헛간에 숨겨 두고 가면 넘긴다.

## 6c. 세계의 구조가 움직인다
- **자리 승계** (`engine/sim/offices.mjs`, 23 §2.1): 사람이 죽으면 그 자리는 '후계·부·대리' 자리의 주인 → 실제 인물이 있는 첫 부하 자리 → 공석. 이은 사람은 다음 날 06시부터 전임자의 일과를 살고, 반응 층의 '윗선'이 된다. 점호는 감독관 *자리*의 일 — 즈닉이 죽으면 이은 사람이, 공석이면 점호도 없다. 승계는 공개 기록(소문의 재료).
- **장소의 상태** (content/base/places, 24 §3.7): 닫힘·통제·불탐. 그 기간 일과는 그곳에 가지 않고(집으로), 플레이어도 갈 수 없다. 목표 행동 효과 `close <장소> <날수> <이유>`·`burn <장소>`.
- **평판의 규모** (`engine/sim/reputation.mjs`, 10·21 §8): 평판은 저장하지 않는다 — 행적 + 그 행적을 아는 사람들(반응 층의 믿음)에서 계산한다. 아무도 모르면 퍼지지 않고, 누가 했는지 모르면 사건만 퍼진다. 마을(반나절) → 영지(크기 2 이상, 2~4일) → 지방(3, 1~2주) → 국가(4, 3~6주) → 대륙(5). 단계마다 계수(1·0.7·0.5·0.35·0.2)와 왜곡(과장·주체 바뀜·동기 바뀜·신원 흐림). 처음 보는 사람과의 화술에 그 집단의 시선이 ±8.
- **모든 NPC의 성향** (tools/build_content.py): 손으로 쓴 성향이 없는 사람은 카드의 성향 6축(용기→담력, 탐욕, 충성→의무)·기질 낱말(과묵·수다·의심)·관계(호감·신뢰→마음)에서 뽑는다. 고장마다 윗선 사슬(감독 → 기사 → 영주)과 신분별 돈도 뽑는다. 372명.

- **하루를 늘 하던 대로** (`routine_day`, 18 「기억대로 보낸다」): 저녁 배급 → 막사 → 잠 → 점호를 기록 하나로. LLM은 두세 문장 몽타주 한 번 — 그사이 주인공 눈앞에서 일어난 일만 짚는다. 긴 판에서 호출과 시간을 아끼는 기본 수단.

## 6c-2. 회색여울 밖으로 — 탈주와 검문
- 지도에서 이웃한 고장(까마귀 문 12시간, 용주 역참 16시간…)으로 `travel`. 그 고장이 '활성'이 되어 그곳 사람들이 보고 반응한다 (27 LOD).
- 주인공은 농노다: 점호에 두 번 빠진 채 마을 밖에 있으면 **탈주 노예** — 감독관이 바르그 조합에 현상금, 행적 '탈주'(크기 2)가 평판으로 퍼진다.
- 낯선 고장의 인간은 검문을 받는다: 들어서는 길목 35%, 그 뒤 낮에 시간마다 8%(밤 4%), 마을 밖·숨은 곳·인간 거처는 그 ¼. 통행증이 없으면 붙잡힌다. 위조 통행증(헨릭에게 동화 240닢)은 기만 판정 — 얼굴이 소문으로 닿은 고장이면 −10. 한 번 넘기면 하루는 다시 묻지 않는다. 윗선이 없는 고장(자유민의 늪 같은)은 묻지 않는다.
- 쫓는 사람(수배)은 자기 고장에서만 찾는다. 다른 고장에서는 검문과 소문이 그 일을 맡는다.
- 검사: 통행증 없이 까마귀 문에 간 12번 모두 이틀 안에 붙잡힌다. 탈주는 준비가 필요하다 (기만을 키우고, 진짜 통행증을 얻고, 숨을 곳을 알고).

## 6d. 성능
- 위치 엔진의 시각·날짜 해석을 기억해 두고(memo), 장면은 이 고장에 올 수 있는 사람만 본다(LOD) → 재생 1,217ms → 76ms (열흘), **한 달 450개 기록 재생 0.3초**. 일 년도 몇 초 — 하루 단위 스냅숏은 아직 필요 없다.
