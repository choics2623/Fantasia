## 1. 저장 = 시드 + 행동 기록 (검토 #1 해결)
| 무엇 | 어떻게 |
|------|--------|
| 저장 | `{seed, loop, journal[], carry}` — 플레이어가 고른 행동과, LLM이 만든 것 중 엔진이 받아들인 기억만 |
| 불러오기 | 회귀점부터 기록을 **다시 재생**한다. 세계 상태(클로저·Map·덮어쓰기)를 직렬화할 일이 없다 |
| LLM 실패 되돌리기 | 마지막 기록을 빼고 재생. 판정도 시간도 흐르지 않은 것이 된다 |
| 주사위 | `hash(시드, 회차, 기록 번호)` — 다시 시도해도 같은 주사위. 재시도로 이득을 보지 못한다 |
| 회귀 | `carry`(수첩, 알게 된 사실 = 다음 회차의 '미래 기억', 죽음의 기록)만 넘기고 새 기록으로 |
| 비용 | 재생은 빠르다 (첫 달 기준 1초 미만). 길어지면 하루 단위 스냅숏을 둔다 (다음) |

## 2. 진실은 한 곳에 (검토 #2 해결)
| 전에는 | 이제 |
|--------|------|
| 브람의 돈 = 목표 행동 변수 `bram_coin`, 반응 층에는 따로 지갑 | **하나의 지갑** `state.purse` (못 단위). 목표 행동의 `coin`·`pay`, 시체 털기, 플레이어의 거래가 모두 같은 지갑. 헨릭이 받은 입막음 값은 실제로 헨릭의 지갑에 쌓인다 |
| 목격·소문은 반응 층 안에만 | 믿음은 세계 상태(`state.beliefs`). 목표 행동은 `believes npc kind 대상` 조건으로, LLM 장면은 "셋째에 대해 믿는 것"으로 같은 것을 읽는다 |
| LLM 기억의 인상은 대화 화면에만 | 받아들인 인상이 관계 수치로 → 반응 층이 "고발할까 침묵할까"를 정할 때 쓴다 |
| 공개 조건은 글 | 엔진이 판정하는 조건(§4) |

## 3. 시간이 흐르는 법 (검토 #4 해결)
| 행동 | 시간 |
|------|------|
| 말 걸기 1분, 대화 한 박자 5분, 물건 보이기 2분, 팔기 3분 | |
| 걷기 | 실제 거리 ÷ 80m/분 (24) |
| 뒤지기 10분, 시체 뒤지기 5분, 시체 숨기기 20분 | |
| 기다리기 60분, 자기 | 다음 04:40까지 → 점호 날이면 막사 사람들과 광장으로 끌려 나간다 |

시간이 흐르는 동안 30분마다 세계가 돈다 (목표 행동 → 반응 층). 그 사이 시각에 걸린 규칙:
- **점호** (05:00, 안식일 제외): 광장에 없으면 즈닉의 명단에 빈칸.
- **통금 순찰** (21:00·23:00·02:00): 막사 밖이면 은신 판정, 걸리면 몽둥이(아픔 +15)와 막사로 끌려감.
- **배고픔**: 하루에 한 칸.
- **수배 3 이상**: 낮에는 사람을 풀어 찾는다 — 막사·광장처럼 뻔한 곳은 금방, 비밀 장소·마을 밖은 느리게 (숨는 것이 길이다). 쫓는 윗선과 같은 자리에 있으면 붙잡힌다.
- 플레이어가 아는 것: 그 자리에서 일어난 공개 기록, 그리고 자기에 대한 것만.

## 4. 할 수 있는 것 (어포던스)
**장면**: 그 자리에 실제로 있는 사람에게 말 걸기 · 덤벼들기(자는 사람은 +20, 칼이 있으면 +10, 무장한 상대 −8) · 시체 뒤지기·숨기기 · 뒤져 보기(숨긴 물건) · 챙기기 · 다른 곳으로(출입 규칙: 공용·농노는 그냥, 주인·일꾼·닫힌 시간·비밀 장소는 **몰래** = 은신 판정, 실패하면 반응 층의 '숨어듦' 자극) · 기다리기 · 자기.
**대화**: 잡담(마음이 열리면 들은 소문 하나) · 주제를 묻기(플레이어가 **아는 이름만** 주제가 된다) · 숨긴 것을 들먹이기(위압) · 돈 건네기 · 물건 보이기 · 팔기 · 끝내기. 인내가 다하거나 화가 차면 상대가 끝낸다.
**자유 입력**: LLM이 위 행동 중 하나 + 논거 태그로 옮긴다 (21 §7). 판정은 엔진.

### 숨긴 사실의 공개 조건 (검토 #3)
카드의 `reveal_when` 글을 엔진 조건으로 옮긴다: `{trust: 40}` · `{tier: "대성공", trust: 10}` · `{dead: npc_henrik}` · `{told_by: npc_thomas}` · `{like: 40, scene: 술자리, self: true}`(물어서는 열리지 않음). 카드에 `reveal:`이 있으면 그것을 쓴다.
지금 647개 중 540개가 자동으로 옮겨진다. 나머지 107개는 기본값(신뢰 50, 또는 대성공 + 신뢰 25)으로 돌며 `tools/check_reveals.py`가 목록을 뽑는다 (다음).

## 5. LLM — 부르는 때와 아끼는 법 (검토 #5·6·7)
| | |
|--|--|
| 한 턴 | 서술 + 다음 선택지를 **한 번에**. 형식: `<서술>…</서술><선택지>{json}</선택지>` |
| 스트리밍 | 서술이 오는 대로 화면에 흐른다 (CLI `stream-json`, API stream → 서버 SSE). 체감 대기가 5~10초에서 1~2초로 |
| 부르지 않는 때 | 아무도 없는 곳으로 걷기, 아무 일 없이 기다리기·자기 → 엔진의 짧은 문장 |
| 선택지 문장 | 대화·말 걸기·덤비기만 LLM이 다듬는다. 이동·시간은 엔진 문장 (토큰 절약) |
| 카드 자르기 | 대화 상대만: 말투(셋째에게), 말버릇, 쓰는·안 쓰는 말, **장면에 맞는 견본 3개**, 마음, 셋째에 대해 믿는 것, 털어놓은 것, 숨긴 것의 **얼버무림만**, 기억 6개. 나머지 사람은 한 줄 |
| 검증 | 아직 모르는 이름이 서술에 나오면 다시 생성(2번), 선택지면 엔진 문장으로. 확률·수치 언급 금지 |
| 실패 | 기록을 되돌린다 — LLM이 없으면 게임은 진행되지 않는다 (21 §1) |

## 6. 대화 결과를 세계에 넣는 법 — 대화 에이전트와 기록관 (2026-10 결정)
- **대화(서술) 에이전트**: 빠르게, 문장과 선택지만. 플레이어가 기다리는 유일한 호출.
- **기록관 에이전트** (`session.mjs`의 기록관, `prompts.mjs`의 `recorderPrompt`): 대화가 끝난 뒤 **뒤에서** 돈다 — 플레이어는 기다리지 않는다. 대화를 *제안*으로 옮긴다: 기억·인상, 약속("내일 정오 방앗간"), 플레이어가 한 거짓말, NPC가 새로 안 것. 엔진이 대화 기록에서 근거를 확인하고 기록(journal)에 넣는다. 여러 대화를 묶어 한 번에, 더 싼 모델로.
- **세계선 에이전트는 두지 않는다.** LLM이 세계를 직접 바꾸면 같은 회차가 같게 흐르지 않아 회귀자의 기억이 쓸모없어지고, 재생 저장이 깨진다. 기록관의 제안이 **규칙을 통해서** 세계에 닿는다: 약속 → 그 NPC의 일정(덮어쓰기), 거짓말 → 반응 층의 믿음 → 소문으로 퍼짐, 새로 안 것 → 그 NPC의 지식.
- 기록관의 결과는 **턴과 턴 사이에만** 기록에 들어간다 — 진행 중인 턴이 실패해 되돌릴 때 섞이지 않게. 실패하면 2초·4초 뒤 다시, 세 번 실패하면 버린다 (게임은 멈추지 않는다 — 서술과 달리 기록관은 필수가 아니다).
- 약속 장소는 장소 이름과 별칭(`aka`)으로 찾는다 ("방앗간" → 물레방아간). 시각은 "오늘 밤·내일 정오·모레 새벽 다섯 시" 같은 말을 엔진이 읽는다. 못 읽으면 기억으로만 남는다.
- 검사: 근거 없는 제안은 버림, 약속 → 브람이 다음 날 정오 실제로 방앗간에 있음, 믿은 주장 → 이틀 안에 페인·게르다·즈닉에게 퍼짐, 플레이어가 모르는 사실을 '말해 주었다'는 제안은 버림.

## 7. 검사 결과 (지금)
- 규칙(`test_game`): 회귀점 장면, 아는 이름만 주제, 재생 = 같은 세계, 되돌리기, 같은 주사위, 밤에 자는 하겐을 죽이고 털고 막사로 → 점호 → 사흘 안에 누군가 시체를 찾음, 수탉에서 사람들 앞에서 죽이면 고발 → 붙잡힘 → 회귀(하겐이 살아 있고 죽음의 기록이 남음), 지난 회차의 비밀로 몰아붙이면 '이상함' 기억, 기억 검증과 관계 반영, 기억도 재생됨.
- 한 판(`test_session`, 가짜 LLM): 서술 스트리밍, 대화 끝 = 호출 1, 빈 곳 걷기 = 호출 0, LLM 실패 → 기록 그대로 → 다시 시도로 이어짐, 자동 저장.
