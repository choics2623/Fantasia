# 16. 메아리와 맹세 — 결과가 원인을 부르고, 사람이 목표를 말한다
> 세계는 플레이어가 없는 동안에도 돈다 (00 규칙 ⑤ "대가는 늦게, 멀리서 온다"). 그런데 **늦게, 멀리서 온 대가는 플레이어 눈에는 그냥 '사건'으로 보인다.**
> 여섯 달 전의 선택이 이 장면을 만들었다고 아무도 말해 주지 않으면, 정교한 시뮬레이션은 무작위와 구별되지 않는다. 이 문서는 그 간극을 메우는 세 장치를 정의한다.
>
> | 장치 | 한 줄 | 해결하는 문제 |
> |------|-------|---------------|
> | **A. 메아리** | 결과가 도착할 때, 그 결과로 이어진 **플레이어 자신의 과거 선택**을 한 줄로 불러 준다 | 보이지 않는 시뮬레이션 |
> | **B. 당신이 없던 N년** | 아기로 다시 태어나 15~24년을 건너뛸 때, 그 사이 세계가 **당신의 사람들에게** 무엇을 했는지 보여 준다 | 시간 도약의 단절감, 다음 생애의 동기 부재 |
> | **C. 맹세** | 플레이어가 **스스로** 말하는 개인 목표. 증인이 듣고, 세계가 기억하고, 생애를 넘어 따라온다 | 샌드박스의 동기 부재, 퀘스트 목록 피로 |
>
> 세 장치는 같은 데이터 — **인과의 실(Causal Thread)** — 를 공유한다. 메아리는 실을 거꾸로 읽고, 당신이 없던 N년은 실을 요약하고, 맹세는 실의 끝에 플레이어가 미리 매듭을 지어 두는 것이다.
>
> **식별자 주의**: 영문 코드에서 `echo_*`는 이미 **잔향**(SCENARIOS §0.4 `echo_awakening`, `echo_signs`, `echo_misattribution`)이 쓰고 있다.
> 이 문서의 메아리는 코드에서 **`ripple_*`**, 인과의 실은 **`thread`**, 맹세는 **`oath`** 로 쓴다.

## 1. 목표
### 1.1 문제
| 문제 | 이 게임에서의 모습 | 장치 |
|------|--------------------|------|
| **보이지 않는 시뮬레이션** | 사실→소문→기억→세력→클락 연쇄(00 §3)는 대부분 화면 밖에서 일어난다. 플레이어는 "갑자기 바르그가 왔다"고만 느낀다 | 메아리 |
| **시간 도약의 단절** | 아기 환생(03 §4.1)은 15년 이상을 한 번에 건너뛴다. 돌아온 세계가 낯선 세계로만 느껴지면, 이전 생애의 노력은 증발한 것처럼 보인다 | 당신이 없던 N년 |
| **동기 부재** | 샌드박스 + 로그라이트 = "이번 생엔 뭘 하지?" 게임이 목표를 주면 퀘스트 목록이 되고, 안 주면 방황한다 | 맹세 |
| **설교의 유혹** | 결과를 보여 주다 보면 "당신 때문에"라는 훈계가 된다 (WORLD_BIBLE §0.2 위반) | 메아리 문장 규칙 (§3.4.3) |
### 1.2 참고 작품 — 가져올 것과 피할 것
| 작품 | 가져올 것 | 피할 것 |
|------|-----------|---------|
| Telltale 계열 "○○가 이것을 기억할 것이다" | 선택과 결과를 **이어 준다**는 약속 자체 | **즉시** 띄우는 알림 — 결과가 오기도 전에 원인을 표시하면 기대만 만들고 배신한다. 우리는 **결과가 도착한 뒤에만** 원인을 부른다 |
| *Pentiment* (시간 도약 후 마을) | 몇 년 뒤 같은 사람들이 늙고 죽고 원한을 품은 모습으로 돌아오는 무게 | 정해진 3막 구조 — 우리의 도약은 시뮬레이션 로그에서 생성된다 |
| *Crusader Kings* 연대기 · *Dwarf Fortress* 전설 모드 | 로그에서 이야기를 뽑아내는 생성 방식 | 사건 나열. 우리는 **정서 가중치로 고르고 줄인다** |
| *Disco Elysium* 생각 캐비닛 | 플레이어가 **스스로 고른** 내면의 목표가 능력이 되는 구조 | 목표를 메뉴로 고르는 감각 — 우리는 맹세를 **장면 안의 말**로 한다 |
| *Shadow of Mordor* 숙적 | 적이 나를 기억하고 맹세하는 것 | 적을 위한 시스템 (17 문서 몫) — 여기서는 '적의 맹세' 데이터만 공유한다 |
| *Frostpunk* 서약 | 약속을 공개적으로 하면 기대가 생기고, 못 지키면 불신이 온다 | 게이지와 타이머가 화면을 지배하는 것 — 맹세에는 진행 막대가 없다 |

## 2. 플레이어 경험 — 화면 장면
> 모바일 세로, 19 문서의 화면 구성(박자·기록 스크롤·선택지 영역)을 따른다. 판정 표기는 01·SCENARIOS 형식.
### 장면 1 — 큰 메아리: 에길의 매듭 (AS 313 해빙월 27일, 굶주린 언덕)
전제: 312년 낙엽월 2일, 플레이어는 수탉 지하의 가짜 벽이 에길의 기침 소리를 흘린다는 것을 알고, 밤새 진흙으로 다시 발랐다.
에길 가족은 낙엽월 말 잿빛 실로 남쪽에 닿았다. 그 소식은 엘사 → 옛 돌 고리 → 카스파르 → 까마귀 문 밀수꾼을 거쳐 서리 길 너머로 갔다 — **플레이어는 이 중간 고리를 모른다.**
```
┌──────────────────────────────────┐
│ ☁ 진눈깨비 · 아침 7시   굶주린 언덕 ≡ │
├──────────────────────────────────┤
│  늑대굴 입구의 눈이 반쯤 녹아        │
│  진창이 되었다.                    │
│  아래 골짜기에서 서른 남짓한 사람이   │
│  한 줄로 올라오고 있다. 맨 앞의     │
│  사내가 서리말로 무언가를 외치자     │
│  시그리드의 창끝이 내려간다.        │
│  "…'수탉 아래에서 온 말을 따라      │
│  왔다'고 한다." 시그리드가 당신을    │
│  본다. "에길이 보냈대. 남쪽에       │
│  닿았대. 살아서."                  │
│  사내가 품에서 실 한 가닥을 꺼낸다.  │
│  매듭이 다섯 개. 다섯 명.           │
│  〰 메아리 · 다섯 달 전             │
│    당신은 수탉 지하의 가짜 벽을       │
│    밤새 다시 발랐다.         [실 ▸] │
├──────────────────────────────────┤
│ ▸ 서른한 명을 들인다  (늑대굴 식량 ▮▯▯) │
│ ▸ 아이와 여자만 들인다               │
│ ▸ 브람에게 사람을 보낸다            │
│ ⋯ 다른 행동                        │
└──────────────────────────────────┘
```

`[실 ▸]`을 누르면 **실타래** 화면이 펼쳐진다.
```
┌──────────────────────────────────┐
│ 실타래 — 수탉 아래에서 온 말          │
├──────────────────────────────────┤
│ ● 312.9.2  낙엽월 2일    ⟪당신⟫     │
│ │ 수탉 지하의 가짜 벽을 다시 발랐다    │
│ ● 312.9.14 낙엽월 14일   ⟪목격⟫     │
│ │ 볼크의 사냥개가 수탉 앞에서         │
│ │ 냄새를 잃었다                     │
│ ● 312.9.27 낙엽월 27일   ⟪들음⟫     │
│ ┆ 에길 가족이 검은 굴뚝 숯막에        │
│ ┆ 닿았다 — 브람에게서               │
│ ▒ ????                ⟪모르는 고리⟫ │
│ ┆ 누군가 그 소식을 북쪽으로 옮겼다    │
│ ● 313.1.27 해빙월 27일   ⟪지금⟫     │
│   서리 길을 넘은 서른한 명            │
│   └ 북쪽의 흐름이 바뀌었다           │
├──────────────────────────────────┤
│  실선 = 본 것 · 점선 = 들은 것        │
│  ▒ = 아직 모르는 고리                │
└──────────────────────────────────┘
```
- 마지막 줄 "북쪽의 흐름이 바뀌었다"는 **클락 노드**의 표현이다 (북방 대탈주 클락이 '정착' 쪽으로 가중치 +1). 숫자는 보이지 않는다.
- `▒` 고리는 나중에 플레이어가 카스파르의 역할을 알게 되면 **채워진다** (§3.6 "고리가 채워졌다").
### 장면 2 — 맹세의 순간: 서리월 아흐레 (AS 312 서리월 9일, 채찍 기둥 광장)
전제: O-01 출신. 「명단」에서 키트를 빼내지 못했다.
```
┌──────────────────────────────────┐
│ ☁ 안개 · 새벽 5시   채찍 기둥 광장  ≡ │
├──────────────────────────────────┤
│  마흔 명이 두 줄로 서 있다. 발목에서  │
│  발목으로 쇠사슬이 이어진다.         │
│  키트는 열네 번째다.                │
│  즈닉이 머릿수를 세다 키트 앞에서     │
│  멈추고, 아이의 턱을 들어 이빨을     │
│  본다. "튼튼해. 1비늘 반."          │
│  어머니는 오지 못했다. 기침 때문에    │
│  일어나지 못했다. 키트가 줄 너머로    │
│  당신을 찾는다. 울지 않는다. 울면    │
│  맞는다는 걸 열 살은 안다.           │
│  사슬이 당겨진다. 용의 대로 남쪽으로. │
├──────────────────────────────────┤
│ ▸ 키트에게 달려간다    [운동] 무모하다 │
│ ▸ "저 아이 대신 저를."  [화술] 어렵다 │
│ ▸ 경비 손에 동화 세 닢을 쥐여 준다    │
│                      [흥정] 가망 없다 │
│ ▸ 키트의 눈을 보고 말한다:           │
│   "어디로 가든, 찾아서 여울강        │
│    이쪽으로 데려온다."              │
│ ▸ 고개를 숙인다                     │
└──────────────────────────────────┘
```

넷째 줄을 고르면: *키트가 고개를 끄덕인다. 한 번. 즈닉이 웃는다. "크릭 앞에서 맹세하는 무혈자라니. 내가 증인이다, 쥐새끼." 사슬이 움직인다.* 그리고 작게 `· 맹세록에 새겨졌다 — 키트`.
- 넷째 줄은 퀘스트 수락 버튼처럼 생기지 않았다. 다른 선택지와 같은 모양의 **말**이다. 보상 미리보기도, 아이콘도 없다.
- 증인: 키트(수혜자), 즈닉(적대 증인 — 맹세를 지키지 못하면 그가 조롱할 재료가 된다).
- "맹세록에 새겨졌다"는 한 생애의 **첫 세 번**만 표시된다. 그 뒤로는 기록 스크롤에만 남는다.
### 장면 3 — 짐작 메아리와 끊어진 실 (AS 312 긴밤월 15일 → 굶주림월 1일)
전제: 「명단」에서 플레이어는 헨릭에게 동화를 쥐여 주고 "키트 대신 다른 이름을" 적게 했다 (SCENARIOS O-01 선택지 4, 성공).
긴밤월 15일, 사라가 2차 매각 명단(31명, 굶주림월 3일 인도)에 **자기 이름이 있다**는 것을 알게 된다.
```
│  사라가 세탁장 잿물 통에 손을 담근    │
│  채로 말한다. "서른한 명 안에 제가    │
│  있대요." 갈라진 손바닥에서 피가      │
│  잿물로 번진다. "이상하죠. 지난달까진 │
│  없었는데."                        │
│  〰 메아리? · 짐작 · 두 달 전        │
│    당신은 헨릭에게 동화를 쥐여 주고,  │
│    명단의 이름 하나를 지우게 했다.    │
```
- **'짐작'** 메아리는 언제나 점선이고 물음표가 붙는다. 플레이어가 아는 것만으로 이은 실이다. 짐작 메아리의 약 절반은 맞고, 절반은 틀리다 (§3.7).
- 이 짐작은 **틀렸다.** 사라의 이름을 쓴 것은 마르타다 (CHARACTERS R02-11 비밀 ②: 명단 마지막 자리를 리즈 대신 사라로).

굶주림월 1일, 사라의 신뢰가 50을 넘은 밤:
```
│  "마르타 아주머니가 명단의 마지막     │
│  이름을 고쳐 쓰는 걸 봤어요. 그      │
│  자리에 원래 누가 있었는지도요."      │
│  〰 실이 끊어졌다                    │
│    사라의 이름은 당신에게서 오지      │
│    않았다.                          │
│    ─ 그러나 다른 실이 드러났다 ─      │
│    당신이 지운 이름 대신, 남 막사의    │
│    아홉 살 토비가 1차 명단에 올라     │
│    서리월 9일 남쪽으로 갔다.  [실 ▸]  │
```
- 짐작 메아리가 틀렸을 때 게임은 플레이어를 **안도시키지 않는다.** 대개 진짜 실이 함께 드러난다. 죄책감은 옮겨갈 뿐 사라지지 않는다 — 설교 없이, 사실만으로.
### 장면 4 — 생애를 넘는 맹세 (AS 328 파종월, 세렌 소금계단)
전제: 리사(1생애)는 키트에게 한 맹세를 지키지 못하고 313년에 죽었다. 인연이 없어 아기로 다시 태어났고, 15년 뒤 세렌 계약민의 몸(O-05)에서 깨어났다. 「당신이 없던 15년」(§4.5)에서 "다시 짊어진다"를 골랐다.
```
│  소금 나루 명부 4,112번. 스물여섯의    │
│  사내가 자루를 내려놓고 허리를 편다.   │
│  왼쪽 눈썹 끝이 갈라져 있다. 여섯 살   │
│  때 여울강 돌에 찧은 자리다. 당신은   │
│  그것을 안다. 알 리가 없는데.         │
│  ⟨리사⟩ 키트야.                     │
│  〰 메아리 · 한 생애 전, 당신이 리사   │
│    였을 때 — 당신은 사슬에 묶여 가는   │
│    키트에게 "찾아서 데려온다"고 말했다. │
├──────────────────────────────────┤
│ ▸ "키트." 이름을 부른다 (그는 당신을 모른다) │
│ ▸ 남은 빚 9두카트를 알아본다 ▸ 지나간다  │
```
- `⟨리사⟩`는 15 문서의 전생 목소리다. **맹세를 한 몸이 목소리가 되어** 맹세에 반응한다.
- "이름을 부른다"를 고르면 키트는 당신을 모르지만, 그 이름을 부른 낯선 사람을 경계한다. 그가 리사의 맹세를 들은 **증인**이기 때문에, 맹세를 지키는 순간 그는 "누나가 한 말을 네가 어떻게 아느냐"고 묻게 된다 → 잔향 징후 노출 판정 (§5.8).

## 3. 메아리 (Ripple)
### 3.1 인과의 실 — 무엇을 어떻게 추적하는가
00 문서의 흐름(사건 → 사실 → 소문 → 평판·관계·기억 → 세력 AI → 클락 → 세계 사건 → 선택지)의 **모든 화살표에 원인 꼬리표**를 붙인다.
#### 3.1.1 원칙: 상태 출처(provenance) — 특별 규칙 없이 자동으로
> 시스템마다 "이건 누구 때문" 코드를 넣으면 00 문서 규칙 ④(특별 규칙 금지)를 깬다.
> 대신 **세계 상태의 모든 키에 '마지막으로 쓴 사건(lastWriter)'** 을 기록한다.
> 어떤 시스템이 상태를 **읽고** 결정을 내려 새 사건을 만들면, 그 사건의 원인은 자동으로 **읽은 키들의 lastWriter** 가 된다.
```
사건 E가 생길 때:
  E.causes = { 그 결정을 내리며 읽은 상태 키들의 lastWriter } (기여도 가중치 포함)
  E.roots  = 부모들의 roots를 합쳐 링크 가중치를 곱한 뒤 상위 3개만 남김   ← 런타임 역추적 불필요
  E가 쓴 상태 키들의 lastWriter = E
```
- 스토리렛·대사 규칙·세력 AI·클락은 모두 "조건을 평가하는" 순수 함수다 (05 §9). 평가기가 **읽은 키 목록**을 돌려주면 끝이다.
- `roots`(플레이어 뿌리 상위 3개)는 사건 생성 시 **앞으로 전파**되므로, 메아리 판정 때 그래프를 거꾸로 탐색하지 않는다. 경로 전체 복원은 플레이어가 `[실 ▸]`을 눌렀을 때만 한다.
#### 3.1.2 고리의 종류와 기본 가중치
| 고리 종류 `kind` | 발생 시스템 | 예 | 기본 가중치 |
|------------------|-------------|-----|-------------|
| `choice` | 선택지 (02·05) | "가짜 벽을 다시 바른다" | **뿌리** (작자성 1.0) |
| `check` | 판정 결과 (01) | 화술 성공으로 헨릭이 이름을 바꿈 | **뿌리** (0.8) |
| `declined` | 개입 기회를 거절 (REGIONS §2.14 "개입 기회") | 이르마의 신고를 막을 기회를 지나침 | **뿌리** (0.4) |
| `nature` | 잔향의 본성 — 각성·징후·`echo_misattribution` | 깨어나는 순간 주변 아이가 같은 꿈을 꿈 | **뿌리** (0.3, §3.8) |
| `companion_act` | 동료가 관계 때문에 독자 행동 | 페인이 당신을 위해 증언함 | 0.6 |
| `fact` | 사실 생성 (08) | `fact_wall_replastered` | 0.95 |
| `rumor_hop` | 소문 전파 한 단계 (08·10) | 수탉 → 이르마 → 즈닉 | 0.85 (왜곡될수록 0.7) |
| `memory` | NPC 기억 태그 (05 §4.1) | `player_hid_refugees` | 0.9 |
| `npc_decision` | NPC 목표·스토리렛 발동 (08 §7.3) | 마르타가 보고를 미룸 | 읽은 키 기여도 비례 |
| `faction_tier` | 대응 단계 변화 (10 §5) | 레이번 위협도 1 → 2 | 위협도 기여 비례 |
| `clock_tick` | 월드 클락 분기 가중치 변화 | 북방 대탈주 '정착' +1 | 분기 가중치 기여 비례 |
| `world_event` | 클락이 낳은 세계 사건 | 2차 물결 300명 도착 | 0.9 |
- 경로 가중치 = 경로 위 고리 가중치의 곱. **0.25 미만인 경로는 메아리 후보가 아니다** (원인이 너무 흐리다).
- 확정 사건(REGIONS §2.14 "확정")은 플레이어가 손대지 않았다면 뿌리가 없다 → 메아리가 생기지 않는다. 플레이어가 개입 기회를 **명시적으로 거절**했을 때만 `declined` 뿌리가 붙는다.
### 3.2 메아리 가치 점수 — 의미 있는 것만 떠오르게
결과 사건이 **플레이어에게 인지되는 순간** (직접 목격, 또는 소문이 도착함 — `onPlayerLearns`) 그 사건의 `roots`를 꺼내 점수를 매긴다.

**`R = 100 × (0.25·D + 0.35·M + 0.25·A + 0.15·S) + 보정`** (최대 100)

| 항목 | 정의 | 계산 |
|------|------|------|
| **D 지연** | 뿌리 선택에서 **플레이어가 결과를 안 날**까지의 게임 일수 | `min(1, log2(1 + 일수) / 12)` → 1일 0.08 · 7일 0.25 · 30일 0.41 · 90일 0.54 · 1년 0.71 · 11년 이상 1.0 |
| **M 크기** | 결과 사건의 크기 (아래 표) | 0.1 ~ 1.0 |
| **A 작자성** | 뿌리 종류 계수 × √(경로 가중치) | 직접 선택 1.0 · 판정 0.8 · 동료 독자 행동 0.6 · 거절 0.4 · 본성 0.3 |
| **S 놀라움** | 0.5 × (선택 당시 이 결과가 **암시되지 않았음**) + 0.3 × (결과가 뿌리와 **다른 장소 또는 다른 인물**에서 일어남) + 0.2 × min(1, 뿌리의 주요 인물을 마지막으로 본 뒤 지난 일수 / 60) | 0 ~ 1. "암시"는 선택지 미리보기·판정 근거·대사에 결과가 언급되었는지 (`hintedAt`) |

**M 크기 표**

| M | 결과의 크기 |
|---|-------------|
| 0.1 | NPC 한 명의 대사 하나가 바뀜 (→ 05 문서 몫, 메아리 대상 아님) |
| 0.3 | 관계 ±10 이상, 가격·물건 하나, 소문 하나 |
| 0.5 | 이름 있는 NPC의 처지 변화 (팔림·풀림·부상·직위), 영역 수치 ±10, 비밀 하나가 드러남 |
| 0.7 | 이름 있는 NPC의 죽음·출생, 세력 대응 단계 변화, 칭호 생성, 무리(10명 미만)의 운명 |
| 0.9 | 10명 이상의 생사, 정착지 생성·파괴, 클락 **단계** 변화 |
| 1.0 | 찬가 단계 변화, 시대급 사건 |

**보정**

| 보정 | 값 | 이유 |
|------|----|------|
| 생애를 넘는 메아리 (뿌리의 몸 ≠ 현재 몸) | **+10** | 이 게임의 핵심 판타지 |
| 맹세와 연결된 결과 (§5) | +8 | 플레이어가 스스로 정한 목표 |
| 숙적의 탄생·귀환 (17) | +6 | |
| 같은 결과를 05 대사가 이미 명시적으로 언급함 (`과거_*` 개념 대사 발동) | **−25** | 중복 제거 — NPC가 이미 "네가 그때…"라고 말했으면 메아리는 조용히 |
| 메아리 빈도 설정 적게 / 많이 | −10 / +10 | 접근성 |

**문턱 (필수 조건: A ≥ 0.3 그리고 M ≥ 0.3)**

| R | 등급 | 표현 |
|---|------|------|
| 70 이상 | **큰 메아리** | 본문 뒤 한 박자 쉼(0.8초) + 낮은 단음 1회 + 메아리 줄. 실타래 자동 펼침은 하지 않음 |
| 50~69 | **메아리** | 메아리 줄 |
| 35~49 | **조용한 메아리** | 줄 없이 장면 끝에 `〰` 표식 하나. 기록 스크롤과 실타래 보관함에만 저장 |
| 35 미만 | 없음 | 인과는 저장되지만 표시하지 않음 |

**계산 예 (장면 1, 에길)**: 150일 → D 0.60 · 30명 생존과 정착 → M 0.9 · 직접 선택, 경로 0.62 → A 0.79 · 암시 없음, 다른 장소·인물, 오래 못 봄 → S 1.0
→ R = 100 × (0.150 + 0.315 + 0.197 + 0.150) = **81 → 큰 메아리**.

**반례 (메아리가 아닌 것)**: 어제 페인에게 빵을 줬고 오늘 페인이 정보를 준다 → D 0.08 · M 0.3 · A 1.0 · S 0.2 → R = 41 → 조용한 메아리. 즉각적인 반응은 05 문서(기억 태그 대사)의 일이다.
### 3.3 상한과 쿨다운 — 흔하면 무뎌진다
| 규칙 | 값 |
|------|-----|
| 한 세션(18 문서의 짧은 세션 단위)당 메아리 줄(큰 메아리 + 메아리) | **최대 3** |
| 한 세션당 큰 메아리 | **최대 1** |
| 한 세션당 생애를 넘는 메아리 | **최대 1** |
| 메아리 줄 사이 최소 간격 | 장면 6개 또는 실제 10분 |
| 게임 하루당 메아리 줄 | 최대 2 |
| 같은 뿌리에서 나온 메아리 줄 | 한 생애에 최대 3 (네 번째부터 조용한 메아리) |
| 한 장면에 메아리 줄 | 1 (둘 이상 겹치면 R 최고 하나, 나머지는 대기열) |

**대기열**: 상한에 걸린 메아리는 R 순으로 대기열에 들어간다.
- 다음 **쉼표**(밤 잠자리, 안식일, 이동 몰아 보내기의 끝)에 「밤의 메아리」로 최대 2개를 묶어 보여 준다.
- 대기 중 게임 하루마다 R −5. 50 아래로 떨어지면 조용한 메아리로 보관된다.
- 연출가(18)는 큰 메아리를 **최대 장면 2개까지** 붙잡아 긴장 곡선의 내리막(안도·여운 구간)에 놓을 수 있다. 결과 장면 자체를 늦추지는 않는다 — 메아리 줄만 늦춘다.
### 3.4 표현
#### 3.4.1 메아리 줄 (본문 안)
형식: `〰 메아리 · {지연 문구}` 다음 줄에 `{뿌리 문장}.`
- 위치: 결과 장면 본문의 끝, 선택지 바로 위 (SCENARIOS 「잔향의 각성」 블록과 같은 자리 규칙).
- 서체: 본문보다 한 단계 작고, 왼쪽에 실 모양 세로선. 19 문서 `{ripple|…}` 태그로 표시 형식을 넘긴다.
- **결과는 이미 장면이 보여 주었다. 메아리 줄은 원인만 말한다.** 중간 고리는 실타래에서만 보인다.
- 길이: 지연 문구 포함 **최대 2줄, 60자.** 뿌리 문장은 플레이어가 한 행동을 과거형 2인칭 평서문으로.

**지연 문구 규칙**

| 일수 | 문구 |
|------|------|
| 1~13 | "닷새 전", "열사흘 전" (고유어 날수) |
| 14~59 | "스무날 전", "마흔이레 전" — 길면 "한 달 반 전" |
| 60~364 | "두 달 전" ~ "열한 달 전" |
| 1년 이상 | "세 해 전, 겨울" (계절 부기) |
| 다른 생애 | "한 생애 전, 당신이 {몸 이름}였을 때" / "두 생애 전, …" / 네 생애 이상: "아주 오래전, 당신이 {몸 이름}였을 때" |
| 본성 뿌리 | "당신이 이 몸에서 처음 눈을 뜬 새벽" 등 각성 시점 기준 |
#### 3.4.2 실타래 (Thread view)
- 세로 시간선. 노드마다: **날짜(AS 연.월.일 + 달 이름)**, 확신 표지, 한 줄 설명(최대 22자 × 2줄).
- 확신 표지는 08 문서 인물 수첩과 같다: **본 것(실선 ⟪목격⟫) / 들은 것(점선 ⟪들음⟫) / 짐작(물음표 ⟪짐작⟫) / 모르는 고리(▒)**.
- **스포일러 금지 규칙**: 노드는 플레이어가 그 사건·사실을 알 때만(`known_by`에 플레이어) 내용이 보인다. 모르는 고리는 범주 힌트만 보인다 — "누군가 무엇을 보았다", "누군가 말을 옮겼다", "어떤 세력이 움직였다", "북쪽의 흐름이 바뀌었다".
- 모르는 고리가 4개를 넘으면 연속된 것은 "▒ × 3 — 당신이 모르는 일들"로 접는다.
- 노드 최대 9개 표시 (가중치가 낮은 중간 노드부터 접음). 뿌리와 결과는 항상 표시.
- 실타래에서 노드를 길게 누르면 관련 인물 수첩(08)·지도(07)로 이동한다. **실타래는 퍼즐이 된다** — 모르는 고리를 채우려고 사람을 찾아간다.
- 클락·세력 노드는 숫자 대신 세계 안의 말로: "레이번 성채가 사냥꾼을 불렀다"(대응 2단계), "북쪽의 흐름이 바뀌었다"(클락 가중치).
#### 3.4.3 문장 규칙 — 설교하지 않는다
| 규칙 | 예 (금지 → 허용) |
|------|------------------|
| 평가어 금지: 덕분에, 때문에, 잘했다, 잘못, 죄, 대가, 업보, 결국 | "당신 때문에 토마스가 맞았다" → "당신은 두 번째 바닥의 보리를 언덕으로 날랐다." |
| 감정 지시 금지: "가슴이 아프다", "뿌듯하다" | 감정은 장면 본문과 전생 목소리(15)가 맡는다 |
| 뿌리는 **플레이어가 실제로 고른 선택지의 내용**으로만 | 선택하지 않은 함의를 덧붙이지 않는다 |
| 결과를 반복하지 않는다 | 장면이 보여 준 결과를 메아리 줄이 다시 말하지 않는다 |
| 거절 뿌리는 "보았고, 지나쳤다"처럼 **행동으로** | "당신은 방관했다"(평가) → "당신은 일곱 번째 칼자국을 보았고, 아무 말도 하지 않았다." |

> 자동 검증(05 §7.4)에 메아리 금지어 목록을 추가한다.
#### 3.4.4 진동·소리
- **진동 없음** (19 원칙: 몸의 감각만 진동). 큰 메아리만 0.8초 침묵 + 낮은 단음 1회(1.2초, 저역 현). 생애를 넘는 메아리에서는 **그 몸의 주제 선율 첫 음** (19 §7.1).
### 3.5 생애를 넘는 메아리
- 뿌리의 `authorBody` ≠ 현재 몸이면 생애를 넘는 메아리다. 점수 +10, 세션당 1개.
- 지연 문구에 **그 몸의 이름**이 들어간다: "두 생애 전, 당신이 리사였을 때".
- 결과 속 NPC는 대개 **당신이 누구인지 모른다.** 메아리 줄 뒤에 이 한 줄을 붙일 수 있다 (작가 지정 시): "그는 당신이 누구였는지 모른다."
- 세계 안 계승(자녀·제자·동료로 이어짐)일 때 그 사람 자신의 기억도 섞인다 → 뿌리가 **새 몸이 원래 살던 삶**에 있을 수도 있다 (예: 페인으로 깨어났는데, 페인이 예전에 한 일). 이때 문구: "이 몸이 열네 살이었을 때, 페인은…" — 3인칭으로, 섞임을 드러낸다.
### 3.6 보지 못한 일의 메아리 — 소문으로 도착하는 결과
- 결과를 플레이어가 **소문으로** 들으면 「소문 메아리」. 실타래의 결과 노드 자체가 점선이다.
- 지연(D)은 "일어난 날"이 아니라 **"들은 날"** 기준. 실타래에는 두 날짜를 모두 적는다: `일어난 날 312.11.? · 들은 날 312.12.20`.
- 메아리 줄에 출처를 붙인다: `〰 소문 메아리 · 요한에게서`.
- 소문은 왜곡된다 (10 §4.1). 소문 메아리의 결과 노드는 **소문의 문장 그대로** 쓴다. 나중에 진실을 알면 노드가 실선으로 바뀌며 문장이 고쳐진다 — 이것도 「고리가 채워졌다」의 일종이다.
- **고리가 채워졌다**: 실타래의 `▒` 고리나 점선 노드가 나중에 확정되면 작은 메아리(상한 계산 시 0.5개)로 알린다.
  `〰 고리가 채워졌다 · 에길의 소식을 북쪽으로 옮긴 것은 카스파르였다.`
### 3.7 짐작 메아리와 거짓 메아리
> 사람은 원인을 짐작한다. 짐작은 자주 틀린다. 이것은 이 세계의 소문·인식 시스템(08 §3.3 `believed_false_by`)의 플레이어판이다.

**짐작 메아리 생성 조건**

1. 결과 C가 플레이어에게 인지되었는데, C의 `roots`에 작자성 0.3 이상인 플레이어 뿌리가 **없거나**, 있어도 그 경로에 모르는 고리가 50% 이상이다.
2. 플레이어가 아는 과거 행동 P 중 C와 **주제 꼬리표 2개 이상**을 공유하는 것이 120일 안에 있다 (같은 NPC, 같은 장소, 같은 물건·문서, 같은 세력).
3. 그러면 확률 35%로 P를 뿌리로 한 **짐작 메아리**를 띄운다: `〰 메아리? · 짐작 · {지연}`.

**거짓 메아리** = 2의 P가 실제로는 원인이 아닌 짐작 메아리.

| 규칙 | 값 |
|------|-----|
| 거짓 메아리는 **진짜 원인 사실(F)이 존재하고, 발견 가능할 때만** 생성 | F를 아는 살아 있는 NPC가 있고, 그 NPC에게 이르는 관계 경로가 있어야 함 |
| 동시에 열린 거짓 메아리 | 한 생애 최대 **1** |
| 한 시대 거짓 메아리 | 최대 **3** |
| 드러남 보장 | 생성 시 드러남 경로 1개 이상을 작가 데이터 또는 스토리렛 조건으로 확인. 없으면 생성 안 함 |
| 짐작 메아리 중 참의 비율 목표 | 약 50% (거짓만 나오면 플레이어가 표지를 무시하게 된다) |
| UI 정직성 | 짐작 메아리는 **언제나** 물음표·점선으로 표시. 게임은 확실하다고 말한 것을 뒤집지 않는다 — 플레이어의 짐작만 뒤집힌다 |

**드러남 연출: 「실이 끊어졌다」**
- 짐작 실이 거짓으로 판명되면 실타래에서 그 고리에 `✂`가 그어지고, 진짜 실이 **나란히** 펼쳐진다.
- 드러남은 대개 **이중**이다: "당신 때문이 아니었다"와 "그러나 이것은 당신 때문이었다"가 함께 온다 (장면 3: 사라 → 마르타, 그리고 토비). 순수한 면죄는 시대당 1회 이하로 제한한다.
- 반대 방향도 있다: **숨은 메아리** — 플레이어가 자기와 무관하다고 믿은 결과가 사실 자기에게서 나온 경우. 숨은 메아리는 처음엔 표시되지 않고(조용한 메아리로 보관), 진짜 실이 드러날 때 「실이 이어졌다」로 나타난다. §3.8의 잔향 메아리가 대표적이다.
### 3.8 잔향 메아리 — 당신의 본성이 만든 결과
- 잔향의 각성과 재능 사용은 근처 평범한 인간이 징후자로 오인될 확률 `echo_misattribution`을 올린다 (SCENARIOS §0.4). 이 오인으로 누군가 끌려가거나 불타면, 그 사건의 뿌리는 `nature`다.
- 작자성 0.3으로 낮지만 M이 크다 (처형 0.7). 대부분 **숨은 메아리**로 보관되었다가, 플레이어가 그 인과를 알게 되는 순간(이졸의 보고서, 엘사의 고백, 계시 R4 「기다림의 장부」) 한꺼번에 이어진다.
- 한 생애에 **최대 2개**만 줄로 보여 준다 (그 이상은 연대기의 "당신 대신 탄 사람들" 목록으로). ACH-57 「아무도 대신 타지 않았다」와 짝을 이룬다.
### 3.9 메아리 예시 — 회색여울 (최종 문장)
> 형식: 제목 · 등급 R (D·M·A·S) / 상황 / **메아리 줄 — 최종 문장, 줄바꿈은 `/`** / 실타래. R은 최대 100.

**M1. 첫 메아리 — 세 소나무의 매듭** · 메아리 R 69 (.37 · .7 · .89 · .87) — 권장: 생애의 첫 메아리 (14 문서와 맞출 것)
- 상황: 312.9.5 하겐이 세 소나무 그루터기에 탈주자 위치 매듭을 남긴다. 플레이어가 매듭을 풀어 다른 골짜기를 가리키게 다시 묶었다. 9.25 볼크의 대수색은 서쪽 골짜기에서 빈손으로 돌아오고, 저녁에 볼크가 수탉 앞에서 하겐의 멱살을 쥔다.
- **〰 메아리 · 스무날 전 / 당신은 세 소나무 그루터기의 매듭을 풀어, 다른 골짜기를 가리키게 다시 묶었다.**
- 실: ⟪당신⟫ 9.5 매듭 → ⟪들음⟫ 9.6 볼크의 사냥꾼이 매듭을 거둬 감 (페인) → ▒ 누군가 그 매듭을 읽었다 → ⟪목격⟫ 9.25 빈손의 사냥대, 하겐의 멱살

**M2. 큰 메아리 — 수탉 아래에서 온 말** · 큰 메아리 R 81 — 장면 1
- **〰 메아리 · 다섯 달 전 / 당신은 수탉 지하의 가짜 벽을 밤새 다시 발랐다.**
- 고리 채움 (카스파르 신뢰 40 이상): **〰 고리가 채워졌다 · 에길의 소식을 북쪽으로 옮긴 것은 카스파르였다.**

**M3. 거절의 메아리 — 일곱 번째 칼자국** · 메아리 R 54 (.21 · .9 · .34 · .55)
- 상황: 312.9.20 이르마의 지팡이에 일곱 번째 칼자국이 새로 생긴 것을 보았고 (`hintedAt`: 칼자국 = 확인한 길목), "이르마를 따라간다 / 페인을 이르마에게 데려간다"를 고르지 않았다 (`declined`). 9.24 안식일에 이르마가 즈닉에게 늑대굴을 신고하고, 9.25 대수색에 시그리드 무리 11명이 잡힌다.
- **〰 메아리 · 닷새 전 / 당신은 이르마의 지팡이에서 일곱 번째 칼자국을 보았고, 아무 말도 하지 않았다.**
- 실: ⟪당신⟫ 9.20 → ⟪들음⟫ 9.24 이르마가 초소에 다녀감 → ⟪짐작⟫ 즈닉이 볼크에게 → ⟪목격⟫ 9.25 사슬에 묶인 열한 명
- M1과 M3은 같은 생애에 함께 일어날 수 없다 — 매듭을 바꿨다면 수색은 서쪽으로 갔다.

**M4. 마르타의 침묵** · 큰 메아리 R 71 (.47 · .7 · .85 · .9)
- 상황: 10.23 플레이어가 리즈를 요한의 순례 행렬 맨 끝에 숨겨 루멘으로 보냈다. 12.10 마르타는 수탉 지하의 냄새를 맡고도 즈닉에게 가지 않는다. 플레이어는 마르타가 브람의 솥 옆에 말없이 빵 한 덩이를 놓고 가는 것을 본다.
- **〰 메아리 · 마흔이레 전 / 당신은 리즈를 요한의 순례 행렬 맨 끝에 세웠다.**
- 실: ⟪당신⟫ 10.23 → ⟪들음⟫ 11.10 행렬이 까마귀 문을 지남 → ▒ 누군가 마르타에게 말을 전했다 → ⟪목격⟫ 12.10 빵 한 덩이

**M5. 소문 메아리 — 루멘의 손가락 글씨** · 메아리 R 65 (.55 · .5 · .77 · 1.0)
- 상황: 9.11 플레이어가 요한의 목패 끈 안쪽에 오스릭의 필사본 석 장을 꿰매 넣었다. 12.20 돌아온 요한이 수탉에서 말한다: "루멘 하층 빨래터에선 아이들이 젖은 돌에 손가락으로 뭘 써요. 물이 마르면 지워지니까 괜찮대요. 제일 많이 쓰는 건 '나'래요." 플레이어는 루멘에 가 본 적이 없다.
- **〰 소문 메아리 · 요한에게서 · 석 달 전 / 당신은 요한의 목패 끈 안쪽에 필사본 석 장을 꿰매 넣었다.**
- 실: ⟪당신⟫ 9.11 → ▒ 까마귀 문 검문 → ▒ 바알카르 → ⟪들음⟫ 루멘, 아그네스 (일어난 날 긴밤월 중 · 들은 날 12.20) → "끊어진 고리가 조금 커졌다"

**M6. 생애를 넘는 메아리 — 아흔아홉 번째 수** · 큰 메아리 R 100 (.78 · .7 · 1.0 · 1.0, +생애 10 +숙적 6)
- 상황: 1생애 리사가 군나르에게 6개월 넘게 배워 비전 '아흔아홉 번째 수'를 받았다 (R02-21). 2생애, 원형장 투사(O-06)로 깨어나 첫 경기에서 몸이 그 수를 쓴다. 관중석의 그롬 노투사가 일어선다: "(그롬 전투어) 저건 군나르의 발이다. 백 번을 채우지 않고 달아난 놈의 발이다." 우르가쉬의 '탈주 투사의 제자들' 수배는 아직 살아 있다.
- **〰 메아리 · 한 생애 전, 당신이 리사였을 때 / 당신은 마구간 뒤에서 군나르에게 아흔아홉 번째 수를 배웠다.**

**M7. 생애를 넘는 메아리 — '물'** · 큰 메아리 R 100 (1.0 · .9 · .8 · .9, +생애 10)
- 상황: 리사는 흙바닥에 '물'을 쓴 페인의 "…맞다고 해 줘."에 "맞다"를 골랐다. 15년 뒤 늑대굴 셋째 동굴 벽은 **기억의 벽**(09)이 되었다. 맨 위에 서툰 글씨로 '리사', 그 아래 이름 백열둘.
- **〰 메아리 · 한 생애 전, 당신이 리사였을 때 / 당신은 흙바닥에 '물'을 쓴 페인에게, 맞다고 말해 주었다.** 덧붙는 줄: **그는 당신이 누구였는지 모른다.**

**M8. 잔향 메아리 (숨은 메아리) — 미카** · 메아리 R 65 (.7 · .7 · .3 · 1.0)
- 상황: O-01 각성(`echo_wake_serf`) 직후 남 막사의 여덟 살 미카가 "불타는 하얀 도시" 꿈을 말한다 (REGIONS §2.19-9). 313 태양월 이졸이 미카를 명단에 올리고, 미카는 잿빛 탑으로 간다. 그때는 표시 없음(조용히 보관). 이졸 충성 아크 30 장면에서 그가 말한다: "그 아이의 꿈은 그 아이 것이 아니었어요. 진짜가 가까이 있으면, 아이들이 그 꿈을 주워 꿔요. 탑에서 그걸 열 번 봤어요."
- **〰 실이 이어졌다 · 당신이 이 몸에서 처음 눈을 뜬 새벽 / 같은 새벽, 남 막사의 미카는 하얀 도시의 꿈을 꾸었다.**
- 뿌리 문장이 "당신은 …했다"가 아닌 유일한 형식. 플레이어는 아무것도 고르지 않았다.

**M9. 거짓 메아리 — 사라의 이름** · 짐작 → 실이 끊어짐 (장면 3)
- **〰 메아리? · 짐작 · 두 달 전 / 당신은 헨릭에게 동화를 쥐여 주고, 명단의 이름 하나를 지우게 했다.**
- **〰 실이 끊어졌다 / 사라의 이름은 당신에게서 오지 않았다. / ─ 그러나 다른 실이 드러났다 ─ / 당신이 지운 이름 대신, 남 막사의 아홉 살 토비가 1차 명단에 올라 서리월 9일 남쪽으로 갔다.**
- 진짜 실: `fact_martha_swapped_list` (9.3 이전, R02-11 비밀 ②). 드러남 경로: 사라 신뢰 50 / 리즈가 직접 말함 / 오스릭의 고해 누설(역린 — 거의 불가능). 토비는 이 선택이 C등급 인구에서 즉석 생성해 B등급으로 승격시킨 아이다 (08 §2).

## 4. 당신이 없던 N년
> 인연이 없어 아기로 다시 태어나면 15~24년이 흐른다 (03 §4.1, SCENARIOS §0.4). 깨어나기 직전, 잔향은 그 세월을
> **인연을 따라 건너는 꿈**으로 본다 — 이것이 이 요약의 세계 안 정당화다. 잔향은 인연을 따라 돌아오는 영혼이고,
> 그래서 **인연이 강한 사람일수록 선명하게, 약한 사람일수록 흐리게** 보인다. 증오도 인연이다.
### 4.1 구조
| 순서 | 카드 | 내용 | 항목 수 |
|------|------|------|---------|
| 0 | **표지** | "당신이 없던 {N}년" · 기간 · 지난 몸의 이름·출신·생몰 | — |
| 1 | **첫 문장** | 전체에서 정서 가중치가 가장 높은 항목 하나. 섹션과 무관 | 1 |
| 2 | **세상** | 클락 단계 변화, 지배자의 죽음, 지역 체제 변화 — 이 몸이 15년 동안 **들으며 자란** 공공의 일 | ≤ 3 |
| 3~5 | **당신의 사람들 / 당신의 땅 / 당신의 적** | 세 섹션은 **섹션 가중치 순**으로 정렬된다 (아래 §4.3) | 각 ≤ 4 |
| 6 | **당신의 전설** | 칭호·노래·가면의 운명, 아이들의 이름, 장부의 기록. 항상 마지막 — 닫는 섹션 | ≤ 3 |
| 7 | **지키지 못한 맹세** | 지난 생애에서 이어진 맹세 (§5.8). 「다시 짊어진다 / 내려놓는다」 | ≤ 3 |
| 8 | **눈을 뜬다** | 출신 선택 = "어느 몸에서 깨어날 것인가" (SCENARIOS §0.4) | — |
- **당신의 사람들**: 지난 몸들과 애정·신뢰 40 이상이었던 NPC, 가족(12), 제자.
- **당신의 땅**: 영역(09) — 개인 은닉처, 가문 영역, 인간의 영역. 숨긴 물건의 위치 (09 §1: "위치를 기억하면 되찾을 수 있다").
- **당신의 적**: 원한 −40 이하 NPC, 숙적(17), 대응 단계 2 이상이었던 세력, 잔향 사냥.
- 시간 도약 외에, 「몰아서 보내기」(03 §3.3)로 **30일 이상** 건너뛸 때는 같은 생성기로 **「계절 요약」**(사람들·땅 섹션만, 최대 3항목)을 만든다. 세션 시작 요약은 18 문서 몫이며 이것과 겹치지 않는다.
### 4.2 생성 파이프라인
```

```

|------|-----|
| 관련 NPC가 지난 몸(들)과 \|애정\| ≥ 40 또는 신뢰 ≥ 40 또는 기억 태그 강도 ≥ 3 | 키트, 사라, 브람, 볼크 |
| 플레이어 영역·가문·숨긴 물건 | 늑대굴, 셋째 동굴의 낫 |
| 플레이어 맹세의 대상·증인 (§5) | 키트, 즈닉 |
| 숙적 (17) | 볼크 |
| 플레이어의 칭호·별칭·노래 (10) | "여울은 얕아도 차갑다" |
| 월드 클락 **단계** 변화, 찬가 단계 변화 | 용황의 죽음 |
| 지난 생애의 실(플레이어 뿌리 가중치 ≥ 0.25)에서 이어진 사건 | 이졸의 보고서 |
### 4.3 정서 가중치와 순서
**`W = Rel × Mag × Final × Hook`**

| 인수 | 값 |
|------|-----|
| **Rel** 관련도 | 인물: 지난 몸과의 관계 강도 max(\|애정\|, 신뢰, 원한)/100 × 0.8^(몇 생애 전) · 영역 1.0 · 맹세 대상 1.0 · 숙적 0.9 · 세상(클락) 0.5 |
| **Mag** 크기 | §3.2 M 표와 같다 |
| **Final** 돌이킬 수 없음 | 죽음·출생·파괴 1.5 · 영구 신분 변화(팔림·풀림·혼인) 1.2 · 진행 중 1.0 |
| **Hook** 지금 할 수 있는 것 | 지금 살아 있고 찾아갈 수 있는 인물·회수 가능한 물건·열린 맹세로 이어지면 ×1.3 |
- **첫 문장** = 전체 W 최댓값. 단 세상 섹션 항목은 첫 문장이 될 수 없다 (첫 문장은 언제나 개인적인 것).
- **섹션 가중치** = 섹션 안 상위 2개 W의 합. 사람들·땅·적 세 섹션을 이 값 순서로 배치한다. 동점이면 사람들 → 땅 → 적.
- 섹션 안은 W 내림차순. 단 같은 인물의 항목은 병합되어 하나로 나온다.

**⑤ 앎의 정도 — 인연이 선명도를 정한다**

| 인연 강도 (지난 몸 기준 max(애정, 신뢰, 원한 절댓값)) | 표현 |
|------|------|
| 70 이상 | **선명** — 현재 처지, 장소, 숫자까지 |
| 40~69 | **흐림** — 마지막으로 공개된 사실까지 + 고리 문장 ("어디로 갔는지는 보이지 않는다") |
| 40 미만, 공공 정보 | **들은 것** — 이 몸이 자라며 들은 소문 그대로 (왜곡 포함, 점선) |
- 흐림과 들은 것 항목은 다음 생애에 **확인할 거리**가 된다 → 실타래의 `▒`와 같은 역할.
- 목표 비율: 선명 40% · 흐림 35% · 들은 것 25%. 전부 선명하면 발견할 것이 없고, 전부 흐리면 요약이 무의미하다.

## 5. 맹세 (Oath)
### 5.1 원칙 — 맹세는 퀘스트가 아니다
| 원칙 | 구현 |
|------|------|
| **말이다, 버튼이 아니다** | 맹세는 장면의 선택지 중 하나로, 다른 선택지와 같은 모양으로 나온다. 체크 표시·보상 미리보기·"새 목표" 팝업 없음 |
| **게임이 아니라 사람이 원하는 순간에** | 맹세 제안은 상실·불의·배신의 순간에만, 그것도 드물게 (§5.3). 아무 때나 하려면 맹세록에서 스스로 |
| **언제나 거절할 수 있다** | 맹세하지 않아도 불이익이 없다. 거절은 기록되지도 않는다 |
| **진행 막대가 없다** | 맹세록에는 "이야기된 것"만 쌓인다 (§5.5). 게이지·퍼센트·화살표 표지 없음 |
| **세계가 듣는다** | 증인이 기억하고 소문을 옮긴다. 보상과 벌의 대부분은 시스템 보너스가 아니라 **사람들의 반응**이다 |
| **잔향이 말한 것은 영혼에 남는다** | 맹세는 몸이 아니라 영혼이 한다 — 생애를 넘어 따라온다 (§5.8) |
### 5.2 유형 (6)
| 유형 | 동사 | 대상 | 지켜짐 조건 (판정 엔진) | 예 |
|------|------|------|--------------------------|-----|
| **지킨다** (protect) | 지킨다, 데려온다, 살린다 | 인물·무리·장소 | 대상이 기한(또는 생애) 끝까지 살아 있고 지정 상태(자유·안전·장소)에 있음 | "키트를 여울강 이쪽으로 데려온다" |
| **갚는다** (avenge) | 갚는다, 데려온다(심판대로), 죽인다 | 인물·세력의 일원 | 대상이 죽음 / 지정 처지(폭로·재판·추방)에 놓임. **플레이어 또는 플레이어가 움직인 자**에 의해 (경로 가중치 ≥ 0.3) | "울프를 죽인 자를 당신 앞에 데려온다" |
| **세운다** (build) | 세운다, 가르친다, 남긴다 | 영역·시설·사람 수 | 영역 수치·시설·인원 문턱 도달 (09) | "늑대굴에서 글을 아는 사람 서른" |
| **풀어준다** (free) | 풀어준다, 빼낸다 | 인물·무리 | 대상의 신분이 노예 → 탈주·자유민·계약 해지 | "굶주림월 사흘 전에 서른한 명을" |
| **배운다** (learn) | 배운다, 받는다, 안다 | 스킬·지식·진명 | 스킬 문턱 / 지식 획득 / 스승의 전수 이벤트 | "엘사가 죽기 전에 낱말 140개를 모두 받는다" |
| **무너뜨린다** (destroy) | 무너뜨린다, 불태운다, 끝낸다 | 장소·조직·문서·체제 | 대상 파괴 / 조직 와해 / 문서 소멸 | "목줄단의 명단을 불태운다" |
- 판정 엔진은 대상 상태를 세계 상태에서 읽는다 → **새 조건 코드 없음**. 맹세 데이터의 `fulfill` 조건식은 스토리렛 조건식(05)과 같은 문법이다.
### 5.3 선언 — 두 가지 길
#### 5.3.1 감정의 순간 — 맹세 제안
장면 안에 **맹세 줄**이 선택지 하나로 끼어든다. 맹세 제안 규칙(`OathPromptRule`)이 다음 계기에서 발동한다.

| 계기 | 조건 | 제안되는 유형 |
|------|------|---------------|
| **상실** | 애정 50 이상 NPC가 눈앞에서 죽음·팔림·끌려감 | 지킨다(남은 이) / 갚는다 / 풀어준다 |
| **불의** | 공개 처형·매질·매각을 목격, 희생자 중 이름 아는 자 1명 이상 | 갚는다 / 무너뜨린다 / 풀어준다 |
| **배신 발견** | 신뢰 40 이상 NPC의 배신 사실을 알게 됨 | 갚는다 |
| **임종의 부탁** | 신뢰 50 이상 NPC가 죽어 가며 부탁 (NPC 데이터 `dying_request`) | NPC가 정한 유형 (NPC에게 하는 맹세, §5.9) |
| **죽을 뻔함** | 체력 0 직전에서 살아남은 직후 | 세운다 / 배운다 ("살아남으면…") |
| **가르침의 문턱** | 스승이 비전 전수 조건을 말함 | 배운다 |

**빈도 상한**

| 규칙 | 값 |
|------|-----|
| 한 세션당 맹세 제안 | 최대 **1** |
| 맹세 제안 사이 | 게임 시간 5일 이상 |
| 한 생애당 맹세 제안 | 최대 **8** |
| 생애 시작 후 첫 실제 20분 | 제안 없음 (출신 첫 장면에 작가가 넣은 것은 예외) |
| 활성 맹세가 3개(상한)일 때 | 제안하지 않음 — 단 **임종의 부탁**은 예외 (그때는 "다른 맹세를 내려놓고" 선택지가 함께 나온다) |
| 같은 대상에게 이미 활성 맹세가 있을 때 | 제안하지 않음 |

**맹세 줄 문장 규칙**
- 따옴표 안에 **주인공이 실제로 하는 말**만. 유형 이름·"맹세" 같은 시스템 단어 금지 (장면 2 참고).
- 기한은 세계 안의 사건으로 말한다: "굶주림월 사흘 전에", "볼크가 다시 오기 전에", "재의 날이 오기 전에". 날짜 숫자 금지.
- 한 장면에 맹세 줄은 최대 1개. 위치는 마지막에서 두 번째 (마지막은 늘 "물러서는" 선택지).
- 맹세 줄이 다른 선택지의 행동과 합쳐질 수 있다: "▸ 사슬을 끊으며 말한다: …" — 행동 판정 + 맹세.
#### 5.3.2 맹세록에서 — 조용한 맹세
- 언제든 맹세록 → `새 맹세`. 고르는 것: 동사(유형) + 대상(인물 수첩·지도·지식에서 **아는 것만**) + 기한(없음 / 세계 사건 목록에서) + 거는 것(§5.4).
- 바로 등록되지 않는다. **다음 쉼표(밤 잠자리)에 「밤의 맹세」 짧은 장면**으로 말하게 된다: "그날 밤, 당신은 소리 내어 말한다."
- 그 자리에 동료가 있으면 **증인이 된다**. 혼자면 증인 없음 → 보상은 작지만 벌도 작다 (§5.6~5.7).
- 쿨다운: 조용한 맹세는 게임 시간 7일에 1회.
### 5.4 매개변수

```
┌──────────────────────────────────┐
│ 맹세록                      ≡    │
├──────────────────────────────────┤
│ 「어디로 가든, 찾아서 여울강 이쪽으로 │

│  증인 키트, 즈닉 · 말을 걸었다       │
│  · 서리월 19일 — 사슬 부두로 갔다 (요한)│
│  · 긴밤월 2일 — 세렌행 배 '젖은 소금'  │
│  · 오늘 — 즈닉: "쥐새끼는 아직 여기 있네." │
├──────────────────────────────────┤
│ 「굶주림월 사흘 전에, 서른한 명을…」  │
│  디트마르 앞에서 · 피를 걸었다        │
│  굶주림월 3일까지 — 아직 시간이 있다  │
├──────────────────────────────────┤
│ ▢ 지난 생의 맹세 (1) ▢ 당신을 향한 맹세 (2) │
│ ▢ 지켜진 · 깨진 맹세               │
└──────────────────────────────────┘
```
- 각 맹세 아래 쌓이는 줄 = 그 맹세의 대상·증인과 관련된 사건 중 플레이어가 **알게 된** 것. 실(thread)에서 자동 추출 (`oath.target`을 읽은 사건 중 `known_by` 플레이어).
- 기한은 숫자 대신 말로: "아직 시간이 있다"(기한까지 50% 이상) / "시간이 줄고 있다"(20~50%) / "곧이다"(20% 미만). 설정에서 날수 표시 가능.
- **선택지 표지**: 맹세를 직접 돕는 선택지에는 판정 표기 뒤에 작게 `· 맹세` (예: `[흥정] 어렵다 · 맹세`). 길게 누르면 어느 맹세인지. 보너스 수치는 판정 근거 미리보기(01 §4.3)에만.
- 증인의 생사가 바뀌면 증인 이름에 줄이 그어진다.

**쉬운 맹세 방지 (보상 농사 금지)**
- 맹세 시점에 **난이도 추정**을 한다: 연출가(18)의 시뮬레이션으로 기한 안 달성 확률 p를 어림.
- p ≥ 0.9이거나 맹세 후 게임 하루 안에 지켜지면 **사소한 맹세**: 업적·TP·칭호 진척 없음, 증인 반응은 "…그건 맹세할 일도 아니었잖아." (05 개념 `약속지킴` 의 `trivial` 변형)
- 이미 거의 끝난 일(대상 상태가 조건의 80% 이상 충족)은 맹세 대상이 될 수 없다.

### 5.7 깨짐
| 상태 | 언제 | 증인 반응 | 그 밖 |
|------|------|-----------|-------|
| **깨짐** | 맹세와 정면으로 어긋나는 선택을 직접 함 (키트를 지키겠다 해 놓고 키트를 판다) | 신뢰 −25, 애정 −10, 기억 `oath_broken:{id}` 강도 4 (반감기 2년), 05 개념 `약속어김` 대사 | 증인 집단 시선 −5, 이름을 걸었으면 −10 |
| **늦음** | 기한이 지났는데, 맹세를 돕는 행동을 2회 미만 시도 | 신뢰 −15, 기억 `oath_lapsed` 강도 3 | 깨짐으로 집계 (칭호 '말을 판 자') |
| **지키지 못함** | 기한이 지났거나 대상이 사라졌지만, 돕는 행동을 2회 이상 시도 | 신뢰 −5. 일부 증인(용기 +40 이상)은 존경 +5 — "애는 썼지" | 깨짐으로 집계하지 않음 |
| **꺼짐** | 대상이 플레이어와 무관하게 사라짐 (자연사, 플레이어가 개입할 기회가 없었음) | 반응 없음 | 맹세록에 "꺼진 맹세"로 보관 |
| **풀림** | 대상 인물이 스스로 맹세를 풀어 줌 (§5.9) | 신뢰 +5 | 벌 없음. ACH-O3 |

**두르강의 돌심장 (06)**
- 깨짐·늦음 1회마다 **체질 영구 −1** (06 규칙). '지키지 못함'도 돌에게는 깨짐이다 — 돌은 노력을 세지 않는다. '꺼짐'·'풀림'은 아니다.
- 깨질 때마다 몸 어딘가가 회색으로 굳는 묘사 1줄 (손끝 → 손등 → 손목 순). 두르강 NPC는 이것을 본다 → '맹세를 훔친 자' 노출 판정 +10 (06 사냥당할 이유).
- 깨진 뒤 30일 동안 의지 +10 보너스 꺼짐.

**페이의 그림자 (06 "맹세하면 반드시 묶임")**
- 활성 맹세와 정면으로 어긋나는 선택지는 **잠긴다**: `(묶여 있다)`. 풀려면 `[의지 D70]` — 성공하면 선택할 수 있고, 맹세는 깨진다.
- 깨지면 **페이 저주** 1개 (d6):

| d6 | 저주 | 지속 |
|----|------|------|
| 1 | 그림자가 반 박자 늦게 따라온다 — 은신 −10 | 30일 |
| 2 | 맹세의 증인 앞에서 진짜 이름을 말할 수 없다 — 그 증인 상대 화술 −10 | 생애 |
| 3 | 철에 닿는 통증 ×2 | 다음 맹세를 지킬 때까지 |
| 4 | 가시 왕관의 여왕이 당신의 이름을 듣는다 → 결점 '저주받은 이름' 획득 | 영구 (몸에 속함) |
| 5 | 고인 물과 거울에 비치지 않는다 — 잔향 징후 노출 판정 −10 | 90일 |
| 6 | 당신이 다음에 하는 거짓말 하나가 사실이 된다 (작가 스토리렛 `fae_lie_made_true`) | 1회 |
- 또한 페이의 그림자를 가진 몸은 **대사에서 한 약속도 작은 맹세가 된다**: 05 대사 규칙의 `then: promise` 효과가 붙은 선택지를 고르면 증인 1명(상대)짜리 작은 맹세로 자동 등록 (최대 5개 추적, 활성 맹세 상한에 포함되지 않음). 작은 맹세를 깨면 50% 확률로 저주 d6.
### 5.8 생애를 넘는 맹세 — 지키지 못한 맹세
1. 몸이 죽으면 활성 맹세는 모두 **'이어진 맹세'** 가 된다 (지켜짐·깨짐 판정 없음 — 죽음은 깨짐이 아니다).
2. 다음 몸에서 깨어날 때 (아기 환생이면 「당신이 없던 N년」 카드 7, 세계 안 계승이면 각성 장면 직후) 맹세마다 고른다:
   - **다시 짊어진다** — 활성 맹세로 돌아온다 (상한 3에 포함). 기한이 지난 맹세는 기한 없음으로 바뀐다.
   - **내려놓는다** — 벌 없음. 맹세를 한 몸의 목소리가 한 마디 한다 (⟨리사⟩ "…그래."). 연대기에 '내려놓은 맹세'로 남는다.
   - '영혼'을 건 맹세는 내려놓을 수 없다 — 자동으로 다시 짊어진다.
3. 따라잡기 시뮬레이션 동안 대상이 바뀐다: 대상이 죽었으면 '꺼짐'(누가 죽였는지 실타래로 보여 줌 — 갚는다 맹세로 이어 맹세할 계기가 된다). 대상이 이미 조건을 충족했다면(누군가 대신 키트를 풀어 줌) '다른 손이 지켰다' — 그 손이 누구인지 실타래로.
4. **증인은 몸을 기억한다.** 새 몸으로 맹세를 지키면 원래 증인들은 "리사의 맹세를 아는 낯선 사람"을 본다:
   - 증인 앞에서 지키면 그 증인의 `통찰 vs 플레이어 기만` 판정 — 실패 시 증인이 "당신은 누구냐"고 묻는 장면 (10 §3.2 "나는 돌아왔다" 정체 공개의 선택지가 열림).
   - 증인이 이졸·마르타·볼크 같은 사냥 쪽 인물이면 `echo_signs` +5 (SCENARIOS 맹약회의 변수).
   - 이것이 '돌아와서 갚은 자' 칭호의 대가다.
5. 한 시대에 이어진 맹세는 최대 6개까지 보관. 넘치면 가장 오래된 것부터 '바래진 맹세'로 연대기에만 남는다.
### 5.9 NPC에게 하는 맹세, NPC가 하는 맹세
#### 5.9.1 플레이어가 NPC에게 (부탁받은 맹세)
- NPC 데이터의 `asks_oath` (임종의 부탁, 스승의 조건, 동료 아크의 문턱)에서 제안된다. 그 NPC는 **수혜자이자 증인**이다.
- 그 NPC가 살아 있으면 맹세를 **풀어 줄** 수 있다 (`release_condition`): 예) 군나르는 플레이어가 그롬마르행 대신 브란을 지키는 쪽을 고르면 "…100번째는 내 몫이다. 놓아 줘라." → 풀림, ACH-O3.
- 그 NPC가 죽은 뒤 지키면, 그 NPC의 가장 가까운 사람(08 관계 최댓값)이 대신 반응한다.
#### 5.9.2 NPC가 플레이어에게 (당신을 향한 맹세)
| 항목 | 규칙 |
|------|------|
| 발생 | 동료 충성 아크 문턱(CHARACTERS의 "충성 아크 70" 대사가 대개 맹세다), 구해 준 NPC, 적의 맹세 (17) |
| 받는 이 | `body`(그 몸에게) / `returner`(잔향에게 — 정체를 아는 NPC만) / `legacy`(그 몸의 가족·영역에게) |
| 지킴 판정 | **압박 지점**(`pressure_points`)마다: `p = clamp(0.5 + 충성/200 + 정직/400 + 신뢰/200 − 압박, 0.05, 0.98)`. 압박 = 그 지점에 정의된 값 (굶주림 0.2, 가족 위협 0.5, 고문 0.4 등) |
| 플레이어가 죽으면 | `body` 맹세 → `legacy`로 바뀌어 남은 이들에게 이어지거나(성향 충성 +50 이상), 꺼진다 / `returner` 맹세는 영혼을 따라온다 |
| 표시 | 맹세록 「당신을 향한 맹세」. 적의 맹세는 그 존재를 **알 때만** 보인다 (소문으로 들었으면 점선) |
| 메아리 | NPC가 맹세를 지키거나 깬 결과는 플레이어 뿌리(그 NPC를 그렇게 만든 선택)로 메아리가 된다 |
### 5.10 어두운 맹세
- 대상 범위에 **비전투원·아이·한 종족 전체·이름 모를 다수**가 들어가는 맹세. 데이터 `scope: all` 또는 `includes_noncombatants: true`.
- 제안 조건 (둘 중 하나): 자비 −20 이하, 또는 애정 40 이상 인물 5명 이상이 한 번에 처형되는 것을 목격.
- 게임은 판단하지 않는다 (WORLD_BIBLE §0.2, 13 문서). 결과는 세계 안에서:
  - 증인은 자기 성향으로 반응한다: 디트마르 신뢰 +20 ("이제야 말이 통하네") / 사라 신뢰 −30, 자비 +40 이상 동료는 이탈 판정 / 브란은 '고드릭'이 대상에 들어 있으면 +25.
  - 지키면 13 문서 '학살자' 경로 효과: 대상 세력 위협도 +1~2, 칭호 '피로 맹세한 자', 연합 대응 위험.
  - 대상 안에는 **인간도 있을 수 있다** — 레이번 성채의 인간 하인 38명. 맹세의 말은 그들을 빼지 않았다. 지킬 때 그 장면이 온다.
  - 몇 해 뒤의 메아리: 살아남은 자식이 숙적(17)이 되어 돌아온다.

## 7. 기존 시스템 연동
| 시스템 | 이 문서가 **읽는** 것 | 이 문서가 **쓰는** 것 |
|--------|------------------------|------------------------|
| **00 연동도** | 사건 버스, 세계 상태 | 모든 사건에 `causes`·`roots` 필드, 상태 키 `lastWriter` (엔진 공통 규약) |
| **01 판정** | 판정 결과(뿌리 `check`), 성향 | 맹세의 힘 +5/+8, 지킨 순간 스트레스 −20·용기 +3 |
| **02 선택지** | 선택지 id, 미리보기 내용(`hintedAt`) | 선택지 데이터의 `root_phrase` 필드, `· 맹세` 표지 |
| **03 계승** | 죽음, 영혼 이동 대상, 따라잡기 시뮬레이션 로그, 연대기 | 「당신이 없던 N년」, 이어진 맹세, 연대기의 '내려놓은 맹세'·'당신 대신 탄 사람들' |
| **05 대사** | 기억 태그 대사 발동 여부(중복 제거 −25), `then: promise` | 개념 `약속지킴`·`약속어김`·`맹세들음`(신규) 대사 조건 `memory has oath_*`, 메아리 금지어 검증 |
| **06 생성** | 신체 특질: 두르강의 돌심장, 페이의 그림자, 진짜 이름 | 체질 영구 −1, 페이 저주, 진짜 이름 공개(이름을 건 맹세) |
| **08 관계·사실** | 관계 강도, `known_by`, 사실, 승격 규칙 | 기억 태그 `oath_heard/kept/broken/lapsed`, 신뢰·애정 변화, C→B 승격(증인·토비) |

## 10. 수직 슬라이스 범위
### 반드시 들어갈 것
- **인과의 실 엔진**: 모든 사건의 `causes`/`roots`, 상태 출처(`lastWriter`). — 이것이 없으면 나머지가 전부 수작업이 된다.
- 메아리 점수식, 문턱 4단계, 세션 상한과 대기열, 「밤의 메아리」.
- 메아리 줄 + 실타래 (목격·들음·짐작·▒ 표지, `known_by` 게이트). 「고리가 채워졌다」.
- 소문 메아리, 거절 뿌리(`declined`) — REGIONS §2.14의 개입 기회 30개에 연결.
- 짐작 메아리와 거짓 메아리 **1건** (M9 사라의 이름) — 드러남 장면 포함.
- 잔향 메아리 **1건** (M8 미카).
- 맹세: 6유형 판정, 감정의 순간 제안(계기 상실·불의·임종의 부탁·스승 문턱 4종), 맹세록(조용한 맹세 포함), 증인 기억·반응, 깨짐/늦음/지키지 못함/꺼짐/풀림.
- 맹세 데이터 10개(§5.11), NPC 맹세 8개, 적의 맹세 1개(볼크 — 17과 공유).
- 이어진 맹세 (죽음 → 다음 몸에서 다시 짊어진다/내려놓는다).
- 「당신이 없던 N년」 생성기 — 슬라이스에서도 인연 없는 죽음은 일어난다. 사건 유형 25개, §4.5 수준의 결과물.
- 두르강의 돌심장 맹세 규칙 (06 문서에 이미 있음).
### 나중으로 미룰 것
- 페이의 그림자 저주 표와 작은 맹세 (페이 지역·출신이 생길 때).
- 생애를 넘는 메아리의 **다른 지역판** (원형장 M6 등) — 슬라이스에서는 회색여울 안에서 두 번째 생애가 이어지는 경우만.
- 어두운 맹세의 전체 반응 세트 — 슬라이스에서는 `oath_raven_keep_ashes` 1개만.
- '영혼'을 건 맹세의 적대 목소리 (15 문서 완성 후).
- 「계절 요약」(30일 이상 몰아서 보내기).
- LLM 이야기꾼 모드의 요약 다듬기.
- 업적 O2·O4·O5 (시대 단위 플레이가 필요).
