# 16. 메아리와 맹세 — 결과가 원인을 부르고, 사람이 목표를 말한다
> 세계는 플레이어가 보지 않는 곳에서도 돈다 (00 규칙 ⑤ "대가는 늦게, 멀리서 온다"). 그런데 **늦게, 멀리서 온 대가는 플레이어 눈에는 그냥 '사건'으로 보인다.**
> 그리고 이 게임에는 하나가 더 있다. 주인공은 죽으면 낙엽월 1일 저녁 배급 줄로 돌아가고(WORLD_BIBLE §1.3.1), 세계는 모든 것을 잊는다. **기억하는 것은 주인공뿐이다.**
> 지난 회차에 본 것으로 이번 회차를 바꿨을 때, 그 결과가 '지식 덕'인지 '운'인지 아무도 말해 주지 않으면 회귀는 무작위와 구별되지 않는다. 이 문서는 그 간극을 메우는 세 장치를 정의한다.
>
> | 장치 | 한 줄 | 해결하는 문제 |
> |------|-------|---------------|
> | **A. 메아리** | 결과가 도착할 때, 그 결과로 이어진 **플레이어 자신의 과거 선택**을 한 줄로 불러 준다. 그 선택이 **지난 회차의 기억**에서 나왔다면 그것도 | 보이지 않는 시뮬레이션, 보이지 않는 기억의 힘 |
> | **B. 회차 비교 「두 겹의 날」** | 지난 회차의 같은 날·같은 사람과 이번 회차를 **나란히** 보여 준다. 주인공이 그때 알았던 것만 | 회귀의 단절감, "무엇이 달라졌나"의 불투명, 기억의 불확실성 |
> | **C. 맹세** | 플레이어가 **스스로** 말하는 개인 목표. 증인이 듣고, 세계가 기억한다 — 그 회차 안에서는. 회귀하면 **증인은 잊었다, 나는 기억한다** | 샌드박스의 동기 부재, 퀘스트 목록 피로, 회차를 넘는 목표 |
>
> 세 장치는 같은 데이터 — **인과의 실(Causal Thread)** 과 **기억의 출처(Memory Provenance)** — 를 공유한다. 메아리는 실을 거꾸로 읽고, 회차 비교는 회차마다 남긴 실을 겹쳐 보고, 맹세는 실의 끝에 플레이어가 미리 매듭을 지어 두는 것이다.
>
> **식별자 주의**: 영문 코드에서 `echo_*`는 이미 **잔향**(SCENARIOS §0.4 `echo_awakening`, `echo_signs`, `echo_misattribution`)이 쓰고 있다.
> 이 문서의 메아리는 코드에서 **`ripple_*`**, 인과의 실은 **`thread`**, 회차 비교는 **`loop_compare`**, 맹세는 **`oath`** 로 쓴다.
> **용어**: 주인공에 관해서는 '생애' 대신 **회차**를 쓴다 (NPC의 일생은 생애라 해도 된다). 회차·회귀점·회차 기록은 14 문서 머리말을 따른다.

## 1. 목표
### 1.1 문제
| 문제 | 이 게임에서의 모습 | 장치 |
|------|--------------------|------|
| **보이지 않는 시뮬레이션** | 사실→소문→기억→세력→클락 연쇄(00 §3)는 대부분 화면 밖에서 일어난다. 플레이어는 "갑자기 바르그가 왔다"고만 느낀다 | 메아리 |
| **보이지 않는 기억의 힘** | 두 번째 회차에 볼크의 수색을 피했다. 그런데 그게 지난번에 본 개들의 방향 덕인지, 이번엔 그냥 운이 좋았는지 모른다 | 회차를 넘는 메아리 (§3.5) |
| **회귀의 단절** | 회귀하면 사람·관계·영역이 전부 처음으로 돌아간다. 지난 회차가 증발한 것처럼 느껴지고, 이번 회차가 지난번과 무엇이 달랐는지 흐려진다 | 회차 비교 |
| **기억의 불확실성** | 시간의 표류(14 §7.1)로 작은 일들이 매번 어긋난다. 무엇이 믿을 만한 기억인지 모르면 지식이 짐이 된다 | 회차 비교의 같음·달라짐·어긋남 표기 (§4.4), 어긋난 메아리 (§3.5.2) |
| **동기 부재** | 샌드박스 + 회귀 = "이번 회차엔 뭘 하지?" 게임이 목표를 주면 퀘스트 목록이 되고, 안 주면 방황한다 | 맹세 — 그리고 지키지 못한 맹세가 다음 회차의 목표가 된다 |
| **설교의 유혹** | 결과를 보여 주다 보면 "당신 때문에"라는 훈계가 된다 (WORLD_BIBLE §0.2 위반) | 메아리 문장 규칙 (§3.4.3) |
### 1.2 참고 작품 — 가져올 것과 피할 것
| 작품 | 가져올 것 | 피할 것 |
|------|-----------|---------|
| Telltale 계열 "○○가 이것을 기억할 것이다" | 선택과 결과를 **이어 준다**는 약속 자체 | **즉시** 띄우는 알림. 우리는 **결과가 도착한 뒤에만** 원인을 부른다. 그리고 우리 세계에서 "기억할 것"은 아무도 없다 — 주인공 말고는 |
| *Majora's Mask* 봄버즈 수첩 | 사람마다 사흘의 일정을 기록해 **다음 사흘**에 개입하는 구조 | 체크 표시로 끝나는 진행 목록. 회차 비교는 사람의 **두 겹의 운명**을 보여 준다 |
| *Outer Wilds* 우주선 기록 | 루프를 넘어 쌓이는 **지식 지도**, 모르는 것이 '?'로 남는 정직함 | 지식만 남고 감정이 남지 않는 것. 우리는 증인이 잊은 맹세를 주인공이 지고 간다 |
| *Crusader Kings* 연대기 · *Dwarf Fortress* 전설 모드 | 로그에서 이야기를 뽑아내는 생성 방식 | 사건 나열. 우리는 **정서 가중치로 고르고 줄인다** |
| *Disco Elysium* 생각 캐비닛 | 플레이어가 **스스로 고른** 내면의 목표가 능력이 되는 구조 | 목표를 메뉴로 고르는 감각 — 우리는 맹세를 **장면 안의 말**로 한다 |
| *Shadow of Mordor* 숙적 | 적이 나를 기억하고 맹세하는 것 | 적을 위한 시스템 (17 문서 몫) — 여기서는 '적의 맹세' 데이터만 공유한다 |
| *Frostpunk* 서약 | 약속을 공개적으로 하면 기대가 생기고, 못 지키면 불신이 온다 | 게이지와 타이머가 화면을 지배하는 것 — 맹세에는 진행 막대가 없다 |

## 2. 플레이어 경험 — 화면 장면
> 모바일 세로, 19 문서의 화면 구성(박자·기록 스크롤·선택지 영역)을 따른다. 판정 표기는 01·SCENARIOS 형식. 기억 표지(◈ 기억 선택지 · ┊ 기억 잉크 · ◇ 기억과 다름)는 14 §7.5.
### 장면 1 — 큰 메아리: 에길의 매듭 (AS 313 해빙월 27일, 굶주린 언덕 · 회차 안)
전제: 312년 낙엽월 2일, 플레이어는 수탉 지하의 가짜 벽이 에길의 기침 소리를 흘린다는 것을 알고, 밤새 진흙으로 다시 발랐다.
에길 가족은 낙엽월 말 잿빛 실로 남쪽에 닿았다. 그 소식은 엘사 → 옛 돌 고리 → 카스파르 → 까마귀 문 밀수꾼을 거쳐 서리 길 너머로 갔다 — **플레이어는 이 중간 고리를 모른다.**
```
┌──────────────────────────────────┐
│ ☁ 진눈깨비 · 아침 7시   굶주린 언덕 ≡ │
├──────────────────────────────────┤
│  늑대굴 입구의 눈이 반쯤 녹아        │
│  진창이 되었다.                    │
│  아래 골짜기에서 서른 남짓한 사람이   │
│  한 줄로 올라오고 있다. 맨 앞의     │
│  사내가 서리말로 무언가를 외치자     │
│  시그리드의 창끝이 내려간다.        │
│  "…'수탉 아래에서 온 말을 따라      │
│  왔다'고 한다." 시그리드가 당신을    │
│  본다. "에길이 보냈대. 남쪽에       │
│  닿았대. 살아서."                  │
│  사내가 품에서 실 한 가닥을 꺼낸다.  │
│  매듭이 다섯 개. 다섯 명.           │
│  〰 메아리 · 다섯 달 전             │
│    당신은 수탉 지하의 가짜 벽을       │
│    밤새 다시 발랐다.         [실 ▸] │
├──────────────────────────────────┤
│ ▸ 서른한 명을 들인다  (늑대굴 식량 ▮▯▯) │
│ ▸ 아이와 여자만 들인다               │
│ ▸ 브람에게 사람을 보낸다            │
│ ⋯ 다른 행동                        │
└──────────────────────────────────┘
```

`[실 ▸]`을 누르면 **실타래** 화면이 펼쳐진다.
```
┌──────────────────────────────────┐
│ 실타래 — 수탉 아래에서 온 말          │
├──────────────────────────────────┤
│ ● 312.9.2  낙엽월 2일    ⟪당신⟫     │
│ │ 수탉 지하의 가짜 벽을 다시 발랐다    │
│ ● 312.9.14 낙엽월 14일   ⟪목격⟫     │
│ │ 볼크의 사냥개가 수탉 앞에서         │
│ │ 냄새를 잃었다                     │
│ ● 312.9.27 낙엽월 27일   ⟪들음⟫     │
│ ┆ 에길 가족이 검은 굴뚝 숯막에        │
│ ┆ 닿았다 — 브람에게서               │
│ ▒ ????                ⟪모르는 고리⟫ │
│ ┆ 누군가 그 소식을 북쪽으로 옮겼다    │
│ ● 313.1.27 해빙월 27일   ⟪지금⟫     │
│   서리 길을 넘은 서른한 명            │
│   └ 북쪽의 흐름이 바뀌었다           │
│  ─ 실선 본 것 · ┆ 들은 것 · ▒ 모르는 고리 │
└──────────────────────────────────┘
```
- 마지막 줄 "북쪽의 흐름이 바뀌었다"는 **클락 노드**의 표현이다 (북방 대탈주 클락이 '정착' 쪽으로 가중치 +1). 숫자는 보이지 않는다.
- `▒` 고리는 나중에 플레이어가 카스파르의 역할을 알게 되면 **채워진다** (§3.6 "고리가 채워졌다"). 그 앎은 기억이므로, 다음 회차의 실타래에서는 처음부터 채워져 있다.
### 장면 2 — 맹세의 순간: 서리월 아흐레 (AS 312 서리월 9일, 채찍 기둥 광장 · 회차 안)
전제: O-01 출신. 배급 줄에서도, 마르타의 값에서도 키트를 빼내지 못했다.
```
┌──────────────────────────────────┐
│ ☁ 안개 · 새벽 5시   채찍 기둥 광장  ≡ │
├──────────────────────────────────┤
│  마흔 명이 두 줄로 서 있다. 발목에서  │
│  발목으로 쇠사슬이 이어진다.         │
│  키트는 열네 번째다.                │
│  즈닉이 머릿수를 세다 키트 앞에서     │
│  멈추고, 아이의 턱을 들어 이빨을     │
│  본다. "튼튼해. 1비늘 반."          │
│  어머니는 오지 못했다. 기침 때문에    │
│  일어나지 못했다. 키트가 줄 너머로    │
│  당신을 찾는다. 울지 않는다. 울면    │
│  맞는다는 걸 열 살은 안다.           │
│  사슬이 당겨진다. 용의 대로 남쪽으로. │
├──────────────────────────────────┤
│ ▸ 키트에게 달려간다    [운동] 무모하다 │
│ ▸ "저 아이 대신 저를."  [화술] 어렵다 │
│ ▸ 경비 손에 동화 세 닢을 쥐여 준다    │
│                      [흥정] 가망 없다 │
│ ▸ 키트의 눈을 보고 말한다:           │
│   "어디로 가든, 찾아서 여울강        │
│    이쪽으로 데려온다."              │
│ ▸ 고개를 숙인다                     │
└──────────────────────────────────┘
```

넷째 줄을 고르면: *키트가 고개를 끄덕인다. 한 번. 즈닉이 웃는다. "크릭 앞에서 맹세하는 무혈자라니. 내가 증인이다, 쥐새끼." 사슬이 움직인다.* 그리고 작게 `· 맹세록에 새겨졌다 — 키트`.
- 넷째 줄은 퀘스트 수락 버튼처럼 생기지 않았다. 다른 선택지와 같은 모양의 **말**이다. 보상 미리보기도, 아이콘도 없다.
- 증인: 키트(수혜자), 즈닉(적대 증인 — 맹세를 지키지 못하면 그가 조롱할 재료가 된다).
- "맹세록에 새겨졌다"는 한 회차의 **첫 세 번**만 표시된다. 그 뒤로는 기록 스크롤에만 남는다.
### 장면 3 — 짐작 메아리와 끊어진 실 (AS 312 긴밤월 15일 → 굶주림월 1일 · 회차 안)
전제 (장면 2와 다른 갈래): 배급 줄 여는 장면(14 §6.1)의 2번, 플레이어는 헨릭에게 동화를 쥐여 주고 "키트 대신 다른 이름을" 적게 했다 (성공).
긴밤월 15일, 사라가 2차 매각 명단(31명, 굶주림월 3일 인도)에 **자기 이름이 있다**는 것을 알게 된다.
```
│  사라가 세탁장 잿물 통에 손을 담근    │
│  채로 말한다. "서른한 명 안에 제가    │
│  있대요." 갈라진 손바닥에서 피가      │
│  잿물로 번진다. "이상하죠. 지난달까진 │
│  없었는데."                        │
│  〰 메아리? · 짐작 · 석 달 전        │
│    당신은 헨릭에게 동화를 쥐여 주고,  │
│    명단의 이름 하나를 지우게 했다.    │
```
- **'짐작'** 메아리는 언제나 점선이고 물음표가 붙는다. 플레이어가 아는 것만으로 이은 실이다. 짐작 메아리의 약 절반은 맞고, 절반은 틀리다 (§3.7).
- 이 짐작은 **틀렸다.** 사라의 이름을 쓴 것은 마르타다 (CHARACTERS R02-11 비밀 ②: 명단 마지막 자리를 리즈 대신 사라로).

굶주림월 1일, 사라의 신뢰가 50을 넘은 밤:
```
│  "마르타 아주머니가 명단의 마지막     │
│  이름을 고쳐 쓰는 걸 봤어요. 그      │
│  자리에 원래 누가 있었는지도요."      │
│  〰 실이 끊어졌다                    │
│    사라의 이름은 당신에게서 오지      │
│    않았다.                          │
│    ─ 그러나 다른 실이 드러났다 ─      │
│    당신이 지운 이름 대신, 남 막사의    │
│    아홉 살 토비가 1차 명단에 올라     │
│    서리월 9일 남쪽으로 갔다.  [실 ▸]  │
```
- 짐작 메아리가 틀렸을 때 게임은 플레이어를 **안도시키지 않는다.** 대개 진짜 실이 함께 드러난다. 죄책감은 옮겨갈 뿐 사라지지 않는다 — 설교 없이, 사실만으로.
- 이 회차에서 알게 된 "마르타가 명단을 고쳐 쓴다"는 기억이 된다. 다음 회차의 마르타의 값(14 §6.3) 6번 ◈ "리즈 이야기를 꺼낸다"가 여기서 열린다 → M7.
### 장면 4 — 회차를 넘는 메아리: 무두장 가죽 (AS 312 낙엽월 25일, 굶주린 언덕 · 회차 3)
전제: 회차 2에서 플레이어는 대수색 날 볼크의 사냥대를 늑대굴에서 떼어 내려다 계곡에서 죽었다 (14 B1). 죽기 직전, 비탈 끝에서 **개들이 오른쪽 비탈로 올라오는 것**을 보았다. 회차 3, 9.24 밤 플레이어는 브람에게서 무두장 가죽 넉 장을 얻어 늑대굴 오른쪽 비탈 입구에 깔았다. 시그리드에게는 이유를 말하지 않았다 (말할 수 없었다).

## 3. 메아리 (Ripple)
### 3.1 인과의 실 — 무엇을 어떻게 추적하는가
00 문서의 흐름(사건 → 사실 → 소문 → 평판·관계·기억 → 세력 AI → 클락 → 세계 사건 → 선택지)의 **모든 화살표에 원인 꼬리표**를 붙인다.
#### 3.1.1 원칙: 상태 출처(provenance) — 특별 규칙 없이 자동으로
> 시스템마다 "이건 누구 때문" 코드를 넣으면 00 문서 규칙 ④(특별 규칙 금지)를 깬다.
> 대신 **세계 상태의 모든 키에 '마지막으로 쓴 사건(lastWriter)'** 을 기록한다.
> 어떤 시스템이 상태를 **읽고** 결정을 내려 새 사건을 만들면, 그 사건의 원인은 자동으로 **읽은 키들의 lastWriter** 가 된다.
```
사건 E가 생길 때:
  E.causes = { 그 결정을 내리며 읽은 상태 키들의 lastWriter } (기여도 가중치 포함)
  E.roots  = 부모들의 roots를 합쳐 링크 가중치를 곱한 뒤 상위 3개만 남김   ← 런타임 역추적 불필요
  E가 쓴 상태 키들의 lastWriter = E
```
- 스토리렛·대사 규칙·세력 AI·클락은 모두 "조건을 평가하는" 순수 함수다 (05 §9). 평가기가 **읽은 키 목록**을 돌려주면 끝이다.
- `roots`(플레이어 뿌리 상위 3개)는 사건 생성 시 **앞으로 전파**되므로, 메아리 판정 때 그래프를 거꾸로 탐색하지 않는다. 경로 전체 복원은 플레이어가 `[실 ▸]`을 눌렀을 때만 한다.
- **회귀하면 세계 상태와 함께 인과 그래프도 회귀점으로 돌아간다.** 지난 회차의 그래프는 **회차 보관함**(§4.3)으로 압축되어 회차 비교와 '되풀이 메아리'(§3.5.3)에만 쓰인다. 새 회차의 사건은 지난 회차의 사건을 원인으로 가질 수 없다 — 세계는 그것을 모르기 때문이다. 회차를 넘는 실은 오직 **주인공의 기억**을 통해서만 이어진다 (§3.1.3).
#### 3.1.2 고리의 종류와 기본 가중치
| 고리 종류 `kind` | 발생 시스템 | 예 | 기본 가중치 |
|------------------|-------------|-----|-------------|
| `choice` | 선택지 (02·05) | "가짜 벽을 다시 바른다" | **뿌리** (작자성 1.0) |
| `check` | 판정 결과 (01) | 화술 성공으로 헨릭이 이름을 바꿈 | **뿌리** (0.8) |
| `recall` | **기억 선택지 ◈** 또는 기억 카드가 논거 보정으로 들어간 선택 (14 §7.5) | "◈ 헨릭에게: 남작님의 담보라면…" | **뿌리** (작자성 1.0) + 기억 출처 꼬리표 |
| `declined` | 개입 기회를 거절 (REGIONS §2.14 "개입 기회") | 이르마의 신고를 막을 기회를 지나침 | **뿌리** (0.4) |
| `nature` | 잔향의 본성 — 각성·징후·`echo_misattribution` | 깨어나는 순간 주변 아이가 같은 꿈을 꿈 | **뿌리** (0.3, §3.8) |
| `companion_act` | 동료가 관계 때문에 독자 행동 | 페인이 당신을 위해 증언함 | 0.6 |
| `fact` | 사실 생성 (08) | `fact_wall_replastered` | 0.95 |
| `rumor_hop` | 소문 전파 한 단계 (08·10) | 수탉 → 이르마 → 즈닉 | 0.85 (왜곡될수록 0.7) |
| `memory` | NPC 기억 태그 (05 §4.1) | `player_hid_refugees` | 0.9 |
| `npc_decision` | NPC 목표·스토리렛 발동 (08 §7.3) | 마르타가 보고를 미룸 | 읽은 키 기여도 비례 |
| `faction_tier` | 대응 단계 변화 (10 §5) | 레이번 위협도 1 → 2 | 위협도 기여 비례 |
| `clock_tick` | 월드 클락 분기 가중치 변화 | 북방 대탈주 '정착' +1 | 분기 가중치 기여 비례 |
| `world_event` | 클락이 낳은 세계 사건 | 2차 물결 300명 도착 | 0.9 |
- 경로 가중치 = 경로 위 고리 가중치의 곱. **0.25 미만인 경로는 메아리 후보가 아니다** (원인이 너무 흐리다).
- 확정 사건(REGIONS §2.14 "확정")은 플레이어가 손대지 않았다면 뿌리가 없다 → 메아리가 생기지 않는다. 플레이어가 개입 기회를 **명시적으로 거절**했을 때만 `declined` 뿌리가 붙는다.
#### 3.1.3 기억의 출처 — 회차를 넘는 유일한 다리
- 모든 지식 카드·사실·날짜·낱말·지도 노드는 **처음 알게 된 회차와 사건**을 꼬리표로 가진다 (14 §11 `MemoryCard.learned`).
- 선택이 기억 카드를 **읽으면** (◈ 선택지의 요구 조건, 또는 논거 보정으로 들어간 카드) 그 선택의 뿌리는 `recall`이 되고, `memorySource = { loop, event }`가 붙는다.
- 같은 회차 안에서 알게 된 기억이면 그것은 평범한 `choice`다 (회차를 넘지 않았다). **지난 회차에서 온 기억**일 때만 회차를 넘는 메아리 후보가 된다.
- 기억 카드가 여러 회차에서 거듭 확인되었으면 출처는 **처음 알게 된 회차**와 **가장 최근에 확인한 회차** 둘을 가진다. 메아리 문장은 가장 최근 것을 쓴다 ("지난 회차"가 "일곱 회차 전"보다 와닿는다).
### 3.2 메아리 가치 점수 — 의미 있는 것만 떠오르게
결과 사건이 **플레이어에게 인지되는 순간** (직접 목격, 또는 소문이 도착함 — `onPlayerLearns`) 그 사건의 `roots`를 꺼내 점수를 매긴다.

**`R = 100 × (0.25·D + 0.35·M + 0.25·A + 0.15·S) + 보정`** (최대 100)

| 항목 | 정의 | 계산 |
|------|------|------|
| **D 지연** | 뿌리에서 **플레이어가 결과를 안 날**까지, 주인공이 **실제로 살아 낸 날수** (주관 일수). 회차를 넘는 메아리는 앎의 순간부터 지금까지 여러 회차에 걸쳐 산 날을 모두 더한다 | `min(1, log2(1 + 일수) / 12)` → 1일 0.08 · 7일 0.25 · 30일 0.41 · 90일 0.54 · 1년 0.71 · 11년 이상 1.0 |
| **M 크기** | 결과 사건의 크기 (아래 표) | 0.1 ~ 1.0 |
| **A 작자성** | 뿌리 종류 계수 × √(경로 가중치) | 직접 선택·기억 선택 1.0 · 판정 0.8 · 동료 독자 행동 0.6 · 거절 0.4 · 본성 0.3 |
| **S 놀라움** | 0.5 × (선택 당시 이 결과가 **암시되지 않았음**) + 0.3 × (결과가 뿌리와 **다른 장소 또는 다른 인물**에서 일어남) + 0.2 × min(1, 뿌리의 주요 인물을 마지막으로 본 뒤 지난 일수 / 60) | 0 ~ 1. "암시"는 선택지 미리보기·판정 근거·대사에 결과가 언급되었는지 (`hintedAt`). 기억 선택의 결과가 **지난 회차에 본 그대로**면 놀라움 0.5 감점 (예상한 결과다) |

**M 크기 표**

| M | 결과의 크기 |
|---|-------------|
| 0.1 | NPC 한 명의 대사 하나가 바뀜 (→ 05 문서 몫, 메아리 대상 아님) |
| 0.3 | 관계 ±10 이상, 가격·물건 하나, 소문 하나 |
| 0.5 | 이름 있는 NPC의 처지 변화 (팔림·풀림·부상·직위), 영역 수치 ±10, 비밀 하나가 드러남 |
| 0.7 | 이름 있는 NPC의 죽음·출생, 세력 대응 단계 변화, 칭호 생성, 무리(10명 미만)의 운명 |
| 0.9 | 10명 이상의 생사, 정착지 생성·파괴, 클락 **단계** 변화 |
| 1.0 | 찬가 단계 변화, 시대급 사건 |

**보정**

| 보정 | 값 | 이유 |
|------|----|------|
| 회차를 넘는 메아리 (뿌리 `recall`, 기억 출처 회차 ≠ 현재 회차) | **+10** | 이 게임의 핵심 판타지 — 기억이 세계를 바꾼다 |
| 지난 회차에 **그 결과 때문에 죽었던** 일을 이번엔 피함 | +8 | "어제의 너는 여기까지였다"의 짝 |
| 맹세와 연결된 결과 (§5) | +8 | 플레이어가 스스로 정한 목표 |
| 숙적의 탄생·귀환 (17) | +6 | |
| 같은 결과를 05 대사가 이미 명시적으로 언급함 (`과거_*` 개념 대사 발동) | **−25** | 중복 제거 — NPC가 이미 "네가 그때…"라고 말했으면 메아리는 조용히 |
| 메아리 빈도 설정 적게 / 많이 | −10 / +10 | 접근성 |

**문턱 (필수 조건: A ≥ 0.3 그리고 M ≥ 0.3)**

| R | 등급 | 표현 |
|---|------|------|
| 70 이상 | **큰 메아리** | 본문 뒤 한 박자 쉼(0.8초) + 낮은 단음 1회 + 메아리 줄. 실타래 자동 펼침은 하지 않음 |
| 50~69 | **메아리** | 메아리 줄 |
| 35~49 | **조용한 메아리** | 줄 없이 장면 끝에 `〰` 표식 하나. 기록 스크롤과 실타래 보관함에만 저장 |
| 35 미만 | 없음 | 인과는 저장되지만 표시하지 않음 |

**계산 예 (장면 1, 에길)**: 150일 → D 0.60 · 30명 생존과 정착 → M 0.9 · 직접 선택, 경로 0.62 → A 0.79 · 암시 없음, 다른 장소·인물, 오래 못 봄 → S 1.0
→ R = 100 × (0.150 + 0.315 + 0.197 + 0.150) = **81 → 큰 메아리**.

**계산 예 (장면 4, 무두장 가죽 — 회차를 넘음)**: 앎(회차 2, 9.25)부터 지금(회차 3, 9.25)까지 주관 일수 = 회차 2의 남은 0일 + 회차 3의 25일 → D 0.39 · 시그리드 무리 열한 명이 잡히지 않음 → M 0.9 · 기억 선택, 경로 0.8 → A 0.89 · 암시 없음, 같은 장소, 시그리드는 어제 봄 → S 0.5 → R = 100 × (0.098 + 0.315 + 0.223 + 0.075) + 10 + 8 = **89 → 큰 메아리**.

**반례 (메아리가 아닌 것)**: 어제 페인에게 빵을 줬고 오늘 페인이 정보를 준다 → D 0.08 · M 0.3 · A 1.0 · S 0.2 → R = 41 → 조용한 메아리. 즉각적인 반응은 05 문서(기억 태그 대사)의 일이다.
### 3.3 상한과 쿨다운 — 흔하면 무뎌진다
| 규칙 | 값 |
|------|-----|
| 한 세션(18 문서의 짧은 세션 단위)당 메아리 줄(큰 메아리 + 메아리) | **최대 3** |
| 한 세션당 큰 메아리 | **최대 1** |
| 한 세션당 회차를 넘는 메아리 | **최대 1** (되풀이·어긋난 메아리 포함) |
| 메아리 줄 사이 최소 간격 | 장면 6개 또는 실제 10분 |
| 게임 하루당 메아리 줄 | 최대 2 |
| 같은 뿌리에서 나온 메아리 줄 | 한 회차에 최대 3 (네 번째부터 조용한 메아리) |
| 한 장면에 메아리 줄 | 1 (둘 이상 겹치면 R 최고 하나, 나머지는 대기열) |
| 「기억대로 보낸다」(18 §5.6)로 접힌 날 | 메아리 줄 없음. 접힌 날의 결과는 접힘이 끝난 뒤 「밤의 메아리」로 최대 1 |

**대기열**: 상한에 걸린 메아리는 R 순으로 대기열에 들어간다.
- 다음 **쉼표**(밤 잠자리, 안식일, 이동 몰아 보내기의 끝)에 「밤의 메아리」로 최대 2개를 묶어 보여 준다.
- 대기 중 게임 하루마다 R −5. 50 아래로 떨어지면 조용한 메아리로 보관된다.
- 연출가(18)는 큰 메아리를 **최대 장면 2개까지** 붙잡아 긴장 곡선의 내리막(안도·여운 구간)에 놓을 수 있다. 결과 장면 자체를 늦추지는 않는다 — 메아리 줄만 늦춘다.
- **회귀하면 대기열은 사라진다.** 아직 보이지 않은 메아리는 그 회차와 함께 없어진다. 단, 회차 비교(§4)에는 남는다.
### 3.4 표현
#### 3.4.1 메아리 줄 (본문 안)
형식: `〰 메아리 · {지연 문구}` 다음 줄에 `{뿌리 문장}.`
- 위치: 결과 장면 본문의 끝, 선택지 바로 위 (SCENARIOS 「잔향의 각성」 블록과 같은 자리 규칙).
- 서체: 본문보다 한 단계 작고, 왼쪽에 실 모양 세로선. 19 문서 `{ripple|…}` 태그로 표시 형식을 넘긴다. 기억 잉크(┊, 14 §7.5)와 **다른 세로선**이다 — 메아리는 원인, 기억 잉크는 지나간 일.
- **결과는 이미 장면이 보여 주었다. 메아리 줄은 원인만 말한다.** 중간 고리는 실타래에서만 보인다.
- 길이: 지연 문구 포함 **최대 2줄, 60자.** 회차를 넘는 메아리는 **최대 3줄, 80자** (앎 + 행동 두 마디). 뿌리 문장은 플레이어가 한 행동을 과거형 2인칭 평서문으로.

**지연 문구 규칙**

| 경우 | 문구 |
|------|------|
| 1~13일 | "닷새 전", "열사흘 전" (고유어 날수) |
| 14~59일 | "스무날 전", "마흔이레 전" — 길면 "한 달 반 전" |
| 60~364일 | "두 달 전" ~ "열한 달 전" |
| 1년 이상 | "세 해 전, 겨울" (계절 부기) |
| 지난 회차 | "지난 회차, {같은 날이면 '이날' / 아니면 날짜와 때}" — 예: "지난 회차, 이날 정오" · "지난 회차, 굶주림월 첫날 밤" |
| 두~아홉 회차 전 | "두 회차 전, {날짜}" ~ "아홉 회차 전, {날짜}" |
| 열 회차 이상 전 | "오래전 회차, {날짜}" — 숫자를 세지 않는다. 숫자가 무뎌지기 때문이다 |
| 본성 뿌리 | "당신이 빵 냄새를 처음 맡은 저녁" 등 회귀점 기준 |
#### 3.4.2 실타래 (Thread view)
- 세로 시간선. 노드마다: **날짜(AS 연.월.일 + 달 이름)**, 확신 표지, 한 줄 설명(최대 22자 × 2줄).
- 확신 표지는 08 문서 인물 수첩과 같다: **본 것(실선 ⟪목격⟫) / 들은 것(점선 ⟪들음⟫) / 짐작(물음표 ⟪짐작⟫) / 모르는 고리(▒)**. 회차를 넘는 실에는 하나가 더 있다: **⟪기억⟫** — 지난 회차에 본 것. 노드 앞에 작은 회차 표지("셋째 저녁")가 붙고, 그 노드와 이번 회차 노드 사이에 **접힌 선**(〜)이 그어진다. 세계는 그 선을 모른다.
- **스포일러 금지 규칙**: 노드는 플레이어가 그 사건·사실을 알 때만(`known_by`에 플레이어) 내용이 보인다. 모르는 고리는 범주 힌트만 보인다 — "누군가 무엇을 보았다", "누군가 말을 옮겼다", "어떤 세력이 움직였다", "북쪽의 흐름이 바뀌었다".
- 모르는 고리가 4개를 넘으면 연속된 것은 "▒ × 3 — 당신이 모르는 일들"로 접는다.
- 노드 최대 9개 표시 (가중치가 낮은 중간 노드부터 접음). 뿌리와 결과는 항상 표시.
- 실타래에서 노드를 길게 누르면 관련 인물 수첩(08)·지도(07)·회차 비교(§4)로 이동한다. **실타래는 퍼즐이 된다** — 모르는 고리를 채우려고 사람을 찾아간다. 채운 고리는 기억이므로 **다음 회차에도 채워진 채** 남는다.
- 클락·세력 노드는 숫자 대신 세계 안의 말로: "레이번 성채가 사냥꾼을 불렀다"(대응 2단계), "북쪽의 흐름이 바뀌었다"(클락 가중치).
#### 3.4.3 문장 규칙 — 설교하지 않는다
| 규칙 | 예 (금지 → 허용) |
|------|------------------|
| 평가어 금지: 덕분에, 때문에, 잘했다, 잘못, 죄, 대가, 업보, 결국, 드디어, 이번엔 성공 | "당신 때문에 토마스가 맞았다" → "당신은 두 번째 바닥의 보리를 언덕으로 날랐다." / "드디어 볼크를 피했다" → "지난 회차, 이날 정오 당신은 개들이 오른쪽 비탈로 오는 것을 보았다." |
| 감정 지시 금지: "가슴이 아프다", "뿌듯하다" | 감정은 장면 본문과 내면의 목소리(15)가 맡는다 |
| 뿌리는 **플레이어가 실제로 고른 선택지의 내용**으로만 | 선택하지 않은 함의를 덧붙이지 않는다 |
| 결과를 반복하지 않는다 | 장면이 보여 준 결과를 메아리 줄이 다시 말하지 않는다 |
| 거절 뿌리는 "보았고, 지나쳤다"처럼 **행동으로** | "당신은 방관했다"(평가) → "당신은 일곱 번째 칼자국을 보았고, 아무 말도 하지 않았다." |
| 회차를 넘는 메아리에서 **지난 회차의 죽음을 직접 말하지 않는다** | "지난 회차, 당신은 여기서 죽었다"(✗) → "지난 회차, 이날 정오 당신은 계곡에 있었다."(✓) — 죽음은 플레이어가 안다 |

> 자동 검증(05 §7.4)에 메아리 금지어 목록을 추가한다.
#### 3.4.4 진동·소리
- **진동 없음** (19 원칙: 몸의 감각만 진동). 큰 메아리만 0.8초 침묵 + 낮은 단음 1회(1.2초, 저역 현). 회차를 넘는 메아리에서는 **빵 냄새의 장작 소리**가 0.5초 겹친다 (19 — 회귀점의 소리 주제).
- 예외: 지난 회차의 죽음을 피한 메아리(+8 보정)에서는 14 §4.2 **H4 유령 진동**이 한 번 온다 — 그 죽음의 마지막 감각이, 이번엔 오지 않았다는 것을 손이 안다.
### 3.5 회차를 넘는 메아리
#### 3.5.1 기억 메아리 — 지난 회차의 앎이 이번 회차를 바꿨다
- 조건: 결과의 뿌리 중 하나가 `recall`이고, 그 `memorySource.loop` < 현재 회차. 점수 +10, 세션당 1개.
- 형식: **두 마디.** 첫 마디는 앎 (지난 회차에 본 것·들은 것), 둘째 마디는 행동 (이번 회차에 한 것).
  `〰 메아리 · 지난 회차, {때}` / `당신은 {앎}. 이번에는 {행동}.`
- 결과 속 NPC는 **당신이 무엇을 아는지 모른다.** 작가 지정 시 이 한 줄을 붙일 수 있다: "그녀는 그것이 운이었다고 생각한다." / "그는 당신이 무엇을 알았는지 모른다."
- 앎의 출처가 사람이었다면 (사라가 낱말을 알려 주었다), 첫 마디에 그 사람을 쓴다: "지난 회차, 열하루 우물가에서 사라가 알려 준 낱말로". 그 사람은 지금 그 말을 한 적이 없다. 그 부조리가 회귀의 슬픔이다. 문장은 그것을 설명하지 않는다.
#### 3.5.2 어긋난 메아리 — 기억과 달랐다
- 조건: 플레이어가 기억(◈ 또는 기억 카드)에 기대어 행동했는데, 그 기억의 전제가 **시간의 표류**(14 §7.1 '흔들림·흩어짐')로 바뀌어 결과가 기대와 다르게 왔다.
- 형식: `〰 기억과 달랐다` / `지난 회차, {때} {무엇}은 {그때의 값}.` — 이번의 값은 장면이 이미 보여 주었다.
  예: "〰 기억과 달랐다 · 지난 회차, 스니는 두 시에 왔다."
- **어긋난 메아리는 플레이어를 탓하지 않는다.** 뿌리가 아니라 **전제**를 말한다. 점수는 계산하지 않고, 회차당 처음 3번은 언제나 보인다 (그 뒤로는 14 §7.5의 ◇ 표지만). 플레이어가 "어떤 기억이 단단한가"를 배우는 장치다.
- 표류가 아니라 **플레이어 자신의 다른 선택**이 전제를 바꿨다면 (어제 다른 일을 해서 페인이 다른 곳에 있다) 그것은 어긋남이 아니라 인과다 → 평범한 메아리 또는 회차 비교의 `≠`.
#### 3.5.3 되풀이 메아리 — 같은 실
- 조건: 이번 회차의 결과 C가 지난 회차(들)에도 **같은 뿌리 선택에서 같은 결과**로 일어났고, 주인공이 그때 그 결과를 알았다 (`known_by` 그 회차).
- 형식: `〰 같은 실 · {횟수} 번째` / `{n} 회차 모두, 당신은 {행동}. {n} 번 모두 {결과의 핵심 인물}…`
  예: "〰 같은 실 · 세 번째 / 세 회차 모두, 당신은 헨릭에게 동화를 쥐여 주었다. 세 번 모두 토비가 대신 갔다."
- 같은 결과가 두 번째일 때는 표시하지 않는다 (우연일 수 있다). **세 번째부터** 한 번만, 그 뒤로는 회차 비교에만.
- 되풀이 메아리는 결과 문장을 일부 말하는 **유일한 예외**다 (§3.4.3 "결과를 반복하지 않는다"의 예외) — 반복 그 자체가 내용이기 때문이다.
- 15 문서 목소리 ⟨아스테리온⟩의 반응 후보: "나도 같은 사람을 네 번 팔았다. 다섯 번째에 그만뒀지. 그 사람이 그걸 알았을 것 같으냐?"
#### 3.5.4 오지 않은 결과
- 지난 회차에 심어 두었는데 그 결과가 오기 전에 회차가 끝났다면, 그 결과는 **오지 않는다.** 세계는 그 씨앗을 모른다.
- 회차 비교(§4)에는 "┊ 씨앗만 있었다" 줄로 남는다. 메아리 줄로는 나오지 않는다.
- 예: 회차 5에서 요한의 목패에 필사본을 꿰매 넣었고(M5의 뿌리), 루멘의 손가락 글씨가 돌아오기 전인 서리월에 죽었다. 회차 6의 비교: "┊ 낙엽월 11일, 요한의 목패. 그 뒤는 보지 못했다."
### 3.6 보지 못한 일의 메아리 — 소문으로 도착하는 결과
- 결과를 플레이어가 **소문으로** 들으면 「소문 메아리」. 실타래의 결과 노드 자체가 점선이다.
- 지연(D)은 "일어난 날"이 아니라 **"들은 날"** 기준. 실타래에는 두 날짜를 모두 적는다: `일어난 날 312.11.? · 들은 날 312.12.20`.
- 메아리 줄에 출처를 붙인다: `〰 소문 메아리 · 요한에게서`.
- 소문은 왜곡된다 (10 §4.1). 소문 메아리의 결과 노드는 **소문의 문장 그대로** 쓴다. 나중에 진실을 알면 노드가 실선으로 바뀌며 문장이 고쳐진다 — 이것도 「고리가 채워졌다」의 일종이다.
- **고리가 채워졌다**: 실타래의 `▒` 고리나 점선 노드가 나중에 확정되면 작은 메아리(상한 계산 시 0.5개)로 알린다.
  `〰 고리가 채워졌다 · 에길의 소식을 북쪽으로 옮긴 것은 카스파르였다.`
- 채운 고리는 기억이다. 다음 회차에서 같은 실이 다시 생기면 그 고리는 처음부터 ⟪기억⟫으로 채워져 있다 — 그러나 **표류 등급이 '흔들림' 이상인 고리는 점선으로** (이번에도 카스파르가 옮겼는지는 모른다).
### 3.7 짐작 메아리와 거짓 메아리
> 사람은 원인을 짐작한다. 짐작은 자주 틀린다. 이것은 이 세계의 소문·인식 시스템(08 §3.3 `believed_false_by`)의 플레이어판이다.

**짐작 메아리 생성 조건**

1. 결과 C가 플레이어에게 인지되었는데, C의 `roots`에 작자성 0.3 이상인 플레이어 뿌리가 **없거나**, 있어도 그 경로에 모르는 고리가 50% 이상이다.
2. 플레이어가 아는 과거 행동 P 중 C와 **주제 꼬리표 2개 이상**을 공유하는 것이 120일 안에 있다 (같은 NPC, 같은 장소, 같은 물건·문서, 같은 세력).
3. 그러면 확률 35%로 P를 뿌리로 한 **짐작 메아리**를 띄운다: `〰 메아리? · 짐작 · {지연}`.

**거짓 메아리** = 2의 P가 실제로는 원인이 아닌 짐작 메아리.

| 규칙 | 값 |
|------|-----|
| 거짓 메아리는 **진짜 원인 사실(F)이 존재하고, 발견 가능할 때만** 생성 | F를 아는 살아 있는 NPC가 있고, 그 NPC에게 이르는 관계 경로가 있어야 함 |
| 동시에 열린 거짓 메아리 | 한 회차 최대 **1** |
| 한 시대 거짓 메아리 | 최대 **3** |
| 같은 거짓 메아리의 반복 | **금지.** 한 번 드러난 거짓 실(예: M9)은 그 진짜 원인이 기억이 되므로, 다음 회차에는 짐작이 아니라 ⟪기억⟫으로 이어진다 |
| 드러남 보장 | 생성 시 드러남 경로 1개 이상을 작가 데이터 또는 스토리렛 조건으로 확인. 없으면 생성 안 함. 드러나기 전에 회차가 끝나면 그 거짓은 회차 비교에 "┊ 짐작만 했다"로 남는다 |
| 짐작 메아리 중 참의 비율 목표 | 약 50% (거짓만 나오면 플레이어가 표지를 무시하게 된다) |
| UI 정직성 | 짐작 메아리는 **언제나** 물음표·점선으로 표시. 게임은 확실하다고 말한 것을 뒤집지 않는다 — 플레이어의 짐작만 뒤집힌다 |

**드러남 연출: 「실이 끊어졌다」**
- 짐작 실이 거짓으로 판명되면 실타래에서 그 고리에 `✂`가 그어지고, 진짜 실이 **나란히** 펼쳐진다.
- 드러남은 대개 **이중**이다: "당신 때문이 아니었다"와 "그러나 이것은 당신 때문이었다"가 함께 온다 (장면 3: 사라 → 마르타, 그리고 토비). 순수한 면죄는 시대당 1회 이하로 제한한다.
- 반대 방향도 있다: **숨은 메아리** — 플레이어가 자기와 무관하다고 믿은 결과가 사실 자기에게서 나온 경우. 숨은 메아리는 처음엔 표시되지 않고(조용한 메아리로 보관), 진짜 실이 드러날 때 「실이 이어졌다」로 나타난다. §3.8의 잔향 메아리가 대표적이다.
### 3.8 잔향 메아리 — 당신의 본성이 만든 결과
- 잔향의 각성과 재능 사용은 근처 평범한 인간이 징후자로 오인될 확률 `echo_misattribution`을 올린다 (SCENARIOS §0.4). 이 오인으로 누군가 끌려가거나 불타면, 그 사건의 뿌리는 `nature`다.
- **잔향은 회귀점에서 깨어난다.** 그러므로 각성은 **매 회차 같은 저녁에** 다시 일어나고, 그 본성의 파문(미카의 꿈 등)도 회차마다 다시 일어날 수 있다 (표류 등급 '흔들림', 14 §7.1). 플레이어가 그 인과를 한 번 알게 되면, 그것은 기억이 된다 — 다음 회차에 미카를 지키는 일은 `recall` 뿌리의 평범한 선택이 된다.
- 작자성 0.3으로 낮지만 M이 크다 (처형 0.7). 대부분 **숨은 메아리**로 보관되었다가, 플레이어가 그 인과를 알게 되는 순간(이졸의 보고서, 엘사의 고백, 계시 R4 「기다림의 장부」) 한꺼번에 이어진다.
- 기억으로 바꾼 일이 `echo_misattribution`을 올리는 것(14 §7.3 `과하게_앎`)도 `nature` 뿌리로 센다. 아는 것을 함부로 쓰면, 누군가 대신 불탄다.
- 한 회차에 **최대 2개**만 줄로 보여 준다 (그 이상은 회차 기록의 "당신 대신 탄 사람들" 목록으로). ACH-57 「아무도 대신 타지 않았다」와 짝을 이룬다.
### 3.9 메아리 예시 — 회색여울 (최종 문장)
> 형식: 제목 · 등급 R (D·M·A·S) / 상황 / **메아리 줄 — 최종 문장, 줄바꿈은 `/`** / 실타래. R은 최대 100.

**M1. 첫 메아리 — 세 소나무의 매듭** · 메아리 R 69 (.37 · .7 · .89 · .87) — 권장: 첫 회차의 첫 메아리 (14 문서와 맞춤)
- 상황: 312.9.5 하겐이 세 소나무 그루터기에 탈주자 위치 매듭을 남긴다. 플레이어가 매듭을 풀어 다른 골짜기를 가리키게 다시 묶었다. 9.25 볼크의 대수색은 서쪽 골짜기에서 빈손으로 돌아오고, 저녁에 볼크가 수탉 앞에서 하겐의 멱살을 쥔다.
- **〰 메아리 · 스무날 전 / 당신은 세 소나무 그루터기의 매듭을 풀어, 다른 골짜기를 가리키게 다시 묶었다.**
- 실: ⟪당신⟫ 9.5 매듭 → ⟪들음⟫ 9.6 볼크의 사냥꾼이 매듭을 거둬 감 (페인) → ▒ 누군가 그 매듭을 읽었다 → ⟪목격⟫ 9.25 빈손의 사냥대, 하겐의 멱살
- 하겐의 매듭 날은 표류 '흔들림'(9.4~9.6). 다음 회차에 같은 일을 하려면 그 날을 맞춰야 한다.

**M2. 큰 메아리 — 수탉 아래에서 온 말** · 큰 메아리 R 81 — 장면 1
- **〰 메아리 · 다섯 달 전 / 당신은 수탉 지하의 가짜 벽을 밤새 다시 발랐다.**
- 고리 채움 (카스파르 신뢰 40 이상): **〰 고리가 채워졌다 · 에길의 소식을 북쪽으로 옮긴 것은 카스파르였다.**
- 회차를 넘는 변형: 배급 줄 ◈ "브람에게: 지하실 벽, 오늘 밤 기침 소리가 새요"(14 §6.5)로 벽을 **첫날 밤** 바르게 했다면 → **〰 메아리 · 지난 회차, 낙엽월 이틀 밤 / 당신은 수탉 벽 너머의 기침을 들었다. 이번에는 첫날 저녁, 브람에게 그 벽을 말했다.**

**M3. 거절의 메아리 — 일곱 번째 칼자국** · 메아리 R 54 (.21 · .9 · .34 · .55)
- 상황: 312.9.20 이르마의 지팡이에 일곱 번째 칼자국이 새로 생긴 것을 보았고 (`hintedAt`: 칼자국 = 확인한 길목), "이르마를 따라간다 / 페인을 이르마에게 데려간다"를 고르지 않았다 (`declined`). 9.24 안식일에 이르마가 즈닉에게 늑대굴을 신고하고, 9.25 대수색에 시그리드 무리 11명이 잡힌다.
- **〰 메아리 · 닷새 전 / 당신은 이르마의 지팡이에서 일곱 번째 칼자국을 보았고, 아무 말도 하지 않았다.**
- 실: ⟪당신⟫ 9.20 → ⟪들음⟫ 9.24 이르마가 초소에 다녀감 → ⟪짐작⟫ 즈닉이 볼크에게 → ⟪목격⟫ 9.25 사슬에 묶인 열한 명
- M1과 M3은 같은 회차에 함께 일어날 수 없다 — 매듭을 바꿨다면 수색은 서쪽으로 갔다.

**M4. 마르타의 침묵** · 큰 메아리 R 71 (.47 · .7 · .85 · .9)
- 상황: 10.23 플레이어가 리즈를 요한의 순례 행렬 맨 끝에 숨겨 루멘으로 보냈다. 12.10 마르타는 수탉 지하의 냄새를 맡고도 즈닉에게 가지 않는다. 플레이어는 마르타가 브람의 솥 옆에 말없이 빵 한 덩이를 놓고 가는 것을 본다.
- **〰 메아리 · 마흔이레 전 / 당신은 리즈를 요한의 순례 행렬 맨 끝에 세웠다.**
- 실: ⟪당신⟫ 10.23 → ⟪들음⟫ 11.10 행렬이 까마귀 문을 지남 → ▒ 누군가 마르타에게 말을 전했다 → ⟪목격⟫ 12.10 빵 한 덩이

**M5. 소문 메아리 — 루멘의 손가락 글씨** · 메아리 R 65 (.55 · .5 · .77 · 1.0)
- 상황: 9.11 플레이어가 요한의 목패 끈 안쪽에 오스릭의 필사본 석 장을 꿰매 넣었다. 12.20 돌아온 요한이 수탉에서 말한다: "루멘 하층 빨래터에선 아이들이 젖은 돌에 손가락으로 뭘 써요. 물이 마르면 지워지니까 괜찮대요. 제일 많이 쓰는 건 '나'래요." 플레이어는 루멘에 가 본 적이 없다.
- **〰 소문 메아리 · 요한에게서 · 석 달 전 / 당신은 요한의 목패 끈 안쪽에 필사본 석 장을 꿰매 넣었다.**
- 실: ⟪당신⟫ 9.11 → ▒ 까마귀 문 검문 → ▒ 바알카르 → ⟪들음⟫ 루멘, 아그네스 (일어난 날 긴밤월 중 · 들은 날 12.20) → "끊어진 고리가 조금 커졌다"

**M6. 회차를 넘는 메아리 — 무두장 가죽** · 큰 메아리 R 89 (.39 · .9 · .89 · .5, +회차 10 +죽음 회피 8) — 장면 4
- 상황: 회차 2에서 B1으로 죽기 직전, 계곡에서 개들이 오른쪽 비탈로 오는 것을 보았다. 회차 3, 9.24 밤 그 입구에 무두장 가죽을 깔았다. 9.25 사냥대가 돌아서고, 시그리드 무리 열한 명이 잡히지 않는다.
- **〰 메아리 · 지난 회차, 이날 정오 / 당신은 계곡에서 개들이 오른쪽 비탈로 오는 것을 보았다. 이번에는 전날 밤, 그 입구에 가죽을 깔았다.** 덧붙는 줄: **시그리드는 그것이 운이었다고 생각한다.**
- 실: ⟪기억 · 둘째 저녁⟫ 9.25 정오 개들이 오른쪽 비탈로 〜 ⟪당신⟫ 9.24 밤 가죽 넉 장 (브람에게서) → ⟪목격⟫ 9.25 개들의 재채기 → ⟪목격⟫ 사냥대가 돌아섬 → ⟪지금⟫ 열한 명
- 14 §4.2 H4 유령 진동(B 이빨, ×0.3)이 한 번 온다.

**M7. 회차를 넘는 메아리 — 리즈의 이름** · 큰 메아리 R 78 (.62 · .7 · .89 · .8, +회차 10)
- 상황: 회차 1의 굶주림월 1일 밤, 사라에게서 "마르타가 명단의 마지막 이름을 고쳐 쓴다"는 것을 들었다 (장면 3). 회차 2, 낙엽월 2일 19:40 마르타의 값에서 ◈ "리즈 이야기를 꺼낸다"(14 §6.3 6번)를 골랐고, 리즈를 위협하지 않았다. 마르타는 플레이어에게 밀고자를 붙이지 않는다. 9.25 대수색 전날, 마르타가 즈닉의 사냥대 명부에서 늑대굴 길잡이 칸을 비워 둔 것이 드러난다.
- **〰 메아리 · 지난 회차, 굶주림월 첫날 밤 사라에게서 들은 말로 / 당신은 낙엽월 이틀 저녁, 마르타에게 리즈의 이름을 꺼냈다.** 덧붙는 줄: **사라는 그 말을 한 적이 없다.**
- 지난 회차의 사라는 신뢰 50에 그 말을 했다. 이번 회차의 사라는 아직 플레이어의 이름도 모른다. 앎의 출처가 된 사람이 그 앎을 준 적이 없는 세계 — 덧붙는 줄은 그것만 말하고 멈춘다.

**M8. 잔향 메아리 (숨은 메아리) — 미카** · 메아리 R 65 (.7 · .7 · .3 · 1.0)
- 상황: 배급 줄 각성(`echo_wake_serf`) 직후 남 막사의 여덟 살 미카가 "불타는 하얀 도시" 꿈을 말한다 (REGIONS §2.19-9). 313 태양월 이졸이 미카를 명단에 올리고, 미카는 잿빛 탑으로 간다. 그때는 표시 없음(조용히 보관). 이졸 충성 아크 30 장면에서 그가 말한다: "그 아이의 꿈은 그 아이 것이 아니었어요. 진짜가 가까이 있으면, 아이들이 그 꿈을 주워 꿔요. 탑에서 그걸 열 번 봤어요."
- **〰 실이 이어졌다 · 당신이 빵 냄새를 처음 맡은 저녁 / 같은 저녁, 남 막사의 미카는 하얀 도시의 꿈을 꾸었다.**
- 뿌리 문장이 "당신은 …했다"가 아닌 유일한 형식. 플레이어는 아무것도 고르지 않았다.
- 이 실을 알게 된 뒤의 회차에서, 미카의 꿈은 60% 확률로 다시 온다 (표류 '흔들림'). 오지 않는 회차도 있다 → 회차 비교 "◇ 미카는 꿈을 꾸지 않았다".

**M9. 거짓 메아리 — 사라의 이름** · 짐작 → 실이 끊어짐 (장면 3)
- **〰 메아리? · 짐작 · 석 달 전 / 당신은 헨릭에게 동화를 쥐여 주고, 명단의 이름 하나를 지우게 했다.**
- **〰 실이 끊어졌다 / 사라의 이름은 당신에게서 오지 않았다. / ─ 그러나 다른 실이 드러났다 ─ / 당신이 지운 이름 대신, 남 막사의 아홉 살 토비가 1차 명단에 올라 서리월 9일 남쪽으로 갔다.**
- 진짜 실: `fact_martha_swapped_list` (9.3 이전, R02-11 비밀 ②). 드러남 경로: 사라 신뢰 50 / 리즈가 직접 말함 / 오스릭의 고해 누설(역린 — 거의 불가능). 토비는 이 선택이 C등급 인구에서 즉석 생성해 B등급으로 승격시킨 아이다 (08 §2). **회귀하면 토비는 다시 C등급 인구 속으로 사라진다.** 그러나 플레이어는 그 아이의 이름과 나이를 기억한다 — 다음 회차에 헨릭과 흥정하면 같은 막사에서 같은 이름이 승격된다 (단단함).

**M10. 어긋난 메아리 — 스니의 순회** · (점수 없음, 회차당 처음 3번 표시)
- 상황: 회차 2 첫 밤, 플레이어는 ◈ "잠들기 전에 짚을 깔아 둔다"를 골랐다. 스니가 01:20에 왔다 (표류). 짚을 깔기 전이었다.
- **〰 기억과 달랐다 · 지난 회차, 스니는 두 시에 왔다.**
- 14 §4.2 H5 진동. 회차 비교의 그 시각 줄에 ◇가 붙는다.

**M11. 되풀이 메아리 — 토비** · (세 번째에 한 번)
- 상황: 회차 2·3·4 모두 배급 줄에서 헨릭과 흥정해 키트를 명단에서 뺐다. 세 번 모두 서리월 9일, 토비가 사슬의 열네 번째 자리에 섰다. 회차 4의 서리월 9일 새벽.
- **〰 같은 실 · 세 번째 / 세 회차 모두, 당신은 헨릭에게 동화를 쥐여 주었다. 세 번 모두 토비가 열네 번째에 섰다.**
- 토비는 플레이어를 모른다. 그는 세 번 다 처음 사슬에 묶였다.

## 4. 회차 비교 — 「두 겹의 날」
> 회귀하면 세계는 잊는다. 주인공은 기억한다. 그러나 기억은 흐려지고, 표류는 기억을 배신한다. 회차 비교는 **주인공이 그때 알았던 것**을 이번 회차의 같은 자리 옆에 놓는다.
> 세계 안 정당화: 잔향자는 같은 날을 여러 번 산 사람이다. 그는 같은 새벽에 서 있는 자기 자신을 겹쳐 본다. 이것은 꿈도 계시도 아니다. **기억**이다 — 그래서 그가 몰랐던 것은 나오지 않는다.
### 4.1 원칙
| 원칙 | 구현 |
|------|------|
| **주인공이 알았던 것만** | 지난 회차의 항목은 그 회차에서 `known_by`에 플레이어가 있던 사건·사실뿐. 그때 몰랐던 진실은 지금도 비교에 없다 (그 뒤 다른 회차에서 알게 되었다면 ⟪나중에 앎⟫ 표지로) |
| **미래를 말하지 않는다** | 이번 회차가 아직 닿지 않은 시각은 "아직 오지 않았다". 지난번의 그 시각에 무엇이 있었는지만 보여 준다 — 그것은 예언이 아니라 기억이다 |
| **인과와 표류를 구별한다** | 달라진 것이 **당신이 바꾼 것**(≠)인지 **세계가 어긋난 것**(◇)인지를 언제나 구별해 표시한다. 이것이 플레이어가 기억의 신뢰도를 배우는 유일한 창이다 |
| **평가하지 않는다** | "더 나아졌다/나빠졌다" 표시 없음. 같음·달라짐·어긋남·아직·모름 다섯 표지뿐 |
| **세계 안의 말** | 숫자(신뢰 30)는 인물 수첩 확신도처럼 말로 바꿀 수 있다 (설정). 기본은 수첩과 같은 매듭 표기 |
### 4.2 세 가지 보기
| 보기 | 축 | 질문 | 진입 |
|------|----|------|------|
| **날** | 같은 날짜, 두 회차 | "지난번 이날 무엇이 있었나" | 기억 메뉴 → 두 겹의 날 / 새벽 슬롯의 "지난 회차의 오늘" 한 줄 / 회차 기록에서 날짜 탭 |
| **사람** | 한 NPC, 회차별 궤적 | "이 사람은 회차마다 어떻게 끝났나" | 인물 수첩 → 얼굴 길게 누르기 → 「회차마다」 |
| **갈림길** | 회차 목록, 처음 갈라진 선택 | "어느 회차가 어디서 갈라졌나" | 기억 메뉴 → 회차 기록 보관함 → 「갈림길」 |

**사람 보기 — 예 (페인, 회차 1~4)**
```
┌──────────────────────────────────┐
│ 페인 — 회차마다                     │
├──────────────────────────────────┤
│ 첫째 저녁부터  ┊ 9.21 갈대 속으로     │
│              ┊ 뛰었다. 그 뒤는 못 봄 │
│ 둘째 저녁부터  ┊ 9.25 바위 위에서     │
│              ┊ "왼쪽!" 그 뒤는 못 봄  │
│ 셋째 저녁부터  ┊ 흙바닥에 '물'을 썼다  │
│              ┊ 서리월 20일까지 살았다 │
│ 넷째 저녁부터  ● 오늘 처마에서 손을    │
│              ● 내밀었다. 처음 보는 얼굴│
│ ─ 단단한 것 ─                       │
│  · 배급 줄 처마에서 손바닥을 내민다    │
│  · 빵을 주면 하겐 이야기를 한다        │
│  · 하겐은 그를 세베로에게 판다 (3비늘) │
└──────────────────────────────────┘
```
- "단단한 것"은 **세 회차 이상 같았던** 그 사람의 행동만 자동으로 모은다 (14 §7.1 '단단함'의 플레이어판). 플레이어가 공략을 손으로 적을 필요가 없게.
- "그 뒤는 못 봄"은 그 회차에서 주인공이 그 사람을 마지막으로 본 때. 주인공이 죽은 뒤의 그 사람은 존재하지 않는다 — 그 회차가 없어졌으므로.

**갈림길 보기 — 예**
```
┌──────────────────────────────────┐
│ 갈림길                              │
├──────────────────────────────────┤
│ 낙엽월 1일 19:02 배급 줄             │
│ ├ 하겐의 빵 ──── 첫째 · 9.21 물굽이   │
│ ├ 헨릭과 흥정 ─┬ 둘째 · 9.25 계곡     │
│ │             ├ 셋째 · 서리월 20일    │
│ │             └ 넷째 · (지금) 9.21    │
│ └ (아직 가지 않은 길) 사라를 쫓는다…   │
└──────────────────────────────────┘
```
- 가장 많이 쓰는 갈림길은 **첫 저녁**이다 (14 §7.2). 회차들이 처음 갈라진 선택 하나만 줄기로 보이고, 그 뒤는 끝(날짜·장소)만. 가지를 누르면 그 회차의 회차 기록으로.
- "아직 가지 않은 길"은 플레이어가 **본 적 있는** 선택지 중 한 번도 고르지 않은 것 최대 2개. 결과는 보여 주지 않는다.
### 4.3 생성 파이프라인
```
① 회차 보관        — 회귀 정산(14 §4.3) 때 그 회차의 사건 로그를 압축: 플레이어 known_by 사건·사실만,
                     하루 단위 슬롯(새벽·낮·저녁·밤) 요약 + 인물별 마지막 상태 + 지식 획득 이벤트
② 관련성 필터     — 비교 대상(날/사람)에 걸린 항목만 (아래 표)
③ 정렬            — 날 보기: 슬롯 순. 사람 보기: 회차 순. 항목 안은 정서 가중치(§4.6) 순
④ 대응 짓기       — 지난 회차 항목마다 이번 회차의 같은 자리 항목을 찾는다 (같은 사건 ID / 같은 NPC·장소·슬롯)
⑤ 표지 판정       — 같음 · 달라짐(≠) · 어긋남(◇) · 아직 · 모름 (§4.4)
⑥ 문장화          — 템플릿(05 §4.3 방식, 조사 보정). 지난 회차 = 기억 잉크 과거형, 이번 회차 = 현재형
⑦ 실 연결         — ≠ 항목은 이번 회차의 메아리 뿌리 후보, ◇ 항목은 어긋난 메아리(§3.5.2) 후보로 등록
```

**② 관련성 필터**

| 조건 | 예 |
|------|-----|
| 그날 그 슬롯에 주인공이 직접 본 사건 | 9.21 밤 물굽이 |
| 관련 NPC가 주인공과 지난 회차 \|애정\| ≥ 30 또는 신뢰 ≥ 30 또는 기억 태그 강도 ≥ 3 | 페인, 사라, 키트, 하겐 |
| 확정 박자 (고정) | 9.25 대수색 — 언제나 '같음'이지만, 주인공이 그때 무엇을 하고 있었는지가 다르다 |
| 지난 회차 사망일 (고정 표지) | "어제의 너는 여기까지였다" |
| 맹세의 대상·증인 (§5) | 키트, 즈닉 |
| 주인공이 지난 회차에 ◈로 바꾼 것 | 무두장 가죽 |
### 4.4 다섯 표지
| 표지 | 뜻 | 판정 | 예 |
|------|----|------|-----|
| **=** 같음 | 지난 회차와 같은 일이 같은 자리에 일어남 | 같은 사건 ID, 같은 결과 | 9.14 볼크 도착 |
| **≠** 달라짐 (인과) | 달라졌고, 그 원인이 이번 회차 플레이어 뿌리에 있음 (경로 가중치 ≥ 0.25) | 결과 사건의 `roots`에 플레이어 | "키트는 늑대굴에 있다 ≠ 당신이 9.14에 옮겼다" |
| **◇** 어긋남 (표류) | 달라졌고, 플레이어 뿌리 없이 표류 등급 '흔들림·흩어짐' 요소에서 갈림 | `roots` 없음 + drift 꼬리표 | "◇ 사라는 정오 우물에 왔다" |
| **아직** | 이번 회차가 그 시각에 닿지 않음 | 현재 게임 시각 < 항목 시각 | "아직 오지 않았다" |
| **▒** 모름 | 지난 회차에도 그 자리에서 무엇이 있었는지 주인공은 몰랐다 | 지난 회차 `known_by` 없음 | "┊ (그날 밤 페인이 어디 있었는지는 모른다)" |

- `≠`에는 언제나 **한 마디 원인**이 붙는다 ("당신이 9.14에 옮겼다"). 메아리 줄과 같은 문장 규칙(§3.4.3).
- `◇`에는 원인이 붙지 않는다. 표류에는 원인이 없다. 대신 처음 3번은 14 §4.2 H5 진동.
- 두 회차 이상 전과 비교할 때 (◂ ▸ 버튼으로 회차를 고름), 지금 회차와 그 회차 사이의 회차들은 건너뛴다. "가장 멀리 간 회차" 바로가기가 있다 (18 §6.1 「넘어섬」에 쓰인다).
### 4.5 자동으로 떠오르는 때
회차 비교는 대부분 플레이어가 **열어 보는** 화면이다. 단 네 경우에만 스스로 떠오른다.

| 때 | 형태 | 규칙 |
|----|------|------|
| **지난 회차의 오늘** | 새벽 슬롯 맨 위에 기억 잉크 한 줄: "┊ 지난 회차의 오늘, {그날 가장 무거운 일}." 누르면 날 보기 | 그날 지난 회차에 심각도(18 §3.4) 3+ 사건이 있었고 주인공이 알았을 때만. 하루 1줄, 연속 2일 금지. 「기억대로 보낸다」 중엔 없음 |
| **지난 회차 사망일 7일 전** | 하루 요약 카드에 한 줄: "┊ 이레 뒤, 지난 회차의 너는 {장소}에 있었다." | 회차마다 1회. 사망을 직접 말하지 않는다 (§3.4.3) |
| **어제의 너는 여기까지였다** | 지난 회차 사망 시각을 살아서 넘긴 다음 장면 (아래) | 회차마다 1회. 가장 멀리 간 회차의 사망 시각을 넘을 때는 한 줄이 더 붙는다 |
| **회차 시작 정리** | 18 §5.7 「다시, 낙엽월 1일」의 '지난번과 다르게' 칸이 이 생성기를 쓴다 | 18 소관 |

**「어제의 너는 여기까지였다」** — 회차 4, 9.22 00:40, 방앗간 다락 (지난 회차는 9.21 22:44 물굽이에서 끝났다)
```
┌──────────────────────────────────┐
│ 00:40 · 낙엽월 22일 · 물레방아간 다락 │
├──────────────────────────────────┤
│  짚 속에 눕는다. 아래층에서 토마스가   │
│  코를 곤다. 페인이 사다리 위에서       │
│  잠꼬대를 한다. 살아 있는 사람의       │
│  잠꼬대다.                          │
│  강 쪽에서 노 젓는 소리는 들리지 않는다.│
│  ┊ 이 시각, 물이 찼다.               │
│  ── 어제의 너는 여기까지였다 ──       │
│  이 밤의 다음은, 너도 모른다.         │
├──────────────────────────────────┤
│ ▸ 잠든다                            │
│ ▸ 깨어 있는다. 아침을 본다            │
└──────────────────────────────────┘
```
- 이 장면 뒤로 회차 비교의 **날 보기 위 줄이 비어 있다** ("┊ —"). 지도 위에서 주인공의 기억이 끝나는 날짜에 가는 선이 그어진다 (07). 플레이어는 처음으로 **아무것도 모르는 날**에 들어선다.
- 가장 멀리 간 회차(`loop.furthest`)를 넘는 순간에는 한 줄이 더 붙는다: "어느 회차의 너도, 여기까지 오지 못했다." 18 §6.1 「넘어섬」 단계가 시작된다.
- 15 목소리 반응 후보 (회차 3 이상에서만): ⟨다라⟩ "아홉 번째에 처음으로 해 뜨는 걸 봤어. 별거 없더라. 그래도 봐."
### 4.6 정서 가중치와 분량
**`W = Rel × Mag × Turn`**

| 인수 | 값 |
|------|-----|
| **Rel** 관련도 | 인물: 지난 회차 관계 강도 max(\|애정\|, 신뢰, 원한)/100 · 맹세 대상 1.0 · 지난 회차 사망 원인 1.0 · 확정 박자 0.6 |
| **Mag** 크기 | §3.2 M 표와 같다 |
| **Turn** 갈림 | ≠ 1.3 · ◇ 1.1 · = 0.8 · 아직 1.0 · ▒ 0.5 |

| 항목 | 상한 |
|------|------|
| 날 보기 | 슬롯 4 × 회차 2 = 8줄 + 사람 칸 최대 3명 × 2줄 |
| 사람 보기 | 회차 최대 6 (넘으면 "· · · 회차 셋, 같은 끝" 처럼 같은 끝끼리 접음) + 단단한 것 3 |
| 갈림길 | 줄기 1 + 가지 최대 8 (넘으면 같은 끝끼리 접음) |
| 항목 하나 | 최대 2줄, 44자 |
| 표시 | 한 화면. 좌우(◂ ▸)로 날짜 또는 비교 회차를 넘김 |
### 4.7 전체 예시 — 셋째와 넷째, 낙엽월 25일 (최종 텍스트)
> 전제 (예시 시드): 회차 3 — 배급 줄에서 헨릭과 흥정(키트 제외, 토비 대신), 9.20 이르마의 칼자국을 지나침, 9.25 대수색 날 늑대굴에서 시그리드 무리 11명이 잡히는 것을 숲 가장자리에서 봄, 서리월 20일 용의 대로에서 사망.
> 회차 4 — 9.5 세 소나무 매듭을 다시 묶음(M1), 9.14 키트를 늑대굴로, 9.20 페인을 이르마에게 데려감. 오늘 9.25 저녁.

```
┌──────────────────────────────────┐
│ 두 겹의 날 — 낙엽월 25일      ◂ ▸   │
│ 셋째 저녁부터 ┊  넷째 저녁부터 ●     │
├──────────────────────────────────┤
│ 새벽 ┊ 이르마가 초소에서 돌아왔다      │
│      ● 이르마는 초소에 가지 않았다     │
│      ≠ 당신이 9.20 페인을 데려갔다     │
│ 정오 ┊ 사냥대가 늑대굴로. 열한 명      │
│      ● 사냥대는 서쪽 골짜기로 갔다     │
│      ≠ 당신이 9.5 매듭을 다시 묶었다   │
│ 저녁 ┊ 수탉 앞, 볼크가 개를 쓰다듬었다  │
│      ● 수탉 앞, 볼크가 하겐의 멱살을    │
│        쥐었다                       │
│ 밤   ┊ 숲 가장자리. 사슬 소리          │
│      ● 아직 오지 않았다               │
│ ── 사람 ──                          │
│ 시그리드 ┊ 사슬에 묶여 남쪽으로        │
│          ● 늑대굴. 창을 닦고 있다      │
│ 키트     ┊ 움막. 명단에 없었다         │
│          ● 늑대굴. ◇ 열이 있다         │
└──────────────────────────────────┘
```
- 글자 수: 약 380자. 지난 회차 줄 6, 이번 회차 줄 7, ≠ 2, ◇ 1.
- "키트 ◇ 열이 있다"는 표류다 (아이의 가벼운 열병 '흩어짐'). 플레이어가 한 일과 무관하다는 것이 ◇로 보인다 — 그래도 플레이어는 늑대굴의 추위를 의심할 것이다. 비교는 그 의심을 막지 않는다. 다만 거짓 원인을 붙이지 않는다.
### 4.8 회차가 길 때
- 회차가 1년을 넘기면 날 보기의 단위가 **달**로, 3년을 넘기면 **계절**로 바뀐다 ("313년 봄 ┊ / ●").
- **「그 회차에 세운 것」** 비교 (14 §6.6 회차 기록 2장과 같은 데이터):
  `늑대굴 ┊ 여섯째 저녁부터 — 백마흔 명, 글을 아는 사람 열아홉 / ● 아직 아무도 없다.`
  `아이 ┊ 여섯째 저녁부터 — 314년 봄에 태어났다 / ● (다시 태어나지 않는다)`
- 마지막 줄은 템플릿이 아니라 **고정 문장**이다. 회차 안에서 낳은 아이에 관한 비교에는 언제나 이 줄만 붙는다 (WORLD_BIBLE §1.3.1). 플레이어가 이 칸을 닫을 수 있다 (설정 「회차 비교에서 아이 숨기기」).

## 5. 맹세 (Oath)
### 5.1 원칙 — 맹세는 퀘스트가 아니다
| 원칙 | 구현 |
|------|------|
| **말이다, 버튼이 아니다** | 맹세는 장면의 선택지 중 하나로, 다른 선택지와 같은 모양으로 나온다. 체크 표시·보상 미리보기·"새 목표" 팝업 없음 |
| **게임이 아니라 사람이 원하는 순간에** | 맹세 제안은 상실·불의·배신의 순간에만, 그것도 드물게 (§5.3). 아무 때나 하려면 맹세록에서 스스로 |
| **언제나 거절할 수 있다** | 맹세하지 않아도 불이익이 없다. 거절은 기록되지도 않는다 |
| **진행 막대가 없다** | 맹세록에는 "이야기된 것"만 쌓인다 (§5.5). 게이지·퍼센트·화살표 표지 없음 |
| **세계가 듣는다 — 그 회차 안에서는** | 증인이 기억하고 소문을 옮긴다. 보상과 벌의 대부분은 시스템 보너스가 아니라 **사람들의 반응**이다. 회귀하면 증인은 잊는다 |
| **증인은 잊었다, 나는 기억한다** | 맹세는 주인공의 기억에 남는다. 회차를 넘어 따라온다 (§5.8). 세계에는 아무 흔적이 없다. 그래서 회차를 넘는 맹세는 **오직 주인공의 것**이다 |
### 5.2 유형 (6)
| 유형 | 동사 | 대상 | 지켜짐 조건 (판정 엔진) | 예 |
|------|------|------|--------------------------|-----|
| **지킨다** (protect) | 지킨다, 데려온다, 살린다 | 인물·무리·장소 | 대상이 기한(또는 회차) 끝까지 살아 있고 지정 상태(자유·안전·장소)에 있음 | "키트를 여울강 이쪽으로 데려온다" |
| **갚는다** (avenge) | 갚는다, 데려온다(심판대로), 죽인다 | 인물·세력의 일원 | 대상이 죽음 / 지정 처지(폭로·재판·추방)에 놓임. **플레이어 또는 플레이어가 움직인 자**에 의해 (경로 가중치 ≥ 0.3) | "울프를 죽인 자를 당신 앞에 데려온다" |
| **세운다** (build) | 세운다, 가르친다, 남긴다 | 영역·시설·사람 수 | 영역 수치·시설·인원 문턱 도달 (09) | "늑대굴에서 글을 아는 사람 서른" |
| **풀어준다** (free) | 풀어준다, 빼낸다 | 인물·무리 | 대상의 신분이 노예 → 탈주·자유민·계약 해지 | "굶주림월 사흘 전에 서른한 명을" |
| **배운다** (learn) | 배운다, 받는다, 안다 | 스킬·지식·진명 | 스킬 문턱 / 지식 획득 / 스승의 전수 이벤트 | "엘사가 죽기 전에 낱말 140개를 모두 받는다" |
| **무너뜨린다** (destroy) | 무너뜨린다, 불태운다, 끝낸다 | 장소·조직·문서·체제 | 대상 파괴 / 조직 와해 / 문서 소멸 | "목줄단의 명단을 불태운다" |
- 판정 엔진은 대상 상태를 세계 상태에서 읽는다 → **새 조건 코드 없음**. 맹세 데이터의 `fulfill` 조건식은 스토리렛 조건식(05)과 같은 문법이다.
- **`fulfill`은 끝 상태로 쓴다** ("키트가 여울강 이쪽에서 자유롭다"), 과정으로 쓰지 않는다 ("팔려 간 키트를 데려온다" ✗). 그래야 회귀한 세계에서 같은 조건이 다시 평가될 수 있다 (§5.8 ③).
- **배운다** 맹세는 회차를 넘기 쉽다: 스킬·지식·진명은 남는 것이다 (14 §4.3). 그래서 배운다 맹세는 회귀하면 진척이 그대로 이어진다 — 엘사의 낱말 140개 중 지난 회차에 받은 60개는 이번 회차에도 60개다. 엘사는 그것을 모른다 (`과하게_앎` 위험).
### 5.3 선언 — 두 가지 길
#### 5.3.1 감정의 순간 — 맹세 제안
장면 안에 **맹세 줄**이 선택지 하나로 끼어든다. 맹세 제안 규칙(`OathPromptRule`)이 다음 계기에서 발동한다.

| 계기 | 조건 | 제안되는 유형 |
|------|------|---------------|
| **상실** | 애정 50 이상 NPC가 눈앞에서 죽음·팔림·끌려감 | 지킨다(남은 이) / 갚는다 / 풀어준다 |
| **불의** | 공개 처형·매질·매각을 목격, 희생자 중 이름 아는 자 1명 이상 | 갚는다 / 무너뜨린다 / 풀어준다 |
| **배신 발견** | 신뢰 40 이상 NPC의 배신 사실을 알게 됨 | 갚는다 |
| **임종의 부탁** | 신뢰 50 이상 NPC가 죽어 가며 부탁 (NPC 데이터 `dying_request`) | NPC가 정한 유형 (NPC에게 하는 맹세, §5.9) |
| **죽을 뻔함** | 체력 0 직전에서 살아남은 직후 | 세운다 / 배운다 ("살아남으면…") |
| **가르침의 문턱** | 스승이 비전 전수 조건을 말함 | 배운다 |
| **기억의 재회** | 지난 회차에 **눈앞에서 잃은** 사람을 이번 회차에 처음 다시 만남 (14 §7.3 재회) | 지킨다 — 그리고 기억 속 맹세가 이미 있으면 "다시 말한다" (§5.8 ②) |

**빈도 상한**

| 규칙 | 값 |
|------|-----|
| 한 세션당 맹세 제안 | 최대 **1** |
| 맹세 제안 사이 | 게임 시간 5일 이상 |
| 한 회차당 맹세 제안 | 최대 **8** |
| 회차 시작 후 첫 실제 10분 | 제안 없음 (예외: 출신 첫 장면에 작가가 넣은 것, 기억의 재회) |
| 활성 맹세가 3개(상한)일 때 | 제안하지 않음 — 단 **임종의 부탁**은 예외 (그때는 "다른 맹세를 내려놓고" 선택지가 함께 나온다) |
| 같은 대상에게 이미 활성 맹세가 있을 때 | 제안하지 않음 (기억 속 맹세의 "다시 말한다"는 제안이 아니라 그 맹세의 갱신) |

**맹세 줄 문장 규칙**
- 따옴표 안에 **주인공이 실제로 하는 말**만. 유형 이름·"맹세" 같은 시스템 단어 금지 (장면 2 참고).
- 기한은 세계 안의 사건으로 말한다: "굶주림월 사흘 전에", "볼크가 다시 오기 전에", "재의 날이 오기 전에". 날짜 숫자 금지.
- 한 장면에 맹세 줄은 최대 1개. 위치는 마지막에서 두 번째 (마지막은 늘 "물러서는" 선택지).
- 맹세 줄이 다른 선택지의 행동과 합쳐질 수 있다: "▸ 사슬을 끊으며 말한다: …" — 행동 판정 + 맹세.
#### 5.3.2 맹세록에서 — 조용한 맹세
- 언제든 맹세록 → `새 맹세`. 고르는 것: 동사(유형) + 대상(인물 수첩·지도·지식에서 **아는 것만** — 지난 회차에 알게 된 것도 포함) + 기한(없음 / 세계 사건 목록에서) + 거는 것(§5.4).
- 바로 등록되지 않는다. **다음 쉼표(밤 잠자리)에 「밤의 맹세」 짧은 장면**으로 말하게 된다: "그날 밤, 당신은 소리 내어 말한다."
- 그 자리에 동료가 있으면 **증인이 된다**. 혼자면 증인 없음 → 보상은 작지만 벌도 작다 (§5.6~5.7).
- 쿨다운: 조용한 맹세는 게임 시간 7일에 1회.
### 5.4 매개변수
| 매개변수 | 값 | 효과 |
|----------|-----|------|
| **대상** | 인물·무리·장소·세력·문서·지식·영역 | 판정 대상 |
| **유형** | §5.2의 6개 | 판정 조건 |
| **기한** | 없음 / 세계 사건 (`deadline_event`) / 회차 끝 | 기한이 지나면 '늦음' 판정 (§5.7). 고정 박자인 기한은 회귀하면 **다시 앞에 온다** (§5.8 ③) |
| **증인** | 자동: 장면에 있던 NPC 전원 (C등급은 B로 승격, 08 §2) | 기억 태그 `oath_heard:{id}`, 소문의 씨앗. **그 회차 안에서만** |
| **거는 것** | **말** (기본) / **이름** / **피** / **돌아와서도** | 아래 표 |

**거는 것**

| 거는 것 | 하는 법 | 지켰을 때 | 깼을 때 | 제약 |
|----------|---------|-----------|---------|------|
| **말** | 그냥 말한다 | 기본 보상 | 기본 벌 | — |
| **이름** | 진짜 이름(06 §1.1)을 증인 앞에서 밝히고 건다 | 증인 신뢰 보상 ×2, "진짜 이름을 알려줌" 관계 사건 발생 | 벌 ×2. 진짜 이름은 그 회차 동안 **증인들에게 알려진 채** 남는다 (진명 마법 저항 −15의 표적) | 증인 중 적대 NPC가 있으면 큰 위험. 회귀하면 증인들은 이름을 잊는다 — 위험도, 신뢰도 함께 |
| **피** | 손바닥을 긋는다 (체력 −5) | 의지 판정 보너스 +5 → +8 | 흉터(외모 특징 — 10 §3.1 식별 요소 추가). 흉터는 몸의 것이라 회귀하면 사라진다 | 그롬·두르강 증인에게 존중 +10 |
| **돌아와서도** | "몇 번을 돌아와도"를 덧붙인다 | 회차를 넘어 지키면 보상 ×1.5 (영혼 겹만) | 깨진 맹세의 무게(§5.8 ⑥) ×2 | 내려놓을 수 없다. 한 번에 1개만. 세계 안에서 이 말은 **이상하게 들린다** — 증인의 통찰 판정 성공 시 잔향 징후 노출 +3 ("몇 번을 돌아와도? 어디서 돌아와?") |

- 각 맹세 아래 쌓이는 줄 = 그 맹세의 대상·증인과 관련된 사건 중 플레이어가 **알게 된** 것. 실(thread)에서 자동 추출 (`oath.target`을 읽은 사건 중 `known_by` 플레이어). 회귀하면 이 줄들은 지워지고 맹세 문장·처음 맹세한 회차·증인 이름만 남는다.
- 기한은 숫자 대신 말로: "아직 시간이 있다"(기한까지 50% 이상) / "시간이 줄고 있다"(20~50%) / "곧이다"(20% 미만). 설정에서 날수 표시 가능.
- **증인 표기**: 이번 회차에 들은 증인은 이름만. 지난 회차의 증인은 "(잊었다)". 증인이 이번 회차에 죽으면 이름에 줄. 다시 말해 같은 증인이 이번 회차에 다시 들었다면 "(다시 들었다)".
- **선택지 표지**: 맹세를 직접 돕는 선택지에는 판정 표기 뒤에 작게 `· 맹세` (예: `[흥정] 어렵다 · 맹세`). 길게 누르면 어느 맹세인지. 보너스 수치는 판정 근거 미리보기(01 §4.3)에만. 기억 속 맹세를 돕는 ◈ 선택지는 `◈ … · 맹세`.

**쉬운 맹세 방지 (보상 농사 금지)**
- 맹세 시점에 **난이도 추정**을 한다: 연출가(18)의 시뮬레이션으로 기한 안 달성 확률 p를 어림.
- p ≥ 0.9이거나 맹세 후 게임 하루 안에 지켜지면 **사소한 맹세**: 업적·TP·칭호 진척 없음, 증인 반응은 "…그건 맹세할 일도 아니었잖아." (05 개념 `약속지킴` 의 `trivial` 변형)
- 이미 거의 끝난 일(대상 상태가 조건의 80% 이상 충족)은 맹세 대상이 될 수 없다.
- **회귀 농사 금지**: 같은 대상·같은 유형의 맹세로 얻는 사람들 겹 보상은 회차마다 다시 주어지지만(세계가 잊으므로 당연하다), **영혼 겹 보상(업적·TP)은 한 번뿐**이다. 기억 속 맹세를 지킬 때 p 추정은 **주인공의 기억을 넣고** 계산한다 — 아는 사람에게 쉬운 일은 쉬운 일이다.

### 5.7 깨짐
| 상태 | 언제 | 증인 반응 (그 회차 안) | 그 밖 |
|------|------|-----------|-------|
| **깨짐** | 맹세와 정면으로 어긋나는 선택을 직접 함 (키트를 지키겠다 해 놓고 키트를 판다) | 신뢰 −25, 애정 −10, 기억 `oath_broken:{id}` 강도 4 (반감기 2년), 05 개념 `약속어김` 대사 | 증인 집단 시선 −5, 이름을 걸었으면 −10. **깨진 맹세의 무게**(§5.8 ⑥)가 주인공에게 남는다 |
| **늦음** | 기한이 지났는데, 맹세를 돕는 행동을 2회 미만 시도 | 신뢰 −15, 기억 `oath_lapsed` 강도 3 | 깨짐으로 집계 (칭호 '말을 판 자'). 무게는 깨짐의 절반 |

| **풀림** | 대상 인물이 스스로 맹세를 풀어 줌 (§5.9) | 신뢰 +5 | 벌 없음. ACH-O3 |

**두르강의 돌심장 (06)**
- 깨짐·늦음 1회마다 **체질 −1** (06 규칙). '지키지 못함'도 돌에게는 깨짐이다 — 돌은 노력을 세지 않는다. '꺼짐'·'풀림'·'회차의 끝'은 아니다.
- 체질은 몸의 것이라 회귀하면 돌아간다. 그러나 돌심장은 **영혼의 재능**이다: 깨진 맹세 하나마다 **영혼의 흉터**가 남아, 회귀할 때마다 체질 −1이 회귀점에서 다시 적용된다 (06과 맞출 것). 갚음(§5.8 ⑥)으로 지운다.
- 깨질 때마다 몸 어딘가가 회색으로 굳는 묘사 1줄 (손끝 → 손등 → 손목 순). **회귀해도 회색은 돌아오지 않는다** — 배급 줄의 첫 화면에 그 손이 보인다: "그릇을 받는 손끝이 회색이다." 두르강 NPC는 이것을 본다 → '맹세를 훔친 자' 노출 판정 +10 (06 사냥당할 이유).
- 깨진 뒤 30일 동안 의지 +10 보너스 꺼짐.

**페이의 그림자 (06 "맹세하면 반드시 묶임")**
- 활성 맹세와 정면으로 어긋나는 선택지는 **잠긴다**: `(묶여 있다)`. 풀려면 `[의지 D70]` — 성공하면 선택할 수 있고, 맹세는 깨진다. 기억 속 맹세에도 묶인다 (페이의 묶음은 몸이 아니라 말에 걸린다).
- 깨지면 **페이 저주** 1개 (d6):

| d6 | 저주 | 지속 |
|----|------|------|
| 1 | 그림자가 반 박자 늦게 따라온다 — 은신 −10 | 30일 |
| 2 | 맹세의 증인 앞에서 진짜 이름을 말할 수 없다 — 그 증인 상대 화술 −10 | 회차 |
| 3 | 철에 닿는 통증 ×2 | 다음 맹세를 지킬 때까지 (회귀해도) |
| 4 | 가시 왕관의 여왕이 당신의 이름을 듣는다 → 결점 '저주받은 이름' 획득 | 회차 (회귀하면 여왕도 잊는다 — 다시 깨면 다시 듣는다) |
| 5 | 고인 물과 거울에 비치지 않는다 — 잔향 징후 노출 판정 −10 | 90일 (회귀하면 끝) |
| 6 | 당신이 다음에 하는 거짓말 하나가 사실이 된다 (작가 스토리렛 `fae_lie_made_true`) | 1회 |
- 또한 페이의 그림자를 가진 주인공은 **대사에서 한 약속도 작은 맹세가 된다**: 05 대사 규칙의 `then: promise` 효과가 붙은 선택지를 고르면 증인 1명(상대)짜리 작은 맹세로 자동 등록 (최대 5개 추적, 활성 맹세 상한에 포함되지 않음). 작은 맹세를 깨면 50% 확률로 저주 d6. 작은 맹세는 회귀하면 사라진다 (기억 속 맹세가 되지 않는다).
### 5.8 회차를 넘는 맹세 — 증인은 잊었다, 나는 기억한다
> **정리 — 맹세는 회차를 넘어 남는가?** 남는다. 단, **주인공 안에만** 남는다.
> - **남는 것 (주인공의 기억)**: 맹세의 말·대상·처음 맹세한 회차·증인의 이름이 맹세록의 「기억 속 맹세」와 기억 카드(`oath_memory:{id}`)로 남는다. 마음의 압박도 남는다 — 맹세의 힘(+5), 깨진 맹세의 무게(⑥), 내면의 목소리(15)의 반응. 배운다 맹세의 진척(스킬·낱말)은 그 자체가 남는 것이라 이어진다.
> - **돌아가는 것 (세계 효과)**: 증인은 잊는다. 증인의 기억 태그·신뢰·존경, 소문, 칭호, 증인 집단 시선, 이름을 건 맹세의 노출, 피를 건 흉터 — 그 회차에 맹세가 세계에 만든 모든 것이 회귀점으로 돌아간다. 다시 세우려면 **다시 말해야** 한다 (②).
> - 한 줄로: **증인은 잊었다, 나는 기억한다.** (프로토타입 문구와 같다)

1. **회귀하면** 활성 맹세는 모두 **기억 속 맹세**가 된다 (지켜짐·깨짐 판정 없음 — 죽음은 깨짐이 아니다). 증인은 모두 "(잊었다)". 맹세록의 사건 줄은 지워지고, 맹세 문장·처음 맹세한 회차·증인 이름만 남는다.
2. **새 회차의 첫 잠자리**(14 §6.6 회차 기록 다음 장, 장면 6)에서 기억 속 맹세마다 고른다:
   - **마음에 둔다** — 활성 맹세로 돌아온다 (상한 3에 포함). **증인이 없다.** 맹세의 힘(+5)은 있지만 사람들 겹 보상은 없다. 깼을 때의 증인 반응도 없다 — 그러나 무게(⑥)는 그대로다.
   - **다시 말한다** — 이번 회차에 같은 대상(또는 원래 증인) 앞에서 그 말을 **다시 하는 기회**를 기다린다. 「기억의 재회」 계기(§5.3.1)나 맹세 제안이 오면 그 맹세 줄이 원래 문장 그대로 나온다. 말하면 새 증인이 생기고, 맹세록에 "(다시 들었다)". 듣는 사람에게는 **처음 듣는 말**이다. 기억 잉크 한 줄이 붙는다: "┊ 지난번에도 즈닉은 웃었다."
   - **내려놓는다** — 벌 없음. 회차 기록에 '내려놓은 맹세'로 남는다. 15 목소리 중 하나가 한 마디 한다 (⟨군데⟩ "…내려놓는 소리, 들었다.").
   - '돌아와서도'를 건 맹세는 내려놓을 수 없다 — 자동으로 "마음에 둔다".
3. **조건을 다시 본다**: 회귀한 세계에서 맹세의 `fulfill`(끝 상태)과 기한을 다시 평가한다.
   - 기한이 고정 박자면 **다시 앞에 온다** ("서리월 아흐레까지 서른여드레").
   - 맹세를 하게 만든 일이 아직 일어나지 않았으면 **앞질러 지킨다**: 키트가 팔린 뒤 "데려온다"고 맹세했어도, 끝 상태는 "키트가 여울강 이쪽에서 자유롭다"이므로, 키트가 처음부터 팔리지 않으면 지켜진 것이다 (ACH-O6). 그 순간 주인공은 아무도 듣지 않은 약속을 지킨다. 화면에는 맹세록에 한 줄만: "· 지켜졌다. 아무도 모른다."
   - 대상이 회귀점 이전에 이미 없는 사람이면 (회귀점보다 앞서 죽은 울프 등) 기억 속 맹세는 '꺼짐'이 된다.
4. **증인은 몸을 기억하지 않는다. 아무것도 기억하지 않는다.** 이전 설계의 "새 몸의 정체 노출"은 없다. 대신 기억 속 맹세를 **지나치게 아는 방식으로** 지키면 (아무도 모르는 일을 미리 막음) 14 §7.3 `과하게_앎`과 같은 의심이 생길 수 있다: 이졸·마르타·볼크 같은 사냥 쪽 인물이 그 장면을 보면 `echo_signs` +3 (SCENARIOS 맹약회의 변수). 이것이 칭호 '이상하게 아는 자'의 대가다.
5. 한 시대에 기억 속 맹세는 최대 6개까지 보관. 넘치면 가장 오래된 것부터 '바래진 맹세'로 회차 기록 보관함에만 남는다.
6. **깨진 맹세의 무게** — 세계는 당신이 깬 것을 잊는다. 당신은 잊지 않는다.

   | 무게 | 내용 | 지속 |
   |------|------|------|
   | 스트레스 | 회귀할 때마다 시작 스트레스 +3 / 깨진 맹세 하나 (늦음 +1.5, '돌아와서도'는 ×2). 합계 상한 +12 | 갚을 때까지 |
   | 기억 잉크 | 깨진 맹세의 대상을 새 회차에서 처음 볼 때 한 줄: "┊ {n}번째 저녁부터, 너는 이 아이를 팔았다." 대상은 아무것도 모른다 | 회차마다 1회 |
   | 같은 배신의 표지 | 같은 맹세를 같은 방식으로 다시 깰 선택지 끝에 작게 `(전에도)` | 갚을 때까지 |
   | 목소리 | 15 문서. 맹세를 깬 회차 수가 늘면 ⟨다라⟩·⟨군데⟩의 말이 짧아진다 | — |
   | 돌의 흉터 | 두르강의 돌심장 보유 시 위 규칙 | 갚을 때까지 |
   - **갚음**: 이후 회차에서 **같은 대상·같은 유형**의 맹세를 지키면, 깨진 맹세에 "· {m}번째 저녁부터 지켰다"가 붙고 무게가 걷힌다. 깨진 기록 자체는 지워지지 않는다. 회차 기록 보관함에는 둘 다 있다.
   - 무게는 벌이 아니라 **기억**이다. 수치는 작고, 회복할 길이 있다. 플레이어가 맹세를 아예 하지 않게 되면 장치가 실패한 것이다 (§9 지표).
### 5.9 NPC에게 하는 맹세, NPC가 하는 맹세
#### 5.9.1 플레이어가 NPC에게 (부탁받은 맹세)
- NPC 데이터의 `asks_oath` (임종의 부탁, 스승의 조건, 동료 아크의 문턱)에서 제안된다. 그 NPC는 **수혜자이자 증인**이다.
- 그 NPC가 살아 있으면 맹세를 **풀어 줄** 수 있다 (`release_condition`): 예) 군나르는 플레이어가 그롬마르행 대신 브란을 지키는 쪽을 고르면 "…100번째는 내 몫이다. 놓아 줘라." → 풀림, ACH-O3.
- 그 NPC가 죽은 뒤 지키면, 그 NPC의 가장 가까운 사람(08 관계 최댓값)이 대신 반응한다.
- **임종의 부탁을 한 사람은 회귀하면 다시 살아 있다.** 부탁은 기억 속 맹세가 되고, 부탁한 사람은 그 부탁을 한 적이 없다. "다시 말한다"를 고르면, 그 사람이 살아 있는 동안 그에게 직접 그 말을 할 수 있다 — 그는 왜 낯선 이가 자기 소원을 아는지 모른다. 풀어 줄 수 있는 사람이 살아 있다는 것, 그것이 회귀가 주는 드문 위로다.
#### 5.9.2 NPC가 플레이어에게 (당신을 향한 맹세)
| 항목 | 규칙 |
|------|------|
| 발생 | 동료 충성 아크 문턱(CHARACTERS의 "충성 아크 70" 대사가 대개 맹세다), 구해 준 NPC, 적의 맹세 (17) |
| 받는 이 | `player`(주인공에게) / `cause`(주인공이 세운 것 — 영역·무리에게) |
| 지킴 판정 | **압박 지점**(`pressure_points`)마다: `p = clamp(0.5 + 충성/200 + 정직/400 + 신뢰/200 − 압박, 0.05, 0.98)`. 압박 = 그 지점에 정의된 값 (굶주림 0.2, 가족 위협 0.5, 고문 0.4 등) |
| 플레이어가 죽으면 | **모든 NPC 맹세는 그 회차와 함께 꺼진다.** 그 NPC는 맹세한 적이 없다. `cause` 맹세도 같다 — 늑대굴은 아직 없다 |
| 주인공의 기억 | NPC가 맹세했던 **조건과 말**은 주인공의 기억이 된다 (지식 카드 `npc_oath_known:{id}`). 다음 회차에 그 NPC가 같은 문턱에서 같은 말을 하면 기억 잉크 한 줄: "┊ 지난번에도 그녀는 이 말을 했다." — 그리고 그 맹세가 어디서 깨졌는지도 기억한다 (압박 지점을 미리 막을 수 있다) |
| 표시 | 맹세록 「당신을 향한 맹세」. 적의 맹세는 그 존재를 **알 때만** 보인다 (소문으로 들었으면 점선). 기억 메뉴에 「지난 회차에 들은 맹세」 |
| 메아리 | NPC가 맹세를 지키거나 깬 결과는 플레이어 뿌리(그 NPC를 그렇게 만든 선택)로 메아리가 된다 |
### 5.10 어두운 맹세
- 대상 범위에 **비전투원·아이·한 종족 전체·이름 모를 다수**가 들어가는 맹세. 데이터 `scope: all` 또는 `includes_noncombatants: true`.
- 제안 조건 (둘 중 하나): 자비 −20 이하, 또는 애정 40 이상 인물 5명 이상이 한 번에 처형되는 것을 목격.
- 게임은 판단하지 않는다 (WORLD_BIBLE §0.2, 13 문서). 결과는 세계 안에서:
  - 증인은 자기 성향으로 반응한다: 디트마르 신뢰 +20 ("이제야 말이 통하네") / 사라 신뢰 −30, 자비 +40 이상 동료는 이탈 판정 / 브란은 '고드릭'이 대상에 들어 있으면 +25.
  - 지키면 13 문서 '학살자' 경로 효과: 대상 세력 위협도 +1~2, 칭호 '피로 맹세한 자', 연합 대응 위험.
  - 대상 안에는 **인간도 있을 수 있다** — 레이번 성채의 인간 하인 38명. 맹세의 말은 그들을 빼지 않았다. 지킬 때 그 장면이 온다.
  - 그 회차의 몇 해 뒤 메아리: 살아남은 자식이 숙적(17)이 되어 돌아온다.
- **기억 속 어두운 맹세**: 회귀하면 성채의 38명은 다시 살아 있다. 어두운 맹세를 "마음에 둔다"로 지고 가면, 첫날 저녁 배급 줄에서 성채 쪽을 볼 때마다 기억 잉크가 한 줄 붙는다: "┊ 서른여덟. 리즈는 부엌에 있었다." 어두운 맹세는 그 회차에 이미 지켰더라도 다시 '활성'이 될 수 있다 — 그 사람들이 돌아왔으므로. 게임은 어느 쪽도 권하지 않는다.

## 7. 기존 시스템 연동
| 시스템 | 이 문서가 **읽는** 것 | 이 문서가 **쓰는** 것 |
|--------|------------------------|------------------------|
| **00 연동도** | 사건 버스, 세계 상태, 스냅샷 | 모든 사건에 `causes`·`roots`·`loop` 필드, 상태 키 `lastWriter` (엔진 공통 규약). 회귀 시 인과 그래프 → 회차 보관함 |
| **01 판정** | 판정 결과(뿌리 `check`), 성향, 논거 보정에 들어간 기억 카드 | 맹세의 힘 +5/+8, 지킨 순간 스트레스 −20·용기 +3 |
| **02 선택지** | 선택지 id, 미리보기 내용(`hintedAt`) | 선택지 데이터의 `root_phrase`·`memory_phrase` 필드, `· 맹세` 표지, `(전에도)` 표지 |
| **03 회귀·회차** | 회귀 정산, 회차 기록, 시대 연대기, 스트레스 이월 | 회차 보관함(`LoopArchive`), 회차 기록의 '내려놓은 맹세'·'당신 대신 탄 사람들'·'깨진 맹세', 깨진 맹세의 무게 → 시작 스트레스 |
| **05 대사** | 기억 태그 대사 발동 여부(중복 제거 −25), `then: promise` | 개념 `약속지킴`·`약속어김`·`맹세들음` 대사 조건 `memory has oath_*`, 메아리 금지어 검증. `과하게_앎`(14)과 '이상하게 아는 자' |
| **06 생성** | 재능: 두르강의 돌심장, 페이의 그림자, 진짜 이름 | 돌심장 '영혼의 흉터'(회귀점에서 체질 −1 재적용 — 06과 맞출 것), 페이 저주 지속을 회차 기준으로 |
| **08 관계·사실** | 관계 강도, `known_by`(회차별), 사실, 승격 규칙 | 기억 태그 `oath_heard/kept/broken/lapsed`, 신뢰·애정 변화, C→B 승격(증인·토비) |
| **09 영역** | 영역 수치·시설(기억의 벽) | 세운다 맹세 판정, 회차 비교 「그 회차에 세운 것」 |

| **13 어둠의 길** | 학살자 경로 | 어두운 맹세 (§5.10) |

| 증인 대사 (05 개념 `맹세들음`·`약속지킴`·`약속어김`) | ① 고유 22인 × 3 = **66** + ② 역할 15 × 3 = 45 + ④ 범용 12 | ① 120인 × 3 + ② 45 × 3 + ③ 원형 12 × 3 × 3 = **약 600** |

## 9. 위험과 대응
| 위험 | 어떻게 재미를 해치나 | 대응 |
|------|----------------------|------|
| **메아리 범람** | 모든 일에 "N일 전 당신은…"이 붙으면 소음이 되고 생색으로 읽힌다 | 문턱 50, 세션 3·큰 1·회차를 넘는 것 1, 간격 6장면, 같은 뿌리 회차당 3. 접힌 날은 메아리 없음. 헤드리스 시뮬레이션으로 "세션당 평균 메아리 줄 1.2~2.0"을 검증 지표로 둔다 |
| **훈계로 읽힘** | "당신 때문에 토마스가 맞았다" = 설교. "이번엔 성공!" = 생색 | 금지어 자동 검증(평가어에 '드디어·이번엔' 추가), 뿌리만 말하고 결과를 평가하지 않음, 지난 회차의 죽음을 직접 말하지 않음, 감정은 목소리(15)에 위임 |
| **거짓 메아리가 신뢰를 깬다** | "게임이 거짓말했다"는 느낌 → 모든 메아리를 의심 | 짐작은 언제나 물음표·점선. 확정 표지는 절대 뒤집지 않음. 거짓은 회차 1·시대 3, 같은 거짓의 반복 금지, 드러남 경로 보장, 짐작의 참 비율 50% |
| **표류를 인과로 착각** | 운으로 어긋난 것을 "내가 망쳤다"로 / 내가 바꾼 것을 "운"으로 읽음 → 기억을 신뢰할 수 없게 됨 | 회차 비교의 ≠/◇ 구별, 어긋난 메아리(회차당 3번 언제나 표시), 표류에는 원인 문장을 붙이지 않음 |
| **실타래·비교 스포일러** | 실타래나 회차 비교가 주인공이 모르는 비밀을 누설 | 회차별 `known_by` 게이트, 모르는 고리는 범주 힌트만, 비교는 "주인공이 그때 알았던 것만". 검증 도구: 렌더러가 비공개 사실 문자열을 출력하면 빌드 실패 |
| **회차 비교가 공략표가 됨** | 플레이어가 비교 화면만 보며 기계적으로 따라간다 | 미래를 말하지 않음("아직 오지 않았다"), 표류가 세부를 매번 흔듦, "단단한 것"은 3회차 이상 같은 것만 (플레이어가 실제로 겪은 것). 공략이 되는 것은 **플레이어가 번 지식**이므로 허용 |
| **결과 없는 선택의 노출** | 메아리가 안 뜨면 "내 선택은 무의미했나?" | 조용한 메아리 `〰` 표식으로 "무언가 이어졌다"만 알림. 회차 기록·실타래 보관함·회차 비교의 ≠ |
| **회귀가 노력의 증발로 느껴짐** | "다 잊었잖아" → 이번 회차에 공들일 이유가 없다 | 기억 메아리(§3.5.1)가 지난 회차의 앎을 이번 회차의 결과에 **이름 붙여** 보여 줌. 「어제의 너는 여기까지였다」로 진척을 날짜로 느끼게 함. 배운다 맹세는 진척이 이어짐 |
| **맹세가 퀘스트 목록이 됨** | 제안이 잦으면 "게임이 준 할 일" | 계기 8종만, 세션 1·회차 8, 첫 10분 금지, 시스템 단어 없는 대사형, 진행 막대 없음, 거절 무기록 |
| **맹세 보상 농사** | 쉬운 맹세를 반복해 TP·칭호 / 같은 맹세를 회차마다 지켜 보상 반복 | 난이도 추정(주인공 기억 포함, p ≥ 0.9 사소한 맹세), 거의 끝난 일 금지, 맹세 TP 시대당 +3 상한, 영혼 겹 보상은 맹세당 한 번, 조용한 맹세 7일 쿨다운 |
| **맹세가 발목을 잡음** | 깨진 맹세의 무게가 쌓여 플레이어가 맹세를 아예 안 함 / 기억 속 맹세가 쌓여 부담 | 무게 수치 작음(스트레스 +3, 상한 +12), 갚음으로 걷힘, 내려놓기 언제나 가능('돌아와서도' 1개 제외), 활성 상한 3, 시대 보관 6. 지표: "회차 3 이후 맹세를 한 번도 하지 않는 플레이어 비율" < 25% |
| **기억 속 맹세의 증인 없는 공허** | 증인이 잊어서 지켜도 아무 반응이 없다 → 의미 없음 | 그것이 의도된 슬픔이다. 대신 "다시 말한다"로 증인을 다시 세울 길, 앞질러 지킨 말(ACH-O6), 목소리의 반응(§5.6.1), 맹세록의 "· 지켜졌다. 아무도 모른다." |
| **어두운 맹세의 수위** | 학살 묘사가 무분별해짐. 회귀로 같은 학살을 반복하는 구조 | 장면이 요구하는 만큼(WORLD_BIBLE §0.2), 05 §7.4 콘텐츠 태그 `학살`, 남겨두는 선 2개 자동 검증. 같은 어두운 맹세를 두 번째로 지킬 때는 장면을 반복하지 않고 요약 한 줄 + 기억 잉크 |
| **성능·저장 용량** | 회차마다 수만 사건의 인과 그래프 | `roots` 앞 전파로 런타임 역추적 없음. 회차 보관함은 `known_by` 플레이어 사건만 — 회차당 약 2천 항목, 압축 후 약 150KB. 시대당 회차 보관 상한 60 (넘으면 같은 끝을 가진 짧은 회차부터 병합) |
| **인과가 틀리게 이어짐** | 엉뚱한 선택이 원인으로 표시 | 경로 가중치 0.25 미만 제외, A ≥ 0.3 필수. 커버리지 도구: 헤드리스 시뮬레이션의 메아리 표본 200개를 사람이 검수(슬라이스) |

## 10. 수직 슬라이스 범위
### 반드시 들어갈 것
- **인과의 실 엔진**: 모든 사건의 `causes`/`roots`/`loop`, 상태 출처(`lastWriter`), **기억 출처**(`MemorySource`). — 이것이 없으면 나머지가 전부 수작업이 된다.
- 메아리 점수식(주관 일수 D 포함), 문턱 4단계, 세션 상한과 대기열, 「밤의 메아리」.
- 메아리 줄 + 실타래 (목격·들음·짐작·▒·기억 표지, 회차별 `known_by` 게이트). 「고리가 채워졌다」.
- 소문 메아리, 거절 뿌리(`declined`) — REGIONS §2.14의 개입 기회 30개에 연결.
- **회차를 넘는 메아리 3종**: 기억 메아리(M6 무두장 가죽, M7 리즈의 이름), 어긋난 메아리(M10), 되풀이 메아리(M11).
- 짐작 메아리와 거짓 메아리 **1건** (M9 사라의 이름) — 드러남 장면 포함.
- 잔향 메아리 **1건** (M8 미카).
- **회차 비교**: 회차 보관함, 날 보기·사람 보기 (갈림길 보기는 단순 목록), 다섯 표지, 자동으로 떠오르는 때 4가지, 「어제의 너는 여기까지였다」.
- 맹세: 6유형 판정, 감정의 순간 제안(계기 상실·불의·임종의 부탁·스승 문턱·기억의 재회 5종), 맹세록(조용한 맹세 포함), 증인 기억·반응, 깨짐/늦음/지키지 못함/꺼짐/풀림.
- **기억 속 맹세**: 회귀 시 전환, 첫 잠자리의 마음에 둔다/다시 말한다/내려놓는다, 앞질러 지킴, 깨진 맹세의 무게와 갚음.
- 맹세 데이터 10개(§5.11의 7 포함), NPC 맹세 8개(§5.11의 5 포함 — 적의 맹세 볼크는 17과 공유).
- 두르강의 돌심장 맹세 규칙 (06 문서에 이미 있음 — 영혼의 흉터는 06과 맞춘 뒤).
### 나중으로 미룰 것
- 페이의 그림자 저주 표와 작은 맹세 (페이 지역·출신이 생길 때).
- 회차 비교의 갈림길 보기 트리 시각화 (슬라이스는 목록), 「그 회차에 세운 것」 비교 (VS 회차는 대개 1년 미만).
- 어두운 맹세의 전체 반응 세트 (슬라이스는 `oath_raven_keep_ashes` 1개), 기억 속 어두운 맹세의 기억 잉크.
- LLM 자유 서술 모드(05 §8)의 비교 문장 다듬기, 업적 O2·O4·O5 (시대 단위 플레이 필요).
- ⟨아스테리온⟩의 회차 5+ 반응 (15 완성 후).
