# 03. 회귀 — 회차와 시대, 수련 남용 방지, 죽음과 돌아옴

> 정본: WORLD_BIBLE §1.3.1 「신의 마지막 말 — 잔향(殘響)과 회귀」, §11 「무혈자의 찬가」.
>
> 문제 정의
> 1. 그림다크 세계 → 죽음은 흔하고, **아파야** 한다.
> 2. 자유도가 높으면 "안전한 마을에서 수백 시간 수련"이라는 최적해가 생긴다.
> 3. 회귀가 있으면 죽음이 **"다시 하기 버튼"** 처럼 가벼워지거나, 반대로 20년 쌓은 회차를 한 번에 잃는 허무가 생긴다.
> 4. 미래를 아는 주인공은 게임을 망가뜨리기 쉽다. **아는 미래는 강력하되 완벽해서는 안 된다.**

해답은 **4가지 장치의 조합**이다.

| 장치 | 해결하는 문제 |
|------|---------------|
| A. 시간이 곧 비용인 세계 (회차 안) | 마을에 틀어박혀 수련하는 것을 막는다 |
| B. 수련의 한계 구조 (회차 안 + 회차를 넘어) | 안전한 수련만으로, 또는 죽고 다시 하는 것만으로 강해질 수 없게 한다 |
| C. 회귀 — 남는 것과 돌아가는 것 | 죽음에 의미를 주되, 죽음의 값을 지킨다 |
| D. 시간의 표류와 회귀의 대가 | 아는 미래가 완벽하지 않게, 죽음이 공짜가 아니게 한다 |

## 1. 플레이 구조: "회차 → 시대"

```
시대(Era) ── 한 잔향자의 모든 회차. 하나의 세계 시드.
            진짜 죽음(§4.5) 또는 찬가 엔딩 또는 '회귀를 놓는다'(§4.6)로 끝난다.
 회귀점: 붕괴력(AS) 312년 낙엽월 1일 저녁, 회색여울 배급 줄
 ├─ 1회차   312.9.1 ~ 312.12.3   (93일)    굶주림월 2차 매각 호송에서 사망 — 첫 죽음
 ├─ 2회차   312.9.1 ~ 312.9.19   (19일)    하겐의 배를 피했으나 볼크의 사냥대에게
 ├─ 3회차   312.9.1 ~ 312.9.2    (하루)    마르타에게 딸 이야기를 너무 일찍 꺼냈다
 ├─ 4회차   312.9.1 ~ 315.7.9    (2년 10개월) 숨은 마을, 찬가 1단계 — 인두세 수레에서
 ├─ …
 ├─ 17회차  312.9.1 ~ 331.5      (18년 8개월) 인간의 도시, 찬가 5단계 — 잿빛 탑의 유리 칼 → 진짜 죽음
 └─ 시대 종결 → 시대 연대기 → 새 시대 (새 세계 시드 · 새 출신 · 그 출신의 회귀점)
```

| 단위 | 실제 플레이 시간 (목표) | 끝나면 |
|------|------------------------|--------|
| **회차** (회귀점에서 다음 죽음까지) | 짧으면 5분(첫날 죽음), 평균 2~8시간, 길면 40시간+ | 회차 기록 → **회귀점으로 돌아간다** |
| **시대** (한 잔향자의 모든 회차) | 30~150시간 | 시대 연대기 → 새 시대, 새 세계 시드, 새 잔향자 |

- **세계는 이어지지 않는다. 기억이 이어진다.** 다음 회차의 세계는 회귀점의 세계 그대로다. 내가 도운 반용 서자는 다시 쫓기는 신세이고, 내가 세운 비밀 학교는 아직 아무도 글을 모르며, 내가 태운 성채는 멀쩡히 서 있다.
  달라진 것은 오직 **나** — 그리고 내가 아는 것으로 이번 회차를 다르게 움직이는 방식이다.
- 로그라이크의 긴장(죽으면 세계를 잃는다) + 회귀물의 쾌감(아는 자의 두 번째 기회)을 동시에 얻는다.
- 찬가(WORLD_BIBLE §11)는 **한 회차 안에서** 이뤄야 한다. 수많은 실패한 회차의 기억으로, 마지막 한 회차에서.
- **첫 회차의 시작과 회귀점은 다르다.** 첫 회차는 출신의 첫 장면에서 시작하고(14 문서), 잔향은 그날 저녁 배급 줄에서 처음 깨어난다. 그 순간이 회귀점이다. 회귀점 이전의 몇 시간은 다시 살 수 없다 — 이미 지나간 일이다.

### 1.1 시간 흐름 기준

| 게임 시간 | 대략의 실제 플레이 시간 |
|-----------|------------------------|
| 하루 | 5~15분 (행동 밀도에 따라) |
| 한 계절 (90일) | 1~2시간 ("몰아서 보내기"로 이동·노동·수련을 빠르게) |
| 1년 | 3~6시간 |
| 이미 겪은 날 | 하루 10~30초 ("기억대로 보낸다", §3.5 — 표류 위험) |

### 1.2 회차의 리듬 — 짧은 회차와 긴 회차
회귀는 플레이 리듬을 자연스럽게 두 종류로 나눈다. 게임이 이름을 붙여 강요하지는 않는다.

| 리듬 | 모습 | 얻는 것 | 잃는 것 |
|------|------|---------|---------|
| **짧은 회차** (며칠~몇 달) | 위험한 곳을 들여다보고, 비밀을 캐고, 실패해 보는 회차 | 지식 카드, 사건의 날짜, 사람의 속마음 | `loop.count` (§7), 죽음의 기억 |
| **긴 회차** (몇 년~수십 년) | 아는 것으로 조심스럽게 쌓는 회차. 마을, 학교, 가족, 영지 | 찬가 단계, 업적, 깊은 관계 | 죽으면 **그 모든 것이 한 번에** 사라진다 |

- 회차가 길어질수록 죽음으로 잃는 것도 커진다 (WORLD_BIBLE §11). 이것이 회귀의 무게이고, 긴 회차 후반의 긴장을 만든다.
- 짧은 회차는 싸 보이지만 공짜가 아니다 — 젖은 재의 냄새와 기시감은 회차 수로 쌓인다 (§7). **열 번 죽어 배운 것은 열 번 죽은 냄새와 함께 온다.**

## 2. 장치 A: 시간이 곧 비용인 세계 (회차 안)

마을에 틀어박혀 있어도 **세계는 플레이어를 가만두지 않는다.** 그리고 회차마다 세계는 같은 순서로 찾아온다.

### 2.1 생활비 (매일 빠져나가는 것)
| 항목 | 하루 비용 (용제국 기준) | 미지불 시 |
|------|-------------------------|-----------|
| 식비 | 2~3못 | 굶주림 → 판정 페널티 → 기아 |
| 숙박 | 0(노숙)~6못 | 노숙: 피로 회복 절반, 강도·추위·질병 위험 |
| 인두세·노역 할당 | 계절마다 정산 (주인 몫) | 할당 미달 → 채찍, 배급 삭감, 매각 |
| 수련비 | 스승 수업료 하루 1~5은 | 스승이 떠남 |

> 일하지 않으면 수련할 수 없고, 일하면 수련할 시간이 줄어든다. **삶 자체가 자원 관리.**
> 돈은 회귀하면 사라진다. 그러나 **돈이 어디 있는지는 남는다** — 누가 어디에 무엇을 숨겼는지 아는 자는 둘째 주에 이미 첫 회차의 석 달 치를 쥘 수 있다. 단, 그 돈이 이번에도 거기 있는지는 표류가 정한다 (§4.4).

### 2.2 세상이 마을을 찾아온다 (마을은 영원히 안전하지 않다)

시작 마을 '회색여울'에 계속 머물 때 시간이 지나면 일어나는 일 (월드 클락 연동). 꼬리표는 표류 등급(§4.4)이다.

```
312 가을  〔흐름〕 북방 거인 노예 탈주자 유입 → 배급 감소, 바르그 노예사냥꾼 순찰 증가
312 겨울  〔흐름〕 탈주자 은닉 수색 — 집집마다 수색, 숨긴 자는 공개 처벌
313 봄    〔고정〕 흰 알 부화 / 용황 병세 악화 → 레이번 남작이 후계자 편을 고름
313 여름  〔고정〕 맹약회의 + 징발 포고: 마을 인간 1/5을 군용 짐꾼·방패병으로 징발 ← 플레이어도 대상!
          (거부 = 탈주 노예 수배 / 뇌물 / 숨기 / 끌려가기)
313 가을  〔흐름〕 용제국 계승 전쟁 본격화, 군대가 지나가며 곡식과 사람을 징발
314 봄    〔표류〕 역병 (재열병) 유행 — 첫 환자가 누구인지는 회차마다 다르다
          〔흐름〕 남작이 빚을 갚으려 농노를 세렌에 팔기 시작
...
```

- 각 사건은 **선택**을 강요한다. 숨어서 수련만 하는 선택지는 점점 비싸진다.
- 그리고 이 사건들이 오히려 가장 좋은 성장 기회다 (아래 수련 구조 참고).
- 〔고정〕 사건은 **매 회차 같은 날** 온다. 그래서 두 번째 회차부터 플레이어는 달력을 안다 — 그리고 달력을 안다는 것이 곧 이 게임의 전략이 된다. 그러나 달력을 알아도 징발 포고는 온다. 피할 수는 있어도 없앨 수는 없다 (주인공이 세계를 바꾸지 않는 한).

### 2.3 노화
- 시작 나이는 출신이 정한다 (회색여울 농노 기준 15~25세). 35세부터 신체 능력치 성장 상한 하락, 50세부터 능력치 감소 판정.
- **노화는 몸의 것이다.** 회귀하면 몸은 회귀점의 나이로 돌아간다. 노환으로 죽은 회차도 회귀한다 — 일흔에 숨을 거두고, 열일곱의 몸으로 배급 줄에서 눈을 뜬다.
- 그래서 한 회차에서 할 수 있는 일에는 여전히 한계가 있다. **찬가를 한 회차 안에 이루려면, 그 몸이 늙기 전에 해야 한다.**
- **영혼의 햇수** `soul.years_lived`: 모든 회차에서 살아낸 날의 합. 기계적 효과는 작다 — 50년을 넘으면 특성 `늙은 눈`(통찰 +5, 처음 만난 사람이 "나이에 맞지 않는 눈"이라 느끼는 대사 조건, 잔향 징후 판정 +2%). 연대기와 목소리(15)가 이 숫자를 읽는다.

## 3. 장치 B: 수련의 한계 구조

### 3.1 수련 방식별 상한

| 방식 | 경험치 배율 | **스킬 상한** | 비용 |
|------|-------------|---------------|------|
| 독학 (허수아비 치기, 혼자 연습) | ×0.3 | **25** | 시간, 피로 |
| 안전한 실습 (목검 대련, 견습 노동) | ×0.6 | **40** | 시간, 상대 필요 |
| 스승 수업 | ×2~3 | **스승 스킬 − 10** | 돈, 스승의 요구(의뢰·충성) |
| **실전** (진짜 위험이 걸린 판정) | ×1.0 | 제한 없음 | 부상·죽음의 위험 |
| 목숨이 걸린 실전 | ×2.0 | 제한 없음 | 큰 위험 |
| 책·문헌 (지식 계열) | ×1.0 | **책의 수준** | 책 구하기, 읽고쓰기 필요 |

→ **안전하게 오를 수 있는 건 40까지** (영혼의 재능 등급이 이 두 상한을 조금씩 올린다 — 06 §3). 이 상한은 회차를 넘어도 같다. 백 번 회귀해 백 번 허수아비를 쳐도 검술은 25에서 멈춘다.
→ 좋은 스승은 대도시·성·탑에 있고, 공짜로 가르쳐주지 않는다 → **모험의 동기**가 된다.
→ 스승은 회귀하면 나를 잊는다. 다시 받아 달라고 해야 한다. 다만 **스승이 무엇을 원하는지는 안다** — 군나르가 어떤 의뢰를 내밀지 알면, 신뢰 40까지 가는 길은 첫 회차의 절반이다.

### 3.2 수확 체감 + 녹슮
```
수확 체감 = (1 − 현재스킬/상한)²      → 상한 근처에선 거의 안 오름
녹슮     = 30일간 미사용 시 하루 −0.05 (단, 최고치의 80% 아래로는 안 떨어짐)
```
- 녹슮은 **영혼이 쓰지 않은 날**로 센다. 회귀는 녹슮 타이머를 되돌리지 않는다 — 회귀점 직후에도 마지막으로 칼을 쥔 날은 그대로 기억된다.

### 3.3 "몰아서 보내기"는 위험을 동반한다
- "일주일 동안 수련한다" 같은 시간 건너뛰기는 가능하지만, 그 사이에도 **세계 시뮬레이션은 돌아간다**.
- 건너뛰는 도중 중요한 사건이 생기면 중단되고 장면이 시작된다.
- 이미 겪은 날을 지난 회차처럼 다시 보내는 것은 별도 장치다 → §3.5 「기억대로 보낸다」.

### 3.4 기술은 기억, 몸은 재단련 — 몸의 상한
스킬 수치는 영혼에 남는다. 그러나 몸은 회귀점의 몸이다. 열일곱 농노의 팔은 명인의 검을 따라가지 못한다. **공식과 수치는 06 문서 §4가 정본이다.** 여기서는 이 문서의 다른 장치와 어떻게 맞물리는지만 적는다.

| 스킬 갈래 (06 §4.1) | 예 | 회귀 직후 |
|---------------------|-----|-----------|
| **머리의 스킬** | 화술, 기만, 통찰, 학식, 언어, 읽고쓰기, 마법 이론 | 그대로. 첫날부터 쓴다 |
| **몸의 스킬** | 모든 무술, 운동, 은신, 지구력, 승마, 손재주, 궁술 | 수치는 기억하지만 **몸의 상한**에 묶인다 |
| **그릇의 스킬** | 마법 시전 (근원별) | 수치는 기억하지만 **그릇의 상한**에 묶인다 |

- 상한은 단련도로 오르고, 단련도는 회귀하면 0이다. 이전 회차들의 최고치까지는 **3배 속도**(근육 기억)로 되찾는다 (06 §4.2).
- 판정 미리보기(01 §4.3)는 두 숫자를 다 보여 준다: `검술 72 (몸이 따라오는 만큼: 31)`.
- 진명의 대가(체력·체온)는 **지금의 몸**이 치른다. 기억하는 진명이 많아도 약한 몸으로 큰 이름을 말하면 몸이 탄다.
- 결과: 회귀 직후의 주인공은 **아는 것은 많고 몸은 약한** 상태다. 첫 몇 주는 몸을 되찾는 시간이며, 이것이 회귀 직후의 자연스러운 긴장이 된다. 「기억대로 보낸다」(§3.5)로 그 몇 주를 빠르게 지나갈 수 있지만, 몸은 그동안에도 처음 하는 것처럼 단련된다.

### 3.5 「기억대로 보낸다」 — 아는 날을 빠르게 지나가기
두 번째 회차부터, 이미 겪은 날들을 지난 회차의 일과대로 빠르게 보낼 수 있다. 같은 첫 열흘을 스무 번 손으로 다시 하게 만들지 않기 위한 장치다. 그러나 시간은 찢어져 있고, 같은 날은 정말로 같지 않다.

**쓰는 법**
1. 인물 수첩·달력 화면에서 「기억대로 보낸다」를 고른다.
2. **기억된 길**을 하나 고른다: 지난 회차 하나의 일과(예: "4회차의 낙엽월 1~13일"), 또는 플레이어가 지난 회차들에서 이어 붙여 저장한 **정석**(예: "첫날 밤 마르타 → 2일 수탉 지하 → 3일 여울강 나루…").
3. 멈출 날을 정한다. 엔진은 지금 회차의 시드로 세계를 돌리면서, 기억된 길의 행동을 **의도**로 다시 넣는다.

**멈추는 조건** — 하나라도 생기면 그 자리에서 장면이 시작된다.

| 조건 | 화면 |
|------|------|
| **어긋남**: 의도가 실패한다 (그 사람이 거기 없다, 길이 막혔다, 날씨가 다르다) — 표류 | 〰 "기억과 다르다. 하겐의 배가 나루에 없다." |
| **처음 보는 일**: 지난 회차들에서 한 번도 없었던 사건이 나와 관계있게 일어난다 | "이런 일은 없었다." |
| **위험 판정**: 위험도 3 이상의 판정 — 판정은 **다시 굴린다**. 기억대로 보내도 주사위는 기억해 주지 않는다 | 판정 장면 |
| 확정·인과 사건이 나와 관계있게 일어난다 (§3.3과 같음) | 사건 장면 |

**대가와 위험**
- **보지 않은 표류는 멈추지 않는다.** 기억대로 보내는 동안 엔진은 *내 의도에 닿은* 어긋남만 잡는다. 내가 찾아가지 않은 사람이 이번 회차엔 이틀 일찍 팔려 갔다면, 보내기는 멈추지 않는다 — 플레이어는 나중에, 대개 너무 늦게 안다.
- 기억대로 보낸 날에는 **새 지식 카드가 생기지 않는다.** 아는 날은 새로 가르쳐 주지 않는다.
- 머리 스킬의 성장은 ×0.5 (같은 것을 다시 했을 뿐). 몸의 상한은 보통대로 오른다 — 몸은 처음 하는 것이니까.
- 관계는 기억된 대화의 결과를 다시 적용하되, 판정이 걸린 대화는 다시 굴린다. 표류 등급이 〔표류〕인 사람의 반응은 회차 시드에 따라 흔들린다.
- 회차가 길어질수록, 기억된 길이 길수록 멈출 확률이 오른다. 엔진은 시작 전에 체감 등급으로 보여 준다 (01 §4.1): `이 길은 대개 그대로 흘러간다 / 어딘가에서 어긋날 것 같다 / 기억을 믿기 어렵다`.
- 18 연출가는 기억대로 보내기 중에 연출 사건을 넣지 않는다. 확정·인과 사건만 멈춘다.

### 3.6 회귀를 이용한 남용 — 그리고 그것을 막는 것
회귀는 새로운 최적해를 만든다. 금지하지 않는다. **값을 매긴다.**

| 남용 | 모습 | 막는 것 |
|------|------|---------|
| **자살 리셋** | 일이 틀어지면 일부러 죽어 다시 시작 | `loop.count` +1 → 냄새·기시감 누적 (§7), 죽음의 기억 (§4.1), 이번 회차의 모든 것 상실 |
| **첫 주 농사** | 안전한 첫 주만 반복해 스킬을 쌓기 | 안전 수련 상한 40은 회차를 넘어도 같다 (§3.1). 몸은 매번 처음부터. 실전 없이 40을 넘지 못한다 |
| **표류 뽑기** | 원하는 우연(하겐이 배신하지 않는 회차)이 나올 때까지 죽기 | 가능하다. 다만 회차마다 냄새가 짙어지고, 시간에 민감한 존재들이 더 일찍 온다. 운을 고르는 값은 시간이다 |
| **정찰 회차** | 죽을 것을 알고 성채 금고를 들여다보러 가기 | 정당한 전략이다. 대가는 위와 같고, 경비 교대 같은 작은 일은 〔표류〕다 — 정찰한 것이 다음 회차에 그대로라는 보장은 없다 |

> 원칙: **회귀는 두 번째 기회를 주지, 공짜 기회를 주지 않는다.** 백 번 죽은 아스테리온은 백 번 죽은 냄새를 풍겼고, 결국 그 냄새가 그를 찾아냈다.

## 4. 장치 C: 회귀 — 남는 것과 돌아가는 것

### 4.1 회귀 — 죽음 이후 (세계 안)

잔향자가 죽으면 **시간이 접혀 회귀점으로 돌아간다.** 세계는 그 순간의 상태로 돌아가고, 아무도 아무것도 기억하지 못한다. 기억하는 것은 잔향자뿐이다.
첫 죽음은 그대로 가장 강한 훅이다: 죽음의 어둠 뒤에, **배급 줄의 빵 냄새로 다시 눈을 뜬다.**

| 남는 것 (영혼) | 시스템 | 돌아가는 것 (몸과 세계) | 시스템 |
|----------------|--------|--------------------------|--------|
| **지식 카드** (장소, 사람의 비밀, 레시피, 길) | 02 지식 태그, 07 | **능력치** (회귀점의 값) | 01 |
| **지도 지식** (안개가 걷힌 곳) — 단, 정보는 "지난 회차" 꼬리표를 단다 | 07 | **부상·흉터·영구 장애** | 01 |
| **인물 수첩** — 아는 관계·사실은 남고, 상대의 관계 수치는 0으로 | 08 | **이식 특질** (용심은 그 몸과 함께 사라진다) | 06 |
| **사건의 날짜** (달력에 기록된 고정·흐름 사건) | 클락 | **소지품·돈·숨긴 재산** | 02 |
| **언어·단어** (노예말, 서리말, 진명어 단어) | 01 | **관계** — 모든 NPC의 호감·신뢰·존경이 회귀점 값으로 | 08 |
| **진명** — 배운 이름은 영혼에 새겨진다 | 01 마법, 11 | **평판·칭호·위협도·세력 대응 단계** | 10 |
| **스킬 수치** (몸·그릇의 스킬은 상한에, §3.4), 경지, 단련도 최고치 | 01, 06 §4 | **영역·관리자·가문** | 09, 12 |

| **성향** (용기·자비·정직…)·**각성도**·**본디**·**고독** — 마음의 것이므로 (15·20과 맞춤) | 01 §1.3 | **월드 클락·찬가 단계** (회귀점의 진행으로) | WORLD_BIBLE §10~11 |
| **죽음의 기억** (스트레스·트라우마 일부, 아래) | 01 §1.4 | 원한·빚·현상금 — 세계가 잊는다 | 10, 11 |
| **재능 포인트·해금·업적** (§4.2) | 06 | 맹세의 상대방 기억 (맹세 자체는 16 문서가 정한다) | 16 |
| `loop.count`, 기시감, 냄새 (§7) | 17 | 단련도 (몸·그릇의 상한, §3.4) | 06 |

- **물려받는 것이 없다.** 이전 회차의 검은 시체와 함께 남지도 않는다 — 그 검은 이번 회차에도 늑대굴 바닥에, 처음 그 자리에 있다. 되찾으러 갈 필요가 없다. **처음 찾으러 가는 것이다.** 그리고 어디 있는지 안다.
- **무덤이 없다.** 회귀한 세계에서 주인공은 죽은 적이 없다. 313번 말뚝에 내 이름은 없다. 다만 회차 중에 **남이 죽은 자리**는 본다 — 그리고 다음 회차에 그 사람이 살아서 배급 줄에 서 있는 것을 본다.
- **일기·지도·편지는 세계 안의 물건이라 사라진다.** 남는 것은 영혼에 새긴 것뿐이다. (UI상 기록은 "인물 수첩"과 "지식 카드"에 자동으로 남는다 — 이것이 곧 주인공의 기억이다.)
- **아는 것을 아는 척하면 들킨다.** 처음 가는 길을 알고, 아직 일어나지 않은 일을 말하고, 처음 본 사람의 이름을 부르면 → 잔향 징후 판정 (§4.3, 「앎의 흔적」).

**죽음의 기억** — 죽음은 사라지지 않는다.
| 죽음의 방식 (예) | 남는 것 | 극복 |
|------------------|---------|------|
| 불 (바르스카르 계열 제외 — 그것은 진짜 죽음) | `불의 기억`: 큰 불 앞에서 용기 판정 −10 | 불 앞에서 용기 판정 성공 3회 |
| 물 | `물의 기억`: 수영·물 건너기 판정 전 공포 판정 | 같은 방식 |
| 바르그의 이빨, 짐승 | `이빨의 기억`: 바르그와 마주치면 첫 합 −5 | 그 짐승을 한 번 이긴다 |
| 고문 끝의 죽음 | `부서진 밤`: 회귀 직후 스트레스 시작값 +20, 심문 저항 −10 | 오래 걸린다 (15 목소리, 20 애도와 연결) |
| 처형 (공개) | `군중의 얼굴`: 군중 장면에서 통찰 +5, 스트레스 +5 | 없음 — 남는다 |
| 노환·병 | 없음 | — |

- 회귀 직후 스트레스 시작값 = 기본값 + 직전 죽음의 잔혹도 (0~20) + 사흘 안에 연달아 죽은 횟수 × 10.
- 같은 방식의 죽음을 세 번 겪으면 그 기억은 **특성**으로 굳는다. 극복하면 반대쪽 특성이 붙을 수도 있다 (`불을 지나온 자`: 불 앞 용기 +10).

### 4.2 세계 밖 계승 — "잔향(殘響)"

#### 세계관 설정으로 정당화한다
> 죽어가던 신 에오르가 남긴 마지막 말 **"너희는 끝나지 않을 것이다"** 는 흩어지지 않았다. 그것이 **잔향**이다.
> 잔향은 한 시대에 단 한 사람에게 깃든다. 그 사람은 죽어도 끝나지 않고, **시간이 접혀 처음 깨어난 저녁으로 돌아간다.** 이것이 주인공이다.
> 평범한 인간의 영혼은 돌아오지 않는다. 오직 하나뿐이다.
> 고대 종족들은 3,400년 동안 이 하나를 사냥해 왔다. 재의 법은 잔향의 징후가 있는 인간을 화형에 처하고 — 그래서 **주인공 대신 무고한 사람들이 불탄다.** 회귀하면 그들은 다시 살아 있다. 그리고 주인공이 또 징후를 보이면, 또 탄다.
> 순종의 빛은 잔향 전설을 "순종하면 다음 생에 빛의 종족으로 태어난다"는 거짓으로 비틀어 가르친다.
> 잿빛 탑과 엘다르 존속파, 멜리산드는 진짜 잔향을 가려내 붙잡으려 한다. 그들 가운데 몇은 **죽여도 소용없다는 것**을 어렴풋이 안다.

→ 메타 성장이 게임 시스템이 아니라 **세계관의 핵심**이 된다. 세상에서 특별한 것은 **오직 주인공뿐**이다.
→ 잔향을 너무 드러내면 사냥의 표적이 된다 = 메타 성장에도 리스크.

#### 잔향 = 재능 포인트(TP)
메타 계승의 주된 형태는 **재능 포인트**다 (상세: [06_CHARACTER_CREATION.md](06_CHARACTER_CREATION.md)).

| 항목 | 값 |
|------|-----|
| 첫 시대 기본 TP | 10 |
| 업적 보상 | 업적마다 영구 TP +1~+5 (목록: world/SCENARIOS.md) |
| 최대 TP | 40 |

- 회차가 죽음으로 끝나면 **회차 기록**(§5)이 작성되고, 그 회차에서 달성한 업적이 확정된다. TP는 그 즉시 잔향에 더해진다.
- **회차 안에서 얻은 TP는 회귀할 때 쓸 수 있다** — **회귀 각성**(06 §8.3, 이 문서 §5.1). 회귀점에서 눈을 뜨기 직전의 어둠 속에서 **영혼의 재능**만 새로 깨우거나 등급을 올린다. 몸의 특질(혈통)은 같은 몸이므로 시대 내내 그대로이고, 시대가 시작될 때만 고른다. 이식 특질은 몸과 함께 사라진다.
- **죽는다고 TP가 생기지는 않는다.** TP는 업적에서만 온다 (06 §2.1).
- 쓰지 않은 TP는 잔향에 남아 다음 회귀나 다음 시대로 간다.
- 업적은 오래 버티기보다 **"이야기가 있는 회차"** 에 더 많이 주어진다 (월드 클락 분기 변경, 찬가 단계 진전, 평생의 친구·원수, 기억에 남는 죽음). **같은 업적은 시대마다 한 번만** TP를 준다 — 같은 클락 분기를 열 번 바꿔도 TP는 한 번이다.

#### 잔향으로 해금하는 것 (TP 외)

| 종류 | 예시 | 해금 조건 | 설계 의도 |
|------|------|-----------|-----------|
| **출신 해금** | 반용, 반엘다르, 재태생, 투사의 자식, 늪 마녀의 딸 | 관련 업적 | 다음 **시대**의 새로운 시작점 = 새로운 게임 |
| **신재 등급 해금** | 검신의 재능 등 (06 §3) | 해당 분야 업적 | 성장 천장 확장, 경지 |
| **앞선 잔향자의 꿈** | 회차 중 가끔 앞선 잔향자들의 기억이 꿈으로 떠오름 (지도, 비밀, 진명 조각) | 첫 회귀 | 지식 계승, 15 문서 목소리와 연결 |
| **가보의 메아리** | 진짜 죽음 때 지니고 있던 고유 아이템 1개가 **다음 시대의 세계에 '전설의 물건'으로 존재** — 찾아야 함 | 같은 시대에서 그 아이템을 합계 1년 이상 지님 (회차를 넘어 다시 손에 넣은 것도 합산) | 시대를 건너는 유일한 물건. 공짜가 아니다 |
| **연대기 도서관** | 모든 회차 기록·시대 연대기 열람, 세계 설정 백과 해금 | 항상 | 수집 욕구, "내가 무엇을 해 봤나"의 지도 |

**재능의 원칙:**
- 재능은 **성장 속도·상한·열리는 길**을 바꾼다. 30 TP 캐릭터도 회귀 직후엔 숙련된 용인 기사에게 일대일로 진다.
- 회귀 자체를 다루는 **영혼 분야 재능**(06 §5.9 — 선명한 회귀, 재 냄새 억제, 기시감 차단, 표류 읽기, 회귀점의 고요, 끝나지 않는 자 등)은 이 문서의 장치 D(§4.4, §4.5, §7)를 직접 깎는다. 회귀의 값을 TP로 사는 길이다.
- 강한 특질일수록 **그것을 노리는 자**가 생긴다 (용심 → 용족의 처단, 엘다르의 눈 → 영혼 정원의 납치).
- 시작 금화 대량 지급 ✗, 사망 방지 ✗.

> 그림다크의 긴장감을 지키는 원칙: **"더 강하게 시작하지 않는다. 더 많이 알고, 더 높이 오를 수 있게, 더 다양하게 시작한다."**

### 4.3 잔향자의 리스크 — 징후

- 잔향 효과(앞선 잔향자의 꿈, 잔향의 눈)를 쓰면 낮은 확률로 **잔향 징후**가 남는다
  (눈동자에 잿빛 고리, 모르는 언어로 잠꼬대, 처음 가는 곳의 길을 앎).
- **앎의 흔적** — 회귀자만의 징후. 목격자 앞에서 아래를 하면 징후 판정 (심각도는 15 문서 중얼거림과 같은 척도):

| 행동 | 심각도 | 예 |
|------|--------|-----|
| 처음 보는 사람의 이름·비밀을 말함 | 1~2 | "마르타, 리즈는 부엌에 있지?" |
| 처음 가는 길을 앎 | 1 | 늑대굴의 뒷구멍을 바로 찾음 |
| 아직 일어나지 않은 일을 경고함 | 2~3 | "사흘 뒤에 수색이 온다" — 그리고 정말로 온다 |
| 배운 적 없는 언어·진명을 씀 | 3 | 농노가 서리말로 대답함 |
| 공개적으로 미래를 예언함 | 4 | 광장에서 맹약회의 날짜를 외침 |

- 징후가 목격되면 소문 → 목줄단의 밀고 → 잿빛 탑 밀정과 바르그 사냥꾼의 추적.
- 징후와 소문은 회귀하면 세계와 함께 지워진다. **그러나 그 회차 안에서는 진짜다** — 그리고 내가 징후를 보인 탓에 대신 끌려가 타는 사람이 생긴다.

### 4.4 시간의 표류 — 아는 미래는 완벽하지 않다

대붕괴로 '시간'의 진명이 찢어진 뒤로 회귀는 완벽하지 않다. 엔진에서는 **회차 시드** `loop.seed`가 이것을 만든다.

| 표류 등급 | 무엇 | 회차마다 |
|-----------|------|----------|
| 〔고정〕 | 월드 클락의 고정 날짜, 큰 사건 (흰 알 부화, 맹약회의, 용황의 병세 단계, 서리 길 폐쇄) | **똑같다** — 주인공이 직접 바꾸지 않는 한 |
| 〔흐름〕 | 큰 흐름 안의 일 (탈주자 유입, 수색, 징발 대상 명단의 크기) | 결과는 같고, 날짜가 0~3일, 규모가 ±15% 어긋난다 |
| 〔표류〕 | 작은 일 — 누가 어디 있는지, 날씨, 우연한 만남, 소문이 도착하는 시각, **일부 NPC의 흔들리는 선택** | 회차 시드에 따라 결과가 달라질 수 있다 |

- **흔들리는 선택**: S·A등급 NPC의 일부 결정에는 표류 확률이 붙어 있다 (예: 하겐의 배신 70%, 이졸이 고리를 알아보는 것 40%). 플레이어는 회차를 거듭하며 이 확률을 **관찰로** 배운다 — "하겐은 열 번에 일곱 번 판다."
- **표류와 갈래는 다르다.** 표류는 시드가 만든 어긋남이고, 갈래는 **주인공이 지난 회차와 다르게 움직여서** 생긴 변화다 (첫날 밤 마르타를 찾아가면, 마르타의 그 뒤 석 달이 모두 바뀐다). 갈래는 인과의 실(16 문서)로 추적되고, 표류는 〰 "기억과 다르다"로 표시된다.
- **지식 카드의 확신도**: 사건·사람에 관한 카드에는 관찰 횟수로 쌓이는 확신도가 붙는다.

| 표시 | 뜻 | 얻는 법 |
|------|-----|---------|
| ■ 정해진 일 | 〔고정〕으로 확인됨 | 같은 일이 3회차 이상 같게 일어남 + 고정 사건 |
| ▣ 대개 그렇다 | 〔흐름〕, 또는 표류지만 대개 같음 | 2회 이상 같게 관찰 |
| □ 한 번 본 일 | 한 번만 봤다 | 첫 관찰 |
| ◇ 어긋난 적 있음 | 회차마다 달랐다 | 다르게 관찰됨 |

- **오래된 기억은 흐려진다** (06 §5.9 기본 규칙). 지식 카드가 **5회차 동안** 다시 관찰되지 않으면 세부가 흐려진다 — 날짜는 "낙엽월 중순쯤"이 되고, 경비 교대표의 숫자 몇 개가 `?`가 되고, 확신도가 한 칸 내려간다. 다시 관찰하면 돌아온다. 진명·단어·지도 지식은 흐려지지 않는다. 「선명한 회귀」·「기억의 궁전」·「사진 같은 기억」 재능은 흐려짐을 막는다.

> 미래를 아는 것은 이 게임에서 가장 강한 힘이다. 그래서 그 힘에는 □과 ◇가 섞여 있다.

### 4.5 진짜 죽음 — 회귀의 단절

회귀를 끊을 수 있는 것은 **시간에 닿은 것들뿐**이다. 넷뿐이다 (WORLD_BIBLE §1.3.1).

| 단절의 수단 | 어디서 만나는가 | 예고 |
|-------------|-----------------|------|
| **용황 바르스카르의 불** | 용좌, 또는 바르스카르가 직접 움직일 때 (클락 1) | 숨결 전, 공기가 늙는다 — 주변 사물의 색이 바래는 시간 잔상 |
| **엘다르의 '시간의 그물'** | 영혼 정원 (클락 5 「잔향 포획」) | 정원의 노래가 박자를 잃는다. 그물 안에서는 **죽어도 회귀점에 닿지 못한다** |
| **시간의 상처** | 재의 황무지 중심 (지도에 표시되는 위험 구역) | 들어가는 순간부터 화면 가장자리가 바랜다. 그 안의 죽음은 모두 진짜다 |
| **잿빛 탑의 시간 유리 칼** | 세 자루 — 소재는 ITEMS_AND_ARTIFACTS 정본 | 칼집에서 나오면 목소리들이 한꺼번에 침묵한다 |

**예고 규칙 — 진짜 죽음은 기습하지 않는다**
1. **얇아짐** (단절 수단이 같은 지역에 들어옴): 감각 문장 한 줄. "시간이 얇다." 목소리(15)가 경고한다.
2. **닿음** (단절 수단이 주인공을 노림): 화면 가장자리의 바램, 진동 패턴(19 문서), 판정 미리보기에 `이번 죽음은 돌아오지 못한다` 표시.
3. **실행**: 그 수단에 의한 죽음만 진짜다. 같은 장면이라도 바르스카르의 발톱에 죽으면 회귀하고, **불**에 죽으면 끝난다.

- 단절 수단이 없는 곳의 죽음은 **언제나** 회귀한다. 무작위 진짜 죽음은 없다.
- 시간에 민감한 존재들은 회차가 쌓일수록 일찍 다가온다 (§7) — 그래서 진짜 죽음의 위험은 `loop.count`와 함께 자란다.
- 시간의 그물에 걸린 것은 아직 죽음이 아니다. 클락 5의 탈출 시나리오가 열린다. **그물 안에서 죽는 것**이 진짜 죽음이다.
- 재능 「육감」의 오의는 얇아짐을 한 단계 일찍 느끼게 하고, 신재 전용 「끝나지 않는 자」는 단절 수단 하나를 시대에 **한 번** 버틴다 (06 §5). 그 밖에 진짜 죽음을 막는 장치는 없다 (이야기 모드의 되돌리기 제외, §6).

### 4.6 시대의 끝과 새 시대

시대가 끝나는 길은 셋이다.

| 끝 | 조건 | 결과 |
|----|------|------|
| **진짜 죽음** | §4.5 | 그 시대가 끝난다. 잔향은 찢어진 시간의 **다른 갈래**에서 새 잔향자를 찾는다 |
| **찬가 엔딩** | 찬가 7단계 (WORLD_BIBLE §11), 또는 13 문서의 어둠의 찬가들 | 시대 종결 — 그 갈래의 세계가 이어진 모습을 에필로그로 본다 |
| **회귀를 놓는다** | 플레이어의 선택 (아래) | 그 회차가 마지막 회차가 된다 |

**「마지막 회차」 선언 — 회귀를 놓는다**
- 회차 중 언제든 잠드는 경계(18 §5.2)에서, 또는 회차 기록 화면에서 고를 수 있다. 군데가 그랬다는 이야기가 있다 — 회귀를 스스로 멈췄다고.
- 선언하면 **되돌릴 수 없다.** 이 회차에서 죽으면, 그 죽음이 진짜 죽음이다.
- 이유는 플레이어의 것이다: 이 회차의 아이를 지우고 싶지 않아서, 이 회차의 마을이 충분히 좋아서, 더 죽고 싶지 않아서.
- 선언 뒤에는 화면 구석의 회차 표시가 사라진다. 목소리들은 한 번씩만 말한다 (15 문서).
- 시대 연대기는 이 회차의 세계가 **주인공이 죽은 뒤에도 이어진 모습**을 헤드리스 시뮬레이션으로 20~50년 돌려 에필로그로 보여 준다. 처음으로, 내가 없는 세계가 나를 기억한다.

**새 시대**
- 새 세계 시드, 새 출신(해금된 출신 중 선택), 새 회귀점 = 그 출신에서 잔향이 처음 깨어나는 순간.
- 잔향에 남는 것: **TP·해금·업적, 연대기 도서관, 가보의 메아리 1개.** 지식 카드·스킬·영혼의 재능·진명은 그 시대의 잔향자의 것이었다 — 새 잔향자는 그것들을 **연대기 도서관**으로만 만난다. 이전 시대의 회차들은 목소리가 되지 않는다 (15 문서 — 그것은 다른 갈래, 다른 잔향자의 회차였다).
- 첫 시대에서 열린 시스템은 영혼에 남아, 두 번째 시대부터는 처음부터 열려 있다 (14 문서).

## 6. 난이도 모드 (생사의 법)

18 문서의 화자 축과 독립이다 (18 §4.5).

| 모드 | 회귀 | 진짜 죽음 | 잔향 (TP·깨우기) | 회귀의 대가 | 세이브 | 대상 |
|------|------|-----------|------------------|-------------|--------|------|
| **이야기** | O. 그리고 죽었을 때 회귀 대신 **마지막 아침으로 되돌리기** (회차당 3회, 두 번째 죽음부터 — 14 문서) | 예고 단계가 길고 분명하다. 진짜 죽음도 마지막 아침 되돌리기를 쓸 수 있다 (시대당 1회) | O | `loop.count`의 효과 절반 (§7) | 자동 | 입문자, 긴 회차를 잃는 것이 두려운 사람 |
| **그림다크 (기본)** | O | O | O | 그대로 | 자동 저장만 (세이브 스컴 불가) | 기본 |
| **잿빛 (하드코어)** | O | O | ✗ (TP 10 고정, 재능 깨우기 없음) | 냄새·기시감 2배 | 자동 저장만 | 숙련자 |
| ┗ 옵션 **「단 한 번」** | ✗ — 첫 죽음이 진짜 죽음. 시대 = 한 회차 | — | 업적만 기록 | — | 자동 저장만 | 회귀 없는 순수 로그라이크를 원하는 사람 |

- 이야기 모드의 되돌리기는 **회귀가 아니다.** 회귀점은 옮겨지지 않는다. 되돌리기는 이야기의 자비이고, 세계관 안의 사건이 아니다 — `loop.count`도 오르지 않고, 죽음의 기억도 남지 않는다.
- 되돌리기 지점 "마지막 아침"은 18 문서의 **아침 표지**다. 되돌릴 때 연출 난수와 회차 시드의 진행은 아침 상태로 복원된다 (같은 선택이면 같은 하루).
- 「기억대로 보낸다」(§3.5)는 「단 한 번」을 뺀 모든 모드에서 쓸 수 있다.

## 7. `loop.count` — 회차가 쌓이면

`loop.count`는 이 시대에 회귀한 횟수다 (= 죽음의 횟수. 1회차 동안 0). 회귀의 대가는 모두 이 숫자를 읽는다.

### 7.1 젖은 재의 냄새
회귀할수록 찢어진 시간의 냄새 — 젖은 재 — 가 짙어진다. 냄새는 몸이 아니라 영혼에서 난다. 씻어도 지워지지 않는다. 덮을 수는 있다.

```
냄새 = min(30, 3 × loop.count^0.7)       (잿빛 ×2, 이야기 ×0.5, 재능 「재 냄새 억제」 −25~90%)
바르그·추적견의 추적 판정 보정 = +냄새
냄새로 주인공을 '처음 알아채는 날' = 기본일 × max(0.2, 1 − 냄새/40)
```

| 덮는 것 | 효과 | 대가 |
|---------|------|------|
| 무두장 냄새 (14 문서의 지식) | 냄새 −10, 하루 | 사람들이 피한다 |
| 늪 약초 연기 | 냄새 −15, 사흘 | 약학 판정, 기침 |
| 강물 건너기 | 추적 끊김 1회 | 물의 기억, 추위 |
| 녹테른의 피 향 | 냄새 −20 | 다른 사냥꾼(그림자 사냥꾼)을 부른다 |

- 볼크 같은 숙적(17 문서)은 회차를 넘어 주인공을 기억하지 못한다. **그러나 냄새를 맡는다.** 회차가 쌓일수록 그는 더 일찍, 이유도 모른 채 회색여울로 코를 돌린다.

### 7.2 시간에 민감한 존재들의 기시감
엘다르(시간의 혈명), 시간의 상처를 입은 용황 바르스카르, 시간을 연구하는 잿빛 탑은 회귀를 **기억하지는 못하지만 낌새를 느낀다.**

```
기시감[존재] = loop.count × 감도[존재] + 접촉 보정[존재]
  감도:  바르스카르 1.5 · 영원 여왕·존속파 1.2 · 잿빛 탑(탑주·시간 학파) 1.0 · 그 외 엘다르 0.6
  접촉 보정: 지난 회차들에서 그 존재(또는 그 세력의 핵심 인물)와 직접 만난 회차 수 × 2
접근 시작일 = 기본일 × max(0.15, 1 − 0.03 × 기시감)
  (잿빛 ×2, 이야기 ×0.5, 재능 「기시감 차단」 −25~90% — 06 §5.9)
```

| 기시감 | 그들이 하는 일 (예) |
|--------|---------------------|
| 0~9 | 없음. 기본 일정대로 |
| 10~24 | 처음 만날 때의 대사가 바뀐다 ("…낯설지 않은 아이로구나.") 엘다르 정원사들이 회색여울에 기본보다 한 계절 일찍 온다 |
| 25~44 | 잿빛 탑이 회색여울로 '시간 측정관'을 보낸다. 바르스카르가 잠결에 인간의 이름 하나를 중얼거린다 — 궁정에 소문이 돈다 |
| 45~69 | 존속파가 312년 안에 영혼 정원 의식(클락 5)을 준비한다. 탑이 유리 칼 한 자루를 회색여울 방면으로 옮긴다 |
| 70+ | 첫 달 안에 그들이 온다. 진짜 죽음은 늘 가까이 있다 |

- 기시감은 **평판이 아니다.** 그들은 주인공이 한 일을 모른다. 다만 주인공이 **있다는 것**을 점점 더 일찍 안다 (10 문서 §3.3).
- 접촉 보정 때문에, 지난 회차들에서 그들을 피해 다닌 플레이어는 같은 `loop.count`에서도 조금 더 오래 숨는다. 반대로 영원 여왕과 거래를 거듭한 플레이어는 여왕에게 점점 **익숙한 얼굴**이 된다 — 이것은 위험이자 기회다 (11 문서).
- 끝없이 회귀하는 자의 끝은 대개 이것이다. 회귀를 끊는 수단을 가진 존재들이 점점 일찍 오고, 어느 회차에서 그들이 셋째 날 저녁에 배급 줄 끝에 서 있다. 아스테리온은 백 번 넘게 돌아왔다. 그리고 바르스카르가 그를 찾았다.

### 7.3 그 밖의 효과

| `loop.count` | 효과 |
|--------------|------|
| 1 | 첫 회귀. 「앞선 잔향자의 꿈」 해금. 목소리(15)의 첫 해금 계기 |
| 3+ | 회귀 직후 배급 줄의 몇몇 NPC가 "어디서 본 것 같다"고 말하는 대사 조건 (표류처럼 무작위, 의미 없음 — 그러나 플레이어는 의미를 찾는다) |
| 10+ | 특성 `열 번의 저녁`: 회귀 직후 스트레스 시작값 −5 (익숙해진다). 동시에 몇몇 정서 장면의 선택지가 줄어든다 — 슬퍼하는 법을 잊는다 (20 문서와 맞출 것) |
| 25+ | 아스테리온의 목소리가 이 숫자에 반응한다 ("나는 서른 번째에 처음으로 무서워졌다") |
| 100+ | 업적 「백 번째 저녁」. 아스테리온과 같은 자리 |

## 8. 구현 메모

```ts
interface Soul extends SoulState {      // 세계 상태 밖에 있는 유일한 상태 (00 문서 §2). SoulState = 06 §11 (재능·스킬·단련도 최고치·경지·TP)
  eraId: EraId; loopCount: number; loopSeed: Seed;
  yearsLived: number;                    // soul.years_lived
  unlocks: UnlockId[];
  disposition: Record<Axis, number>;     // 성향 — 마음의 것
  knowledge: KnowledgeCard[];            // { id, subject, firstSeenLoop, lastSeenLoop, observed: number, certainty: 'fixed'|'usual'|'once'|'drifted', blurred: boolean }
  notebook: NotebookMemory;              // 08 인물 수첩 — 관계 수치 없이 사실·관찰만
  trueNames: TrueNameId[]; words: Record<LanguageId, number>;
  deathMemories: { loop: number; cause: CauseId; brutality: number }[];
  dejaVuContact: Record<BeingId, number>; // 기시감 접촉 보정
  achievements: AchievementId[];          // 시대 단위, 중복 TP 없음
  finalLoopDeclared: boolean;
  awakening: number;                      // 각성도 — 회귀해도 내려가지 않는다 (15 문서)
  bondi: number;                          // 본디 0~100 — 첫 회차의 나가 얼마나 남았나 (15 §7.5)
  loneliness: number;                     // 고독 (20 §8.6)
  names: NameRecord[];                    // 플레이어가 붙인 이름 — 세계에서는 사라지고 나에게 남는다 (20)
  memoryWall: { npc: NpcId; loop: number; child?: boolean }[]; // 마음속 기억의 벽 (20 §5.6)
  ritualPhrases: string[];                // 의식 말 (20 RitualInstance.phrase)
  oathsRemembered: OathId[];              // 증인은 잊었다, 나는 기억한다 (16)
}
interface LoopRecord { loop: number; start: GameDate; end: GameDate; farthest: GameDate; cause: CauseId; killer?: NpcId; severed: boolean;
  chronicle: string; gained: Diff<Soul>; disposition: Record<Axis, number>;      // 15 문서의 '지난 회차의 나'(loop:{n})가 이 기록에서 생긴다
  forgottenBy: { npc: NpcId; attachment: number; child?: boolean }[]; vanishedChildren: NpcId[];
  firstWish?: string; hymnStage: number; bondi?: number;                          // 본디 값 (15 §7.5)
  children: ChildRecord[];                                                         // 소멸한 아이 (20 §6.8)
  namesLeft: string[];                                                             // 회차 기록 맨 아래 "남긴 이름들" (20)
  leftBehind: string[] }                                                           // 잊힘 페이지 — "두고 온 것" (20, 14)
```

- **회귀 파이프라인**: 죽음 → 단절 판정(§4.5: 원인이 단절 수단인가) → `LoopRecord` 작성 → `Soul` 갱신 → `loopCount++`, 새 `loopSeed` → **회귀점 스냅샷**에서 세계 재생성 → 표류 적용 → 깨어남 장면.
- **회귀점 스냅샷**은 시대 시작 때 한 번 만든다 (세계 시드 + 회귀점 시각의 전체 세계 상태). 회차마다 이 스냅샷에서 다시 시작한다 → 저장 용량은 스냅샷 1개 + 현재 회차 + `Soul`.
- **표류**: 각 사건·NPC 결정 데이터에 `drift: 'fixed'|'flow'|'drift'`와 (흔들리는 선택이면) `p`를 둔다. `loopSeed`로 결정적으로 굴린다 → 같은 회차를 다시 로드해도 같은 표류.
- 헤드리스 시뮬레이션으로 같은 시드에서 회차 100개를 돌려 〔고정〕 사건이 정말 고정인지, 〔표류〕가 너무 크거나 작지 않은지 검증한다.
- 「기억대로 보낸다」의 기억된 길 = 지난 회차의 행동 로그에서 뽑은 `Intent[]`. 실행은 몰아서 보내기 엔진(§3.3)에 의도 검사기를 붙인 것이다.
