# 03. 로그라이트 구조, 수련 남용 방지, 죽음과 계승

> 문제 정의
> 1. 그림다크 세계 → 죽음이 흔하고 영구적이어야 한다 (로그라이크).
> 2. 그런데 자유도가 높으면 "안전한 마을에서 수백 시간 수련"이라는 최적해가 생긴다.
> 3. 죽었을 때 모든 것을 잃으면 허무하고, 너무 많이 남기면 긴장감이 사라진다.

해답은 **3가지 장치의 조합**이다.

| 장치 | 해결하는 문제 |
|------|---------------|
| A. 시간이 곧 비용인 세계 | 마을에 틀어박혀 수련하는 것을 막는다 |
| B. 수련의 한계 구조 | 안전한 수련만으로는 강해질 수 없게 한다 |
| C. 2단 계승 (세계 안 / 세계 밖) | 죽음에 의미를 주되 긴장감을 지킨다 |

---

## 1. 플레이 구조: "생애 → 시대"

```
시대(Era) ── 하나의 세계 시드. 약 80~150년의 역사.
 ├─ 생애 1: 농노의 딸 리사      (312~319년, 7년 생존, 늑대에게 사망)
 ├─ 생애 2: 리사의 제자 토르    (319~341년, 22년 생존, 계승 전쟁에서 전사)
 ├─ 생애 3: 토르의 아들 에반    (341~380년, 노환으로 사망 — 남작 작위 획득)
 └─ … 시대가 끝나면 (월드 클락 종결 or 플레이어 선택) → 새 시대, 새 세계 시드
```

| 단위 | 실제 플레이 시간 (목표) | 죽으면 |
|------|------------------------|--------|
| **생애** (한 캐릭터) | 짧으면 30분, 평균 3~8시간, 길면 30시간+ | 같은 세계에서 다음 생애로 |
| **시대** (한 세계) | 20~100시간 | 메타 계승 후 새 세계 |

- **같은 세계가 이어진다**: 다음 캐릭터는 이전 캐릭터가 바꿔 놓은 세계에서 산다.
  내가 도운 영주가 왕이 되어 있고, 내가 태운 마을은 폐허로 남아 있다.
- 로그라이크의 긴장감(영구 사망) + 샌드박스의 연속성(세계는 남는다)을 동시에 얻는다.

### 1.1 시간 흐름 기준

| 게임 시간 | 대략의 실제 플레이 시간 |
|-----------|------------------------|
| 하루 | 5~15분 (행동 밀도에 따라) |
| 한 계절 (90일) | 1~2시간 (이동·노동·수련은 "몰아서 보내기"로 빠르게 진행) |
| 1년 | 3~6시간 |

## 2. 장치 A: 시간이 곧 비용인 세계

마을에 틀어박혀 있어도 **세계는 플레이어를 가만두지 않는다.**

### 2.1 생활비 (매일 빠져나가는 것)
| 항목 | 하루 비용 (발도르 기준) | 미지불 시 |
|------|-------------------------|-----------|
| 식비 | 2~3동 | 굶주림 → 판정 페널티 → 기아 |
| 숙박 | 0(노숙)~6동 | 노숙: 피로 회복 절반, 강도·추위·질병 위험 |
| 세금·지대 | 계절마다 정산 | 빚 → 채무노역 / 영주에게 징벌 |
| 수련비 | 스승 수업료 하루 1~5은 | 스승이 떠남 |

> 일하지 않으면 수련할 수 없고, 일하면 수련할 시간이 줄어든다. **삶 자체가 자원 관리.**

### 2.2 세상이 마을을 찾아온다 (마을은 영원히 안전하지 않다)

시작 마을 '회색여울'에 계속 머물 때 시간이 지나면 일어나는 일 (월드 클락 연동):

```
312 가을  북부 난민 유입 → 빵값 상승, 마을 분위기 험악
312 겨울  첫 번째 약탈 (국경 너머 굶주린 씨족)
313 봄    왕 사망 소식 → 레이번 남작이 편을 고름
313 여름  징병 포고: 마을 성인 남녀 1/5 징집 ← 플레이어도 대상!
          (거부 = 탈영병 수배 / 뇌물 / 숨기 / 입대)
313 가을  계승 전쟁 본격화, 군대가 지나가며 곡식 징발
314 봄    역병 (재열병) 유행
...
```

- 각 사건은 **선택**을 강요한다. 숨어서 수련만 하는 선택지는 점점 비싸진다.
- 그리고 이 사건들이 오히려 가장 좋은 성장 기회다 (아래 수련 구조 참고).

### 2.3 노화
- 시작 나이 15~25세. 35세부터 신체 능력치 성장 상한 하락, 50세부터 능력치 감소 판정.
- 한 생애에서 할 수 있는 일에 한계가 있다 → 무엇에 시간을 쓸지 고민하게 된다.

## 3. 장치 B: 수련의 한계 구조

### 3.1 수련 방식별 상한

| 방식 | 경험치 배율 | **스킬 상한** | 비용 |
|------|-------------|---------------|------|
| 독학 (허수아비 치기, 혼자 연습) | ×0.3 | **25** | 시간, 피로 |
| 안전한 실습 (목검 대련, 견습 노동) | ×0.6 | **40** | 시간, 상대 필요 |
| 스승 수업 | ×2~3 | **스승 스킬 − 10** | 돈, 스승의 요구(의뢰·충성) |
| **실전** (진짜 위험이 걸린 판정) | ×1.0 | 제한 없음 | 부상·죽음의 위험 |
| 목숨이 걸린 실전 | ×2.0 | 제한 없음 | 큰 위험 |
| 책·문헌 (지식 계열) | ×1.0 | **책의 수준** | 책 구하기, 읽고쓰기 필요 |

→ **안전하게 오를 수 있는 건 40까지.** 그 이상은 스승을 찾거나, 위험을 감수해야 한다.
→ 좋은 스승은 대도시·성·탑에 있고, 공짜로 가르쳐주지 않는다 → **모험의 동기**가 된다.

### 3.2 수확 체감 + 녹슮
```
수확 체감 = (1 − 현재스킬/상한)²      → 상한 근처에선 거의 안 오름
녹슮     = 30일간 미사용 시 하루 −0.05 (단, 최고치의 80% 아래로는 안 떨어짐)
```

### 3.3 "몰아서 보내기"는 위험을 동반한다
- "일주일 동안 수련한다" 같은 시간 건너뛰기는 가능하지만, 그 사이에도 **세계 시뮬레이션은 돌아간다**.
- 건너뛰는 도중 중요한 사건이 생기면 중단되고 장면이 시작된다.

## 4. 장치 C: 2단 계승

### 4.1 세계 안 계승 (In-World Legacy) — 같은 시대 안에서

캐릭터가 죽으면, **세계 안에서 그 사람과 연결된 인물**로 이어서 플레이한다.

| 후계자 후보 | 조건 | 물려받는 것 |
|-------------|------|-------------|
| 자녀 | 자녀가 있고 나이 12세 이상 | 성(가문), 상속재산, 가문 평판, 원수 |
| 배우자 | 결혼 | 집·재산, 인맥 일부 |
| 제자 | 스승-제자 관계 (6개월 이상 가르침) | 스승 스킬의 일부를 이미 배운 상태, 스승의 비밀 지식 |
| 동료 | 신뢰 70 이상의 동료 | 동료 자신의 능력 + 함께한 기억 |
| 같은 마을의 누군가 | 항상 가능 (최후의 수단) | 거의 없음. 이전 캐릭터의 이야기를 "들어서" 앎 |

**물려받는 방식이 현실적이어야 한다 (그림다크):**
- 재산은 **유언장·은행·금고에 있을 때만** 상속된다. 몸에 지닌 것은 **시체와 함께 그 자리에 남는다.**
  → 다음 캐릭터가 아버지의 검을 되찾으러 늑대굴로 가는 것이 첫 목표가 된다.
- 다른 친척·채권자·영주가 상속에 끼어든다 (상속 분쟁 스토리렛).
- 이전 캐릭터의 **원한과 빚도 상속된다.**
- 이전 캐릭터가 쓴 **일기·지도·편지**는 세계 안의 아이템으로 남아, 읽으면 지식이 복구된다.
- 이전 캐릭터의 무덤이 생긴다. 찾아가면 짧은 회상, 그리고 가끔 도굴꾼.

### 4.2 세계 밖 계승 (Meta Legacy) — "잔향(殘響)"

#### 세계관 설정으로 정당화한다
> 대붕괴 때 '시간'의 진명이 찢어진 이후, 극히 일부의 영혼은 죽은 뒤에도 완전히 흩어지지 않고
> **기억과 재능의 조각을 품은 채 다시 태어난다.** 사람들은 이들을 **잔향자(殘響者)** 라 부른다.
> 성광교는 잔향자를 "찢어진 시간의 오물"이라 하여 이단으로 규정하고 화형에 처한다.
> 잿빛 탑은 그들을 연구하고 싶어 한다.

→ 메타 성장이 게임 시스템이 아니라 **세계관의 일부**가 된다. 플레이어 캐릭터는 (원하면) 잔향자다.
→ 잔향을 너무 드러내면 교단의 표적이 된다 = 메타 성장에도 리스크.

#### 잔향 포인트 획득
생애가 끝나면 **연대기(Chronicle)** 가 작성되고, 업적에 따라 잔향 포인트(EP)를 얻는다.

| 업적 | EP |
|------|----|
| 생존 연수 | 1년당 2 |
| 스킬 명인(65+) 도달 | 스킬당 10 |
| 세계에 영향 (월드 클락 분기 변경) | 15~50 |
| 새로운 지역 발견 | 5 |
| 이름 있는 NPC와 깊은 관계 (평생의 친구/원수) | 5 |
| 개인적 야망 달성 | 20~40 |
| 기억에 남는 죽음 (연대기 평가) | 0~20 |

> 단순히 오래 버티기보다 **"이야기가 있는 삶"** 에 더 많은 보상을 준다.

#### 잔향으로 해금하는 것 (수평 확장 위주 — 파워 인플레이션 방지)

| 종류 | 예시 | 비용 | 설계 의도 |
|------|------|------|-----------|
| **출신 해금** | 엘프 혼혈, 재태생, 드워프 추방자, 세렌 상인 가문 | 20~40 | 새로운 시작점 = 새로운 게임 |
| **혈통 재능** | "검의 혈통": 검술 성장 ×1.25 / "늪의 피": 독 저항 | 15~30 | 성장 **속도**만 올림 (시작 수치 X) |
| **전생의 꿈** | 생애 중 가끔 전생의 지식이 꿈으로 떠오름 (지도, 비밀, 레시피) | 10 | 지식 계승 |
| **잔향의 기억** | 전생에 배운 언어 1개를 기초 수준으로 앎 | 15 | 세계 이해의 지속 |
| **가보의 메아리** | 전생의 고유 아이템 1개가 **새 세계에 '전설의 물건'으로 존재** — 찾아야 함 | 25 | 아이템 계승이지만 공짜가 아님 |
| **연대기 도서관** | 이전 생애·시대의 연대기 열람, 세계 설정 백과 해금 | 무료 | 수집 욕구 |
| **시작 조건 조정** | 시작 나이·지역·계절 선택 | 5~10 | 편의 |

**하지 않는 것:**
- 시작 능력치/스킬 직접 상승 ✗ (첫 생애의 농부와 열 번째 생애의 농부는 **똑같이 약하다**)
- 시작 금화 대량 지급 ✗
- 사망 방지 ✗

> 그림다크의 긴장감을 지키는 원칙: **"더 강하게 시작하지 않는다. 더 많이 알고, 더 다양하게 시작한다."**

### 4.3 잔향자의 리스크 (선택적)

- 잔향 재능을 쓰면(전생의 꿈, 혈통 재능 발현) 아주 낮은 확률로 **잔향 징후**가 남는다
  (눈동자에 잿빛 고리, 모르는 언어로 잠꼬대).
- 징후가 목격되면 소문 → 심문관의 추적.
- 옵션: "잔향 없음(하드코어)" 모드 — 메타 계승 끄기, 연대기만 남음.

## 5. 죽음 연출과 연대기

죽음은 끝이 아니라 **한 편의 이야기가 완성되는 순간**이다.

```
┌──────────────────────────────────────┐
│  리사, 회색여울의 농노의 딸              │
│  붕괴력 297 ~ 319 (22세)              │
├──────────────────────────────────────┤
│  "리사는 열다섯에 아버지의 빚을 갚기 위해   │
│   레이번 남작의 성채에서 일했다. 그곳에서   │
│   도둑질을 배웠고, 열일곱에 처음 사람을     │
│   죽였다. 북부인 난민들은 그녀를 '굶주린    │
│   겨울의 은인'이라 불렀으나, 남작의 기록에는 │
│   '곡물 창고 방화범'으로 남았다.           │
│   319년 겨울, 그녀는 동생을 찾아 재의      │
│   황무지 가장자리로 갔고, 돌아오지 못했다." │
├──────────────────────────────────────┤
│  업적  ▸ 북부 기근 클락 분기 변경 (+30)    │
│        ▸ 손재주 명인 (+10)                │
│        ▸ 생존 7년 (+14)                   │
│  잔향  +54                              │
├──────────────────────────────────────┤
│  [ 이어서: 제자 '토르'로 ]               │
│  [ 이어서: 동생 '미라'로 (행방불명) ]      │
│  [ 이 시대 끝내기 ]                       │
└──────────────────────────────────────┘
```

- 연대기 문장은 **이벤트 로그 → 템플릿 서술**로 오프라인 생성, LLM이 있으면 더 풍부하게 (04_TECH 문서 참고).
- 연대기는 공유 가능한 이미지/텍스트로 내보낼 수 있다 → 입소문 마케팅 장치.
