# 03. 로그라이트 구조, 수련 남용 방지, 죽음과 계승

> 문제 정의
> 1. 그림다크 세계 → 죽음이 흔하고 영구적이어야 한다 (로그라이크).
> 2. 그런데 자유도가 높으면 "안전한 마을에서 수백 시간 수련"이라는 최적해가 생긴다.
> 3. 죽었을 때 모든 것을 잃으면 허무하고, 너무 많이 남기면 긴장감이 사라진다.

해답은 **3가지 장치의 조합**이다.

| 장치 | 해결하는 문제 |
|------|---------------|
| A. 시간이 곧 비용인 세계 | 마을에 틀어박혀 수련하는 것을 막는다 |
| B. 수련의 한계 구조 | 안전한 수련만으로는 강해질 수 없게 한다 |
| C. 2단 계승 (세계 안 / 세계 밖) | 죽음에 의미를 주되 긴장감을 지킨다 |

---

## 1. 플레이 구조: "생애 → 시대"

```
시대(Era) ── 하나의 세계 시드. 약 80~150년의 역사.
 ├─ 생애 1: 농노의 딸 리사      (312~319년, 7년 생존, 늑대에게 사망)
 ├─ 생애 2: 리사의 제자 토르    (319~341년, 22년 생존, 계승 전쟁에서 전사)
 ├─ 생애 3: 토르의 아들 에반    (341~380년, 노환으로 사망 — 남작 작위 획득)
 └─ … 시대가 끝나면 (월드 클락 종결 or 플레이어 선택) → 새 시대, 새 세계 시드
```

| 단위 | 실제 플레이 시간 (목표) | 죽으면 |
|------|------------------------|--------|
| **생애** (한 캐릭터) | 짧으면 30분, 평균 3~8시간, 길면 30시간+ | 같은 세계에서 다음 생애로 |
| **시대** (한 세계) | 20~100시간 | 메타 계승 후 새 세계 |

- **같은 세계가 이어진다**: 다음 캐릭터는 이전 캐릭터가 바꿔 놓은 세계에서 산다.
  내가 도운 반용 서자가 용좌에 올라 있고, 내가 세운 비밀 학교는 아직 남아 있으며, 내가 태운 성채는 폐허로 남아 있다.
- 로그라이크의 긴장감(영구 사망) + 샌드박스의 연속성(세계는 남는다)을 동시에 얻는다.

### 1.1 시간 흐름 기준

| 게임 시간 | 대략의 실제 플레이 시간 |
|-----------|------------------------|
| 하루 | 5~15분 (행동 밀도에 따라) |
| 한 계절 (90일) | 1~2시간 (이동·노동·수련은 "몰아서 보내기"로 빠르게 진행) |
| 1년 | 3~6시간 |

## 2. 장치 A: 시간이 곧 비용인 세계

마을에 틀어박혀 있어도 **세계는 플레이어를 가만두지 않는다.**

### 2.1 생활비 (매일 빠져나가는 것)
| 항목 | 하루 비용 (용제국 기준) | 미지불 시 |
|------|-------------------------|-----------|
| 식비 | 2~3동 | 굶주림 → 판정 페널티 → 기아 |
| 숙박 | 0(노숙)~6동 | 노숙: 피로 회복 절반, 강도·추위·질병 위험 |
| 인두세·노역 할당 | 계절마다 정산 (주인 몫) | 할당 미달 → 채찍, 배급 삭감, 매각 |
| 수련비 | 스승 수업료 하루 1~5은 | 스승이 떠남 |

> 일하지 않으면 수련할 수 없고, 일하면 수련할 시간이 줄어든다. **삶 자체가 자원 관리.**

### 2.2 세상이 마을을 찾아온다 (마을은 영원히 안전하지 않다)

시작 마을 '회색여울'에 계속 머물 때 시간이 지나면 일어나는 일 (월드 클락 연동):

```
312 가을  북방 거인 노예 탈주자 유입 → 배급 감소, 바르그 노예사냥꾼 순찰 증가
312 겨울  탈주자 은닉 수색 — 집집마다 수색, 숨긴 자는 공개 처벌
313 봄    흰 알 부화 / 용황 병세 악화 → 레이번 남작이 후계자 편을 고름
313 여름  맹약회의 + 징발 포고: 마을 인간 1/5을 군용 짐꾼·방패병으로 징발 ← 플레이어도 대상!
          (거부 = 탈주 노예 수배 / 뇌물 / 숨기 / 끌려가기)
313 가을  용제국 계승 전쟁 본격화, 군대가 지나가며 곡식과 사람을 징발
314 봄    역병 (재열병) 유행 / 남작이 빚을 갚으려 농노를 세렌에 팔기 시작
...
```

- 각 사건은 **선택**을 강요한다. 숨어서 수련만 하는 선택지는 점점 비싸진다.
- 그리고 이 사건들이 오히려 가장 좋은 성장 기회다 (아래 수련 구조 참고).

### 2.3 노화
- 시작 나이 15~25세. 35세부터 신체 능력치 성장 상한 하락, 50세부터 능력치 감소 판정.
- 한 생애에서 할 수 있는 일에 한계가 있다 → 무엇에 시간을 쓸지 고민하게 된다.

## 3. 장치 B: 수련의 한계 구조

### 3.1 수련 방식별 상한

| 방식 | 경험치 배율 | **스킬 상한** | 비용 |
|------|-------------|---------------|------|
| 독학 (허수아비 치기, 혼자 연습) | ×0.3 | **25** | 시간, 피로 |
| 안전한 실습 (목검 대련, 견습 노동) | ×0.6 | **40** | 시간, 상대 필요 |
| 스승 수업 | ×2~3 | **스승 스킬 − 10** | 돈, 스승의 요구(의뢰·충성) |
| **실전** (진짜 위험이 걸린 판정) | ×1.0 | 제한 없음 | 부상·죽음의 위험 |
| 목숨이 걸린 실전 | ×2.0 | 제한 없음 | 큰 위험 |
| 책·문헌 (지식 계열) | ×1.0 | **책의 수준** | 책 구하기, 읽고쓰기 필요 |

→ **안전하게 오를 수 있는 건 40까지.** 그 이상은 스승을 찾거나, 위험을 감수해야 한다.
→ 좋은 스승은 대도시·성·탑에 있고, 공짜로 가르쳐주지 않는다 → **모험의 동기**가 된다.

### 3.2 수확 체감 + 녹슮
```
수확 체감 = (1 − 현재스킬/상한)²      → 상한 근처에선 거의 안 오름
녹슮     = 30일간 미사용 시 하루 −0.05 (단, 최고치의 80% 아래로는 안 떨어짐)
```

### 3.3 "몰아서 보내기"는 위험을 동반한다
- "일주일 동안 수련한다" 같은 시간 건너뛰기는 가능하지만, 그 사이에도 **세계 시뮬레이션은 돌아간다**.
- 건너뛰는 도중 중요한 사건이 생기면 중단되고 장면이 시작된다.

## 4. 장치 C: 2단 계승

### 4.1 세계 안 계승 (In-World Legacy) — 같은 시대 안에서

주인공(잔향)의 몸이 죽으면, 영혼은 **인연을 따라** 가까운 사람에게 옮겨가 그 안에서 깨어난다.
그 사람의 기억과 삶은 사라지지 않고 잔향과 섞인다 — 플레이어는 **그 사람으로서** 이어서 산다.

| 영혼이 옮겨갈 곳 | 조건 | 물려받는 것 |
|------------------|------|-------------|
| 자녀 | 자녀가 있고 나이 12세 이상 | 아이 자신의 삶 + 비밀 가문 이름, 숨겨둔 재산, 평판, 원수 |
| 제자 | 6개월 이상 가르친 제자 | 제자 자신의 능력(스승에게 배운 스킬) + 스승의 비밀 지식 |
| 동료 | 신뢰 70 이상의 동료 | 동료 자신의 능력 + 함께한 기억 |
| 배우자·연인 | 깊은 관계 | 그 사람의 삶과 인맥 |
| 인연이 없을 때 | 항상 | **아기로 다시 태어나 15년 뒤에 깨어난다** — 그 사이 세계는 15년을 흘러간다 |

- 영혼이 옮겨간 사람은 원래 평범한 인간이었으므로, 잔향이 깃든 순간부터 **잔향의 세 가지(빈 그릇·배움·돌아옴)** 를 얻는다.
- **신체 특질**은 몸에 속하므로 옮겨가지 않는다. 이식으로 얻은 용심은 시체와 함께 남는다 (다음 몸에는 다시 이식해야 한다).
- 이전 몸과 가까운 사람에게 옮겨갈수록 "왜 저 사람이 갑자기 달라졌지?"라는 의심을 받는다 → 잔향 징후 위험.

**물려받는 방식이 현실적이어야 한다 (그림다크):**
- 인간은 법적으로 재산이 없으므로, 재산은 **숨겨둔 곳·믿는 사람·세렌 계약 금고에 있을 때만** 이어진다. 몸에 지닌 것은 **시체와 함께 그 자리에 남는다.**
  → 다음 캐릭터가 아버지의 검을 되찾으러 늑대굴로 가는 것이 첫 목표가 된다.
- 주인은 죽은 노예의 물건을 자기 것으로 가져가고, 채권자·밀고자가 끼어든다 (상속 분쟁 스토리렛).
- 이전 캐릭터의 **원한과 빚도 상속된다.**
- 이전 캐릭터가 쓴 **일기·지도·편지**는 세계 안의 아이템으로 남아, 읽으면 지식이 복구된다.
- 이전 캐릭터의 무덤이 생긴다. 찾아가면 짧은 회상, 그리고 가끔 도굴꾼.

### 4.2 세계 밖 계승 (Meta Legacy) — "잔향(殘響)"

#### 세계관 설정으로 정당화한다
> 죽어가던 신 에오르가 남긴 마지막 말 **"너희는 끝나지 않을 것이다"** 는 흩어지지 않고 **단 하나의 영혼**이 되었다.
> 그 영혼만이 죽어도 끝나지 않고, **기억과 재능의 조각을 품은 채** 다른 인간의 몸에서 다시 깨어난다. 이것이 **잔향(殘響)** 이고, 주인공이다.
> 평범한 인간의 영혼은 돌아오지 않는다. 오직 하나뿐이다.
> 고대 종족들은 3,400년 동안 이 하나를 사냥해 왔다. 재의 법은 잔향의 징후가 있는 인간을 화형에 처하고 — 그래서 **주인공 대신 무고한 사람들이 불탄다.**
> 순종의 빛은 잔향 전설을 "순종하면 다음 생에 빛의 종족으로 태어난다"는 거짓으로 비틀어 가르친다.
> 잿빛 탑과 엘다르 존속파, 멜리산드는 진짜 잔향을 가려내 붙잡으려 한다.

→ 메타 성장이 게임 시스템이 아니라 **세계관의 핵심**이 된다. 세상에서 특별한 것은 **오직 주인공뿐**이다.
→ 잔향을 너무 드러내면 사냥의 표적이 된다 = 메타 성장에도 리스크.

#### 잔향 = 재능 포인트(TP)
메타 계승의 주된 형태는 **재능 포인트**다 (상세: [06_CHARACTER_CREATION.md](06_CHARACTER_CREATION.md)).

| 항목 | 값 |
|------|-----|
| 1회차 기본 TP | 10 |
| 업적 보상 | 업적마다 영구 TP +1~+5 (목록: world/SCENARIOS.md) |
| 최대 TP | 40 |

생애가 끝나면 **연대기(Chronicle)** 가 작성되고, 그 생애에서 달성한 업적이 확정된다.
업적은 오래 버티기보다 **"이야기가 있는 삶"** 에 더 많이 주어진다 (월드 클락 분기 변경, 찬가 단계 진전, 평생의 친구·원수, 기억에 남는 죽음).

#### 잔향으로 해금하는 것 (TP 외)

| 종류 | 예시 | 해금 조건 | 설계 의도 |
|------|------|-----------|-----------|
| **출신 해금** | 반용, 반엘다르, 재태생, 투사의 자식, 늪 마녀의 딸 | 관련 업적 | 새로운 시작점 = 새로운 게임 |
| **재능 III단계** | 검의 재능 III 등 | 관련 스킬 명인 도달 | 성장 천장 확장 |
| **전생의 꿈** | 생애 중 가끔 전생의 지식이 꿈으로 떠오름 (지도, 비밀, 레시피) | 첫 사망 | 지식 계승 |
| **가보의 메아리** | 전생의 고유 아이템 1개가 **새 세계에 '전설의 물건'으로 존재** — 찾아야 함 | 고유 아이템을 1년 이상 소지 후 사망 | 아이템 계승이지만 공짜가 아님 |
| **연대기 도서관** | 이전 생애·시대의 연대기 열람, 세계 설정 백과 해금 | 항상 | 수집 욕구 |

**재능의 원칙:**
- 재능은 **성장 속도·상한·열리는 길**을 바꾼다. 30 TP 캐릭터도 시작 시점엔 숙련된 용인 기사에게 일대일로 진다.
- 강한 특질일수록 **그것을 노리는 자**가 생긴다 (용심 → 용족의 처단, 엘다르의 눈 → 영혼 정원의 납치).
- 시작 금화 대량 지급 ✗, 사망 방지 ✗.

> 그림다크의 긴장감을 지키는 원칙: **"더 강하게 시작하지 않는다. 더 높이 오를 수 있게, 더 다양하게 시작한다."**

### 4.3 잔향자의 리스크

- 잔향 효과(전생의 꿈, 잔향의 눈)를 쓰면 낮은 확률로 **잔향 징후**가 남는다
  (눈동자에 잿빛 고리, 모르는 언어로 잠꼬대, 처음 가는 곳의 길을 앎).
- 징후가 목격되면 소문 → 목줄단의 밀고 → 잿빛 탑 밀정과 바르그 사냥꾼의 추적.
- 옵션: "잔향 없음(하드코어)" 모드 — TP 기본 10 고정, 연대기만 남음.

## 5. 죽음 연출과 연대기

죽음은 끝이 아니라 **한 편의 이야기가 완성되는 순간**이다.

```
┌──────────────────────────────────────┐
│  리사, 회색여울의 농노의 딸              │
│  붕괴력 297 ~ 319 (22세)              │
├──────────────────────────────────────┤
│  "리사는 열다섯에 아버지의 빚을 갚기 위해   │
│   레이번 남작의 성채에서 일했다. 그곳에서   │
│   몰래 글자를 배웠고, 열일곱에 처음 감독관을 │
│   죽였다. 북방 탈주자들은 그녀를 '굶주린    │
│   겨울의 은인'이라 불렀으나, 남작의 장부에는 │
│   '도망친 재산, 현상금 2비늘'로 남았다.     │
│   319년 겨울, 그녀는 동생을 찾아 재의      │
│   황무지 가장자리로 갔고, 돌아오지 못했다." │
├──────────────────────────────────────┤
│  업적  ▸ 불씨 — 탈주자 공동체 1년 유지     │
│        ▸ 북방 대탈주 클락 분기 변경        │
│        ▸ 손재주 명인                      │
│  잔향  재능 포인트 +6 (다음 생애 16 TP)    │
├──────────────────────────────────────┤
│  [ 이어서: 제자 '토르'로 ]               │
│  [ 이어서: 동생 '미라'로 (행방불명) ]      │
│  [ 이 시대 끝내기 ]                       │
└──────────────────────────────────────┘
```

- 연대기 문장은 **이벤트 로그 → 템플릿 서술**로 오프라인 생성, LLM이 있으면 더 풍부하게 (04_TECH 문서 참고).
- 연대기는 공유 가능한 이미지/텍스트로 내보낼 수 있다 → 입소문 마케팅 장치.
