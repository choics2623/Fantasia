# 26. 목표 행동 — 플레이어가 없어도 세계는 움직인다

> 정본의 사건 달력(REGIONS §2.14)은 "12월 10일 마르타가 냄새를 알아챈다"라고 적는다. 그런데 **왜** 그날인가?
> 목표 행동은 그 '왜'를 시뮬레이션으로 만든다. 헨릭은 돈을 원하고, 브람은 돈이 떨어지고, 즈닉은 곡창 부족분을 덮으려 방앗간을 뒤지고 —
> 그래서 플레이어가 아무것도 하지 않으면 정본의 날짜에 정본의 일이 일어나고, 플레이어가 사슬 하나를 끊으면 그 뒤가 달라진다.

- 데이터: `content/base/agendas/<지역>.yaml`
- 엔진: `engine/sim/agenda.mjs` (+ 위치 엔진 24), 검사: `node engine/sim/test_agenda.mjs`

---

## 1. 목표 하나의 모양

```yaml
- id: ag_henrik_collect
  npc: npc_henrik
  goal: 매주 입막음 값을 받는다
  every: "weekday:2"                 # once | daily | weekday:N | every:N
  chance: 0.3                        # (선택) 그날 일어날 확률 — 회차 시드로 결정적
  when: ["alive npc_henrik", "var egil_hidden == true", "knows npc_henrik fact_gf_bram_pays_henrik", "date >= 312-09-08"]
  at: {place: gf_rooster, from: "21:00", to: "21:30", doing: 수탉 뒷문에서 입막음 값을 받는다}
  effects:
    - "if coin npc_bram >= var:henrik_extortion 발톱: pay npc_bram npc_henrik var:henrik_extortion 발톱 ; var bram_debt = 0"
    - "else: var bram_debt += 1 ; log 브람이 입막음 값을 못 냈다 ({bram_debt}주째)"
```

| 조건 (`when`) | 뜻 |
|---------------|----|
| `alive npc` / `dead npc` | 살아 있나 |
| `present npc` | 이 고장에 있나 (24 체류 기간) |
| `knows npc fact` | 그 사람이 그 사실을 아나 (22 카드의 knows·hides에서 시작, 효과로 늘어난다) |
| `var 이름 연산 값` | 세계 변수. 값 자리에 `var:다른변수` 가능 |
| `coin npc >= 값 [발톱\|비늘]` | 그 사람의 지갑 (27 소지품과 같은 지갑, 못 단위) |
| `date >= 312-09-20` | 날짜 |
| 앞에 `not` | 부정 |

| 효과 (`effects`) | 뜻 |
|------------------|----|
| `var x += n` / `-=` / `=` | 세계 변수 |
| `coin npc += n [단위]` / `pay a b n [단위]` | 돈을 벌거나 넘긴다 (헨릭의 지갑이 실제로 불어난다) |
| `learn npc fact` | 그 사람이 사실을 알게 된다 → 그 사람의 다른 목표 조건이 열린다 (사슬) |
| `rel a>b like ±n` | 관계 |
| `capture npc at 장소` / `punish npc at 장소 for 날수` / `kill npc` | 위치 엔진 덮어쓰기 |
| `log 문장` | 세계 기록 — 소문(21 §8)과 메아리(16)의 재료 |
| `if 조건: 효과 ; 효과` / `else: …` | 갈림 |

## 2. 굴리는 법
- 목표는 **시작 시각에** 조건을 본다 (`stepTo(t)` — 시각 순서. 플레이어가 20시에 한 일이 21시 목표를 막는다). 조건이 맞으면:
  1. NPC를 그 시각·장소로 **실제로 보낸다** (위치 엔진 덮어쓰기 — 그 시각에 그곳에 가면 그 장면을 볼 수 있다).
  2. 효과를 적용한다. 사실이 퍼지면 다른 사람의 목표가 열린다.
- 결정적이다: 같은 회차 시드 = 같은 가을. 다른 회차는 확률 목표(`chance`)가 다른 날 일어난다 — 시간의 표류(03).
- 18 「기억대로 보낸다」로 날을 건너뛰면, 건너뛴 날들도 그대로 굴러간다.

## 3. 회색여울 — 아무도 개입하지 않은 가을 (시드 7)
```
9/21  하겐이 페인에게서 늑대굴 위치를 알아냈다
9/23  하겐이 탈주자 셋을 볼크에게 넘겼다
9/25  볼크의 대수색 — 늑대굴은 찾지 못하고 넷을 잡았다
10/14 헨릭이 입막음 값을 올렸다 (3 발톱) … 11/8 (6 발톱)
10/20 즈닉이 방앗간 두 번째 바닥을 찾았다 — 브람의 곡물 길이 끊겼다
12/8  브람이 입막음 값을 못 냈다
12/10 마르타가 수탉 지하의 냄새를 알아챘다 → 그날 밤 즈닉에게 보고
12/11 즈닉이 수탉 지하를 덮쳤다 — 에길 일가 다섯이 끌려 나갔고, 브람은 채찍 기둥에 묶였다
```
정본(REGIONS §2.14)의 9.22·9.25·10.20·12.10이 **원인과 결과로** 이어진다.

## 4. 플레이어가 사슬을 끊으면
| 개입 | 결과 (검사로 확인) |
|------|--------------------|
| 9/20 하겐을 죽인다 | 9/22 매매가 없다. 늑대굴 위치가 볼크에게 가지 않는다 |
| 10/19 방앗간 두 번째 바닥을 숨겨 준다 | 곡물 길이 살아 있다 → 브람이 계속 값을 낸다 |
| 브람에게 돈을 대고, 11/30 에길 일가를 옮긴다 | 마르타는 아무것도 맡지 못하고, 지하실은 털리지 않는다 |

각 목표의 `when`이 곧 **플레이어가 끊을 수 있는 고리**다. 그래서 회귀자는 회차를 거듭하며 "어느 고리를 끊으면 무엇이 사는지"를 배운다 — 이 게임의 핵심 재미.
