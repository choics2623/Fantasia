# 25. 지역 생성 키트 — 손으로 다 쓰지 않고 세계를 채우는 법

> 제국 수도에는 수만 명이 산다. 그들을 다 쓸 수는 없다. 쓸 필요도 없다.
> **닻**(손으로 쓴 핵심 인물·장소)을 박고, 그 사이를 **키트**(그 지역다운 재료)로 채우고, 플레이어가 말을 거는 순간 LLM이 그 사람을 완성한다.

- 키트: `content/base/kits/<id>.yaml`
- 생성기: `engine/gen/settlement.mjs`(정착지 배치), `engine/gen/person.mjs`(즉석 인물), `engine/gen/rng.mjs`(결정적 난수)
- 검사: `node engine/gen/test_gen.mjs`

---

## 1. 네 층 — 어디에 얼마나 손을 쓰나

| 층 | 무엇 | 누가 | 깊이 |
|----|------|------|------|
| **① 키트** | 이름 목록, 신분·직업 분포, 직업 일과 틀, 말투 원형, 기질 낱말, 정착지 틀, 지역 관습·법(23 세력 데이터에서), 사건 달력 | 사람이 설계, 개발 중 LLM 대량 초안 | 모든 지역 |
| **② 닻 인물** | S/A등급 카드(22) + 일과(24). 세력 조직도의 주요 자리를 실제 사람으로 | 손으로 (LLM 초안 + 검수) | 지역당 20~40명 |
| **③ 즉석 인물** | 키트에서 뼈대를 뽑고, 말을 거는 순간 LLM이 B등급 카드를 쓴다 | 런타임 | 무제한 |
| **④ 회색여울급** | 건물·방·일과·사건 달력·숨긴 것까지 | 손으로 | 이야기가 지나가는 곳만 |

**확장 순서 (결정 2026-10): 회색여울에서 바깥으로.** 주인공이 실제로 가게 될 순서대로 깊어진다.
- 1차: 까마귀 문, 용주 역참, 바알카르(수도), 잿불 언덕, 루멘 — ①②④
- 2차: 나머지 지역 — ①②

## 2. 키트 형식

```yaml
id: kit_human_serf
applies_to: [회색여울 변경, ...]
names:         # 종족·아종별. 인간은 성이 없다 — 주인이 붙인 번호·별명 + 진짜 이름
classes:       # 정착지 인구의 신분 비율
jobs:          # {id, name, class, race?, sex?, age?, weight, schedule}
schedules:     # 직업 일과 틀 — at은 정착지 틀의 '역할' 이름(canteen, barracks, fields…)
voices:        # 말투 원형 {register, tics, use, avoid, sample} — 22 §1.1의 축약판
temperaments:  # 기질 낱말 목록
settlement_templates:
  - id, grid, roles: {역할: {count, place(배치 규칙 글), access, name, locked}}, outer: {역할: {hours, name}}
```

- 종족마다 키트가 다르다: 용인 성읍, 나가 항구, 두르강 굴, 엘다르 정원, 그롬 숙영지… 같은 형식, 다른 재료.
- 지역의 **관습·법·말투의 결**은 키트에 다시 쓰지 않고 세력 데이터(23)를 가리킨다. 한 곳에서만 고친다.

## 3. 생성기

### 3.1 정착지 (`generateSettlement(template, {id, name, size})`)
- 시드 = 정착지 id. 같은 마을은 언제나 같은 배치 — 회귀해도, 다른 플레이어여도.
- 역할마다 개수 범위 안에서 크기(`size`)에 맞게 수를 정하고, 배치 규칙 글(가운데·북·남·동·서·광장 옆…)로 대략의 자리를 잡은 뒤 흔들어 놓는다. 건물끼리 35m 안으로 겹치지 않는다.
- 결과는 손으로 쓴 정착지(24 §1)와 같은 모양이라 위치 엔진이 그대로 읽는다.

### 3.2 즉석 인물 (`generatePerson(kit, settlement, index)`)
- 시드 = (정착지, 번호). 배급 줄의 7번째 사람은 매 회차 같은 사람이다.
- 뽑는 것: 직업(가중치), 성별, 나이, 이름과 주인이 부르는 별명, 기질 두 낱말, 말투 원형, 집, 일과(직업 틀의 역할을 그 마을의 실제 건물로).
- 쓰지 않는 것: 생애, 비밀, 말투 변주 — 플레이어가 말을 거는 순간 LLM이 이 뼈대와 키트로 쓴다 (21 §5, 22 §2.1). 쓴 카드는 세이브에 남고, 승격(08 §2)되면 고정된다.
- 회귀하면: 뼈대는 시드로 같게 다시 나오고, LLM이 쓴 살은 세이브의 '지난 회차 카드'를 참고해 **같은 사람**으로 다시 쓴다 (기억은 없다).

### 3.3 검사 결과 (지금)
- 같은 id = 같은 마을, 다른 id = 다른 배치, 건물 겹침 없음
- 같은 번호 = 같은 사람
- 생성된 40명의 7일 위치가 모두 실제 장소, 저녁 배급 시간에 배급소에 29명이 모인다
