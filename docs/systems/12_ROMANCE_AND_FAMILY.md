# 12. 연애·결혼·가족·가문

> 질문: "다른 NPC와 연애, 데이트, 결혼, 임신, 가족, 가문도 만들 수 있게? 모든 시스템과 조화롭게."
> 답: 가능하다. 그리고 이 게임에서 가족은 단순한 부가 콘텐츠가 아니라 **회귀의 무게가 가장 정확하게 내려앉는 자리**다.
> 사랑도, 혼인도, 아이도, 가문도 **한 회차 안의 것**이다. 주인공이 죽으면 세계는 회귀점으로 돌아가고,
> 사랑한 사람은 주인공을 처음 보는 얼굴이 되며, 낳은 아이는 **다시 태어나지 않는다.** (WORLD_BIBLE §1.3.1)
> 기억하는 쪽은 나뿐이다. 그래서 더 소중하고, 더 덧없다. 그리고 그들은 여전히 주인공의 가장 큰 약점이다.

---

## 1. 원칙

| 원칙 | 내용 |
|------|------|
| **선택 사항** | 연애를 하지 않아도 게임의 모든 길이 열려 있다 |
| **상대도 사람이다** | NPC는 자신의 성향·목표·과거로 주인공을 판단한다. 호감을 "모으는" 게임이 아니다 |
| **성별 무관** | 관계는 성별과 무관하게 가능하다. 임신은 생물학적으로 가능한 조합에서만, 가족은 입양·제자·맹세로도 만들 수 있다 |
| **성인만** | 연애·혼인 대상은 성인 NPC뿐이다 (WORLD_BIBLE §0.3) |
| **장면 전환** | 성적 장면은 장면 전환으로 넘긴다 |
| **권력의 관계도 있다** | 정략혼, 강제 혼인, 첩, 인질 혼인, 노예 계약을 사서 곁에 두는 것 — 이 세계의 현실이고, 주인공도 할 수 있다. 다만 상대는 **자기 마음을 가진 NPC**다: 순종을 연기하고, 증오를 숨기고, 탈출을 꾸미고, 독을 탄다 |
| **그림다크의 무게** | 사랑은 이 세계에서 사치이고, 위험이고, 저항이며, 때로는 거래다 |
| **회차 안의 것** | 모든 관계·혼인·아이·가문은 그 회차의 세계에 속한다. 회귀하면 상대의 기억은 지워지고, 주인공의 기억만 남는다. 게임은 이것을 숨기지도, 위로하지도 않는다 |

## 2. 관계의 단계

08 문서의 관계 데이터(호감·신뢰·존경)를 그대로 쓰고, 연애는 그 위의 **단계**로 표현한다.

```
낯선 사람 → 아는 사이 → 친밀 → 끌림 → 연인 → 맹세(혼인) → 가족
                                  ↘ 짝사랑 / 거절 / 이별 / 배신 / 사별
                    ─── 회귀 ───→ 낯선 사람 (상대에게만)
```

| 단계 | 조건 (예) | 열리는 것 |
|------|-----------|-----------|
| 친밀 | 호감 40 + 신뢰 30 + 함께한 사건 3회 | 개인적인 대화 주제, 비밀 한 조각 |
| 끌림 | 호감 60 + **궁합** 기준 충족 + 한쪽의 고백 | 데이트 장면, 질투 반응 |
| 연인 | 서로 끌림 + 관계 확인 장면 | 함께 살기, 연인 전용 대사, 인질 가치(11 문서) |
| 맹세 | 신뢰 70 + 맹세 장면 | 가족·가문 등록, 공동 재산, 임신 가능성 |

### 2.1 궁합 — 무엇이 끌리게 하는가
각 NPC는 **끌림 기준**을 가진다 (성향 축·행동 기록 기반).

| NPC의 기준 (예) | 끌리는 것 | 식는 것 |
|-----------------|-----------|---------|
| 시그리드 (북방 탈주자) | 용기, 동족을 지키는 행동, 약속을 지킴 | 겁, 탈주자를 버림 |
| 사라 (성채 하녀) | 다정함, 글을 읽어주는 것, 위험에서 구해줌 | 폭력, 거짓말 |
| 하겐 (밀수꾼) | 재치, 대담함, 이익 | 설교 |
| 오웬 레이번 (용인) | 반항, 용기 — 그리고 금기 그 자체 | 순종 |

- 같은 행동이 어떤 NPC에게는 매력, 다른 NPC에게는 거부감이 된다 → 연애도 **세계 시뮬레이션의 일부**.
- NPC끼리도 연애한다 (08 문서 §7.3). 주인공이 끌리는 사람이 이미 다른 사람을 사랑하고 있을 수 있다.
- **끌림 기준은 회귀점의 인물 데이터에 들어 있다** → 회차가 바뀌어도 대개 같다. 주인공은 회차를 거듭하며 그것을 **배운다.** 다만 흔들리는 마음(03 §4.4 〔표류〕)이 있어, 같은 사람이 이번에는 다른 사람에게 먼저 마음을 줄 수도 있다.

### 2.2 다시 만나기 — 나를 처음 보는 사랑한 사람
회귀 뒤의 재회는 이 문서의 중심 장면이다. 주인공은 그 사람의 웃음이 어디서 터지는지, 무엇을 무서워하는지, 잠들기 전에 무슨 말을 하는지 안다. 그 사람은 주인공의 이름도 모른다.

**두 개의 장부**
| 장부 | 누구의 것 | 회귀하면 |
|------|-----------|----------|
| 관계 수치 (호감·신뢰·존경, 연애 단계) | 상대 NPC | 회귀점 값으로 |
| **기억된 인연** `soul.bonds` (가장 깊었던 단계, 함께한 회차 수, 아는 비밀, 아는 취향) | 주인공의 영혼 | 남는다 |

**아는 자의 이점 — 그리고 그 대가**
| 아는 것 | 효과 | 위험 |
|---------|------|------|
| 끌림 기준 | 친밀·끌림 단계 조건의 "함께한 사건" 수 −1 (최소 1) | 없음 — 이것은 그냥 그 사람을 아는 것이다 |
| 좋아하는 선물 태그 | 첫 선물부터 최고 반응 | 없음 |
| 그 사람의 비밀 | 비밀을 조심스럽게 건드리면 신뢰 +10 | **너무 많이 안다** 판정: 상대 통찰 vs 주인공 기만·화술. 실패하면 경계(호감 −15), 심하면 잔향 징후 (03 §4.3 「앎의 흔적」) |
| 지난 회차의 고백 장면 | 같은 말을 할 수 있다 | 같은 말이 같은 대답을 부르지는 않는다 (〔표류〕). 상대는 처음 듣는다 |

> 이것은 유혹 공략이 아니다. 아는 것을 쓰면 빨라지지만, **그 사람이 나를 고른 이유가 내가 그를 미리 알았기 때문**이라는 사실은 주인공만 안다. 대사와 목소리(15)가 이것을 가끔 건드린다.

**재회에서 고를 수 있는 것**
| 선택 | 내용 |
|------|------|
| **다시 시작한다** | 처음부터 다시 사랑한다. 연대기에 "N번째로 처음 만났다"가 남는다 |
| **멀리서 지킨다** | 다가가지 않는다. 그 사람이 지난 회차에 죽은 자리를 이번에는 비켜 가게 한다. 그 사람은 누가 자신을 살렸는지 모른다 |
| **다른 삶을 살게 둔다** | 이번 회차의 그 사람은 다른 사람을 사랑하게 둔다. 그 혼례에 손님으로 갈 수도 있다 |
| **진실을 말한다** | 신뢰 70 이상 + 증거(아직 일어나지 않은 〔고정〕 사건을 맞히는 것)로 믿게 할 수 있다. 믿으면 관계 태그 `knows_regressor` (그 회차에만). 믿지 않으면 미친 사람 — 또는 잔향 징후. 믿어도 위험하다: 그 사람이 잡혀 심문당하면 아는 것을 말한다 |

- 애착 매듭(20 문서)은 **주인공 쪽에 남는다.** 상대 쪽은 0에서 다시 시작한다. 재회 장면의 연출과 알아봄 점수는 20 문서 §8을 따른다 — 시간에 민감하지 않은 평범한 인간은 아무것도 알아보지 못한다. 가끔, 아주 가끔, 이유 없이 오래 쳐다볼 뿐이다.

## 3. 데이트 — 위험한 세계의 작은 시간

데이트는 장소·계절·위험에 따라 생성되는 **짧은 장면(스토리렛)** 이다.

| 장면 (예) | 장소 | 조건 | 위험 |
|-----------|------|------|------|
| 밤에 여울강 둑에서 별 보기 | 회색여울 | 통금 이후 | 감독관 순찰 |
| 몰래 글자 가르쳐주기 | 브람의 지하실 | 읽고쓰기 스킬 | 발각 = 둘 다 사형 |
| 수확제 뒤의 춤 | 마을 광장 | 수확월 | 낮음 |
| 옛 돌 고리에서 금지된 맹세 | 옛 돌 고리 | 연인 단계 | 금지 구역 |
| 원형장 경기 후 상처 치료 | 피의 원형장 | 투사 경로 | 다음 경기 |
| 세렌 시장에서 선물 고르기 | 세렌 | 계약민·돈 | 소매치기, 들킨 돈 |

- 선물은 아이템 시스템과 연결: NPC마다 좋아하는 태그가 있다 (`책`, `악기`, `무기`, `약초`, `단 음식`).
- 데이트도 시간을 쓰고(03 문서의 생활비·시간 압박), 들키면 평판·관계에 영향을 준다.
- **같은 별, 다른 밤**: 지난 회차에 함께 간 자리에 다시 가면 주인공 쪽에만 짧은 메아리 줄이 붙는다 (16 문서 〰). 상대는 처음 와 본 곳이다.
- 「기억대로 보낸다」(03 §3.5)로 연애의 날들을 건너뛸 수 있다. 다만 판정이 걸린 고백·맹세 장면은 다시 굴리고, 그 사람의 마음이 〔표류〕면 멈춘다.

## 4. 금지된 사랑 — 신분과 종족

| 관계 | 세계의 반응 | 이야기 |
|------|-------------|--------|
| 인간 ↔ 인간 (같은 주인) | 결혼은 주인 허가 필요. 허가 없이 = 처벌, 강제 이별(매각) | 비밀 혼례, 함께 도망 |
| 인간 ↔ 인간 (다른 주인) | 둘 중 하나가 팔려가야 한다 | 몸값 모으기, 탈주 |
| 인간 ↔ 용인 | **금기.** 들키면 인간 쪽이 죽고, 용인은 가문에서 쫓겨난다 | 오웬 ↔ 사라 (진룡의 경우: 카스파르의 어머니 엘레나와 고룡 바르스카르의 '작은 몸') |
| 인간 ↔ 엘다르 | 엘다르 존속파는 혼혈을 비밀리에 원한다 → 사랑인가 실험인가 | 반엘다르 아이 |
| 인간 ↔ 드라우르·녹테른(세실파) | 양쪽 사회 모두에서 배척 | 같은 처지의 동맹이 사랑이 된다 |
| 인간 ↔ 그롬 (투사) | 그롬은 "강한 자"를 존중한다 — 의외로 가능 | 원형장의 연인 |

- 금지된 사랑은 **평판(10 문서)** 에 강하게 반영된다: 같은 연애가 인간들에게는 노래가 되고 귀족들에게는 모욕이 된다.
- **엘다르와의 사랑은 특별하다.** 엘다르는 시간의 혈명이다. 그들은 회귀를 기억하지 못하지만 **기시감**을 느낀다 (03 §7.2, 10 §3.3). 여러 회차에 걸쳐 같은 엘다르와 가까워진 주인공에게, 그 엘다르는 첫 만남부터 이상하게 마음을 연다 — 그리고 그 낌새를 정원에 보고할 수도 있다. 사랑받는 것이 곧 들키는 것이다.

## 5. 혼인 — 인간에게 결혼은 불법이다

- 노예 인간의 혼인은 **주인의 허가**가 있어야 하고, 주인은 언제든 부부를 갈라 팔 수 있다.
- 그래서 인간들은 몰래 **끈혼례**(서로의 손목에 실을 묶는 비밀 의식)를 올린다. 증인은 같은 처지의 노예들.
- 순종의 빛 사제가 축복하면 "합법"에 가까워지지만, 주인 허가 없이는 의미가 없다.
- 세렌 계약민은 혼인이 자유롭다. 두르강 계약 광부는 계약에 따라.
- **정략 혼인**: 주인공이 힘을 가지면, 다른 인간 공동체나 세력(드라우르, 세실파 녹테른, 카스파르 측근 가문)과 **혼인 동맹**을 맺을 수 있다 → 11 문서의 '후견'·'인정' 지렛대.
- 회귀하면 손목의 실은 풀린 적도 없는 것이 된다. 주인공은 다음 회차에 **같은 사람과 다시 끈혼례를 올릴 수 있다.** 증인들은 처음 보는 혼례에 처음처럼 운다. 몇 번째 끈인지는 주인공만 안다 (`soul.bonds[npc].vows`).
- 정략 혼인은 회귀하면 무효이고, 그 혼인으로 얻은 동맹도 사라진다. 그러나 **누구와 혼인하면 어느 세력이 움직이는지**는 남는다 (11 문서).

## 6. 임신과 출산

| 항목 | 규칙 |
|------|------|
| 가능 조합 | 인간끼리 / 인간과 일부 종족(용인·엘다르·나가 — 낮은 확률, 혼혈아) |
| 기간 | 인간 9개월 (게임 시간). 혼혈은 다르다 (반용 12개월, 반엘다르 14개월) |
| 임신 중 | 체력·민첩 판정 페널티 단계적 증가, 노동 할당량은 그대로 (주인은 봐주지 않는다) |
| 출산 | 체질·응급처치·치료사·위생 판정. **그림다크: 출산은 위험하다** (치료사 없는 노예 출산 사망률 높음) |
| 노예의 아이 | 법적으로 **주인의 재산**이다. 아이를 지키는 것 자체가 이야기가 된다 |
| 혼혈아 | 반용 → 용족이 처단하려 한다 / 반엘다르 → 존속파가 데려가려 한다 |

> 주인공이 임신하는 쪽인지, 상대가 임신하는지는 조합에 따라 다르다. 어느 쪽이든 가족을 지키는 부담은 함께 진다.
> 주인공이 임신 중에 죽으면, 회귀한 몸은 임신한 적이 없다. 연대기에는 태어나지 못한 아이의 자리가 한 줄 남는다.

- 아이는 **긴 회차에서만** 생긴다. 맹세까지 몇 달, 임신 9개월, 아이가 말을 하기까지 또 몇 해. 아이가 있다는 것은 그 회차가 이미 길다는 뜻이고, 그래서 그 회차를 잃는 값이 크다는 뜻이다.

## 7. 자녀 — 사랑, 약점, 그리고 돌아가지 못하는 것

### 7.1 유전
| 요소 | 규칙 |
|------|------|
| 외형 | 부모 특징의 조합 + 무작위 (출생 순간의 회차 시드로 정해진다) |
| 성향 | 부모 성향 평균 ± 무작위 → **양육 사건**에 따라 자라면서 바뀐다 |
| 능력치 | 부모 평균 ± 2 |
| 혈통 특질 | 부모의 **혈통** 특질은 아이에게 **흔적**으로만 나타난다 (은빛 눈, 비늘 한 조각) — 힘은 없지만 그 흔적만으로도 사냥의 표적이 된다. 이식 특질은 유전되지 않는다 (06 문서) |
| 잔향 | **유전되지 않는다. 예외는 없다.** 아이는 평범한 인간이다. 잔향은 한 시대에 한 사람에게만 깃든다 |

### 7.2 양육
- 자녀는 시간이 흐르며 자란다 (1년 = 실제 3~6시간 플레이, 03 문서).
- 주인공이 가르친 스킬은 자녀의 스킬이 된다 → **자녀는 제자이기도 하다.**
- 주인공의 행동은 자녀의 성향에 영향을 준다 (보고 배운다): 주인공이 잔혹하면 자녀도 잔혹해질 수 있다.
- 자녀는 자기 목표와 관계를 가진 **독립된 NPC**다. 주인공의 뜻대로만 자라지 않는다.

### 7.3 회귀와 아이 — 이 게임만의 슬픔
- 주인공이 죽으면 세계는 회귀점으로 돌아간다. 312년 낙엽월의 세계에 그 아이는 없다. **아이는 다시 태어나지 않는다.**
- 다음 회차에 같은 사람과 다시 아이를 가져도, **같은 아이가 아니다.** 엔진은 같은 아이를 결코 다시 만들지 않는다 — 외형·성향의 무작위는 출생 순간의 시드로 굴리고, 이전 아이의 값과 겹치면 다시 굴린다. 같은 이름을 지어 줄 수는 있다. 아이는 그 이름에 다르게 웃는다.
- 회차 기록의 「너를 잊을 사람들」에서 아이는 맨 위에, 다른 줄 모양으로 나온다 (03 §5.1). 아이는 잊는 것이 아니라 **없어지는 것**이기 때문이다.
- 그래서 아이가 있는 회차의 모든 위험은 무게가 다르다. 성채 금고를 터는 일이 실패하면 주인공만 죽는 것이 아니라, 그 아이의 세계가 통째로 사라진다. 18 연출가와 20 문서는 이 회차를 **가장 큰 상실이 걸린 회차**로 읽는다.
- **이 아이를 지우지 않는 길**은 하나다: **「마지막 회차」 선언** (03 §4.6). 회귀를 놓으면, 이 회차에서 주인공이 죽어도 세계는 돌아가지 않는다. 아이는 그 갈래에서 계속 자란다. 대신 시대가 끝난다 — 찬가를 이루지 못했어도.
- 앞선 잔향자의 목소리(15)는 이 선택에 갈린다. 다라는 아홉 번의 봉기를 되풀이한 사람이다. 그녀가 무엇이라고 말할지는 15 문서가 정한다.

### 7.4 가족은 약점이다
- 적대 세력은 가족을 **인질**로 잡는다 (11 문서 §4).
- 주인공의 정체가 드러나면 가족이 먼저 끌려간다.
- 위협도가 높을수록 가족을 숨기는 것이 영역 관리(09 문서)의 일부가 된다.
- **가족은 회귀를 무겁게 만든다.** 일이 틀어졌을 때 죽어서 다시 하는 것(03 §3.6 자살 리셋)은 기계적으로는 언제나 열려 있다. 가족이 있는 회차에서 그 선택지에는 이름 목록이 붙는다.
- 반대로, 적이 가족을 인질로 잡았을 때 회귀자에게는 섬뜩한 선택지가 하나 더 있다: **죽어서 이 모든 일을 없던 일로 만드는 것.** 인질은 풀려나지 않는다. 처음부터 잡힌 적이 없게 된다. 아이도 함께. 13 문서 「어차피 되돌아간다」.

### 7.5 아이를 갖지 않는 이유, 갖는 이유
게임은 어느 쪽도 권하지 않는다. 다만 시스템이 양쪽을 다 정직하게 보여 준다.
| 갖지 않는 이유 | 갖는 이유 |
|----------------|-----------|
| 아이는 다시 태어나지 않는다. 지금 회차가 마지막이 아니라면, 언젠가 지워진다 | 찬가는 한 회차 안에서 이뤄야 한다. 그 회차는 수십 년이다. 수십 년을 살면서 아무도 곁에 두지 않을 수는 없다 |
| 아이는 인질이 되고, 약점이 된다 | 인간 가문은 찬가 7단계의 한 모습이다 (§8.3) |
| 아이가 있는 회차에서는 위험한 길을 못 간다 | 그래서 그 회차는 다른 이야기가 된다 |

## 8. 가문 — 이름 없는 자들의 이름

인간은 성(姓)을 가질 수 없다. 그래서 인간 가문은 **비밀**이다.

### 8.1 가문 만들기
| 요소 | 내용 |
|------|------|
| **비밀 가문 이름** | 플레이어가 짓는다. 가족끼리만 부른다 |
| **표식** | 옷 안쪽 자수, 매듭, 손목 실 — 가문원끼리 알아보는 표식 |
| **가훈** | 한 문장 |
| **가보** | 가문의 물건 (시대를 건너는 가보의 메아리와 연결 — 03 §4.2) |
| **가문 금고** | 숨겨둔 재산 (09 문서 가문 영역) |
| **가문원** | 혈연 + 입양 + 맹세로 들어온 사람 |

### 8.2 가문의 수치
| 수치 | 의미 |
|------|------|
| 결속 | 가문원끼리의 신뢰 (배신·분열 확률) |
| 명성 | 아는 사람들 사이의 평판 (10 문서의 '집단'으로 취급) |
| 재산 | 숨긴 재화·영역 |
| 기억 | 가문의 구전 역사 길이 — 길수록 사기·정체성 보너스 |

### 8.3 가문은 회차 안에서만 이어진다
- 가문은 **회차의 것**이다. 회귀하면 가문원은 서로를 모르는 사람들로, 금고는 비어 있던 땅으로, 가훈은 아무도 들어 본 적 없는 문장으로 돌아간다.
- 주인공은 가문 이름과 표식과 가훈을 **기억한다.** 다음 회차에 같은 이름으로 다시 세울 수 있다. 처음 듣는 사람들이 그 가훈을 처음처럼 따라 말한다. 가문의 '기억' 수치는 0에서 다시 시작한다 — 가문의 역사는 주인공 한 사람의 머릿속에만 있다.
- **한 회차 안에서는 대를 잇는다.** 긴 회차(수십 년)에서 주인공은 자식과 손주를 보고, 가문원이 가문원을 낳는다. 주인공이 늙어 죽으면 — 회귀한다. 손주까지 함께 사라진다.
- 가문이 커지면 인간의 영역(09 문서)과 겹치고, **인간 가문들이 모여 인간 왕국의 귀족이 되는** 것이 찬가 7단계의 한 모습이다. 그 왕국도 그 회차 안에서 세워져야 한다.
- 「마지막 회차」를 선언한 회차의 가문만이 주인공보다 오래 산다. 시대 연대기의 에필로그는 그 가문의 몇 대를 보여 준다 (03 §4.6).

### 8.4 가문 내부의 이야기
- 상속 다툼 (누가 가문 금고를 지키나 — 주인공이 늙었을 때, 또는 주인공이 오래 자리를 비웠을 때)
- 배신한 가문원 (목줄단에 밀고). 주인공은 지난 회차에 누가 밀고했는지 **알 수도 있다.** 이번에도 그럴지는 〔표류〕다. 미리 내치면, 그 사람은 아직 하지 않은 배신의 대가를 받는다
- 가문원끼리의 연애와 원한
- 가문 이름이 적에게 알려짐 → 가문 전체가 표적

## 10. 구현 메모

```ts
interface Romance {
  a: NpcId | 'player'; b: NpcId; loop: number;   // 회차에 속한다
  stage: 'stranger'|'acquainted'|'close'|'attracted'|'lovers'|'sworn';
  secret: boolean;                 // 들키면 안 되는 관계인가 (금지된 사랑)
  history: EventId[];              // 함께한 사건
  knowsRegressor?: boolean;        // 진실을 말했고, 믿었다 (이 회차만)
}
interface Household {
  id: string; loop: number; secretName?: string; sigil?: string; motto?: string;
  members: { id: NpcId | 'player'; role: 'head'|'spouse'|'child'|'adopted'|'sworn' }[];
  heirlooms: ItemId[]; cache?: DomainId;
  cohesion: number; renown: number; memory: number;
}
// 영혼 쪽 (03 Soul에 포함) — 회귀해도 남는다
interface BondMemory {
  npc: NpcId; deepestStage: Romance['stage']; loopsTogether: number; timesFirstMet: number;
  vows: number;                    // 끈혼례를 올린 회차 수
  knownTastes: Tag[]; knownSecrets: FactId[]; attraction: Observed<AttractionRule>[];
  children: { loop: number; name: string; bornAt: GameDate; lostAt: GameDate }[];  // 연대기 전용. 다시 생성하지 않는다
}
// 임신: Pregnancy { carrier, other, conceivedAt, mixed: Race | null } → 매일 건강 판정, 출산 이벤트
// 자녀: 새 NPC 생성 (08 문서 등급 A), 부모 데이터에서 유전 계산, 양육 사건이 성향을 이동
// 자녀 생성 시드 = hash(loopSeed, conceivedAt, parents) — BondMemory.children의 이전 아이와 외형·성향이 겹치면 다시 굴린다
```
- 회귀 시: 모든 `Romance`·`Household`는 회차 기록에 보관되고 세계에서 지워진다. `BondMemory`만 영혼에 남는다.
