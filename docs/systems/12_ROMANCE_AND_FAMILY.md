# 12. 연애·결혼·가족·가문

> 질문: "다른 NPC와 연애, 데이트, 결혼, 임신, 가족, 가문도 만들 수 있게? 모든 시스템과 조화롭게."
> 답: 가능하다. 그리고 이 게임에서 가족은 단순한 부가 콘텐츠가 아니라 **핵심 시스템의 교차점**이다.
> 주인공의 영혼은 인연을 따라 옮겨간다 — **사랑하는 사람과 자녀는 다음 생애의 몸이 될 수 있는 사람들**이다.
> 동시에 그들은 주인공의 가장 큰 약점이다.

---

## 1. 원칙

| 원칙 | 내용 |
|------|------|
| **선택 사항** | 연애를 하지 않아도 게임의 모든 길이 열려 있다 |
| **상대도 사람이다** | NPC는 자신의 성향·목표·과거로 주인공을 판단한다. 호감을 "모으는" 게임이 아니다 |
| **성별 무관** | 관계는 성별과 무관하게 가능하다. 임신은 생물학적으로 가능한 조합에서만, 가족은 입양·제자·맹세로도 만들 수 있다 |
| **성인만** | 연애 대상은 성인 NPC뿐이다 |
| **표현 수위** | 친밀한 장면은 암시와 장면 전환으로 처리한다 (모바일 심의, WORLD_BIBLE §0.2) |
| **강요 없음** | 주인과 노예, 감독관과 노예처럼 거절할 수 없는 관계에서의 연애는 플레이어가 강요하는 형태로 만들지 않는다. 그런 착취는 세계의 악으로만 존재한다 |
| **그림다크의 무게** | 사랑은 이 세계에서 사치이고, 위험이고, 저항이다 |

---

## 2. 관계의 단계

08 문서의 관계 데이터(호감·신뢰·존경)를 그대로 쓰고, 연애는 그 위의 **단계**로 표현한다.

```
낯선 사람 → 아는 사이 → 친밀 → 끌림 → 연인 → 맹세(혼인) → 가족
                                  ↘ 짝사랑 / 거절 / 이별 / 배신 / 사별
```

| 단계 | 조건 (예) | 열리는 것 |
|------|-----------|-----------|
| 친밀 | 호감 40 + 신뢰 30 + 함께한 사건 3회 | 개인적인 대화 주제, 비밀 한 조각 |
| 끌림 | 호감 60 + **궁합** 기준 충족 + 한쪽의 고백 | 데이트 장면, 질투 반응 |
| 연인 | 서로 끌림 + 관계 확인 장면 | 함께 살기, 영혼 계승 대상 자격(배우자·연인) |
| 맹세 | 신뢰 70 + 맹세 장면 | 가족·가문 등록, 공동 재산, 임신 가능성 |

### 2.1 궁합 — 무엇이 끌리게 하는가
각 NPC는 **끌림 기준**을 가진다 (성향 축·행동 기록 기반).

| NPC의 기준 (예) | 끌리는 것 | 식는 것 |
|-----------------|-----------|---------|
| 시그리드 (북방 탈주자) | 용기, 동족을 지키는 행동, 약속을 지킴 | 겁, 탈주자를 버림 |
| 사라 (성채 하녀) | 다정함, 글을 읽어주는 것, 위험에서 구해줌 | 폭력, 거짓말 |
| 하겐 (밀수꾼) | 재치, 대담함, 이익 | 설교 |
| 오웬 레이번 (용인) | 반항, 용기 — 그리고 금기 그 자체 | 순종 |

- 같은 행동이 어떤 NPC에게는 매력, 다른 NPC에게는 거부감이 된다 → 연애도 **세계 시뮬레이션의 일부**.
- NPC끼리도 연애한다 (08 문서 §7.3). 주인공이 끌리는 사람이 이미 다른 사람을 사랑하고 있을 수 있다.

## 3. 데이트 — 위험한 세계의 작은 시간

데이트는 장소·계절·위험에 따라 생성되는 **짧은 장면(스토리렛)** 이다.

| 장면 (예) | 장소 | 조건 | 위험 |
|-----------|------|------|------|
| 밤에 여울강 둑에서 별 보기 | 회색여울 | 통금 이후 | 감독관 순찰 |
| 몰래 글자 가르쳐주기 | 브람의 지하실 | 읽고쓰기 스킬 | 발각 = 둘 다 사형 |
| 수확제 뒤의 춤 | 마을 광장 | 수확월 | 낮음 |
| 옛 돌 고리에서 금지된 맹세 | 옛 돌 고리 | 연인 단계 | 금지 구역 |
| 원형장 경기 후 상처 치료 | 피의 원형장 | 투사 경로 | 다음 경기 |
| 세렌 시장에서 선물 고르기 | 세렌 | 계약민·돈 | 소매치기, 들킨 돈 |

- 선물은 아이템 시스템과 연결: NPC마다 좋아하는 태그가 있다 (`책`, `악기`, `무기`, `약초`, `단 음식`).
- 데이트도 시간을 쓰고(03 문서의 생활비·시간 압박), 들키면 평판·관계에 영향을 준다.

## 4. 금지된 사랑 — 신분과 종족

| 관계 | 세계의 반응 | 이야기 |
|------|-------------|--------|
| 인간 ↔ 인간 (같은 주인) | 결혼은 주인 허가 필요. 허가 없이 = 처벌, 강제 이별(매각) | 비밀 혼례, 함께 도망 |
| 인간 ↔ 인간 (다른 주인) | 둘 중 하나가 팔려가야 한다 | 몸값 모으기, 탈주 |
| 인간 ↔ 용인 | **금기.** 들키면 인간 쪽이 죽고, 용인은 가문에서 쫓겨난다 | 오웬 ↔ 사라, 카스파르의 어머니 엘레나 |
| 인간 ↔ 엘다르 | 엘다르 존속파는 혼혈을 비밀리에 원한다 → 사랑인가 실험인가 | 반엘다르 아이 |
| 인간 ↔ 드라우르·녹테른(세실파) | 양쪽 사회 모두에서 배척 | 같은 처지의 동맹이 사랑이 된다 |
| 인간 ↔ 그롬 (투사) | 그롬은 "강한 자"를 존중한다 — 의외로 가능 | 원형장의 연인 |

- 금지된 사랑은 **평판(10 문서)** 에 강하게 반영된다: 같은 연애가 인간들에게는 노래가 되고 귀족들에게는 모욕이 된다.

---

## 5. 혼인 — 인간에게 결혼은 불법이다

- 노예 인간의 혼인은 **주인의 허가**가 있어야 하고, 주인은 언제든 부부를 갈라 팔 수 있다.
- 그래서 인간들은 몰래 **끈혼례**(서로의 손목에 실을 묶는 비밀 의식)를 올린다. 증인은 같은 처지의 노예들.
- 순종의 빛 사제가 축복하면 "합법"에 가까워지지만, 주인 허가 없이는 의미가 없다.
- 세렌 계약민은 혼인이 자유롭다. 두르강 계약 광부는 계약에 따라.
- **정략 혼인**: 주인공이 힘을 가지면, 다른 인간 공동체나 세력(드라우르, 세실파 녹테른, 카스파르 측근 가문)과 **혼인 동맹**을 맺을 수 있다 → 11 문서의 '후견'·'인정' 지렛대.

## 6. 임신과 출산

| 항목 | 규칙 |
|------|------|
| 가능 조합 | 인간끼리 / 인간과 일부 종족(용인·엘다르·나가 — 낮은 확률, 혼혈아) |
| 기간 | 인간 9개월 (게임 시간). 혼혈은 다르다 (반용 12개월, 반엘다르 14개월) |
| 임신 중 | 체력·민첩 판정 페널티 단계적 증가, 노동 할당량은 그대로 (주인은 봐주지 않는다) |
| 출산 | 체질·응급처치·치료사·위생 판정. **그림다크: 출산은 위험하다** (치료사 없는 노예 출산 사망률 높음) |
| 노예의 아이 | 법적으로 **주인의 재산**이다. 아이를 지키는 것 자체가 이야기가 된다 |
| 혼혈아 | 반용 → 용족이 처단하려 한다 / 반엘다르 → 존속파가 데려가려 한다 |

> 주인공이 임신하는 쪽인지, 상대가 임신하는지는 조합에 따라 다르다. 어느 쪽이든 가족을 지키는 부담은 함께 진다.

## 7. 자녀 — 사랑, 약점, 그리고 다음 몸

### 7.1 유전
| 요소 | 규칙 |
|------|------|
| 외형 | 부모 특징의 조합 + 무작위 |
| 성향 | 부모 성향 평균 ± 무작위 → **양육 사건**에 따라 자라면서 바뀐다 |
| 능력치 | 부모 평균 ± 2 |
| 혈통 특질 | 부모의 **혈통** 특질은 50% 확률로 유전 (이식 특질은 유전되지 않는다 — 06 문서) |
| 잔향 | **유전되지 않는다.** 아이는 평범한 인간이다. 단 하나의 예외: 주인공이 죽어 영혼이 그 아이에게 옮겨갈 때 |

### 7.2 양육
- 자녀는 시간이 흐르며 자란다 (1년 = 실제 3~6시간 플레이, 03 문서).
- 주인공이 가르친 스킬은 자녀의 스킬이 된다 → **자녀는 제자이기도 하다.**
- 주인공의 행동은 자녀의 성향에 영향을 준다 (보고 배운다): 주인공이 잔혹하면 자녀도 잔혹해질 수 있다.
- 자녀는 자기 목표와 관계를 가진 **독립된 NPC**다. 주인공의 뜻대로만 자라지 않는다.

### 7.3 자녀와 영혼 계승 — 이 게임만의 이야기
- 주인공이 죽으면 영혼은 **12세 이상의 자녀**에게 옮겨갈 수 있다 (03 문서).
- 그러면 플레이어는 **자기 아이로서** 깨어난다. 아이의 기억과 성격은 사라지지 않고 잔향과 섞인다.
- 남은 배우자는 아이에게서 죽은 연인의 눈빛을 본다. 알아챌 수도, 모를 수도 있다 — 이것은 깊은 관계 이벤트가 된다.
- 반대로 **자녀를 위해** 영혼을 다른 곳(제자·동료)으로 보내는 선택도 있다: "이 아이는 이 아이의 삶을 살게 하자."

### 7.4 가족은 약점이다
- 적대 세력은 가족을 **인질**로 잡는다 (11 문서 §4).
- 주인공의 정체가 드러나면 가족이 먼저 끌려간다.
- 위협도가 높을수록 가족을 숨기는 것이 영역 관리(09 문서)의 일부가 된다.

## 8. 가문 — 이름 없는 자들의 이름

인간은 성(姓)을 가질 수 없다. 그래서 인간 가문은 **비밀**이다.

### 8.1 가문 만들기
| 요소 | 내용 |
|------|------|
| **비밀 가문 이름** | 플레이어가 짓는다. 가족끼리만 부른다 |
| **표식** | 옷 안쪽 자수, 매듭, 손목 실 — 가문원끼리 알아보는 표식 |
| **가훈** | 한 문장 |
| **가보** | 가문 대대로 내려오는 물건 (가보의 메아리와 연결 — 03 문서) |
| **가문 금고** | 숨겨둔 재산 (09 문서 개인·가문 영역) |
| **가문원** | 혈연 + 입양 + 맹세로 들어온 사람 |

### 8.2 가문의 수치
| 수치 | 의미 |
|------|------|
| 결속 | 가문원끼리의 신뢰 (배신·분열 확률) |
| 명성 | 아는 사람들 사이의 평판 (10 문서의 '집단'으로 취급) |
| 재산 | 숨긴 재화·영역 |
| 기억 | 가문의 구전 역사 길이 — 길수록 사기·정체성 보너스 |

### 8.3 가문은 생애를 넘어 이어진다
- 영혼이 자녀에게 옮겨가면 가문은 그대로 이어진다.
- 영혼이 가문 밖으로(동료·아기) 옮겨가도 가문은 **NPC 가문으로 계속 살아간다** — 다음 생애에 그 가문의 후손을 만나게 된다.
  ("우리 증조할머니가 이걸 남기셨어요. 언젠가 '돌아오는 이'에게 주라고.")
- 가문이 커지면 인간의 영역(09 문서)과 겹치고, **인간 가문들이 모여 인간 왕국의 귀족이 되는** 것이 찬가 7단계의 한 모습이다.

### 8.4 가문 내부의 이야기
- 상속 다툼 (누가 가문 금고를 지키나)
- 배신한 가문원 (목줄단에 밀고)
- 가문원끼리의 연애와 원한
- 가문 이름이 적에게 알려짐 → 가문 전체가 표적

## 9. 다른 시스템과의 연결 요약

| 시스템 | 연애·가족이 주는 것 | 연애·가족이 받는 것 |
|--------|---------------------|---------------------|
| 영혼 계승 (03) | 다음 몸의 후보 (배우자·자녀) | — |
| 재능 (06) | 혈통 특질 유전 | — |
| 대사 (05) | 연인·가족 전용 대사, 기억 반응 | — |
| 관계망 (08) | 혈연·혼인 데이터, 가계도 자동 생성 | NPC끼리의 연애·질투 |
| 영역 (09) | 가족이 관리자가 될 수 있다 | 가족을 숨길 곳 |
| 평판 (10) | 혼인 동맹, 금지된 사랑의 노래 | 정체가 드러나면 가족이 표적 |
| 음모 (11) | 정략 혼인 = 인정의 지렛대 | 인질, 협박 |
| 찬가 (WORLD_BIBLE §11) | 인간 가문이 모여 인간 귀족이 된다 | — |

## 10. 구현 메모

```ts
interface Romance {
  a: NpcId | 'player'; b: NpcId;
  stage: 'stranger'|'acquainted'|'close'|'attracted'|'lovers'|'sworn';
  secret: boolean;                 // 들키면 안 되는 관계인가 (금지된 사랑)
  history: EventId[];              // 함께한 사건
}
interface Household {
  id: string; secretName?: string; sigil?: string; motto?: string;
  members: { id: NpcId | 'player'; role: 'head'|'spouse'|'child'|'adopted'|'sworn' }[];
  heirlooms: ItemId[]; cache?: DomainId;
  cohesion: number; renown: number; memory: number;
}
// 임신: Pregnancy { carrier, other, conceivedAt, mixed: Race | null } → 매일 건강 판정, 출산 이벤트
// 자녀: 새 NPC 생성 (08 문서 등급 A), 부모 데이터에서 유전 계산, 양육 사건이 성향을 이동
```
