# 07. 지도·현재 위치·전장의 안개

> 원칙: **지도는 '정보'다. 그리고 정보는 이 세계에서 가장 비싼 자원이다.**
> 노예는 지도를 가질 수 없다. 플레이어가 아는 세계는 처음엔 마을 하나와 소문 몇 개뿐이다.

---

## 1. 지도 계층 (4단계 줌)

| 단계 | 범위 | 노드 수 (1.0 목표) | 표시 내용 | 화면 전환 |
|------|------|--------------------|-----------|-----------|
| **대륙** | 에오르달 전체 | 16 지역 + 주요 도시 ~50 | 지역 경계, 큰 길, 강, 산맥, 황무지 | 핀치 아웃 |
| **지역** | 한 지역 | 정착지·장소 10~30 | 마을, 성, 숲, 길, 위험 지대 | 기본 화면 |
| **정착지** | 마을·도시 하나 | 건물·구역 10~60 | 건물, 골목, 성벽, 문 | 마을 탭 |
| **내부** | 건물·던전 | 방 5~30 | 방, 문, 계단, 숨겨진 통로 | 건물 진입 시 |

- 모든 지도는 같은 **노드-엣지 그래프** 데이터에서 그린다 (`content/base/world/map.json`).
- 노드 = 장소, 엣지 = 길(이동 시간·위험·통행 조건).
- 선택지 "어디로 가지?" 는 지도에서 노드를 탭하는 것과 같다 → **텍스트 선택지와 지도가 하나의 시스템.**

---

## 2. 전장의 안개 — 5단계 인지 상태

각 노드·엣지·지역은 플레이어 기준으로 **인지 단계**를 가진다.

| 단계 | 이름 | 화면 표현 | 얻는 방법 |
|------|------|-----------|-----------|
| 0 | **미지** | 짙은 회색 안개. 아무것도 보이지 않음 | — |
| 1 | **소문** | 안개 속 흐릿한 실루엣 + "?" 아이콘. 위치가 **틀릴 수 있음** (±오차) | NPC 대화, 술집 소문, 노래 |
| 2 | **지도로 앎** | 연한 안개, 윤곽선과 이름. 지도 작성 시점의 정보 (**낡을 수 있음**) | 지도 아이템, 지도 구매·훔치기, 길 안내 받기 |
| 3 | **가 봄** | 안개 걷힘, 선명한 색. 마지막 방문 시점의 상태 | 직접 방문 |
| 4 | **현재 위치 / 시야 안** | 밝음 + 실시간 정보 (날씨, 보이는 사람) | 지금 그곳에 있음, 혹은 높은 곳에서 보임 |

### 2.1 정보는 낡는다
- 방문했던 곳도 시간이 지나면 **"마지막으로 본 모습"** 으로 표시된다.
  - 예: "회색여울 — 마지막 방문 47일 전" (그 사이 불탔을 수도 있다)
- 소문으로 들은 곳은 위치 오차가 있다: 지도에 점선 원으로 "이 근처 어딘가".
- 틀린 지도도 존재한다: 위조 지도, 낡은 제국 시대 지도 (대붕괴 이전 → 지금은 황무지).

### 2.2 시야 (Line of Sight)
- 높은 곳(언덕, 탑, 나무)에 오르면 주변 노드가 **단계 4(시야)** 가 된다 → "높은 곳에 오른다" 선택지의 가치.
- 감각 능력치·엘다르의 눈·아에리의 깃뼈가 시야 범위에 보너스.
- 밤·안개·비·재 폭풍은 시야를 줄인다.

## 3. 지도라는 아이템

| 지도 | 정보 범위 | 구하는 법 | 인간에게 |
|------|-----------|-----------|----------|
| 마을 사람의 머릿속 지도 | 반경 하루 거리 | 대화 (관계 필요) | 합법 (말로만) |
| 손으로 그린 약도 | 특정 경로 하나 | 이름 없는 자들, 밀수꾼 | **불법** (그림도 '글'로 취급) |
| 용제국 군용 지도 | 지역 전체 + 요새 | 훔치기, 용인 장교 | 소지 시 사형 |
| 나가 해도 | 해안선, 항구, 해류 | 세렌 구매 (계약민 허용) | 세렌에서만 합법 |
| 두르강 갱도도 | 카즈둠 내부 | 계약 | 계약 범위 내 |
| 엘다르 별지도 | 대륙 전체 (아름답고 정확) | 실바렌에서 훔치기 | 사형 |
| 제국 시대 고지도 | 대붕괴 이전의 대륙 | 유적 | 대부분 틀렸지만, 사라진 길과 비밀이 있다 |
| **잿빛 실 지도** | 탈주 경로의 은신처 | 이름 없는 자들의 신뢰 | 발각되면 연결된 모든 사람이 죽는다 |

- **지도 그리기**: 읽고쓰기(또는 '그림' 하위 스킬) + 학식 판정으로 플레이어가 직접 지도를 만들 수 있다.
  직접 그린 지도는 아이템이 되어 팔거나 남길 수 있다. 종이는 회귀하면 사라지지만 **그린 내용은 기억 지도로 남는다** — 다음 회차의 플레이어 지도에 흐린 선으로 (03 문서 남는 것: 기억).
- 지도를 소지한 채 수색당하면 → 큰 위기 (아이템 시스템의 '숨김 칸'이 중요).

## 4. 현재 위치 매핑

```
┌──────────────────────────────────────┐
│ ▼ 회색여울 변경            ☁ 비 · 저녁 7시 │
│                                        │
│   ░░░░░░░░░░░ 까마귀 문 ? ░░░░░░░       │  ← 소문으로만 앎
│   ░░░░░        ┊                       │
│   굶주린 언덕 ◇ ┊                       │  ← 지도로 앎 (윤곽)
│          ╲     ┊                       │
│    레이번 성채 ■━━━━● 회색여울 마을 ◉     │  ← ◉ 현재 위치 (맥박 애니메이션)
│                  ╲                      │
│                   ◆ 옛 돌 고리           │  ← 가 봄 (마지막 방문 12일 전)
│   ░░ 오물 습지 ░░░░░░░░░░░░░░           │
│                                        │
│ [대륙] [지역] [마을]       📍 일지 · 🔍    │
└──────────────────────────────────────┘
```

- **현재 위치**: 맥박치는 표식 + 위치 이름 + 날씨·시간.
- **노드 탭**: 정보 카드 (아는 것만) + "여기로 간다" 버튼 → 경로·소요 시간·위험·통행 조건 표시.
  - 예: "레이번 성채까지 0.5시간 · ⚠ 통행증 필요 · 경비 2명 (마지막 확인)"
- **이동 경로 미리보기**: 여러 노드를 거치는 길은 경로선 + 총 시간 + 가장 위험한 구간 강조.
- **플레이어 메모**: 노드에 직접 메모 (예: "하겐 믿지 마"). 일지와 연동.
- **이동 중**: 지도 위로 진행 표시가 움직이고, 여정 스토리렛이 발생하면 해당 지점에서 멈춘다.

## 5. 지도 아트 방향

| 방식 | 장점 | 단점 | 판단 |
|------|------|------|------|
| **데이터 기반 SVG + 손그림 질감** | 노드 데이터에서 자동 생성, 안개 처리 쉬움, 해상도 무관, 용량 작음 | 아트 질감 연출 필요 | **추천 (1단계)** |
| 일러스트 배경 + 노드 오버레이 | 가장 아름다움 | 지역마다 그림 필요, 데이터와 위치 맞춤 수작업 | 2단계 (대륙·주요 지역만) |
| 절차적 생성 지도 | 시대마다 새 세계 | 개발 난이도 높음 | 3단계 (새 시대 시드용) |

- 톤: 양피지·잉크 질감, 그림다크 색감 (회갈색·잿빛·핏빛 강조). 안개는 **재(灰)가 흩날리는 질감**.
- 미지 영역에 옛 지도처럼 경고문: *"여기서부터 무혈자의 길은 없다"*

## 6. 구현 메모

```ts
interface MapNode {
  id: string; name: string; region: number;
  x: number; y: number;              // 대륙 좌표 (1000×750)
  type: 'city'|'town'|'village'|'fort'|'ruin'|'wild'|'secret'|...;
  parent?: string;                   // 정착지 → 지역, 건물 → 정착지
}
interface MapEdge {
  from: string; to: string;
  hours: number; road: 'imperial'|'road'|'trail'|'river'|'sea'|'secret';
  danger: 1|2|3|4|5;
  requires?: Requirement;            // 통행증, 계절, 지식
}
interface PlayerMapKnowledge {
  nodes: Record<string, { level: 0|1|2|3|4; seenAt?: GameTime; source?: 'rumor'|'map'|'visit'; offset?: [number, number] }>;
  edges: Record<string, { level: 0|1|2|3 }>;
  notes: Record<string, string>;
}
```

- 안개 렌더링: SVG 마스크 — 인지 단계별로 노드 주변에 반경이 다른 '구멍'을 뚫는다.
- 경로 탐색: 플레이어가 **아는 엣지만** 사용하는 다익스트라 (모르는 지름길은 경로에 안 나온다).
- 프로토타입: `prototypes/map/index.html` (대륙 지도 + 안개 + 현재 위치 + 이동 데모).
