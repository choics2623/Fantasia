# 17. 사냥꾼이 기억한다 — 생애를 넘어 쫓아오는 숙적

> 질문: "주인공은 몸을 바꿔 돌아온다. 그렇다면 적은? 죽을 때마다 모든 원수가 리셋되면, 죽음은 도망이 된다."
> 답: **적도 기억한다.** 당신을 놓친 사냥꾼, 당신에게 코가 녹은 바르그, 당신이 아이를 판 어머니는 당신이 죽어도 끝나지 않는다.
> 그들은 다음 몸의 당신에게서 **익숙한 무언가**를 찾는다 — 냄새, 버릇, 말투, 알 리 없는 지식. 그리고 당신이 그들에게 가르친 것을 배운다.
> 이 문서는 그 장치를 다룬다. 숙적은 새로운 종류의 NPC가 아니다. **이미 있는 인물 위에 얹히는 기억과 집착의 층**이다.

---

## 0. 핵심 결정 세 가지

| # | 결정 | 이유 |
|---|------|------|
| ① | **숙적은 '덧씌우기(overlay)'다.** 모든 이름 있는 NPC(B등급 이상)가 조건을 채우면 숙적이 된다. 고정된 '보스 명단'은 없다 | 00 문서 규칙 ④(특별 규칙 금지). 숙적은 08의 원한 엣지 + 이 문서의 프로필로만 표현된다 |
| ② | **생애를 넘는 알아봄은 '흔적(trace)' 누적으로만 일어난다.** 숙적에게 초자연적 감각은 없다. 그가 붙잡는 것은 플레이어가 실제로 남긴 것 — 영혼에 붙은 버릇·말투·지식·잿빛 고리·젖은 재 냄새 — 뿐이다 | 특별한 것은 주인공뿐이다(WORLD_BIBLE §1.3.1). 그리고 모든 의심은 **나중에 플레이어에게 설명 가능**해야 공정하다 |
| ③ | **동시에 사냥 중인 숙적은 최대 3, 한 생애의 주인공(스포트라이트)은 1.** 나머지는 '잠든 원한'으로 기다린다 | 섀도 오브 모르도르식 '숙적 폭주'를 막는다. 숙적이 흔하면 숙적이 아니다 |

## 1. 목표

### 1.1 이 장치가 해결하는 문제

| 문제 | 지금 상태 | 숙적이 하는 일 |
|------|-----------|----------------|
| **동기 부재** — 죽음이 리셋처럼 느껴진다 | 03 문서는 세계가 이어진다고 하지만, 플레이어가 "개인적으로" 느끼는 연속성은 약하다 | 지난 생애의 실패가 **얼굴을 가지고** 다음 생애에 걸어 들어온다. "그 놈이 아직 살아 있다"는 생애를 넘는 가장 강한 동기다 |
| **보이지 않는 시뮬레이션** | 10 문서의 대응 단계(바르그 사냥대·와이번 기사단)는 숫자다 | 대응 단계에 **이름 붙은 집행자**를 앉힌다. "2단계 사냥대"가 아니라 "반귀 그로드와 그의 코 넷"이 온다 |
| **시스템 과잉** | 평판·위협도·관계·사실이 따로 보인다 | 숙적 한 명이 이 모든 것을 한 사람의 행동으로 묶어 보여 준다 (원한=08, 칭호=10, 작전=11, 인질=12) |
| **초반 무력감** | 인간은 약하다. 이기지 못하는 싸움뿐이다 | **이기지 않아도 되는 승리**를 준다. 따돌리기, 모욕하기, 가르쳐 주기(그가 엉뚱한 교훈을 배우게 하기) — 약자가 강자의 기억에 흉터를 남기는 방식 |

### 1.3 설계 원칙

| 원칙 | 내용 |
|------|------|
| **약자가 남긴 흉터** | 숙적 대부분은 플레이어보다 강하다. 숙적이 되는 이유는 "졌다"가 아니라 "**놓쳤다·당했다·잃었다**"이다 |

  > *요한이 들은 소문 — "송곳니 회관에선 그로드를 '젖은 코'라고 부른대. 볼크가 그 자리에서 그로드 몫 수수료를 깎았다더라."*

### 2.2 장면 B — 「키트의 목줄」 (생애 1, 조우 ③ · 인질과 죽음)

- **숙적이 플레이어를 죽였다 (§3.10 '전설')**:
  - 그로드 공로 +30, 칭호 `'리사를 문 송곳니'`, 공포 −25, 집착 −20(만족). 그러나 믿음 0단계라 그로드에게 리사는 그냥 "죽은 계집"이다.
  - 리사의 시체에서 **어머니의 성표**를 가져간다 → 그로드의 장비에 `전리품:리사` 태그. 다음 생애의 영혼이 이 성표를 알아본다(15 문서의 리사 목소리 반응).
- **연대기 한 줄**: *"리사는 동생의 목줄을 풀어 주고, 그 값을 치렀다. 그녀를 문 송곳니는 그날부터 그녀의 성표를 허리에 찼다."*
- 영혼 이동: 리사와 신뢰 72인 **페인**(CHARACTERS R02-15 충성 아크 70 — "형(누나)이 죽으면 내가 이어서 한다"). 
- 그로드는 믿음 0단계라 '감시 대상'을 정하지 않는다(§3.7.5). 대신 **키트를 미끼로 남겨 둔다** — 탈주자 무리가 아이를 데리러 오는 습성을 이용하는 사냥꾼의 일상적 수법.

### 2.4 장면 D — 「먼저 먹는 개」 (생애 2, 조우 ⑤ · 짧게)

- 그로드: 흉터 **쉰 목소리**(위압 −5), 교훈 **음식 시험** — 이후 그의 음식은 목줄꾼 인간이 먼저 먹는다(독살 D +20).
- 반격 수: 그 목줄꾼은 **사람**이다. 매수하거나(흥정), 그의 가족을 이용하거나(13 문서), 지연독(약학 45+, 반나절 뒤 발현)으로 시험을 통과시키거나.

## 3. 규칙과 수치

### 3.1 숙적 생성 — 상처 사건

플레이어가 원인인 사건에서 **이름 있는 NPC(B등급 이상)가 살아남으면** 상처 점수를 계산한다.

| 상처 사건 | 기본값 | 예 |
|-----------|--------|-----|
| `escaped_hunt` 사냥감이 빠져나감 | 25 | 리사가 여울을 건넘 |
| `wounded` 다침 (부위 중상 이상) | 30 | 잿물에 코가 녹음 |
| `humiliated` 모욕당함 (자기 세력 목격자 앞) | 35 | 사냥대장이 자기 사냥개에게 물에서 건져짐 |
| `humiliation_before_superior` 상관 앞 실패 (가산) | +20 | 볼크가 보는 앞에서 놓침 |
| `failed_assassination` 플레이어의 암살·독살에서 살아남음 | 40 | 국솥의 바꽃 |
| `betrayed` 플레이어에게 배신당함 | 35 | 위장 동료였던 플레이어가 하겐을 함정에 넣음 |
| `kin_killed` 가족·무리·연인이 플레이어 손에 죽음 | 50 | 그로드의 코 둘이 국을 먹고 죽음 (무리 = 가족, 바르그) |
| `kin_sold` 가족이 플레이어에게 팔리거나 밀고됨 (13 문서) | 45 | 노예상 플레이어가 에길의 아이를 세렌에 판다 |
| `property_ruined` 생계·지위를 잃음 (강등, 매각, 영지 소실) | 30 | 플레이어가 노예 장부를 태워 헨릭이 처벌받음 |
| `lost_prize` 거의 손에 넣은 큰 보상을 놓침 | 20 | 이졸의 할당량 마감일, 징후자를 놓침 |

```
상처 점수 = 사건 기본값 합 (같은 장면 내 최대 2개)
          + 목격자 보정  (그 NPC의 세력·무리 목격자 1명당 +3, 최대 +15)
          + 성향 보정    (자비 ≤ −40: +5 / 용기 ≥ +40: +5 / 정직 ≥ +40: −5 — 정직한 자는 원한보다 규칙을 따른다)
```

| 조건 | 결과 |
|------|------|
| 상처 점수 ≥ 40 **이고** 원한(08) ≥ 60 **이고** 행동 능력이 있음* | **숙적 생성** — 사냥 슬롯이 비어 있으면 '사냥 중', 아니면 '잠든 원한' |
| 상처 점수 25~39 또는 원한 40~59 | **숙적 후보** — 같은 NPC와 다음 상처 사건이 나면 점수 합산 |
| 그 외 | 일반 원한 엣지만 남는다 (08) |

\* 행동 능력: 전투·추적 스킬 하나가 40 이상, **또는** 부하·정보원이 3명 이상, **또는** 세력 계급 2단계 이상, **또는** 상처 사건이 `kin_killed`/`kin_sold`(복수자는 약해도 숙적이 된다 — §3.12).

**슬롯 상한**

| 슬롯 | 상한 | 넘치면 |
|------|------|--------|
| 사냥 중 (활성) | **3** | 집착이 가장 낮은 숙적이 잠든 원한으로 내려간다 |
| 스포트라이트 (이번 생애의 주 숙적) | **1** | 18 문서(이야기 연출가)가 생애 시작 시와 숙적 생성 시 고른다. 조우 빈도 우선권 |
| 잠든 원한 | **8** | 가장 오래 접촉 없는 숙적이 '기록'으로 보관된다 (연대기에만 남고, 흔적을 보면 다시 깨어남 판정) |

### 3.2 숙적의 마음 — 네 개의 수치

| 수치 | 범위 | 오르는 때 | 내리는 때 |
|------|------|-----------|-----------|
| **원한** (08의 원한 엣지 값) | 0~100 | 상처 사건 (상처 점수만큼, 상한 100) | 시간 (계절당 −3, 최저 40), 사과·보상(드묾) |
| **집착** | 0~100 | 놓침 +10, 공개 모욕 +20, 치욕 칭호 1개당 +10, 플레이어가 또 돌아왔다는 확신 +10 | 플레이어를 죽임 −20 (믿음 3단계면 대신 +10 — "또 온다"), 접촉 없음 계절당 −5 |
| **공포** | 0~100 | 다침 +10~25 (부상 단계별), 동료 사망 +10, 플레이어의 진명 목격 +20 | 승리 −10, 계절당 −5 |
| **존경** | 0~100 | 플레이어가 약속을 지킴 +10, 1:1로 이김 +10, 그를 살려 줌 +15 | 비겁한 수(인질·독) −10 |

**행동 성향표** (세력 AI가 매주 고르는 '사냥꾼의 수' 가중치에 반영 — §3.9)

| 조건 | 성향 | 이렇게 움직인다 |
|------|------|-----------------|
| 집착 ≥ 70, 공포 < 40 | **사냥개** | 직접 쫓는다. 매복·추적 위주 |
| 집착 ≥ 60, 공포 ≥ 60 | **독사** | 직접 오지 않는다. 함정·인질·대리 사냥·밀고 — 가장 잔인해진다 |
| 공포 ≥ 80, 집착 < 40 | **꺾인 자** | 사냥을 멈춘다. 지렛대만 있으면 정보원이 된다 |
| 집착 < 30, 공포 < 30 | **잠듦** | 잠든 원한 슬롯으로. 흔적을 보면 깨어남 판정 (집착 + 의심/2 ≥ 40) |
| 존경 ≥ 60 | **정직한 적** (위 성향에 덧붙음) | 인질을 쓰지 않는다. 사냥 전에 알린다. 사냥꾼의 예(§3.10)의 전제 |

### 3.3 흉터와 칭호

**흉터** — 부상(01 §1.4)이 영구가 되면 흉터가 된다. 흉터는 외모 태그(10 §3.1)이자 대사 고리이자, 때로 수치다.

| 흉터 (예) | 원인 | 수치 효과 | 알아봄에 미치는 영향 |
|-----------|------|-----------|----------------------|
| 녹은 코 | 잿물·불 (얼굴) | 추적 −15 | 냄새 흔적 가중치 ×0.5 → 대신 버릇·변화 가중치 ×1.2 ("눈을 쓰기로 했다") |
| 쉰 목소리 | 독 | 위압 −5 | — |
| 외눈 | 화살·칼 | 궁술 −10, 감각 판정 −5 | 잿빛 고리 흔적 ×0.7 |
| 절름발이 | 다리 중상 | 추적 거리 진행 판정 −10 (§3.6) | — |
| 손가락 셋 | 손 중상 | 단검·손재주 −10 | — |
| 화상 얼굴 | 불 진명 | 공포 +10 영구 | 진명 목격 기억 → 시험 시 마법 관련 질문 |

- 흉터를 낸 것이 플레이어면 흉터에 `by: player` 와 그때의 **몸 이름**이 기록된다. 대사: *"이 코? 리사라는 계집이 줬지."*
- 숙적은 흉터 수만큼 **집착 하한**이 오른다 (흉터 1개당 하한 +10, 최대 40). 흉터는 잊지 못한다.

**칭호** — 10 문서 §4.1의 칭호 시스템을 숙적에게도 쓴다. 소문으로 생기고, 세력 안에서의 대우를 바꾼다.

| 종류 | 생기는 조건 | 예 | 효과 |
|------|-------------|----|------|
| 치욕 칭호 | 자기 세력 목격자 3+ 앞에서 실패·모욕 | '젖은 코', '물에서 건져진 대장', '계집에게 코를 판 송곳니' | 집착 +10, 공로 −10, 세력 내 시선 −10. 숙적은 이 칭호를 지우려 한다 — 플레이어의 몸을 공개적으로 잡거나 죽여야 지워진다 |
| 영광 칭호 | 플레이어(의 몸)를 잡거나 죽임, 소문 도달 | '리사를 문 송곳니', '두 번 문 자' | 공로 +10, 추종자 +1, **자만** 특성(§3.10 '전설') |
| 잔향 칭호 | 믿음 3단계를 세력이 알게 됨 | '돌아오는 이를 아는 사냥꾼' | 세력의 대응 단계 +1(10 §5), 탑·멜리산드가 접촉해 옴 |

### 3.4 교훈 — 숙적은 당신에게서 배운다

플레이어가 숙적을 **따돌리거나 이긴 결정적 선택**에는 전술 태그가 붙어 있다 (02 문서의 태그 방식). 숙적이 살아남으면 그 태그에 대한 **교훈**을 얻는다.

| 규칙 | 값 |
|------|-----|
| 교훈 획득 | 그 조우를 결정한 선택의 전술 태그 1개 (부분 성공 이상으로 플레이어가 빠져나갔을 때). 지능 7 이하는 획득 확률 50% |
| 교훈 상한 | 2 + 계급 단계 (0~3) → **최대 5**. 넘치면 가장 오래 안 쓰인 교훈을 잊는다 |
| 효과 | 해당 태그 선택지의 D +15 (또는 표에 적힌 2차 판정·비용) |
| 영속 | 교훈은 **숙적에게 붙는다** — 플레이어의 몸이 바뀌어도 남는다 |
| 반격 수 | 모든 교훈은 반격 수 1개 이상을 가진다. 반격 수는 교훈을 **알아야** 보인다 (사냥꾼 판에 교훈이 '목격' 또는 '소문'으로 있을 때) |
| 과적응 | 플레이어가 그 태그를 3번 연속 조우에서 쓰지 않으면, 숙적은 그 교훈에 계속 자원을 쓴다 (추종자 1명이 그 대비에 묶임) → 다른 수의 D −5 |

**교훈 표 (수직 슬라이스 12종)**

| # | 플레이어 전술 태그 | 숙적의 교훈 | 효과 | 반격 수 |
|---|--------------------|-------------|------|---------|
| 1 | `물건너기` (냄새 끊기) | **양안 매복** — 사냥개를 건너편에 먼저 보낸다 | 건너편에서 2차 은신 판정 D 40 | 상류·하류로 3리 이상 크게 돌기 (⏱ +4h), 또는 건너편 사냥개를 미끼로 먼저 꾀어 내기(`미끼`) |
| 2 | `독` (음식·물) | **음식 시험** — 목줄꾼이 먼저 먹는다, 물은 직접 뜬다 | 독살 D +20 | 지연독(약학 45+), 시식자 매수·포섭 |
| 3 | `냄새지우기` (늪 마녀 약·무두장) | **약 냄새를 쫓는다** — 지우는 냄새 자체가 표지 | 냄새 지우기 효과 반감 | 다른 강한 냄새(가축·그나르 시체)로 덮기, 여럿에게 같은 약을 바르게 해 흔적을 흩기 |
| 4 | `밤이동` | **밤에 몰고 낮에 쉰다** | 밤 은신 D +10 | 한낮 군중 속 이동(시장날·예배) |
| 5 | `미끼흔적` | **흔적을 둘로 나눠 쫓는다** | 미끼 효과 반감 | 갈라진 사냥조는 수가 절반 — 매복 판정 +10 |
| 6 | `기습` | **목줄꾼 선두** — 인간 사냥개를 앞세운다 | 첫 공격이 인간 목줄꾼에게 간다 | 목줄꾼에게 노예말로 말 걸기(화술), 또는 그대로 치기 (자비▼, 인간 시선 −) |
| 7 | `함정` | **막대로 땅을 찌르며 간다** | 함정 D +15, 대신 이 숙적의 추적 거리 진행 −5 | 함정 대신 그 느린 속도를 이용한 따돌리기 |
| 8 | `거짓말로빠짐` | **말을 듣지 않는다** | 협상·기만 선택지 D +20, '거래' 조우 가중치 0 | 증거(문서·목격자)를 들고 말하기 — 말이 아니라 사실이면 듣는다 |
| 9 | `군중숨기` | **혀를 군중에 심는다** (목줄단 정보원) | 군중 은신 D +15 | 군중을 흩는 소동(불, 도망친 가축), 혀 매수 |
| 10 | `불` | **젖은 망토와 물통** | 불 공격·불 지르기 D +15 | 불이 아닌 연기(질식), 비 오는 날 피하기 |
| 11 | `동료구출` | **동료부터 노린다** | 동료가 인질 대상 우선순위 1위 | 동료를 숨기거나, 일부러 동료가 아닌 척(관계 공개도 낮추기 — 08 `public: false`) |
| 12 | `은신처` (잿빛 실 거점 이용) | **은신처 망을 판다** (밀고자 매수) | 플레이어 영역 노출 +5/주 (09) | 은신처 이동, 가짜 은신처 흘리기 |

- 교훈은 **장면 안에서 보인다**: 양안 매복이 있으면 여울 장면 묘사에 *"건너편 갈대에서 무언가 숨을 고른다"* 같은 문장이 들어간다 (감각 D 30 이상이면 알아챔).
- 1.0에서는 30종으로 늘린다 (마법·진명, 변장, 위조 문서, 하늘(와이번 기사)용 교훈 등).

### 3.5 승진과 추종자

숙적은 자기 세력 안에서 오르내린다. **공로**(merit, 0~200)가 기준이다.

| 공로 변화 | 값 |
|-----------|-----|
| 플레이어의 동료·가족을 잡음 | +10 |
| 플레이어(의 몸)를 다치게 함 (중상) | +10 |
| 플레이어(의 몸)를 죽이거나 산 채로 잡음 | +30 (그 몸에 현상금이 있었으면 +10) |
| 믿음 3단계를 세력에 보고, 세력이 받아들임 | +40 |
| 치욕 칭호 | −10 |
| 공개 모욕 (§3.10) | −20 |
| 사냥 실패 (거리 4에서 놓침) | −5 |

**바르그 노예사냥 조합 사다리** (HOUSES §5.9)

| 계급 | 정원 | 승진 조건 | 자원 (숙적이 쓰는 것) |
|------|------|-----------|-----------------------|
| 목줄꾼 (인간·크릭) | 약 300 | — (인간은 여기가 끝. 예외: 공로 120 + 사냥대장의 총애 → '목줄 두목') | 추종자 0, 정보원 1, 거리 진행 +0 |
| 코 | 약 900 | 공로 0부터 | 추종자 0~1, 정보원 1, +5 |
| 송곳니 (분대장) | 12 | 공로 60 + **빈자리** (계절마다 15% 확률로 자연 공석, 또는 다른 송곳니 제거 — §3.11) | 추종자(코) 4~6, 정보원 3, +10, 사냥 드레이크 대여 |
| 사냥대장 | 1 | 공석 + 송곳니 중 최고 공로 + 후원자(아우락스파) 승인 | 추종자 12+, 정보원 10, +15, 와이번 정찰 요청(대응 4단계 지원), 맹약회의 발언권 |

다른 세력의 사다리 (1.0, 형식만):

| 세력 | 사다리 |
|------|--------|
| 잿빛 탑 '잿빛 눈' | 사냥개 계약 밀정(이졸) → 잿빛 눈 정원(12) → 대장(카르바) |
| 목줄단 | 혀 → 목줄 → 목줄장 → 수석 목줄장(에베르트) |
| 멜리산드 회수조 | 실험실 조수 → 회수조원 → 회수조장('운구꾼' 페트르) |
| 비늘기사단 (하스트란) | 견습 기사 → 기사 → 백인대장 → 부단장 |
| 순종의 빛 정화청 | 심문 보조 → 심문관 → 정화관 |

- **추종자**는 B등급 NPC로 즉석 생성된다 (08 §2 승격 규칙). 추종자 한 명 한 명이 플레이어가 돌려세우거나 죽일 수 있는 사람이고, **숙적의 후계자 후보**다(§3.10.1). 장면 D의 '먼저 먹는 개'가 그 예다.
- 숙적이 계급을 잃으면(강등) 자원도 잃지만 집착 +20 — **떠돌이 숙적**이 된다: 세력의 보호도 제약도 없다.

### 3.6 추적 거리 — 얼마나 가까이 왔나

| 거리 | 이름 | 의미 | 플레이어에게 보이는 것 (정보가 있을 때) |
|------|------|------|----------------------------------------|
| 0 | 잃음 | 어디 있는지 모른다 | — |
| 1 | 소문을 쫓음 | 다른 지역에서 소문을 모은다 | "그로드가 루멘에서 당신을 묻고 다닌다더라" |
| 2 | 지역 안 | 같은 지역. 1~2주 안에 마을까지 온다 | 사냥 야영지의 연기, 목줄꾼이 수탉에 나타남 |
| 3 | 마을 안 | 며칠 안에 마주친다 | 개 짖는 방향이 바뀐다, 혀가 따라붙는다 |
| 4 | 문 앞 | 1~3일 안에 조우 생성 (§3.9 쿨다운 우선) | 장면 상단 막대 ▮▮▮▮▯ |

**매주 진행 판정** (01 문서 로지스틱 공식)

```
S = 숙적 추적 스킬/2 + 집착/4 + 계급 보정(0/5/10/15) + 정보원 수 × 3
  + 흔적 보정 (지난 7일 플레이어가 남긴 '목격된 흔적' 사건 수 × 4, 최대 +20)
D = 25 + 플레이어 은신/3
  + 지역 이동 보정 (이번 주 다른 지역으로 이동 +15, 같은 지역 내 은신처 이동 +5)
  + 냄새 지우기 (바르그 숙적만, +20 — 교훈 #3이 있으면 +10)
  + 은신처 은폐 (09 영역 은폐도/4)
  + 정세 창 (11 §2.2, +10)
결과: 대성공 +2 · 성공 +1 · 부분 성공 +1 (단, 플레이어에게 '들킨 흔적' 경고) · 실패 0 · 대실패 −1 (가짜 흔적)
```

- 거리 2 이상에서 4주 연속 진행이 없으면 −1.
- **몸이 바뀌면** 모든 숙적의 거리가 0이 된다. 예외는 §3.7.5 '감시 대상'.

### 3.7 생애를 넘는 알아봄

#### 3.7.1 흔적 — 숙적이 붙잡는 것

흔적은 둘로 나뉜다. **몸의 흔적**은 몸이 죽으면 사라지고, **영혼의 흔적**은 다음 몸으로 따라온다.

| 흔적 | 층 | 기록 조건 | 드러나는 조건 | 가중치 (의심 +) |
|------|----|-----------|---------------|-----------------|
| 얼굴·흉터·걸음·목소리 | 몸 | 숙적이 그 몸을 봄 | 같은 몸일 때만 | (10 §3.1 외모 식별로 처리 — 같은 몸이면 의심이 아니라 그냥 "너") |
| **젖은 재 냄새** | 영혼 | 감각 16+ 수인족 숙적이, 플레이어가 잔향을 드러낸 직후(24h 내: 전생의 꿈 사용, 진명, 잔향의 눈 발현, 각성 장면) 가까이에서 맡음 | 각성도 1 이상인 몸 | 8 × 각성도 (최대 40). 지난 24h 잔향 사용 시 +15 |
| **버릇** (전술 태그) | 영혼 | 숙적 앞에서 같은 전술 태그를 쓴 횟수 = 강도 (최대 3) | 같은 태그의 선택을 숙적(또는 그의 추종자·정보원) 앞에서 고름 | 6 × 강도 |
| **말버릇** | 영혼 | 숙적에게 직접 한 고유한 말(도발·맹세·이름), 또는 같은 어조 선택지 3회 | 같은 말 선택지 / 같은 어조 | 같은 말 10 × 강도, 같은 어조 +3 |
| **지식 실수** | 영혼 | — (엔진이 판정: 그 사실의 `known_by`에 이전 몸은 있고 지금 몸의 삶에는 없는 경우) | 숙적 앞에서 그 지식을 말하거나 그 지식에 반응함 | 말함 20 · 행동으로 드러남 10 |
| **잿빛 고리** | 영혼 | 숙적이 고리를 본 적 있음 (렌즈 또는 통찰 60+) | 각성도 3 이상 상시, 또는 잔향 사용 24h 내 | 25 (렌즈 소지 시 ×1.5) |
| **목소리 새어 나옴** (15) | 영혼 | — | 전생 목소리가 입을 빼앗음 (15 문서의 '새어 나옴' 판정 실패) — 그 전생만 할 말을 숙적 앞에서 | 30 |
| **변화 감지** | 몸 쪽에서 | 숙적이 **지금 몸의 각성 전 모습**을 앎 (08 관계 있음) | 이전의 그 사람답지 않은 선택 (성향 차이 40+ 방향의 선택, 이전에 없던 관계 행동) | 5 × 횟수 (최대 30) |

- **각성 전의 몸에는 영혼 흔적이 없다.** 장면 E의 다섯 살 아이처럼, 잔향이 깨어나기 전에는 아무도 알아볼 수 없다.
- 젖은 재 냄새는 볼크의 첫 대사(CHARACTERS R02-07 "너한테서 젖은 재와 은화 냄새가 나는구나")를 잔향의 냄새로 정식화한 것이다. **평범한 인간에게는 없는 냄새**이므로, 이것이 '특별한 것은 주인공뿐'과 충돌하지 않는다 — 냄새를 맡는 쪽은 그저 좋은 코일 뿐이다.

#### 3.7.2 의심 — 몸마다 따로 쌓인다

`의심[숙적][지금 몸]` 0~100. 조우·관찰마다 흔적 가중치를 더한다. 접촉이 없으면 주당 −5.

| 의심 | 구간 | 숙적이 하는 일 |
|------|------|----------------|
| 0~24 | 모름 | 아무것도 |
| 25~49 | **익숙함** | 쳐다본다. 정보원에게 이 사람을 지켜보라 한다(거리 최소 2). '시험' 조우 가중치 +20 |
| 50~74 | **의심** | 시험한다. 이전 몸의 가족·물건으로 반응을 본다(장면 C). 감시 거리 최소 3 |
| 75~99 | **확신 근접** | 행동한다: 직접 사냥 / 인질 / 세력 보고 여부 결정(§3.7.6) |
| 100 | **알아봤다** | 이 몸을 이전 몸들과 연결한다(`linkedBodies`). 10 문서의 정체 연결과 같은 처리 — 이 숙적에게만은 '돌아오는 이'가 공개된 것과 같다 |

#### 3.7.3 변화 감지 — 몸을 알던 사람이 알아채는 것

03 문서 §4.1: "이전 몸과 가까운 사람에게 옮겨갈수록 의심을 받는다." 숙적이 지금 몸을 원래 알았다면(장면 F의 그로드), 영혼 흔적과 **별도로** 변화를 본다. 숙적이 아닌 NPC의 변화 감지는 잔향 징후(03 §4.3)로 처리하고, 숙적의 것만 이 문서의 의심에 들어간다.

#### 3.7.4 시험 — 숙적의 대항 판정

의심 25 이상에서 '시험' 조우가 생기면:

```
숙적 S = 통찰 (냄새 시험이면 추적·사냥) + 의심/4 + 흔적 보정(이번 시험에 쓰인 흔적의 가중치/2)
플레이어 D = 기만 + 의지보정 + 패턴 깨기 누적 보너스(§3.8) + 상황(가면·변장 02)
플레이어 성공: 의심 −15, 숙적 공포 +5 ("헛것을 봤나") / 대성공: −25, 이 숙적의 다음 시험까지 30일
플레이어 실패: 의심 +25 / 대실패: +40, 그리고 숙적이 그 자리에서 행동 (구간 무시)
```

- 시험 수단은 숙적이 **가진 정보**에서 나온다: 이전 몸의 이름 부르기, 전리품(성표) 보이기, 이전 몸의 가족을 앞에 세우기, 그 몸이 쓰던 말을 흘리기, 물가로 데려가기.

#### 3.7.5 죽음과 감시 대상

플레이어의 몸이 죽으면, 숙적은 믿음 단계에 따라 움직인다.

| 믿음 단계 | 조건 | 몸이 죽었을 때 |
|-----------|------|----------------|
| 1 **원한** | 기본 | 원한은 죽은 이름에 남는다. 거리 0. 12 문서 기준 **죽은 몸의 가족에게 원한 일부 이전**(원한 × 0.5, 숙적 아님 — 가족이 표적이 된다) |
| 2 **이어짐 의심** | 두 번째 몸에서 의심 75 이상, 또는 잔향 사냥 경험이 있는 세력(조합·탑·정화청) 소속이며 젖은 재/잿빛 고리 흔적을 기록함 | 죽은 몸의 **알려진 인연**(숙적의 `known_by`에 있는 자녀·제자·동료·연인)을 '감시 대상'으로 정한다 — 영혼이 그중 하나로 옮겨 가면 그 몸의 거리는 **2에서 시작** |
| 3 **잔향 확신** | 두 몸 이상에서 의심 100, 또는 탑의 판별(진명 '타는 시간' 0 — HOUSES §5.8) | 감시 대상 + **보고 결정**(§3.7.6). 아기로 다시 태어나는 경우 15~24년 동안 거리 0이지만, 공백 시뮬레이션에서 숙적은 '돌아오는 이'를 계속 찾는다(16 문서 공백 요약에 표시) |

> 이것이 인연 계승의 대가다. 사랑하는 사람에게 옮겨 가면 이어짐은 따뜻하지만, **숙적이 그 사람을 이미 지켜보고 있을 수 있다.** 인연 없이 아기로 다시 태어나면 숙적을 따돌리지만, 15~24년을 잃는다.

#### 3.7.6 보고할 것인가 — 숙적의 배신 씨앗

믿음 3단계에 이른 숙적은 그 사실을 세력에 알릴지 고른다.

| 정책 | 가중치 | 결과 |
|------|--------|------|
| `report` 보고 | 충성 + 40 | 세력 대응 단계 +1 (10 §5), 숙적 공로 +40 + 잔향 칭호. 그 대신 사냥은 세력의 것이 된다 (탑·멜리산드가 넘겨받으려 함) |
| `withhold` 독점 | 집착 + 탐욕/2 | 혼자 쫓는다. 세력에 거짓 보고 → **약점 사실 생성** (`fact_<id>_withholds_returner`, danger 4). 플레이어가 이 사실을 알면 협박·폭로(11) 가능 |
| `sell` 판매 | 탐욕 + 20 (바르그 조합은 +20 추가: "산 채로 최고가" — HOUSES §6.2) | 최고 입찰자(탑·멜리산드·원로회)와 거래. 숙적이 다른 세력의 하수인처럼 움직이기 시작 |

### 3.8 패턴 깨기와 가짜 버릇

플레이어는 숙적이 기억하는 자신을 **일부러 배반**할 수 있다.

| 장치 | 규칙 |
|------|------|
| **익숙한 수 표시** ◐ | 숙적이 기록한 흔적과 같은 선택지에 표시. 조건: 플레이어가 그 흔적을 안다 (사냥꾼 판에 목격·소문으로 있음, 또는 15 문서 전생 목소리가 경고함). 모르면 표시 없음 — 모르고 같은 수를 둔다 |
| **패턴 깨기** ◑ | 익숙한 수가 아닌 다른 길을 고르는 것. 그 장면의 판정 −8 ("몸이 아는 길을 거스른다") 또는 스트레스 +5 중 플레이어 선택. 숙적 앞에서 패턴 깨기 1회마다 누적 보너스 +3 (시험 방어, 최대 +15, 몸이 바뀌면 초기화) |
| **가짜 버릇** | 숙적(또는 그의 정보원) 앞에서 같은 '가짜' 전술 태그를 3번 쓰면 숙적이 그것을 버릇으로 기록하고 그에 대한 교훈을 준비한다. 다음 조우에서 그 교훈이 빗나가면 플레이어 판정 +15, 숙적 공포 +5 |
| **이전 몸 부정** | 시험에서 이전 몸의 가족·물건을 보고도 반응하지 않기 — 의지 D (25 + 애정/2). 실패하면 지식 실수(행동) 흔적 |

- 패턴 깨기는 15 문서와 맞물린다: 전생 목소리는 익숙한 수를 **원한다**(리사는 강으로 뛰고 싶어 한다). 패턴을 깨는 것은 목소리를 누르는 것이다.

### 3.9 조우 생성 — 사냥꾼의 수

숙적 AI는 **매주** 한 수를 고른다 (10·11 문서의 세력 AI 주기와 같다). 거리 4에 도달하면 조우 장면을 만든다.

| 수 | 기본 가중치 | 보정 | 조건 |
|----|-------------|------|------|
| 추적 (거리 판정만) | 40 | + 집착/2 | — |
| **매복** | 30 | + 집착/2 − 공포/2 | 거리 4 |
| **함정** | 15 | + 지능 × 2 + 공포/4 | 거리 3+ |
| **협상·거래** | 10 | + 탐욕/3 + 존경/2 | 교훈 #8 없음 |
| **인질** | 0 | + 공포/3, 자비 ≤ −40이면 +20 | 숙적이 플레이어의 애정 70+ 인연을 앎(`known_by`). **같은 숙적은 한 생애에 1회**. 존경 60+면 불가 |
| **시험** | 0 | 의심 25~49: 20 / 50~99: 40 | 몸이 바뀐 뒤 |
| **대리 사냥** (추종자·현상금·밀고자) | 10 | + 공포/2 | 추종자 또는 정보원 2+ |
| **공개 도발** (현상금 게시, 모욕 소문) | 10 | + 치욕 칭호 수 × 10 | — |
| **보고·승진 시도** | 5 | 공로가 다음 계급 조건 충족 시 +30 | — |
| **회복** | 부상 중이면 60 | — | 중상 이상 |
| **경쟁 숙적 견제** (§3.11) | 0 | 같은 지역 다른 숙적 거리 3+면 25 | — |
| **주인 배신 제안** (§3.11) | 0 | `withhold` + (탐욕 30+ 또는 집착 80+)면 20 | 믿음 3 |

**빈도 상한** (18 문서가 이 안에서 긴장 곡선을 조절한다)

| 상한 | 값 |
|------|-----|
| 같은 숙적의 조우 간격 | 최소 **10 게임일** |
| 스포트라이트 숙적 | 7일에 최대 1회 |
| 모든 숙적 합계 | 7일에 최대 **2회** |
| 새 몸의 유예 | 생애 시작 후 **3 게임일** 동안 숙적 조우 없음 (플레이어가 찾아가면 예외). 14 문서의 첫 시간 설계와 맞출 것 |
| 같은 유형 연속 금지 | 같은 숙적이 같은 수(매복·인질 등)를 연달아 쓰지 않는다 |

### 3.10 해소 — 숙적을 끝내는 여섯 가지 방법

| 해소 | 조건 | 즉시 결과 | 이후 |
|------|------|-----------|------|
| **죽임** | 전투·암살(11)·사고·다른 세력의 손 | 숙적 종료. 세력 반응(10 평가표), 공로·현상금 | **원한 상속** 판정(§3.10.1) |
| **전향** | 존경 50+ **그리고** 지렛대 1개(그의 세력 안 약점, 가족의 안전, 더 나은 주인) + `[화술 vs 숙적]` | 동료(08) 또는 정보원. `옛_숙적` 플래그 | 집착이 40 이상 남아 있으면 계절마다 배신 판정 (집착 − 존경 + 20)% |
| **모욕** | 그를 이기고 **살려 둔다**, 자기 세력 목격자 3+ 앞에서 | 공로 −20, 강등 판정 (계급 단계 × 20%), 치욕 칭호 | 공포 ≥ 80이면 **꺾인 자**(사냥 중단). 집착 ≥ 80이면 **떠돌이 숙적**(더 위험, 자원 적음). 그 사이면 공포 +15·집착 +20 |
| **꼭두각시** | 그의 약점 사실(08 Fact, danger 3+)을 쥐고 협박(11 §3.6) | 그가 세력 정보를 흘리고 거짓 보고를 한다 | 매 계절 반발 판정: 원한/2 − 공포/3 %. 반발하면 사실 은폐를 시도(정보원 처리) 후 사냥 재개 |
| **사냥꾼의 예** | 존경 60+ **그리고** 숙적 정직 ≥ 0 **그리고** 플레이어가 그에게 한 약속을 지킨 기록 1+ | `pact` — 규칙 있는 적. 인질·함정·대리 사냥 금지, 사냥 전 통보 | 볼크의 "사흘 유예"가 원형. 숙적이 이 예를 깨면 그의 세력 내 시선 −(바르그는 '정직한 사냥'을 존중한다) |
| **당신을 죽임 → 전설** | 숙적이 플레이어의 몸을 죽임 | 영광 칭호, 공로 +30, 추종자 +2, 공포 −25. 시체의 소지품 중 1개를 **전리품**으로 가져감 | 다음 생애에 그는 더 강하다 — 대신 **자만** 특성: 시험·대화에서 지난 사냥을 자랑한다 (그의 교훈 목록이 '소문'으로 사냥꾼 판에 자동 공개), 함정 가중치 −10. 전리품 회수는 다음 생애의 작은 목표가 된다(가보의 메아리 03과 같은 결) |

- **늙음**: 숙적도 늙는다. 수명의 70%를 넘으면 계절마다 '마지막 사냥' 조우 가중치 +10 — 늙은 숙적은 끝을 보고 싶어 한다(장면 F).
- **잠듦에서의 귀환**: 잠든 원한은 플레이어의 흔적을 보는 순간(정보원 보고 포함) 깨어남 판정. 10년 넘게 잠든 숙적은 깨어날 때 교훈 1개를 잊는다.

#### 3.10.1 원한 상속 — 죽인 숙적이 남기는 것

숙적이 죽으면, 그와 **애정 60+** 인 사람(가족·무리·추종자·제자) 각각에 대해:

```
상속 확률 = 30% + 숙적의 집착/4 + (플레이어가 죽인 방식이 잔혹했으면 +15, 공개 처형 +20) − (상속자 공포/2)
최대 1명만 상속 (가장 확률 높은 자). 상속자는 숙적 생성 조건을 자동 충족한 것으로 본다.
```

- 상속자는 **교훈 1개와 흔적 기록의 절반**(가장 강한 것부터)을 물려받는다 — 숙적이 가족에게 이야기했다는 뜻이다. "아버지는 늘 말했지. 그놈은 물을 건넌다고."
- 바르그는 무리(= 가족)이므로 상속이 잘 일어난다. 이것이 볼크가 죽으면 이르가 또는 강경파가 이어받는 정본(CHARACTERS R02-07 사망 시 영향)과 맞물린다.

### 3.11 숙적끼리, 그리고 주인을 배신하는 숙적

**경쟁** — 같은 지역에 숙적 둘 이상이 거리 3+로 들어오면 매주 25% 확률로 경쟁 사건.

| 조합 (예) | 그들이 원하는 것 | 플레이어가 할 수 있는 것 |
|-----------|------------------|--------------------------|
| 그로드 ↔ 세타 | 사냥대장 자리 (둘 다 송곳니) | 한쪽에 다른 쪽의 사냥 경로를 흘려 공을 빼앗게 하기 → 패자 강등·떠돌이화 |
| 그로드 ↔ 이졸 | 그로드: 죽이거나 팔기 / 이졸: 산 채로 탑에 (해방 증서) | 둘이 같은 밤 같은 은신처에 오게 하기 → 서로를 방해 (판정 −10씩), 피 흘리게 하기 |
| 이졸 ↔ 페트르 | 탑 vs 멜리산드 — 같은 '그릇'을 노림 | 한쪽의 증거를 다른 쪽 주인에게 넘기기 |
| 하겐 ↔ 이르마 (복수자) | 하겐: 숨기 / 이르마: 남편의 원수 | 이르마에게 진실을 알리면 이르마가 하겐의 숙적이 된다 — **숙적이 숙적을 만든다** |

**주인 배신** — `withhold` 숙적은 비밀을 품고 있다. 두 방향이 있다.
1. **숙적의 제안**: "네가 도망칠 시간을 주지. 대신 네가 세타를 치워라." 플레이어가 받아들이면 숙적의 공로 경쟁자가 사라지고, 숙적은 빚(08 거래 엣지)을 진다.
2. **플레이어의 폭로**: 숙적이 잔향을 숨긴 사실을 그의 주인(볼크·카르바·멜리산드파)에게 흘린다 → 숙적은 자기 세력에게 쫓긴다 (숙적의 숙적이 숙적의 주인이 된다). 숙적 집착 +20, 그리고 이제 그는 잃을 것이 없다.

### 3.12 어둠의 길이 만드는 숙적 — 피해자의 가족

13 문서의 길을 걸으면 **인간 숙적**이 생긴다. 그들은 약하다. 그래서 다르게 싸운다.

| 유형 | 생성 | 싸우는 법 | 예 |
|------|------|-----------|-----|
| **복수자** | `kin_sold`, `kin_killed` (피해자 가족, 애정 70+) | 직접 전투 거의 없음. 밀고(목줄단·조합에 플레이어 위치 판매), 독, 플레이어의 가족 노리기, 소문(10) | 노예상 플레이어가 판 에길 가족의 아내 룬 |
| **자라는 숙적** | 피해자의 아이 (당시 15세 미만) | **잠든 원한**으로 시작. 그 아이가 16세가 되는 해에 깨어남 판정 (집착 = 사건 당시 아이의 애정/2 + 20) | 에길의 맏아이(9세) — 7년 뒤, 혹은 플레이어가 아기로 다시 태어난 19년 뒤에 사냥꾼이 되어 있다 |
| **배신당한 동료** | `betrayed` (13 '배신자' 경로) | 플레이어의 비밀을 가장 많이 안다 → 지식이 무기. 시험이 가장 정확하다 (지식 흔적 가중치 ×1.5) | 팔아넘긴 연인 |

- 자라는 숙적은 몸이 바뀌어도 플레이어를 놓치지 않는 가장 확실한 숙적이다: 그 아이는 플레이어의 **영혼**이 아니라 **행동**을 기억하고, 그 행동의 버릇이 다음 몸에서도 반복되면 알아본다.
- 어둠의 길로 얻은 효율(13 §1)에는 이 지연된 값이 붙어 있다. 설교 없이, 그냥 15년 뒤에 문을 두드리는 사람으로.

### 4.1 TypeScript

```ts
type NemesisStance = 'hunting'|'dormant'|'pact'|'pawn'|'turned'|'broken'|'rogue'|'dead'|'archived';

interface NemesisProfile {
  npc: NpcId;                                    // 숙적은 인물 위에 얹힌다 (08)
  origin: { event: EventId; kinds: WoundKind[]; score: number; body: NpcId; date: GameDate };
  stance: NemesisStance;
  spotlight: boolean;                            // 이번 생애의 주 숙적 (18)
  mind: { grudge: number; obsession: number; fear: number; respect: number };  // 0~100
  belief: BeliefTier;
  reportPolicy?: 'report'|'withhold'|'sell';     // belief 3에서 결정
  scars: { id: ScarId; part: BodyPart; by: 'player'|NpcId; body?: NpcId; date: GameDate }[];
  titles: { id: TitleId; kind: 'shame'|'glory'|'returner'; text: string; known_in: RegionId[] }[];
  lessons: { tactic: TacticTag; counter: LessonId; learnedFrom: NpcId /*플레이어의 몸*/; lastUsed: GameDate }[];
  rank: { faction: FactionId; tier: number; merit: number };
  followers: NpcId[];                            // B등급 즉석 생성, 후계자 후보
  distance: 0|1|2|3|4;
  watchList: NpcId[];                            // belief 2+ : 죽은 몸의 알려진 인연
  trophies: ItemId[];                            // 플레이어 시체에서 가져간 것

  id: EventId; date: GameDate; body: NpcId; move: NemesisMove;
  decisiveTactic?: TacticTag; outcome: 'escaped'|'won'|'lost'|'killed_player'|'captured_player'|'resolved';

}
// 매주: nemesisTick() → 수 선택(§3.9) → 거리 판정(§3.6) → 거리 4면 조우 장면 큐 (18 문서가 빈도 상한 안에서 배치)
// 조우 후: applyEncounter() → 흉터·칭호·교훈·공로·마음 갱신 → Fact 생성(08) → 소문(10) → 메아리 대기열(16)
```
