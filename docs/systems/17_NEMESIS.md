# 17. 숙적 — 회차 안에서는 그가 기억하고, 회차를 넘어서는 당신이 기억한다

> 질문: "주인공은 죽으면 같은 저녁으로 돌아간다. 세계는 아무것도 기억하지 못한다. 그렇다면 원수도 잊는가? 죽을 때마다 모든 원수가 리셋되면, 죽음은 도망이 된다."
> 답: **회차 안에서는 적이 기억한다.** 당신을 놓친 사냥꾼, 당신에게 코가 녹은 바르그, 당신이 아이를 판 어머니는 그 회차가 끝날 때까지 당신을 잊지 않는다. 흉터와 칭호와 교훈을 달고, 당신이 그에게 가르친 것을 배운다.
> **회차를 넘어서는 그가 잊는다.** 회귀하면 그의 코는 멀쩡하고, 원한은 없고, 당신을 처음 본다. 그러나 둘이 남는다. 하나, **젖은 재의 냄새** — 회차가 쌓일수록 짙어져서, 코 좋은 사냥꾼은 이유도 모른 채 매번 조금 더 일찍 당신 쪽으로 코를 돌린다 (03 §7.1). 그리고 시간에 민감한 자들(잿빛 탑·엘다르·바르스카르)의 **기시감** (03 §7.2). 둘, **당신의 기억** — 당신은 그의 이름과 흉터의 사연과 그가 배운 교훈과 그가 무엇을 무서워하는지 안다. 그는 모른다.
> 이 비대칭이 회귀자의 숙적이다. 숙적은 새로운 종류의 NPC가 아니다. **이미 있는 인물 위에 얹히는 기억과 집착의 층**이고, 그 층은 회차와 함께 벗겨진다 — 당신 쪽에만 남는다.

## 0. 핵심 결정 세 가지

| # | 결정 | 이유 |
|---|------|------|
| ① | **숙적은 '덧씌우기(overlay)'다.** 모든 이름 있는 NPC(B등급 이상)가 조건을 채우면 숙적이 된다. 고정된 '보스 명단'은 없다 | 00 문서 규칙 ④(특별 규칙 금지). 숙적은 08의 원한 엣지 + 이 문서의 프로필로만 표현된다 |
| ② | **숙적 프로필은 회차 안의 것이다.** 회귀하면 원한·흉터·칭호·교훈·의심이 모두 회귀점으로 돌아간다. 회차를 넘는 연결은 **냄새·기시감·플레이어의 기억** 셋뿐이고, 숙적에게 초자연적 감각은 없다 — 기시감은 정본의 시간에 민감한 셋에게만 있다 | 세계는 이어지지 않는다, 기억이 이어진다(03 §1). 특별한 것은 주인공뿐이다(WORLD_BIBLE §1.3.1). 모든 의심은 **나중에 플레이어에게 설명 가능**해야 공정하다 |
| ③ | **동시에 사냥 중인 숙적은 최대 3, 한 회차의 주인공(스포트라이트)은 1.** 나머지는 '잠든 원한'으로 기다린다 | 섀도 오브 모르도르식 '숙적 폭주'를 막는다. 숙적이 흔하면 숙적이 아니다 |

## 1. 목표

### 1.1 이 장치가 해결하는 문제

| 문제 | 지금 상태 | 숙적이 하는 일 |
|------|-----------|----------------|
| **동기 부재** — 죽음이 리셋처럼 느껴진다 | 회귀하면 세계가 처음으로 돌아간다. 원수도, 빚도, 현상금도 사라진다 (03 §4.1) | 지난 회차의 원수가 이번 회차에 **처음 보는 얼굴로** 다시 온다. 그는 모르는데, 당신은 그의 코가 녹던 소리를 안다. 그리고 그는 지난번보다 조금 일찍 온다. "그 놈이 아직 살아 있다"가 아니라 **"그 놈이 또 살아 있다"** — 회차를 넘는 가장 강한 동기다 |
| **아는 미래의 퍼즐화** | 회귀자는 적의 수를 외워 매번 똑같이 이길 수 있다 | 회차 안에서는 숙적이 배운다(교훈). 회차를 넘어서는 냄새가 첫 만남을 당기고, 그의 선택 일부에는 표류가 붙는다(03 §4.4). 그를 죽이면 그 자리에 **당신이 모르는** 후임이 온다 |
| **보이지 않는 시뮬레이션** | 10 문서의 대응 단계(바르그 사냥대·와이번 기사단)는 숫자다 | 대응 단계에 **이름 붙은 집행자**를 앉힌다. "2단계 사냥대"가 아니라 "반귀 그로드와 그의 코 넷"이 온다 |
| **시스템 과잉** | 평판·위협도·관계·사실이 따로 보인다 | 숙적 한 명이 이 모든 것을 한 사람의 행동으로 묶어 보여 준다 (원한=08, 칭호=10, 작전=11, 인질=12) |
| **초반 무력감** | 인간은 약하다. 이기지 못하는 싸움뿐이다 | **이기지 않아도 되는 승리**를 준다. 따돌리기, 모욕하기, 가르쳐 주기(그가 엉뚱한 교훈을 배우게 하기) — 약자가 강자의 기억에 흉터를 남기는 방식. 회귀하면 흉터는 사라진다. 낸 방법은 남는다 |

### 1.3 설계 원칙

| 원칙 | 내용 |
|------|------|
| **약자가 남긴 흉터** | 숙적 대부분은 플레이어보다 강하다. 숙적이 되는 이유는 "졌다"가 아니라 "**놓쳤다·당했다·잃었다**"이다 |
| **알아봄은 설명된다** | 숙적이 당신을 의심할 때마다 메아리 알림(16)이 무엇을 들켰는지 보여 준다. "그로드는 당신이 강을 건넌 방식을 안다 ← 312 낙엽월 22일" |
| **잊는 쪽과 기억하는 쪽** | 회귀하면 숙적은 잊는다. 플레이어는 기억한다. 그 앎은 강력하지만, 처음 보는 사람의 이름을 아는 것은 그 자체로 **「앎의 흔적」**(03 §4.3)이다 — 아는 것을 쓰면 의심이 시작된다 |
| **배움에는 틈이 있다** | 숙적의 모든 적응(교훈)에는 반드시 반격 수가 하나 있다. 적응은 길을 막지 않고 **값을 올린다** |
| **설교 없음** | 숙적은 악당일 수도, 피해자일 수도 있다. 이졸은 무고한 아이 38명을 탑에 넘겼고, 당신이 그 아이들을 판 어머니의 숙적이 될 수도 있다. 게임은 판정하지 않는다 |
| **끝낼 수 있다, 그러나 회차 안에서만** | 죽이기·전향·모욕·꼭두각시·사냥꾼의 예 — 어떤 숙적도 그 회차에서 영원하지 않다. 회귀하면 죽인 숙적도 살아 있다. 그래서 회차를 넘는 진짜 질문은 '죽일 것인가'가 아니라 **'이번 회차에도 그를 만들 것인가'**다 |

### 2.4 장면 D — 「먼저 먹는 개」 (회차 2, 조우 ⑤ · 짧게)

> 셋째는 엘사에게 약학을 배워 바꽃 뿌리를 송곳니 초소의 저녁 국솥에 넣는다. 그로드는 살아남는다 — 그는 볼크가 숟가락을 들기 전에는 먹지 않는다. 그날 밤 먼저 먹은 코 둘이 죽는다.

- 그로드: 흉터 **쉰 목소리**(위압 −5), 교훈 **음식 시험** — 이 회차가 끝날 때까지 그의 음식은 목줄꾼 인간이 먼저 먹는다(독살 D +20).
- 반격 수: 그 목줄꾼은 **사람**이다. 매수하거나(흥정), 그의 가족을 이용하거나(13 문서), 지연독(약학 45+, 반나절 뒤 발현)으로 시험을 통과시키거나.
- 3년 뒤(319) 셋째는 그 목줄꾼 '먼저 먹는 개'를 포섭한다. 이것이 회차 2 내내 그로드의 동선을 아는 정보원이 된다 — **적응은 새로운 약점을 만든다.**
- 회귀하면 교훈도, 흉터도, 포섭한 목줄꾼의 충성도 사라진다. 남는 것은 **볼크의 숟가락**이라는 앎이다. 다음 회차의 셋째는 독이 아니라 볼크의 일정을 노린다.

| 4 | 성공: 늙은 바르그가 물에 빠진다. 물이 무릎까지인 여울에서 그는 일어나지 못한다. 당신은 그를 꺼낼 수도, 둘 수도 있다 | **죽임** 또는 **모욕**(꺼내 줌) | 죽임: 조합 계승 분쟁(§3.10.1 원한 상속 — 그로드의 사냥조 고참 '루그'가 상속 판정). 모욕: 사냥대장이 늙은 농노에게 물에서 건져졌다는 소문 → 강등 판정, 집착 +20 |
| 5 | 그로드는 세타를 서리 길에서 죽였다(325). 당신은 그것을 안다(스칼리에게서 들은 소문 + 시체 위치). "조합장 자리는 피로 산 거지. 그 피를 조합이 알면?" | **꼭두각시** | 그로드는 '산 채로' 관행을 되살리고, 조합의 사냥 일정을 당신에게 흘린다. 매 계절 반발 판정(§3.10) |
| 6 | "첫 번째는 파종월, 굶주린 언덕이었다. 너는 내 동생에게 목줄을 채웠고, 나는 네 수레 판자의 헐거운 못을 알았다." 그로드가 오래 침묵한다. 그는 이해하지 못한다. 그러나 수레 못은 그만 아는 것이다 — 그는 그 못을 이 회차에도 고치지 않았다 | **꺾인 자** 판정 (공포 +30) 또는 2로 이어짐 | 의심 100. 그는 처음으로 당신에게서 물러선다. 거짓말이 아니므로 정직 판정 없음. 그는 그날 밤 '코'를 풀어 준다 — 이유를 말하지 못한다 |

- 어떤 해소든 **회차 기록**에 남는다. 그로드가 죽으면: *"반귀 그로드, 송곳니 회관의 사냥대장. 같은 사람을 세 회차 동안 쫓았고, 매번 처음이었다. 같은 여울에서 끝났다."* 업적 `ACH-05 세 회차의 원수`(같은 숙적과 세 회차에 걸쳐 다시 만나고 한 회차 안에서 해소, TP +1 — SCENARIOS §6.1).
- 이 회차가 끝나면 — 그를 죽였든 살렸든 — 그로드는 다시 스물아홉 살이다. 네 번째 회차의 그는 낙엽월 18일쯤 당신을 맡을 것이다.

### 2.7 장면 G — 사냥꾼 판 (인물 수첩 탭)

> 08 문서 §5 인물 수첩의 한 탭. **플레이어가 아는 것만** 보인다. 확신도: 목격(실선 ━) / 소문(점선 ┄) / 추측(?). **사냥꾼 판은 회귀해도 남는다** — 그것은 주인공의 기억이다. 지난 회차의 정보에는 `〔회차 n〕` 꼬리표가 붙고, 이번 회차에 다시 확인하기 전까지는 표류할 수 있다(03 §4.4 ◇).

```
┌─────────────────────────────────┐
│ 사냥꾼 판 — 송곳니 회관           │
│ 회차 3 · 낙엽월 25일              │
├─────────────────────────────────┤
│ 사냥대장  볼크 회색송곳니       ━  │
│   쫓는 것: 시그리드 무리       ┄  │
│   당신과의 거리: ▯▯▯▯▯ 모름       │
│                                   │
│ 송곳니  반귀 그로드  ★숙적     ━  │
│   쫓는 것: 당신                 ━  │
│   거리: ▮▮▮▯▯ 마을 근처         ┄  │
│   흉터: 없음 (이번 회차)        ━  │
│     〔회차 1〕녹은 코 · 〔회차 2〕쉰 목│
│   교훈: (이번 회차) 없음         ━  │
│     〔회차 1〕양안 매복 · 목줄꾼 선두│
│     〔회차 2〕음식 시험             │
│   약점: 볼크 앞에서 작아진다    ━  │
│         볼크보다 먼저 먹지 않는다 ━│
│   첫 냄새: 〔회차 1〕22일 · 〔회차 2〕│
│            20일 · 이번 19일       ━│
│                                   │
│ 송곳니  세타                    ┄  │
│   북방 탈주자 전담. 볼크의 후계   │
│   후보. 그로드와 반목           ━  │
│                                   │
│ 목줄꾼  하겐                    ━  │
│   그로드에게 물건을 넘긴다      ━  │
│                                   │
│ 코 ×4 (이름 안다 — 〔회차 2〕)     │
├─────────────────────────────────┤
│ [잿빛 눈(탑)]  [목줄단]  [기사단]  │
└─────────────────────────────────┘
```

- 정보를 얻는 길: 하겐·목줄꾼 매수(흥정), 수탉의 소문(요한), 송곳니 불 엿듣기(은신), 이르가와의 관계(정직 +15, CHARACTERS R01-09), 조합에 목줄꾼으로 위장 가입(HOUSES §5.9), 그리고 **지난 회차의 기억** — 가장 값싸고 가장 위험한 길이다. 확인하지 않고 쓰면 표류에 걸리고, 확인하려고 쓰면 「앎의 흔적」이 남는다.
- 거리 막대는 **플레이어가 얻은 마지막 정보 기준**이다. 오래된 정보에는 날짜가 붙는다("12일 전"). 실제 거리와 다를 수 있다.
- '첫 냄새' 줄은 회차마다 숙적이 처음 당신을 알아챈 날이다. 플레이어는 이 숫자가 줄어드는 것을 보며 `loop.count`의 값을 몸으로 안다.

## 3. 규칙과 수치

### 3.1 숙적 생성 — 상처 사건

플레이어가 원인인 사건에서 **이름 있는 NPC(B등급 이상)가 살아남으면** 상처 점수를 계산한다.

| 상처 사건 | 기본값 | 예 |
|-----------|--------|-----|
| `escaped_hunt` 사냥감이 빠져나감 | 25 | 셋째가 여울을 건넘 |
| `wounded` 다침 (부위 중상 이상) | 30 | 잿물에 코가 녹음 |
| `humiliated` 모욕당함 (자기 세력 목격자 앞) | 35 | 사냥대장이 자기 사냥개에게 물에서 건져짐 |
| `humiliation_before_superior` 상관 앞 실패 (가산) | +20 | 볼크가 보는 앞에서 놓침 |
| `failed_assassination` 플레이어의 암살·독살에서 살아남음 | 40 | 국솥의 바꽃 |
| `betrayed` 플레이어에게 배신당함 | 35 | 위장 동료였던 플레이어가 하겐을 함정에 넣음 |
| `kin_killed` 가족·무리·연인이 플레이어 손에 죽음 | 50 | 그로드의 코 둘이 국을 먹고 죽음 (무리 = 가족, 바르그) |
| `kin_sold` 가족이 플레이어에게 팔리거나 밀고됨 (13 문서) | 45 | 노예상 플레이어가 에길의 아이를 세렌에 판다 |
| `property_ruined` 생계·지위를 잃음 (강등, 매각, 영지 소실) | 30 | 플레이어가 노예 장부를 태워 헨릭이 처벌받음 |
| `lost_prize` 거의 손에 넣은 큰 보상을 놓침 | 20 | 이졸의 할당량 마감일, 징후자를 놓침 |

```
상처 점수 = 사건 기본값 합 (같은 장면 내 최대 2개)
          + 목격자 보정  (그 NPC의 세력·무리 목격자 1명당 +3, 최대 +15)
          + 성향 보정    (자비 ≤ −40: +5 / 용기 ≥ +40: +5 / 정직 ≥ +40: −5 — 정직한 자는 원한보다 규칙을 따른다)
```

| 조건 | 결과 |
|------|------|
| 상처 점수 ≥ 40 **이고** 원한(08) ≥ 60 **이고** 행동 능력이 있음* | **숙적 생성** — 사냥 슬롯이 비어 있으면 '사냥 중', 아니면 '잠든 원한' |
| 상처 점수 25~39 또는 원한 40~59 | **숙적 후보** — 같은 NPC와 다음 상처 사건이 나면 점수 합산 |
| 그 외 | 일반 원한 엣지만 남는다 (08) |

\* 행동 능력: 전투·추적 스킬 하나가 40 이상, **또는** 부하·정보원이 3명 이상, **또는** 세력 계급 2단계 이상, **또는** 상처 사건이 `kin_killed`/`kin_sold`(복수자는 약해도 숙적이 된다 — §3.12).

**슬롯 상한**

| 슬롯 | 상한 | 넘치면 |
|------|------|--------|
| 사냥 중 (활성) | **3** | 집착이 가장 낮은 숙적이 잠든 원한으로 내려간다 |
| 스포트라이트 (이번 회차의 주 숙적) | **1** | 18 문서(이야기 연출가)가 회차 시작 시와 숙적 생성 시 고른다. 지난 회차의 스포트라이트 숙적이 휴면 숙적으로 있으면 우선 후보. 조우 빈도 우선권 |
| 잠든 원한 | **8** | 가장 오래 접촉 없는 숙적이 '기록'으로 보관된다 (회차 기록에만 남고, 흔적을 보면 다시 깨어남 판정) |
| 휴면 숙적 (지난 회차의 숙적) | 제한 없음 | 회귀점에서 모든 숙적이 여기로 간다 — 원한 0, 숙적 아님. 냄새·기시감·의심 규칙만 돌아간다 (§3.7.1) |

### 3.2 숙적의 마음 — 네 개의 수치

| 수치 | 범위 | 오르는 때 | 내리는 때 |
|------|------|-----------|-----------|
| **원한** (08의 원한 엣지 값) | 0~100 | 상처 사건 (상처 점수만큼, 상한 100) | 시간 (계절당 −3, 최저 40), 사과·보상(드묾) |
| **집착** | 0~100 | 놓침 +10, 공개 모욕 +20, 치욕 칭호 1개당 +10, 플레이어가 그의 이름·약점을 먼저 안다(앎의 흔적) +5 | 플레이어를 산 채로 잡음 −20, 접촉 없음 계절당 −5. (플레이어를 죽이면 회차가 끝난다 — 그의 만족은 회귀와 함께 사라진다) |
| **공포** | 0~100 | 다침 +10~25 (부상 단계별), 동료 사망 +10, 플레이어의 진명 목격 +20 | 승리 −10, 계절당 −5 |
| **존경** | 0~100 | 플레이어가 약속을 지킴 +10, 1:1로 이김 +10, 그를 살려 줌 +15 | 비겁한 수(인질·독) −10 |

**행동 성향표** (세력 AI가 매주 고르는 '사냥꾼의 수' 가중치에 반영 — §3.9)

| 조건 | 성향 | 이렇게 움직인다 |
|------|------|-----------------|
| 집착 ≥ 70, 공포 < 40 | **사냥개** | 직접 쫓는다. 매복·추적 위주 |
| 집착 ≥ 60, 공포 ≥ 60 | **독사** | 직접 오지 않는다. 함정·인질·대리 사냥·밀고 — 가장 잔인해진다 |
| 공포 ≥ 80, 집착 < 40 | **꺾인 자** | 사냥을 멈춘다. 지렛대만 있으면 정보원이 된다 |
| 집착 < 30, 공포 < 30 | **잠듦** | 잠든 원한 슬롯으로. 흔적을 보면 깨어남 판정 (집착 + 의심/2 ≥ 40) |
| 존경 ≥ 60 | **정직한 적** (위 성향에 덧붙음) | 인질을 쓰지 않는다. 사냥 전에 알린다. 사냥꾼의 예(§3.10)의 전제 |

### 3.3 흉터와 칭호

**흉터** — 부상(01 §1.4)이 영구가 되면 흉터가 된다. 흉터는 외모 태그(10 §3.1)이자 대사 고리이자, 때로 수치다.

| 흉터 (예) | 원인 | 수치 효과 | 알아봄에 미치는 영향 |
|-----------|------|-----------|----------------------|
| 녹은 코 | 잿물·불 (얼굴) | 추적 −15 | 냄새 흔적 가중치 ×0.5 → 대신 버릇·변화 가중치 ×1.2 ("눈을 쓰기로 했다") |
| 쉰 목소리 | 독 | 위압 −5 | — |
| 외눈 | 화살·칼 | 궁술 −10, 감각 판정 −5 | 잿빛 고리 흔적 ×0.7 |
| 절름발이 | 다리 중상 | 추적 거리 진행 판정 −10 (§3.6) | — |
| 손가락 셋 | 손 중상 | 단검·손재주 −10 | — |
| 화상 얼굴 | 불 진명 | 공포 +10 영구 | 진명 목격 기억 → 시험 시 마법 관련 질문 |

- 흉터를 낸 것이 플레이어면 흉터에 `by: player`가 기록된다. 대사: *"이 코? 셋째라는 농노가 줬지."*
- 숙적은 흉터 수만큼 **집착 하한**이 오른다 (흉터 1개당 하한 +10, 최대 40). 그 회차 안에서 흉터는 잊지 못한다.
- **회귀하면 흉터는 없다.** 그의 코는 멀쩡하다. 흉터는 플레이어의 사냥꾼 판에 `〔회차 n〕` 꼬리표로만 남는다 — 그리고 멀쩡한 코를 너무 오래 보는 것은 앎의 흔적이다(§2.3).

**칭호** — 10 문서 §4.1의 칭호 시스템을 숙적에게도 쓴다. 소문으로 생기고, 세력 안에서의 대우를 바꾼다.

| 종류 | 생기는 조건 | 예 | 효과 |
|------|-------------|----|------|
| 치욕 칭호 | 자기 세력 목격자 3+ 앞에서 실패·모욕 | '젖은 코', '물에서 건져진 대장', '농노에게 코를 판 송곳니' | 집착 +10, 공로 −10, 세력 내 시선 −10. 숙적은 이 칭호를 지우려 한다 — 플레이어를 공개적으로 잡아야 지워진다 |
| 영광 칭호 | 플레이어를 산 채로 잡음, 또는 플레이어의 동료·가족을 잡거나 죽임, 소문 도달 (플레이어를 죽인 칭호는 회차 기록에만 남는다) | '농노의 동생을 문 송곳니', '두 번 문 자' | 공로 +10, 추종자 +1, **자만** 특성(§3.10 '전설') |
| 잔향 칭호 | 믿음 3단계를 세력이 알게 됨 | '돌아오는 이를 아는 사냥꾼' | 세력의 대응 단계 +1(10 §5), 탑·멜리산드가 접촉해 옴 |

### 3.4 교훈 — 숙적은 당신에게서 배운다

플레이어가 숙적을 **따돌리거나 이긴 결정적 선택**에는 전술 태그가 붙어 있다 (02 문서의 태그 방식). 숙적이 살아남으면 그 태그에 대한 **교훈**을 얻는다.

| 규칙 | 값 |
|------|-----|
| 교훈 획득 | 그 조우를 결정한 선택의 전술 태그 1개 (부분 성공 이상으로 플레이어가 빠져나갔을 때). 지능 7 이하는 획득 확률 50% |
| 교훈 상한 | 2 + 계급 단계 (0~3) → **최대 5**. 넘치면 가장 오래 안 쓰인 교훈을 잊는다 |
| 효과 | 해당 태그 선택지의 D +15 (또는 표에 적힌 2차 판정·비용) |
| 영속 | 교훈은 **그 회차 안에서** 숙적에게 붙는다. 회귀하면 잊는다 — 플레이어는 그 교훈과 반격 수를 기억한다(사냥꾼 판 `〔회차 n〕`). 다음 회차에 같은 수를 쓰면 그는 처음 당하는 것이고, 같은 회차에 두 번 쓰면 다시 배운다 |
| 반격 수 | 모든 교훈은 반격 수 1개 이상을 가진다. 반격 수는 교훈을 **알아야** 보인다 (사냥꾼 판에 교훈이 '목격' 또는 '소문'으로 있을 때) |
| 과적응 | 플레이어가 그 태그를 3번 연속 조우에서 쓰지 않으면, 숙적은 그 교훈에 계속 자원을 쓴다 (추종자 1명이 그 대비에 묶임) → 다른 수의 D −5 |

**교훈 표 (수직 슬라이스 12종)**

| # | 플레이어 전술 태그 | 숙적의 교훈 | 효과 | 반격 수 |
|---|--------------------|-------------|------|---------|
| 1 | `물건너기` (냄새 끊기) | **양안 매복** — 사냥개를 건너편에 먼저 보낸다 | 건너편에서 2차 은신 판정 D 40 | 상류·하류로 3리 이상 크게 돌기 (⏱ +4h), 또는 건너편 사냥개를 미끼로 먼저 꾀어 내기(`미끼`) |
| 2 | `독` (음식·물) | **음식 시험** — 목줄꾼이 먼저 먹는다, 물은 직접 뜬다 | 독살 D +20 | 지연독(약학 45+), 시식자 매수·포섭 |
| 3 | `냄새지우기` (늪 마녀 약·무두장) | **약 냄새를 쫓는다** — 지우는 냄새 자체가 표지 | 냄새 지우기 효과 반감 | 다른 강한 냄새(가축·그나르 시체)로 덮기, 여럿에게 같은 약을 바르게 해 흔적을 흩기 |
| 4 | `밤이동` | **밤에 몰고 낮에 쉰다** | 밤 은신 D +10 | 한낮 군중 속 이동(시장날·예배) |
| 5 | `미끼흔적` | **흔적을 둘로 나눠 쫓는다** | 미끼 효과 반감 | 갈라진 사냥조는 수가 절반 — 매복 판정 +10 |
| 6 | `기습` | **목줄꾼 선두** — 인간 사냥개를 앞세운다 | 첫 공격이 인간 목줄꾼에게 간다 | 목줄꾼에게 노예말로 말 걸기(화술), 또는 그대로 치기 (자비▼, 인간 시선 −) |
| 7 | `함정` | **막대로 땅을 찌르며 간다** | 함정 D +15, 대신 이 숙적의 추적 거리 진행 −5 | 함정 대신 그 느린 속도를 이용한 따돌리기 |
| 8 | `거짓말로빠짐` | **말을 듣지 않는다** | 협상·기만 선택지 D +20, '거래' 조우 가중치 0 | 증거(문서·목격자)를 들고 말하기 — 말이 아니라 사실이면 듣는다 |
| 9 | `군중숨기` | **혀를 군중에 심는다** (목줄단 정보원) | 군중 은신 D +15 | 군중을 흩는 소동(불, 도망친 가축), 혀 매수 |
| 10 | `불` | **젖은 망토와 물통** | 불 공격·불 지르기 D +15 | 불이 아닌 연기(질식), 비 오는 날 피하기 |
| 11 | `동료구출` | **동료부터 노린다** | 동료가 인질 대상 우선순위 1위 | 동료를 숨기거나, 일부러 동료가 아닌 척(관계 공개도 낮추기 — 08 `public: false`) |

- 교훈은 **장면 안에서 보인다**: 양안 매복이 있으면 여울 장면 묘사에 *"건너편 갈대에서 무언가 숨을 고른다"* 같은 문장이 들어간다 (감각 D 30 이상이면 알아챔).
- 1.0에서는 30종으로 늘린다 (마법·진명, 변장, 위조 문서, 하늘(와이번 기사)용 교훈 등).

### 3.5 승진과 추종자

숙적은 자기 세력 안에서 오르내린다. **공로**(merit, 0~200)가 기준이다.

| 공로 변화 | 값 |
|-----------|-----|
| 플레이어의 동료·가족을 잡음 | +10 |
| 플레이어를 다치게 함 (중상) | +10 |
| 플레이어를 산 채로 잡음 | +30 (현상금이 있었으면 +10). 플레이어를 죽이면 회차가 끝나므로 공로는 회차 기록에만 남는다 |
| 믿음 3단계를 세력에 보고, 세력이 받아들임 | +40 |
| 치욕 칭호 | −10 |
| 공개 모욕 (§3.10) | −20 |
| 사냥 실패 (거리 4에서 놓침) | −5 |

**바르그 노예사냥 조합 사다리** (HOUSES §5.9)

| 계급 | 정원 | 승진 조건 | 자원 (숙적이 쓰는 것) |
|------|------|-----------|-----------------------|
| 목줄꾼 (인간·크릭) | 약 300 | — (인간은 여기가 끝. 예외: 공로 120 + 사냥대장의 총애 → '목줄 두목') | 추종자 0, 정보원 1, 거리 진행 +0 |

| 송곳니 (분대장) | 12 | 공로 60 + **빈자리** (계절마다 15% 확률로 자연 공석, 또는 다른 송곳니 제거 — §3.11) | 추종자(코) 4~6, 정보원 3, +10, 사냥 드레이크 대여 |
| 사냥대장 | 1 | 공석 + 송곳니 중 최고 공로 + 후원자(아우락스파) 승인 | 추종자 12+, 정보원 10, +15, 와이번 정찰 요청(대응 4단계 지원), 맹약회의 발언권 |

다른 세력의 사다리 (1.0, 형식만):

| 세력 | 사다리 |
|------|--------|
| 잿빛 탑 '잿빛 눈' | 사냥개 계약 밀정(이졸) → 잿빛 눈 정원(12) → 대장(카르바) |
| 목줄단 | 혀 → 목줄 → 목줄장 → 수석 목줄장(에베르트) |
| 멜리산드 회수조 | 실험실 조수 → 회수조원 → 회수조장('운구꾼' 페트르) |
| 비늘기사단 (하스트란) | 견습 기사 → 기사 → 백인대장 → 부단장 |
| 순종의 빛 정화청 | 심문 보조 → 심문관 → 정화관 |

- **추종자**는 B등급 NPC로 즉석 생성된다 (08 §2 승격 규칙). 추종자 한 명 한 명이 플레이어가 돌려세우거나 죽일 수 있는 사람이고, **숙적의 후계자 후보**다(§3.10.1). 장면 D의 '먼저 먹는 개'가 그 예다.
- 숙적이 계급을 잃으면(강등) 자원도 잃지만 집착 +20 — **떠돌이 숙적**이 된다: 세력의 보호도 제약도 없다.

### 3.6 추적 거리 — 얼마나 가까이 왔나

| 거리 | 이름 | 의미 | 플레이어에게 보이는 것 (정보가 있을 때) |
|------|------|------|----------------------------------------|
| 0 | 잃음 | 어디 있는지 모른다 | — |
| 1 | 소문을 쫓음 | 다른 지역에서 소문을 모은다 | "그로드가 루멘에서 당신을 묻고 다닌다더라" |
| 2 | 지역 안 | 같은 지역. 1~2주 안에 마을까지 온다 | 사냥 야영지의 연기, 목줄꾼이 수탉에 나타남 |
| 3 | 마을 안 | 며칠 안에 마주친다 | 개 짖는 방향이 바뀐다, 혀가 따라붙는다 |
| 4 | 문 앞 | 1~3일 안에 조우 생성 (§3.9 쿨다운 우선) | 장면 상단 막대 ▮▮▮▮▯ |

**매주 진행 판정** (01 문서 로지스틱 공식)

```
S = 숙적 추적 스킬/2 + 집착/4 + 계급 보정(0/5/10/15) + 정보원 수 × 3
  + 흔적 보정 (지난 7일 플레이어가 남긴 '목격된 흔적' 사건 수 × 4, 최대 +20)
  + 냄새 (바르그·수인족 숙적만 — 03 §7.1의 냄새 값을 그대로, 최대 +30)
D = 25 + 플레이어 은신/3
  + 지역 이동 보정 (이번 주 다른 지역으로 이동 +15, 같은 지역 내 은신처 이동 +5)
  + 냄새 지우기 (바르그 숙적만, +20 — 교훈 #3이 있으면 +10)
  + 은신처 은폐 (09 영역 은폐도/4)
  + 정세 창 (11 §2.2, +10)
결과: 대성공 +2 · 성공 +1 · 부분 성공 +1 (단, 플레이어에게 '들킨 흔적' 경고) · 실패 0 · 대실패 −1 (가짜 흔적)
```

- 거리 2 이상에서 4주 연속 진행이 없으면 −1.
- **회귀하면** 모든 숙적이 휴면 숙적이 되고 거리가 0이 된다. 바르그·수인족 휴면 숙적은 냄새 때문에 **첫 알아챔 날이 당겨진다** (§3.7.2). 기시감 45+인 시간에 민감한 숙적은 거리 1에서 시작한다 (§3.7.3).

### 3.7 회차를 넘는 연결 — 그는 잊고, 당신은 기억한다

#### 3.7.1 회귀하면 — 휴면 숙적

| 숙적 쪽 (세계) | 플레이어 쪽 (영혼) |
|----------------|--------------------|
| 원한·집착·공포·존경 → 회귀점 값 (대개 0) | 사냥꾼 판 전체 (`〔회차 n〕` 꼬리표) |
| 흉터·칭호·교훈·공로·계급 → 회귀점 상태 | 그의 교훈과 반격 수, 약점, 습관, 야영지·동선·일정 (지식 카드) |
| 의심·믿음 단계·보고 여부 → 0 / 1 / 없음 | 그를 어떻게 끝냈는지 (해소 지식 — 같은 해소 판정 +15) |
| 전리품 → 원래 주인에게 (성표는 게르다의 목에) | 죽음의 기억 — 그에게 죽었다면 `이빨의 기억` 등 (03 §4.1) |
| **숙적 상태 → '휴면 숙적'** (`dormant_past`): 숙적은 아니다. 냄새·기시감·의심 규칙만 돌아간다. 다시 상처 사건이 나면 숙적 생성 판정 — 그때 휴면 중 쌓인 의심은 이어진다 | `pastNemesis` 기록: 함께한 회차 수 (업적 ACH-05의 카운트) |

- 휴면 숙적은 B등급 이상으로 유지되고 18 문서가 스포트라이트 후보로 먼저 본다. 지난 회차의 원수가 이번 회차에 다시 원수가 될지는 플레이어의 선택이다 — 그를 피하면 그는 끝까지 '이유 없이 신경 쓰이는 농노'를 쫓는 평범한 사냥꾼으로 남는다.
- **각성 전의 셋째에게는 흔적이 없다.** 잔향은 회귀점(배식대의 칼자국, SCENARIOS O-01)에서 처음 깨어난다. 회귀점 이전의 셋째를 알던 사람의 기억 속 그 아이에게는 냄새가 없다 — 그 기억이 '변화 감지'의 기준선이다.

#### 3.7.2 냄새 — 코 좋은 사냥꾼이 회차마다 조금 더 일찍 오는 이유

젖은 재 냄새는 몸이 아니라 영혼에서 난다. 회차가 쌓일수록 짙어지고, 씻어도 지워지지 않는다 (03 §7.1). 바르그·수인족(감각 16+) 숙적과 휴면 숙적에게:

```
냄새 = min(30, 3 × loop.count^0.7)              (03 §7.1 — 잿빛 모드 ×2, 이야기 모드 ×0.5)
첫 알아챔 날 = 기본일 × max(0.2, 1 − 냄새/40)      기본일 = 첫 회차에 그가 처음 플레이어를 알아챈 날
휴면 숙적의 첫 만남 의심 = 냄새 × 2                (§2.3: loop.count 1 → +6)
추적 판정 보정 = +냄새                             (§3.6)
```

| `loop.count` | 냄새 | 그로드의 첫 냄새 (기본 22일) | 그가 하는 말 (예) |
|--------------|------|------------------------------|-------------------|
| 1 | 3 | 20일 | "젖은 재… 처음 맡는 냄새다." |
| 2 | 4.9 | 19일 | "킁. 너, 어디서 굴러먹었냐. 재 냄새가 진하다." |
| 5 | 9.3 | 17일 | 이유 없이 회색여울 체류를 앞당긴다 |
| 10 | 15 | 14일 | 회귀점 둘째 주에 배급 줄 끝에 서 있다 |
| 17 | 21.8 | 10일 | "…너. 이 냄새. 꿈에서 맡은 것 같군." (꿈이 아니다. 그는 기억하지 못한다) |

**냄새 단계** — 주인공이 느끼는 표지와 회색여울의 첫 사냥꾼들 (14 §4.1 ⑦·§7.4와 같은 문턱)

| `loop.count` | 냄새 | 회귀 시퀀스 ⑦ 첫 줄 (14) | 사냥꾼 |
|--------------|------|--------------------------|--------|
| 0 (첫 회차) | 0 | — | 볼크는 B창 죽음의 순간에만 맡는다. 9.14 `volk_sniff`는 **흔적 등록**만 한다 — 숙적 생성이 아니라, 그 회차에 볼크가 숙적이 되면 첫 의심값이 되는 `scent_ash` 기록 |
| 1~3 | 3~6.5 | "빵 냄새. / 나는 — 이 냄새를 안다." | 볼크의 9.14 냄새 판정(D45) 난이도 −5/회차. 휴면 숙적의 첫 의심 = 냄새 × 2 |
| 4~11 | 7.9~16.1 | **"빵 냄새. 그 밑에, 젖은 재."** | 첫 알아챔 날 ×0.8 이하. `loop.count` 5부터 송곳니 불의 사냥개가 회귀점 첫날 수탉 앞에서 운다 |
| 12+ | 17.1~30 | **"젖은 재. 그 위에, 빵 냄새."** (순서가 뒤집힌다) | 첫 알아챔 날 ×0.57 이하 — 바르그 숙적이 회귀점 첫 주 안에 코를 돌린다 (회귀 직후 유예 3일 뒤) |

- 냄새는 **앎이 아니라 낌새**다. 그는 당신이 누구인지 모른다. 이 냄새가 왜 신경 쓰이는지도 모른다. 그래서 그의 의심은 언제나 '익숙함' 구간에서 시작하고, 그 위는 이번 회차의 흔적으로만 오른다.
- 덮는 것(무두장 냄새·늪 약초 연기·강물·녹테른의 피 향 — 03 §7.1)은 회차 안에서 통한다. 교훈 #3 「약 냄새를 쫓는다」는 같은 회차에 같은 덮개를 두 번 쓰면 생긴다.
- 재능 「재 냄새 억제」(06 §5.9)와 결점 「짙은 잔향」(06 §8.1)이 이 값을 바꾼다.

#### 3.7.3 기시감 — 시간에 민감한 숙적

정본의 셋 — 엘다르(존속파·영원 여왕이 가장 강함), 용황 바르스카르, 잿빛 탑(탑주·시간 학파) — 만이 회귀의 낌새를 느낀다. 그들의 하수인(이졸 같은 탑의 사냥개)은 스스로 느끼지 못하지만 **주인의 낌새를 따라 파견된다.**

```
기시감[존재] = loop.count × 감도 + 접촉 보정            (03 §7.2 — 감도: 바르스카르 1.5 · 존속파·여왕 1.2 · 탑 1.0 · 그 외 엘다르 0.6)
```

| 기시감 | 숙적으로서 |
|--------|-----------|
| 10~24 | 첫 만남 대사가 바뀐다 ("…낯설지 않은 아이로구나"). 휴면 숙적의 첫 만남 의심 +10 |
| 25~44 | 회귀점부터 **숙적 후보**(원한 40 상당)로 시작한다 — 상처 사건 하나면 숙적이 된다. 하수인 파견이 한 계절 이르다 |
| 45~69 | 회귀점부터 **숙적 상태**(사냥 중, 거리 1)로 시작한다. 진짜 죽음의 수단(유리 칼·시간의 그물)이 회색여울 방면으로 움직인다 — 얇아짐 예고(03 §4.5) |
| 70+ | 첫 달 안에 거리 4. 그들이 숙적일 때 조우는 진짜 죽음의 자리일 수 있다 |

- **이졸** (탑의 사냥개 — 그 자신은 감도 0, 탑의 기시감을 따라 움직인다. 수치는 14 §7.4와 공동 소유): 회색여울 도착 9.18 → `loop.count` 3부터 회차당 하루씩 이르게 (최대 9.12) · 첫 응시 3초 → 회차당 +0.5초 (최대 6초) · 플레이어의 징후 숨김 판정 −2/회차 (최대 −10). 탑주 이레네의 기시감이 25+면 이 최대치에 바로 닿는다.
- 시간에 민감한 숙적도 **기억하지 못한다.** 교훈·흉터·칭호는 그들에게도 회귀와 함께 사라진다. 다르게 오는 것은 시점과 거리뿐이다.
- 그래서 이 숙적들은 회차가 쌓일수록 더 위험해지는 유일한 숙적이고, 그들의 해소는 대개 **피하는 것**이다 — 그들이 오기 전에 이번 회차의 일을 끝내는 것.

#### 3.7.4 의심 — 회차 안에서만 쌓인다

`의심[숙적]` 0~100, **그 회차 안에서.** 조우·관찰마다 흔적 가중치를 더한다. 접촉이 없으면 주당 −5. 회귀하면 0 (휴면 숙적의 첫 만남 값에서 다시).

| 흔적 | 기록 조건 | 드러나는 조건 | 가중치 (의심 +) |
|------|-----------|---------------|-----------------|
| **젖은 재 냄새** | 바르그·수인족 숙적이 가까이에서 맡음 | 언제나 (회귀점 이후) | 냄새 × 2 (최대 40). 지난 24h 잔향 사용(앞선 잔향자의 꿈·진명·잔향의 눈 발현) 시 +15 |
| **버릇** (전술 태그) | 이 회차에 숙적 앞에서 같은 전술 태그를 쓴 횟수 = 강도 (최대 3) | 같은 태그의 선택을 숙적(또는 그의 추종자·정보원) 앞에서 고름 | 6 × 강도 |
| **말버릇** | 숙적에게 직접 한 고유한 말(도발·맹세·이름), 또는 같은 어조 선택지 3회 | 같은 말 선택지 / 같은 어조 | 같은 말 10 × 강도, 같은 어조 +3 |
| **앎의 흔적** (지식) | — (엔진이 판정: 그 사실을 플레이어가 이번 회차에 알 수 있었는가 — 03 §4.3) | 숙적 앞에서 이번 회차에 알 리 없는 것을 말하거나 그것에 반응함 (처음 보는 그의 이름, 아직 없는 흉터를 찾는 눈, 아직 일어나지 않은 야영지 이동) | 말함 20 · 행동으로 드러남 10 |
| **잿빛 고리** | 숙적이 고리를 본 적 있음 (렌즈 또는 통찰 60+) | 각성도 3 이상 상시, 또는 잔향 사용 24h 내 | 25 (렌즈 소지 시 ×1.5) |
| **목소리 새어 나옴** (15) | — | 목소리가 입을 빼앗음 (15 문서의 '새어 나옴' 판정 실패) — 지난 회차의 나(`loop:{n}`)가 그 숙적에게 했던 말을 숙적 앞에서 | 30 |
| **변화 감지** | 숙적이 **회귀점 이전의 그 사람**을 앎 (08 관계 있음 — 예: 마을 혀를 통해 셋째를 알던 목줄장) | 그 사람답지 않은 선택 (성향 차이 40+ 방향의 선택, 이전에 없던 관계 행동) | 5 × 횟수 (최대 30) |

| 의심 | 구간 | 숙적이 하는 일 |
|------|------|----------------|
| 0~24 | 모름 | 아무것도 |
| 25~49 | **익숙함** | 쳐다본다. 정보원에게 이 사람을 지켜보라 한다(거리 최소 2). '시험' 조우 가중치 +20 |
| 50~74 | **의심** | 시험한다(§3.7.5). 감시 거리 최소 3 |
| 75~99 | **확신 근접** | 행동한다: 직접 사냥 / 인질 / 세력 보고 여부 결정(§3.7.6) |
| 100 | **알아봤다** | 이 농노가 '잔향 징후자' — 아니, 진짜라고 믿는다. 10 문서의 정체 연결과 같은 처리 — 이 숙적에게만은 '돌아오는 이'가 공개된 것과 같다. 회차가 끝나면 사라진다 |

- 젖은 재 냄새는 볼크의 첫 대사(CHARACTERS R02-07 "너한테서 젖은 재와 은화 냄새가 나는구나")를 잔향의 냄새로 정식화한 것이다. **평범한 인간에게는 없는 냄새**이므로 '특별한 것은 주인공뿐'과 충돌하지 않는다 — 냄새를 맡는 쪽은 그저 좋은 코일 뿐이다.
- **비대칭의 무기와 값**: 플레이어는 지난 회차의 숙적을 안다. 그것을 쓰면 판정이 쉬워지고(지식 선택지), 그것을 드러내면 앎의 흔적이 남는다. 같은 지식이 무기이자 흔적이다.

#### 3.7.5 시험 — 숙적의 대항 판정

의심 25 이상에서 '시험' 조우가 생기면:

```
숙적 S = 통찰 (냄새 시험이면 추적·사냥) + 의심/4 + 흔적 보정(이번 시험에 쓰인 흔적의 가중치/2)
플레이어 D = 기만 + 의지보정 + 패턴 깨기 누적 보너스(§3.8) + 상황(가면·변장 02)
플레이어 성공: 의심 −15, 숙적 공포 +5 ("헛것을 맡았나") / 대성공: −25, 이 숙적의 다음 시험까지 30일
플레이어 실패: 의심 +25 / 대실패: +40, 그리고 숙적이 그 자리에서 행동 (구간 무시)
```

- 시험 수단은 숙적이 **이번 회차에 가진 정보**에서 나온다: 이름 부르기, 전리품 보이기, 가족을 앞에 세우기, 물가로 데려가기, 그리고 회귀자에게만 통하는 것 — **아직 일어나지 않은 일로 떠보기** ("내일 볼크 영감이 오는데, 알고 있었냐?"). 회귀자는 정답을 알아서 실패한다.

#### 3.7.6 믿음 단계와 보고 — 회차 안에서

| 믿음 단계 | 조건 (그 회차 안) | 숙적이 하는 일 |
|-----------|------------------|----------------|
| 1 **원한** | 기본 | 사냥감으로 쫓는다 |
| 2 **징후 의심** | 의심 75 이상, 또는 잔향 사냥 경험이 있는 세력(조합·탑·정화청) 소속이며 젖은 재/잿빛 고리 흔적을 기록함 | "이놈은 평범한 탈주 농노가 아니다." 플레이어의 **알려진 인연**(가족·제자·동료·연인)을 감시해 플레이어를 찾는다 — 인질 가중치 +10 |
| 3 **잔향 확신** | 의심 100, 또는 탑의 판별(진명 '타는 시간' 0 — HOUSES §5.8) | **보고 결정**(아래) |

믿음 3단계에 이른 숙적은 그 사실을 세력에 알릴지 고른다.

| 정책 | 가중치 | 결과 (그 회차 안) |
|------|--------|------|
| `report` 보고 | 충성 + 40 | 세력 대응 단계 +1 (10 §5), 숙적 공로 +40 + 잔향 칭호. 그 대신 사냥은 세력의 것이 된다 (탑·멜리산드가 넘겨받으려 함 — 탑이 받으면 유리 칼이 움직인다, 얇아짐 예고) |
| `withhold` 독점 | 집착 + 탐욕/2 | 혼자 쫓는다. 세력에 거짓 보고 → **약점 사실 생성** (`fact_<id>_withholds_returner`, danger 4). 플레이어가 이 사실을 알면 협박·폭로(11) 가능 |
| `sell` 판매 | 탐욕 + 20 (바르그 조합은 +20 추가: "산 채로 최고가" — HOUSES §6.2) | 최고 입찰자(탑·멜리산드·원로회)와 거래. 숙적이 다른 세력의 하수인처럼 움직이기 시작 |

- **플레이어의 죽음은 회차의 끝이다.** 숙적이 플레이어를 죽이면 그의 승리·보고·칭호는 그 세계와 함께 사라진다. 다만 보고를 받은 세력이 시간에 민감한 세력(잿빛 탑·엘다르)이었다면 접촉 보정 +2가 남는다 (03 §7.2) — 그들은 기억하지 못하지만, 다음 회차에 조금 더 일찍 북쪽을 본다.
- 숙적이 플레이어를 **진짜로** 끝낼 수 있는 것은 그가 진짜 죽음의 수단을 쥐었을 때뿐이다 — 탑에 판 플레이어가 유리 칼 앞에 서거나, 엘다르의 그물 안으로 넘겨지거나. 이 경우 03 §4.5의 예고 규칙을 그대로 따른다.

### 3.8 패턴 깨기와 가짜 버릇

플레이어는 숙적이 기억하는 자신을 **일부러 배반**할 수 있다.

| 장치 | 규칙 |
|------|------|
| **익숙한 수 표시** ◐ | 숙적이 **이번 회차에** 기록한 흔적과 같은 선택지에 표시. 조건: 플레이어가 그 흔적을 안다 (사냥꾼 판에 목격·소문으로 있음, 또는 15 문서의 목소리가 경고함). 모르면 표시 없음 — 모르고 같은 수를 둔다 |
| **지난 회차의 수** ◐ | 지난 회차에 그 숙적에게 쓴 수. **이번 회차의 그는 모른다** — 교훈이 없다. 표시는 플레이어의 기억이 경고하는 것이지 숙적의 기억이 아니다 (§2.3) |
| **패턴 깨기** ◑ | 익숙한 수가 아닌 다른 길을 고르는 것. 그 장면의 판정 −8 ("몸이 아는 길을 거스른다") 또는 스트레스 +5 중 플레이어 선택. 숙적 앞에서 패턴 깨기 1회마다 누적 보너스 +3 (시험 방어, 최대 +15, 회귀하면 초기화) |
| **가짜 버릇** | 숙적(또는 그의 정보원) 앞에서 같은 '가짜' 전술 태그를 3번 쓰면 숙적이 그것을 버릇으로 기록하고 그에 대한 교훈을 준비한다. 다음 조우에서 그 교훈이 빗나가면 플레이어 판정 +15, 숙적 공포 +5 |
| **아는 얼굴 부정** | 지난 회차에 당신을 죽인 그를, 또는 그가 지난 회차에 잡아간 사람을 처음 보는 척하기 — 의지 D (25 + 죽음의 기억 보정 + 그 사람에 대한 애정/2). 실패하면 앎의 흔적(행동) |

- 패턴 깨기는 15 문서와 맞물린다: 지난 회차의 나(`loop:{n}`)는 그 회차에 통했던 수를 **원한다**(회차 1의 셋째는 강으로 뛰고 싶어 한다). 패턴을 깨는 것은 목소리를 누르는 것이다.

### 3.9 조우 생성 — 사냥꾼의 수

숙적 AI는 **매주** 한 수를 고른다 (10·11 문서의 세력 AI 주기와 같다). 거리 4에 도달하면 조우 장면을 만든다.

| 수 | 기본 가중치 | 보정 | 조건 |
|----|-------------|------|------|
| 추적 (거리 판정만) | 40 | + 집착/2 | — |
| **매복** | 30 | + 집착/2 − 공포/2 | 거리 4 |
| **함정** | 15 | + 지능 × 2 + 공포/4 | 거리 3+ |
| **협상·거래** | 10 | + 탐욕/3 + 존경/2 | 교훈 #8 없음 |
| **인질** | 0 | + 공포/3, 자비 ≤ −40이면 +20 | 숙적이 플레이어의 애정 70+ 인연을 앎(`known_by`). **같은 숙적은 한 회차에 1회**. 존경 60+면 불가 |
| **시험** | 0 | 의심 25~49: 20 / 50~99: 40 | 의심 25+ (휴면 숙적 포함) |
| **대리 사냥** (추종자·현상금·밀고자) | 10 | + 공포/2 | 추종자 또는 정보원 2+ |
| **공개 도발** (현상금 게시, 모욕 소문) | 10 | + 치욕 칭호 수 × 10 | — |
| **보고·승진 시도** | 5 | 공로가 다음 계급 조건 충족 시 +30 | — |
| **회복** | 부상 중이면 60 | — | 중상 이상 |
| **경쟁 숙적 견제** (§3.11) | 0 | 같은 지역 다른 숙적 거리 3+면 25 | — |
| **주인 배신 제안** (§3.11) | 0 | `withhold` + (탐욕 30+ 또는 집착 80+)면 20 | 믿음 3 |

**빈도 상한** (18 문서가 이 안에서 긴장 곡선을 조절한다)

| 상한 | 값 |
|------|-----|
| 같은 숙적의 조우 간격 | 최소 **10 게임일** |
| 스포트라이트 숙적 | 7일에 최대 1회 |
| 모든 숙적 합계 | 7일에 최대 **2회** |
| 회귀 직후의 유예 | 회귀점 후 **3 게임일** 동안 숙적 조우 없음 (플레이어가 찾아가면 예외). 냄새로 당겨진 첫 알아챔 날도 4일째 이후로 미룬다 — 빵 냄새가 먼저다. 14 문서의 첫 시간 설계와 맞출 것 |
| 같은 유형 연속 금지 | 같은 숙적이 같은 수(매복·인질 등)를 연달아 쓰지 않는다 |

### 3.10 해소 — 숙적을 끝내는 여섯 가지 방법

| 해소 | 조건 | 즉시 결과 | 이후 |
|------|------|-----------|------|
| **죽임** | 전투·암살(11)·사고·다른 세력의 손 | 숙적 종료. 세력 반응(10 평가표), 공로·현상금 | **원한 상속** 판정(§3.10.1) |
| **전향** | 존경 50+ **그리고** 지렛대 1개(그의 세력 안 약점, 가족의 안전, 더 나은 주인) + `[화술 vs 숙적]` | 동료(08) 또는 정보원. `옛_숙적` 플래그 | 집착이 40 이상 남아 있으면 계절마다 배신 판정 (집착 − 존경 + 20)% |
| **모욕** | 그를 이기고 **살려 둔다**, 자기 세력 목격자 3+ 앞에서 | 공로 −20, 강등 판정 (계급 단계 × 20%), 치욕 칭호 | 공포 ≥ 80이면 **꺾인 자**(사냥 중단). 집착 ≥ 80이면 **떠돌이 숙적**(더 위험, 자원 적음). 그 사이면 공포 +15·집착 +20 |
| **꼭두각시** | 그의 약점 사실(08 Fact, danger 3+)을 쥐고 협박(11 §3.6) | 그가 세력 정보를 흘리고 거짓 보고를 한다 | 매 계절 반발 판정: 원한/2 − 공포/3 %. 반발하면 사실 은폐를 시도(정보원 처리) 후 사냥 재개 |
| **사냥꾼의 예** | 존경 60+ **그리고** 숙적 정직 ≥ 0 **그리고** 플레이어가 그에게 한 약속을 지킨 기록 1+ | `pact` — 규칙 있는 적. 인질·함정·대리 사냥 금지, 사냥 전 통보 | 볼크의 "사흘 유예"가 원형. 숙적이 이 예를 깨면 그의 세력 내 시선 −(바르그는 '정직한 사냥'을 존중한다) |
| **당신을 죽임** | 숙적이 플레이어를 죽임 | **회차 종료.** 회차 기록의 '사냥꾼들' 항목에 그의 마지막 수와 전리품이 적힌다 | 회귀하면 그는 그 승리를 모른다. 플레이어에게 죽음의 기억(`이빨의 기억` 등, 03 §4.1 — 그와 처음 마주칠 때 첫 합 −5, 같은 숙적에게 세 번 죽으면 특성으로 굳는다). 그의 교훈 목록이 사냥꾼 판에 `〔회차 n〕`으로 자동 공개된다 — 그가 어떻게 이겼는지 당신은 안다. `pastNemesis` 회차 수 +1 (ACH-05) |

- **해소는 회차 안의 것이다.** 죽인 숙적은 다음 회차에 살아 있고, 전향시킨 숙적은 다시 사냥꾼이며, 꼭두각시의 약점은 아직 만들어지지 않았을 수도 있다(그로드가 세타를 죽이는 것은 325년이다). 남는 것: 그를 어떻게 끝냈는지에 대한 앎(같은 해소 판정 +15)과 업적.
- **아는 적, 모르는 적**: 숙적을 죽이면 그의 자리는 후임이 채운다 (§3.5 사다리). 후임은 플레이어가 모르는 사람이고, 지난 회차의 기억이 통하지 않는다. 긴 회차를 계획하는 회귀자는 지난 회차의 숙적을 **살려 두는 쪽**을 고를 이유가 있다(장면 F).
- **늙음**: 숙적도 늙는다. 긴 회차에서 수명의 70%를 넘으면 계절마다 '마지막 사냥' 조우 가중치 +10 — 늙은 숙적은 끝을 보고 싶어 한다(장면 F). 회귀하면 그는 다시 젊다.
- **잠듦에서의 귀환**: 잠든 원한은 플레이어의 흔적을 보는 순간(정보원 보고 포함) 깨어남 판정. 10년 넘게 잠든 숙적은 깨어날 때 교훈 1개를 잊는다.

#### 3.10.1 원한 상속 — 죽인 숙적이 남기는 것

숙적이 죽으면, 그와 **애정 60+** 인 사람(가족·무리·추종자·제자) 각각에 대해:

```
상속 확률 = 30% + 숙적의 집착/4 + (플레이어가 죽인 방식이 잔혹했으면 +15, 공개 처형 +20) − (상속자 공포/2)
최대 1명만 상속 (가장 확률 높은 자). 상속자는 숙적 생성 조건을 자동 충족한 것으로 본다.
```

- 상속자는 **교훈 1개와 흔적 기록의 절반**(가장 강한 것부터)을 물려받는다 — 숙적이 가족에게 이야기했다는 뜻이다. "아버지는 늘 말했지. 그놈은 물을 건넌다고."
- 바르그는 무리(= 가족)이므로 상속이 잘 일어난다. 이것이 볼크가 죽으면 이르가 또는 강경파가 이어받는 정본(CHARACTERS R02-07 사망 시 영향)과 맞물린다.

### 3.11 숙적끼리, 그리고 주인을 배신하는 숙적

**경쟁** — 같은 지역에 숙적 둘 이상이 거리 3+로 들어오면 매주 25% 확률로 경쟁 사건.

| 조합 (예) | 그들이 원하는 것 | 플레이어가 할 수 있는 것 |
|-----------|------------------|--------------------------|
| 그로드 ↔ 세타 | 사냥대장 자리 (둘 다 송곳니) | 한쪽에 다른 쪽의 사냥 경로를 흘려 공을 빼앗게 하기 → 패자 강등·떠돌이화 |
| 그로드 ↔ 이졸 | 그로드: 죽이거나 팔기 / 이졸: 산 채로 탑에 (해방 증서) | 둘이 같은 밤 같은 은신처에 오게 하기 → 서로를 방해 (판정 −10씩), 피 흘리게 하기 |
| 이졸 ↔ 페트르 | 탑 vs 멜리산드 — 같은 '그릇'을 노림 | 한쪽의 증거를 다른 쪽 주인에게 넘기기 |
| 하겐 ↔ 이르마 (복수자) | 하겐: 숨기 / 이르마: 남편의 원수 | 이르마에게 진실을 알리면 이르마가 하겐의 숙적이 된다 — **숙적이 숙적을 만든다** |

**주인 배신** — `withhold` 숙적은 비밀을 품고 있다. 두 방향이 있다.
1. **숙적의 제안**: "네가 도망칠 시간을 주지. 대신 네가 세타를 치워라." 플레이어가 받아들이면 숙적의 공로 경쟁자가 사라지고, 숙적은 빚(08 거래 엣지)을 진다.
2. **플레이어의 폭로**: 숙적이 잔향을 숨긴 사실을 그의 주인(볼크·카르바·멜리산드파)에게 흘린다 → 숙적은 자기 세력에게 쫓긴다 (숙적의 숙적이 숙적의 주인이 된다). 숙적 집착 +20, 그리고 이제 그는 잃을 것이 없다.

### 3.12 어둠의 길이 만드는 숙적 — 피해자의 가족

13 문서의 길을 걸으면 **인간 숙적**이 생긴다. 그들은 약하다. 그래서 다르게 싸운다.

| 유형 | 생성 | 싸우는 법 | 예 |
|------|------|-----------|-----|
| **복수자** | `kin_sold`, `kin_killed` (피해자 가족, 애정 70+) | 직접 전투 거의 없음. 밀고(목줄단·조합에 플레이어 위치 판매), 독, 플레이어의 가족 노리기, 소문(10) | 노예상 플레이어가 판 에길 가족의 아내 룬 |
| **자라는 숙적** | 피해자의 아이 (당시 15세 미만) | **잠든 원한**으로 시작. 그 아이가 16세가 되는 해에 깨어남 판정 (집착 = 사건 당시 아이의 애정/2 + 20) — 긴 회차에서만 | 에길의 맏아이(9세) — 같은 회차의 7년 뒤 사냥꾼이 되어 있다 |
| **배신당한 동료** | `betrayed` (13 '배신자' 경로) | 플레이어의 비밀을 가장 많이 안다 → 지식이 무기. 시험이 가장 정확하다 (지식 흔적 가중치 ×1.5) | 팔아넘긴 연인 |

- 자라는 숙적은 회귀하면 다시 아홉 살이고, 아직 아무도 그의 가족을 팔지 않았다. 다음 회차에 그 아이를 처음 마주칠 때 주인공 쪽에만 장면이 붙는다 — 13 문서 §3.2의 **재회**(얼룩 판정)와 같은 장치다. 그 아이는 아무것도 모른다. 당신이 이번에도 팔지 않는 한.
- 어둠의 길로 얻은 효율(13 §1)에는 이 지연된 값이 붙어 있다. 설교 없이, 그냥 같은 회차의 7년 뒤에 문을 두드리는 사람으로 — 또는 다음 회차의 배급 줄에서 아무것도 모른 채 당신 옆에 선 아이로.

### 4.1 TypeScript

```ts
type NemesisStance = 'hunting'|'dormant'|'pact'|'pawn'|'turned'|'broken'|'rogue'|'dead'|'archived'
                   | 'dormant_past';              // 회귀점의 휴면 숙적 (§3.7.1)
type BeliefTier = 1 | 2 | 3;                     // 원한 / 징후 의심 / 잔향 확신 — 회차 안
type TraceKind = 'scent_ash'|'habit'|'speech'|'knowledge'|'ash_ring'|'voice_slip'|'change';

// ── 세계 쪽: 회귀하면 회귀점 상태로 (휴면) ──

interface NemesisProfile {
  npc: NpcId;                                    // 숙적은 인물 위에 얹힌다 (08)
  origin: { event: EventId; kinds: WoundKind[]; score: number; date: GameDate };
  stance: NemesisStance;
  spotlight: boolean;                            // 이번 회차의 주 숙적 (18)
  mind: { grudge: number; obsession: number; fear: number; respect: number };  // 0~100
  belief: BeliefTier;
  reportPolicy?: 'report'|'withhold'|'sell';     // belief 3에서 결정
  scars: { id: ScarId; part: BodyPart; by: 'player'|NpcId; date: GameDate }[];
  titles: { id: TitleId; kind: 'shame'|'glory'|'returner'; text: string; known_in: RegionId[] }[];
  lessons: { tactic: TacticTag; counter: LessonId; lastUsed: GameDate }[];
  rank: { faction: FactionId; tier: number; merit: number };
  followers: NpcId[];                            // B등급 즉석 생성, 후계자 후보
  distance: 0|1|2|3|4;
  watchKin: NpcId[];                             // belief 2+ : 플레이어의 알려진 인연 (인질·감시)
  firstNoticeDay?: number;                       // 이번 회차에 처음 알아챈 날 (냄새로 당겨짐, §3.7.2)
  dejaVu?: number;                               // 시간에 민감한 존재만 (03 §7.2)
  trophies: ItemId[];                            // 플레이어 시체에서 가져간 것
  traces: TraceRecord[];                         // 이 회차에 본 흔적 (회귀하면 비움)
  encounters: EncounterRecord[];
  pact?: { rules: PactRule[]; since: GameDate };
  heirOf?: NpcId;                                // 원한 상속으로 생긴 숙적
}

interface TraceRecord {
  kind: TraceKind; key: string;                  // 예: habit:물건너기, speech:taunt.ask_your_nose
  strength: 1|2|3;
  firstSeen: GameDate; lastSeen: GameDate;
}

interface Recognition {                          // 숙적 × 이번 회차
  nemesis: NpcId; suspicion: number;             // 0~100, 휴면 숙적은 냄새×2에서 시작
  evidence: { kind: TraceKind; key: string; delta: number; at: GameDate; scene: SceneId }[];  // 16 메아리 알림의 원천
  patternBreaks: number;                         // §3.8 누적 (최대 5 → +15)
}

interface EncounterRecord {
  id: EventId; date: GameDate; move: NemesisMove;
  decisiveTactic?: TacticTag; outcome: 'escaped'|'won'|'lost'|'killed_player'|'captured_player'|'resolved';
  woundsTo: { who: 'player'|'nemesis'; part: BodyPart; severity: 1|2|3 }[];
}
// ── 영혼 쪽: 회귀해도 남는다 (플레이어의 기억) ──
interface PastNemesis {
  npc: NpcId;
  loopsShared: number[];                         // 숙적이었던 회차 번호들 — ACH-05 「세 회차의 원수」
  firstNoticeByLoop: Record<number, number>;     // 사냥꾼 판 '첫 냄새' 줄
  knownLessons: { tactic: TacticTag; loop: number }[];
  knownScars: { part: BodyPart; loop: number }[];
  knownWeaknesses: FactId[];                     // 지식 카드 (표류 가능 ◇)
  resolvedBy?: { kind: ResolutionKind; loop: number }[];   // 같은 해소 판정 +15
  killedPlayerInLoops: number[];                 // 죽음의 기억
}
// 회귀: onRegression() → 모든 NemesisProfile을 회귀점 스냅숏으로 되돌리고 stance='dormant_past' → PastNemesis 갱신
// 매주: nemesisTick() → 수 선택(§3.9) → 거리 판정(§3.6) → 거리 4면 조우 장면 큐 (18 문서가 빈도 상한 안에서 배치)
// 조우 후: applyEncounter() → 흉터·칭호·교훈·공로·마음 갱신 → Fact 생성(08) → 소문(10) → 메아리 대기열(16)
```

## 8. 수직 슬라이스 범위

**반드시 들어갈 것**
1. 숙적 생성: 상처 사건 10종, 슬롯(활성 3·잠듦 8), 스포트라이트 1.
2. 고유 숙적 시드 6명 (그로드 완전판 — 장면 A·B·C의 틀 포함, 나머지 5명은 재회·흉터·칭호·최후 대사).
3. 마음 4수치와 행동 성향표, 흉터 15·칭호 30, 교훈 12종과 반격 수.
4. 추적 거리 5단계 + 주간 판정, 사냥꾼 판(조합 탭).
5. 알아봄: 흔적 7종 중 **젖은 재·버릇·말버릇·지식·잿빛 고리·변화** (6종) + 시험 판정 + 패턴 깨기 ◐/◑.
6. 회귀 처리: 숙적 휴면·초기화, `PastNemesis`, 사냥꾼 판 `〔회차 n〕` 꼬리표, 냄새에 의한 첫 알아챔 당김. 믿음 1~2단계. 슬라이스 안에서 플레이어가 죽으면 **다음 회차에서 스포트라이트 숙적과의 '처음 보는 원수' 조우(장면 C)가 2시간 안에 한 번 보장**된다 (회차를 넘는 비대칭을 반드시 체험하게).
7. 조우 수 8종 (추적·매복·함정·협상·인질·시험·대리 사냥·공개 도발), 해소 6종 전부, 원한 상속(바르그 무리만).
8. 연동: 05 개념 12종, 08 Fact, 10 대응 2단계 집행자 배정, 16 메아리 알림 3종(의심·교훈·칭호), 15 목소리 반응 36줄.

**나중으로 미룰 것**
- 믿음 3단계의 보고·판매 정책과 세력 대응 연동, 주인 배신 (슬라이스는 3~8시간 — 한 회차 안에서 확정까지 가기 어렵다).
- 숙적끼리의 경쟁 (그로드↔세타는 1.0의 바알카르·서리 길 확장 때).
- 자라는 숙적, 배신당한 동료 (13 문서 경로가 슬라이스에 일부만 있음).
- 목소리 새어 나옴 흔적 (15 문서의 새어 나옴 판정이 확정된 뒤).
- 공중 숙적의 하늘 교훈, 멜리산드 회수조·탑 잿빛 눈 사다리, 다른 세력 사다리 7개.
- 기시감 숙적(이레네 볼드·아에린)의 회귀점 시작 상태, 긴 회차(10년+)의 숙적 경력 서술 (회차 기록 '사냥꾼들'의 전체판).
