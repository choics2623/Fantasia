# 01. 능력치와 판정 시스템

> 목표: 같은 선택지라도 **누가, 무엇을 들고, 어떤 상태로, 누구에게** 하느냐에 따라 확률과 결과가 달라진다.
> 그리고 그 확률은 숫자가 아니라 **캐릭터가 느끼는 감각**으로 전달된다.

---

## 1. 캐릭터 수치의 4개 층

```
┌─ 능력치 (Attributes) ── 타고난 바탕. 잘 안 변함. 1~20
├─ 스킬 (Skills) ───────── 배우고 쓰면서 오름. 0~100
├─ 성향 (Temperament) ─── 성격. 행동에 따라 천천히 변함. -100~+100
└─ 상태 (Conditions) ──── 지금 이 순간의 몸과 마음. 수시로 변함
```

### 1.1 능력치 (6개, 1~20, 평균 10)

| 능력치 | 의미 | 주로 영향 주는 스킬 | 기타 효과 |
|--------|------|---------------------|-----------|
| **근력** | 힘, 체격 | 무술(둔기·대검), 등반, 노동, 위압 | 운반 한계, 맨손 피해 |
| **민첩** | 몸놀림, 손재주 | 무술(단검·검), 은신, 소매치기, 궁술 | 회피, 도주 성공률 |
| **체질** | 맷집, 면역력 | 지구력, 생존 | 최대 체력, 질병·독 저항, 출혈 속도 |
| **지능** | 학습력, 추론 | 학식, 마법이론, 약학, 공학, 언어 | 스킬 성장 속도(지식 계열) |
| **감각** | 관찰력, 직감 | 통찰, 추적, 수색, 궁술 | 기습 감지, **확률 감각의 정확도** |
| **의지** | 정신력, 자제력 | 마법 시전, 심문 저항 | **용기 판정**, 스트레스 저항, 고통 견디기 |

- 능력치 보정값: `능력치보정 = (능력치 - 10) × 1.5` → 능력치 4면 -9, 16이면 +9.
- 능력치는 거의 고정이지만 **영구 부상(-), 노화(-), 극한 훈련·마법·저주(±)** 로 변한다.

### 1.2 스킬 (0~100)

| 구간 | 칭호 | 의미 |
|------|------|------|
| 0~9 | 문외한 | 해본 적 없음 |
| 10~24 | 초보 | 기본은 안다 |
| 25~44 | 숙련 | 생계를 꾸릴 수 있다 |
| 45~64 | 전문가 | 그 분야로 이름이 난다 |
| 65~84 | 명인 | 지방에서 손꼽힌다 |
| 85~100 | 전설 | 대륙에 몇 명 없다 |

**스킬 목록 (27개)**

| 계열 | 스킬 |
|------|------|
| 무술 | 검술, 창·장병기, 둔기, 단검, 궁술, 맨손격투, 방패술 |
| 신체 | 운동(등반·수영·달리기), 은신, 지구력 |
| 생존 | 추적·사냥, 야외생존, 승마, 응급처치 |
| 사회 | **화술**(설득), 기만, 위압, 흥정, 예법, 통찰 |
| 지식 | 학식(역사·법·지리), 약학, 공학, 읽고쓰기, 언어(종류별 별도) |
| 기술 | 손재주(자물쇠·소매치기·함정), 제작(대장·목공·재봉 등 세부) |
| 신비 | **마법**(근원별 별도: 불·물·바람·대지·생명·정신·그림자·시간) |

### 1.3 성향 (-100 ~ +100)

성향은 확률에도 영향을 주지만, **선택지를 열고 닫는 것**이 더 중요한 역할이다.

| 성향 축 | − 쪽 | + 쪽 | 판정 영향 | 선택지 영향 |
|---------|------|------|-----------|-------------|
| **용기** | 겁 많음 | 대담함 | 공포 판정, 위압, 전투 개시 | 낮으면 "공격한다"가 공포에 잠김, 높으면 무모한 선택지 해금 |
| 자비 | 잔혹 | 자비로움 | 위압(−자비 유리), 치료 | 고문, 처형, 약자 버리기 |
| 정직 | 교활 | 정직 | 기만(−정직 유리), 화술(+정직 유리, 신뢰 쌓인 상대에게) | 거짓말 선택지의 "죄책감" 스트레스 |
| 신앙 | 회의 | 독실 | 기도 효과, 교단 상대 화술 | 신성 의식, 이단 행위 |
| 탐욕 | 무욕 | 탐욕 | 흥정(+), 뇌물 저항(−) | 보상 포기, 배신 |
| 충성 | 기회주의 | 충직 | 심문 저항, 동료 사기 | 배신·투항 선택지 |

- 성향은 **행동에 따라 이동한다**. 겁나는 상황에서 맞서면 용기 +2, 도망치면 −1.
  → 플레이어가 "어떤 사람이 될지"를 숫자 배분이 아니라 **행동으로** 만든다.
- 성향이 극단(±60 이상)이면 **특성(Trait)** 이 붙는다: `무모함`, `겁쟁이`, `냉혈한`, `거짓말쟁이로 소문남` …

### 1.4 상태 (Conditions)

| 상태 | 단계 | 판정 보정 예시 |
|------|------|----------------|
| 피로 | 개운 / 피곤 / 지침 / 탈진 | 0 / −5 / −12 / −25 (모든 신체 판정) |
| 굶주림 | 배부름 / 출출 / 굶주림 / 기아 | +2 / 0 / −8 / −20 |
| 부상 | 부위별 경상·중상·치명 | 해당 부위 사용 판정 −5 / −15 / 불가 |
| 통증 | 0~100 | 의지 판정 실패 시 (통증÷5)만큼 모든 판정 감소 |
| 공포 | 침착 / 불안 / 공포 / 공황 | 0 / −5 / −15(공격 잠김) / 도주만 가능 |
| 취기 | 맑음 / 알딸딸 / 취함 / 만취 | 용기 +5/+10/+15, 민첩·통찰 −3/−10/−25 |
| 스트레스 | 0~100 | 70 이상이면 정신 붕괴 판정 (트라우마 발생) |
| 젖음 / 추위 | 체온 단계 | 민첩 −5~−20, 활·횃불·화약 사용 불가 |

## 2. 판정 공식

### 2.1 기본 구조

```
판정 점수 S = 스킬
            + 능력치보정
            + 장비보정        (02_ITEMS_AND_CHOICES 참고)
            + 상황보정        (환경, 시간, 준비, 정보)
            + 관계보정        (사회 판정일 때, 상대와의 관계)
            + 성향보정
            + 상태보정        (피로, 부상, 공포 …)

난이도 D   = 고정 난이도  또는  상대의 저항 점수(대항 판정)

성공 확률 P = 1 / (1 + e^(−(S − D) / 8))      (최소 3%, 최대 97%)
```

로지스틱 곡선을 쓰는 이유: 실력 차이가 작을 땐 결과가 크게 흔들리고,
차이가 클수록 확실해지지만 **절대 100%는 없다** (그림다크: 명검사도 단검에 찔려 죽는다).

| S − D | 성공 확률 |
|-------|-----------|
| −30 | 3% |
| −20 | 8% |
| −10 | 22% |
| −5 | 35% |
| 0 | 50% |
| +5 | 65% |
| +10 | 78% |
| +20 | 92% |
| +30 | 97% |

### 2.2 고정 난이도 기준표

| 난이도 | D | 예시 |
|--------|---|------|
| 사소함 | 5 | 아는 길로 가기, 문 열기 |
| 쉬움 | 15 | 친절한 상인과 흥정 |
| 보통 | 30 | 지친 경비병 설득, 낮은 담 넘기 |
| 어려움 | 45 | 의심 많은 관리 속이기, 비 오는 날 추적 |
| 매우 어려움 | 60 | 영주 설득, 성벽 오르기 |
| 영웅적 | 75 | 심문관 앞에서 거짓말 |
| 전설적 | 90 | 왕의 마음을 바꾸기 |

### 2.3 결과 등급 (성공/실패의 5단계)

단순한 성공/실패 대신 **5단계 결과**를 둔다. "부분 성공"이 이야기를 가장 많이 만든다.

```
r = 0~1 사이 난수

r < P × 0.15                    → 대성공   (추가 이득)
r < P                           → 성공
r < P + (1 − P) × 0.35          → 부분 성공 (목적은 이루지만 대가를 치름)
r > 1 − (1 − P) × 0.15          → 대실패   (상황 악화)
그 외                            → 실패
```

P = 50%일 때 분포: 대성공 7.5% / 성공 42.5% / 부분 성공 17.5% / 실패 25% / 대실패 7.5%

**부분 성공의 대가 예시**: 시간이 더 걸림, 물건을 잃음, 상대가 의심을 품음, 다침, 소문이 남, 빚이 생김.

### 2.4 대항 판정

상대 NPC도 같은 공식으로 저항 점수를 갖는다.

```
D = 상대의 저항스킬 + 상대 능력치보정 + 상대 상태 + 상대 성향
예) 설득 vs 상대의 (의지보정 + 통찰 + 고집 성향 + 플레이어에 대한 불신)
예) 은신 vs 경비의 (감각보정 + 수색 + 경계 상태 + 조명)
```

## 3. 대표 판정 유형별 공식

### 3.1 화술 (설득)

```
S = 화술 + (지능보정 + 감각보정)/2
  + 장비보정        (옷차림, 신분 증표, 선물)
  + 관계보정        (호감 × 0.3, 신뢰 × 0.2)
  + 논거보정        (아는 정보를 근거로 쓸 때 +5~+20)
  + 이해관계보정    (상대에게 이득이면 +, 손해면 −)
  + 출신·신분 차이  (평민 → 귀족: −10, 같은 출신: +5)
D = 상대의 의지보정 + 통찰/2 + 고집 성향 + 요청의 크기(사소 0 ~ 목숨 걸기 +40)
```

> 핵심: **같은 화술 수치라도 "근거"와 "이해관계"를 갖추면 훨씬 쉬워진다.**
> 플레이어는 설득하기 전에 정보를 모으고, 선물을 준비하고, 옷을 갈아입는 이유가 생긴다.

### 3.2 위압

```
S = 위압 + 근력보정 + 용기/5 − 자비/10
  + 장비보정 (뽑아 든 무기 +10, 갑옷 +5, 피 묻은 옷 +8, 해골 장식 등)
  + 수적 우위 (동료 1명당 +5)
  + 평판 (악명 높으면 +15)
D = 상대 의지보정 + 상대 용기/5 + 상대 장비/동료 + 상대가 잃을 것
```
- 위압은 성공해도 **관계(호감)가 떨어진다.** 대실패 시 상대가 먼저 공격하거나 경비를 부른다.

### 3.3 용기 (공포 판정)

공포스러운 상황(마물 조우, 고문 목격, 압도적 적군, 시간 잔상)에서 자동 발동.

```
S = 의지보정 × 2 + 용기/3 + 경험(같은 공포를 겪은 횟수 × 3) + 동료 사기 + 취기
D = 공포 강도 (도적 무리 20, 재늑대 35, 화형 목격 40, 균열 마물 60, 무명자 90)
```

| 결과 | 효과 |
|------|------|
| 대성공 | 다음 판정 +5 ("오히려 머리가 맑아진다") |
| 성공 | 정상 행동 |
| 부분 성공 | `불안` 상태 + 스트레스 +10 |
| 실패 | `공포` 상태: **공격·접근 선택지 잠김**, 도주·숨기·애원만 선택 가능 |
| 대실패 | `공황`: 무작위로 도주하거나 얼어붙음, 소지품 떨어뜨림, 스트레스 +30 |

> 선택지에 이렇게 보인다:
> ~~3. 검을 뽑고 맞선다~~ *(다리가 말을 듣지 않는다)*

### 3.4 무술 (전투 한 합)

```
공격 S = 무기스킬 + (근력 or 민첩)보정 + 무기 품질 + 거리 상성 + 자세 + 지형 − 부상
방어 D = 상대 (무기스킬 or 방패술 or 회피) + 갑옷 + 자세 + 지형 − 부상
```
- 명중하면 **부위 판정** → 갑옷 관통 판정 → 부상 단계 결정.
- 무기·갑옷 상성 예: 둔기는 판금에 강함(관통 +15), 단검은 붙잡은 상태에서 강함, 창은 거리 유지 시 +10.
- 대부분의 싸움은 3~6합 안에 끝난다. 상대도 부상이 쌓이면 도주·항복 판정을 한다.

### 3.5 마법 시전

```
S = 해당 근원 마법 스킬 + 의지보정 + 지능보정/2 + 촉매 품질 + 집중 상태 − 통증/5
D = 주문 복잡도 (룬 개수 × 10) + 범위·강도 보정 + 대상 저항(대상이 생물일 때)
```

| 결과 | 효과 |
|------|------|
| 대성공 | 대가 절반 |
| 성공 | 정상 발동, 대가 지불 |
| 부분 성공 | 약화된 효과 또는 대가 2배 |
| 실패 | 불발, 대가 절반 지불 |
| 대실패 | **역류(Backlash)**: 대가 3배 + 근원별 재앙 (불: 자기 화상, 정신: 기억 상실, 시간: 나이 듦) |

- 무면허 마법을 사람 앞에서 쓰면 별도로 **목격 판정** → 소문 시스템에 "마녀가 있다" 사실이 기록된다.

## 4. 확률을 플레이어에게 보여주는 방법

숫자 %를 직접 보여주지 않는다. 대신 **캐릭터의 판단**을 보여주고,
그 판단의 정확도가 캐릭터의 관련 스킬과 감각에 따라 달라진다.

### 4.1 체감 등급

| 체감 문구 | 표시 기준 (체감 확률) |
|-----------|-----------------------|
| 식은 죽 먹기 | 90%+ |
| 확실해 보인다 | 75~89% |
| 해볼 만하다 | 55~74% |
| 반반이다 | 40~54% |
| 운이 따라야 한다 | 20~39% |
| 무모하다 | 20% 미만 |

### 4.2 체감 오차 (자기 실력을 모르는 초보)

```
체감 확률 = 실제 P + 과신 편향 + 오차
과신 편향 = +15% × (1 − 관련스킬/50)       (스킬 50 이상이면 0)
오차      = 정규분포, 표준편차 = 20% × (1 − (관련스킬 + 감각×2)/140)
```

- 검을 처음 잡은 농부는 노련한 용병과의 싸움을 "해볼 만하다"고 착각한다.
- 숙련자는 정확히 안다. **실력이 늘면 세계가 더 투명해지는 느낌**이 성장 보상이 된다.
- 설정 옵션: "정확한 % 표시" (쉬운 난이도 / 접근성 옵션)

### 4.3 판정 근거 미리보기 (길게 누르기)

모바일에서 선택지를 길게 누르면 **캐릭터가 아는 범위에서만** 근거를 보여준다.

```
[설득] 경비병에게 "상인 조합원"이라고 한다
 ▲ 경비병이 지쳐 보인다
 ▲ 당신의 옷은 상인처럼 보인다 (괜찮은 모직 외투)
 ▼ 조합 증서가 없다 — 요구하면 끝이다
 ▼ 당신의 북부 억양
 ?  경비병의 성격은 아직 모른다
```

## 5. 성장 공식 (사용 기반)

```
스킬 경험치 획득 = 기본값(판정 난이도에 비례)
                × 위험 배율      (연습 0.3 / 실전 1.0 / 목숨이 걸림 2.0)
                × 결과 배율      (실패 1.2 — 실패에서 더 배운다 / 성공 1.0)
                × 스승 배율      (독학 1.0 / 스승 2.0~3.0)
                × 지능 배율      (지식 계열만: 0.7 + 지능/20)
                × 수확 체감      (1 − 현재스킬/상한)²
```

- **난이도가 너무 낮은 판정(D < 스킬 − 20)은 경험치가 0** → 쉬운 일만 반복해서는 안 큰다.
- 상한(Cap)은 03_ROGUELITE_AND_LEGACY의 "수련 상한" 참고.
