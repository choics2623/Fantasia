# 09. 영역·영지와 관리자

> 주인공의 행보로 **은신처 → 비밀 공동체 → 해방구 → 인간의 도시 → 영지**로 영역이 넓어진다.
> 그러나 이 세계에서 **인간은 땅을 가질 수 없다.** 그래서 영역은 언제나 **숨기거나, 누군가의 이름을 빌리거나, 빼앗는 것**이다.
> 그리고 주인공은 한 곳에 머물 수 없으므로, 영역은 **관리자에게 맡겨야 한다.** 맡긴다는 것은 믿는다는 것이고, 믿음은 배신될 수 있다.

---

## 1. 영역의 세 갈래

| 갈래 | 누구의 것인가 | 예 | 특징 |
|------|---------------|-----|------|
| **개인 영역** | 주인공 자신 | 숨겨둔 은신처, 비밀 창고, 지하 학교, 산속 오두막 | 작고 숨기기 쉽다. 영혼이 다음 몸으로 옮겨가도 **위치를 기억하면** 되찾을 수 있다 |
| **가문 영역** | 주인공이 세운 (비밀) 가문 | 가문 금고, 가문 마을, 세렌 계약 상관 | 자녀·제자에게 영혼이 옮겨가면 **그대로 이어진다.** 인간 가문은 불법이므로 '비밀 이름' 아래 유지 |
| **인간의 영역** | 해방된 인간 공동체 전체 | 탈주자 마을, 해방구, 인간 자유 도시 | 주인공 혼자의 것이 아니다. 공동체의 의사·지도자들이 있다. **「무혈자의 찬가」 클락과 직결** |

> 세 갈래는 서로 섞인다. 주인공의 가문 마을이 커져 해방구가 되면 '인간의 영역'으로 넘어가고,
> 그 순간부터 주인공의 뜻대로만 움직이지 않는다.

---

## 2. 영역의 단계

| 단계 | 이름 | 규모 | 얻는 방법 (예) | 노출도 기본값 |
|------|------|------|----------------|---------------|
| 0 | **은닉처** | 1~5명 | 동굴·폐가·지하실 확보 | 5 |
| 1 | **비밀 거점** | 5~30명 | 탈주자를 모아 숨김, 잿빛 실 중계지 | 15 |
| 2 | **숨은 마을** | 30~200명 | 늪·산속·황무지 가장자리에 정착 | 30 |
| 3 | **해방구** | 200~2,000명 | 지역 봉기로 영주를 몰아냄 / 광산·원형장 장악 | 60 |
| 4 | **인간의 도시** | 2,000~2만 명 | 해방구를 성벽으로 지켜 1년 이상 유지 | 85 |
| 5 | **공인 영지** | 무관 | 고대 종족이 법적으로 인정 (§3) | 100 (숨길 수 없음) |

**노출도(Visibility)** 는 이 시스템의 핵심 수치다.
- 클수록 사람을 많이 모을 수 있고 생산이 늘지만, **진압의 표적이 된다.**
- 노출도 = 기본값 + 인구 × 0.05 + 교역량 + 소문 확산 − 은폐 시설 − 관리자 수완
- 노출도가 지역 지배 세력의 **경계 임계값**을 넘으면 → 수색대 → 노예사냥꾼 → 군대 → 와이번 기사단 → **진룡** (10 문서 §5 대응 단계)

> 그림다크의 긴장: **크게 키울수록 더 많은 사람을 구하지만, 더 큰 칼이 온다.**

## 3. 인간이 땅을 '가지는' 방법

| 방법 | 내용 | 대가·위험 |
|------|------|-----------|
| **숨긴다** | 지도에 없는 곳에 정착. 소유권은 없다 | 발각되면 끝. 노출도를 낮게 유지해야 함 |
| **이름을 빌린다** | 용인 귀족·나가 상가·두르강 씨족의 명의로 땅을 사고, 실제로는 인간이 산다 | 명의자가 배신하거나 죽으면 모두 잃는다. 명의자에게 상납 |
| **계약한다** | 두르강 계약(광산 지분), 세렌 계약민 상관(지분 매입) | 계약 조항이 족쇄. 두르강 계약은 깨면 재판 |
| **하사받는다** | 계승 전쟁에서 공을 세워 후계자에게 "인간 자치령" 칙허를 받는다 (카스파르가 대표적 후보) | 하사한 자가 패배하면 칙허는 휴지. 다른 후계자의 표적 |
| **빼앗는다** | 봉기로 점령 | 즉시 진압 대응. 지켜낼 힘이 없으면 학살 |
| **사들인다** | 세렌에서 파산한 영지를 경매로 (법적으로는 '계약민 공동 소유') | 막대한 돈. 의회가 법을 바꾸면 무효 |

## 4. 영역의 수치 (텍스트 게임에 맞게 단순하게)

| 수치 | 의미 | 바뀌는 원인 |
|------|------|-------------|
| **인구** | 사는 사람 수 (종족별) | 탈주자 유입, 출생, 굶주림, 질병, 학살 |
| **식량** | 계절 단위 비축 (몇 달 버티나) | 경작, 수렵, 교역, 약탈당함 |
| **방어** | 습격을 버틸 힘 | 방벽, 무기, 훈련된 사람, 지형 |
| **은폐** | 노출도를 깎는 힘 | 위장, 정보망, 뇌물, 관리자 수완 |
| **사기** | 공동체의 결속과 희망 | 승리, 축제, 학교, 배신, 굶주림, 처형 |
| **문해율** | 글을 아는 사람 비율 | 비밀 학교 → 찬가 '글' 단계 |
| **질서** | 내부 갈등·범죄·파벌 | 법, 관리자, 식량 분배의 공정성 |
| **재화** | 숨긴 돈·교역품 | 생산, 교역, 상납 |

### 4.1 시설·사업 (예)

| 시설 | 효과 | 노출도 |
|------|------|--------|
| 위장 입구 | 은폐 +10 | −5 |
| 비밀 학교 | 문해율 성장, 사기 +5 | +3 |
| 대장간 | 무기 생산, 방어 +5 | +5 (연기·소리) |
| 망루와 봉화 | 습격 사전 경고 | +4 |
| 약초밭·치료소 | 질병 피해 감소 | +1 |
| 신당 (옛 신 / 끊어진 고리) | 사기 +8, 순종의 빛 신도와 갈등 | +2 |
| 잿빛 실 중계소 | 탈주자 유입 +, 이름 없는 자들과 연결 | +6 |
| 성벽 | 방어 +30 | +20 |
| 교역소 (세렌·두르강 상대) | 재화 +, 식량 + | +10 |
| 기억의 벽 | 죽은 이들의 이름을 새김. 사기 크게 +, 찬가 진척 | +3 |

## 5. 관리 루프 — 계절 단위의 결정

영역은 매 턴 세세하게 관리하지 않는다. **계절마다 한 번** 보고를 받고 결정한다 (주인공이 멀리 있으면 전령·꿈·편지로).

```
[계절 보고 — 붕괴력 313년 해빙월, 굶주린 언덕 숨은 마을]
  인구 142 (+31 북방 탈주자)   식량 2.5개월   방어 18   은폐 41   사기 62   질서 55
  관리자 시그리드: "식량이 모자랍니다. 새로 온 자들을 받을지 결정해 주십시오."

  ▸ 이번 계절 방침 (하나 선택)
    1. 문을 닫는다 — 더는 받지 않는다 (사기 −10, 식량 안정)
    2. 모두 받는다 — 하겐의 밀수로 곡식을 산다 (재화 −40, 노출도 +8, 하겐을 믿어야 한다)
    3. 레이번 성채의 곡물 창고를 턴다 — 주인공이 직접 간다 (임무 스토리렛)
  ▸ 사업 (재화·노동력 내에서)
    [ ] 위장 입구 (노동 20일)   [ ] 비밀 학교 (오스릭이 몰래 가르치겠다고 한다)
  ▸ 정책
    식량 분배: [ 균등 ] 노동량 비례 / 아이 우선
```

- 결정 하나하나가 **스토리렛**을 낳는다 (거절당한 탈주자가 밀고한다 / 밀수꾼이 배신한다 / 학교가 발각된다).
- 주인공이 직접 머무는 동안은 결정 효과가 커지고, 멀리 있으면 **관리자의 판단**이 개입한다.

## 6. 관리자 (Steward)

주인공은 한 곳에 머물 수 없고, 언젠가 죽어 다른 몸으로 옮겨간다. **영역을 지키는 것은 관리자다.**

### 6.1 관리자의 수치

| 수치 | 의미 |
|------|------|
| **수완** (0~100) | 생산·질서·은폐를 얼마나 잘 굴리는가 (관련 스킬: 흥정, 통찰, 지휘, 학식) |
| **충성** (−100~100) | 주인공에게 |
| **신념** | 무엇을 가장 중요하게 여기는가: 생존 / 해방 / 복수 / 신앙 / 이익 / 가족 |
| **야심** (0~100) | 스스로 지배자가 되고 싶은 정도 |
| **원칙** | 판단 성향: 신중함↔대담함, 자비↔냉혹 |
| **비밀** | 관리자 자신이 숨긴 것 (목줄단과의 과거, 숨긴 가족, 빚) |

### 6.2 위임 방식

| 방식 | 내용 | 효과 |
|------|------|------|
| **직접 지시** | 계절 방침을 주인공이 정한다 | 정확하지만 주인공이 연락 가능해야 함 |
| **방침 위임** | "은폐 우선", "인구 우선", "무장 우선" 같은 큰 방향만 준다 | 관리자가 신념에 따라 해석한다 |
| **전권 위임** | 관리자가 알아서 한다 | 수완이 높으면 가장 효율적. 야심이 높으면 위험 |

### 6.3 관리자가 만드는 이야기

| 조건 | 사건 |
|------|------|
| 충성 낮음 + 야심 높음 | 영역을 장악하고 주인공을 밀어낸다 / 고대 종족과 몰래 거래해 자기만 살길을 찾는다 |
| 신념 '복수' + 대담함 | 주인공 허락 없이 보복 습격 → 노출도 폭증 |
| 신념 '생존' + 신중함 | 위기 때 탈주자를 내쫓거나, 최악의 경우 **공동체를 지키려고 주인공을 밀고한다** |
| 비밀 '목줄단 과거' | 옛 동료가 찾아와 협박 → 관리자의 선택 |
| 수완 높음 + 충성 높음 | 주인공이 없는 동안 영역을 크게 키운다 → 노출도도 커진다 |
| 관리자 사망 | 후임 다툼 → 질서 급락 |

### 6.4 관리자 후보 (회색여울 기준 예)
| 후보 | 수완 | 충성(초기) | 신념 | 야심 | 주의 |
|------|------|------------|------|------|------|
| 시그리드 (북방 탈주자 대표) | 55 | 30 | 생존 → 해방 | 40 | 탈주자들만 챙긴다는 원망 |
| 브람 (배급 막사 관리인) | 60 | 40 | 가족 | 10 | 위험을 극도로 싫어함 |
| 엘사 (늪 마녀 출신 노파) | 45 | 50 | 해방 | 5 | 나이가 많다. 이름 없는 자들과 연결 |
| 마르타 (목줄단 목줄장) | 75 | −10 | 가족(딸) | 50 | 가장 유능하지만 가장 위험한 선택 |
| 하겐 (밀수꾼) | 65 | −30 | 이익 | 70 | 돈이 되면 누구든 판다 |

### 6.5 관리자는 영혼 계승과 이어진다
- 주인공의 영혼이 **관리자에게 옮겨갈 수도 있다** (신뢰 70 이상의 동료 조건). 그러면 관리자였던 사람으로 깨어나 직접 영역을 이끈다.
- 반대로 주인공이 아기로 다시 태어나 15년 이상(보통 15~24년) 뒤 깨어나면, **그 공백 동안 관리자가 영역을 어떻게 했는지**가 결과로 기다린다
  (번성 / 배신 / 멸망 / 전설이 되어 있음).

## 7. 영역과 찬가

| 찬가 단계 | 영역 조건 |
|-----------|-----------|
| 1 불씨 | 비밀 거점 이상을 1년 유지 |
| 2 글 | 비밀 학교에서 30명 이상 |
| 4 봉기 | 해방구 확보 |
| 5 성벽 | 인간의 도시를 1년 방어 |
| 6 맹약의 균열 | 공인 영지 (고대 종족 하나 이상의 법적 인정) |

- **인간의 영역에는 다른 인간 지도자들이 생긴다.** 주인공의 뜻과 다른 방향(복수·고립·협력)을 주장하는 파벌.
  주인공은 왕이 아니라 **가장 신뢰받는 한 사람**일 뿐이다 — 신뢰를 잃으면 자기가 세운 도시에서 쫓겨날 수도 있다.

## 8. 구현 메모

```ts
interface Domain {
  id: string; name: string; kind: 'personal'|'house'|'human';
  tier: 0|1|2|3|4|5; node: MapNodeId;            // 지도 노드와 연결 (07 문서)
  legal: 'hidden'|'proxy'|'contract'|'charter'|'seized'|'purchased';
  proxyOwner?: NpcId;                             // 이름을 빌린 경우
  stats: { pop: Record<Race, number>; food: number; defense: number; conceal: number; morale: number; literacy: number; order: number; wealth: number };
  visibility: number;                             // 계산값
  steward?: NpcId; delegation: 'direct'|'policy'|'full'; policy?: string;
  buildings: BuildingId[]; factions: DomainFaction[];
}
```
- 계절 처리는 헤드리스 시뮬레이션과 같은 코드로 돈다 → 플레이어가 없는 동안(15년 이상의 공백)도 같은 규칙으로 계산.
