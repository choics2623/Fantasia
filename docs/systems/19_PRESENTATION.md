# 19. 글이 몸을 가진다 — 텍스트 연출·소리·진동·삽화

> 텍스트 게임의 적은 **글 벽**이다. 같은 분량이라도 읽는 사람이 "읽고 있다"고 느끼면 피로가 되고,
> "겪고 있다"고 느끼면 몰입이 된다. 이 문서는 글이 **캐릭터의 몸 상태를 따라 변하는** 방식과,
> 그 글을 받쳐주는 소리·진동·그림의 규칙을 정한다.

---

## 1. 목표

| 해결할 문제 | 방법 |
|-------------|------|
| 텍스트 피로 (모바일 글 벽) | 장면을 작은 박자로 쪼개고, 박자마다 읽는 양을 제한한다 (§2) |
| 상태 수치가 숫자로만 느껴짐 | 공포·통증·취기·굶주림이 **문장 자체를 바꾼다** (§3) |
| 언어·문맹 설정이 장식에 그침 | 모르는 글자는 정말로 읽을 수 없다. 배우면 화면에서 글자가 하나씩 풀린다 (§4) |
| 세계관의 기괴함(시간 뒤틀림, 재, 진명)이 설명으로만 전달됨 | 글이 반복되고, 거꾸로 흐르고, 재가 앉는다 (§5) |
| 소리 없는 텍스트 게임의 공허함 | 장소·날씨·긴장에 따라 겹치는 환경음, 침묵을 도구로 (§7) |
| 손에 쥔 기기의 물리성 미활용 | 심장 박동·채찍·용의 울림을 진동으로 (§8) |

**참고 작품**
- *Disco Elysium* — 상태가 내면의 목소리로 문장에 끼어드는 방식. 가져온다.
- *80 Days*, *Sorcery!* (inkle) — 짧은 박자, 선택지와 본문의 리듬. 가져온다.
- *Darkest Dungeon* — 내레이터의 목소리와 절제된 판화풍 그림. 가져온다.
- *Eternal Darkness*의 정신력 효과 — **피한다**: 플레이어를 속이는 가짜 시스템 오류 연출은 신뢰를 깎는다. 우리는 "캐릭터의 감각"만 흔든다. 게임 UI(저장, 메뉴, 수치)는 절대 흔들지 않는다.

## 2. 읽기의 기본 — 박자(Beat)

### 2.1 박자 규칙
| 항목 | 값 |
|------|-----|
| 한 박자 최대 분량 | **250자** (공백 포함, 약 3개의 짧은 문단) |
| 박자 사이 | 탭으로 다음 박자 / 또는 선택지 |
| 선택지 없이 이어지는 박자 수 | 최대 **4박자** (약 1,000자). 넘으면 작은 선택이라도 넣는다 ("계속 듣는다 / 끼어든다") |
| 장면 하나의 권장 길이 | 3~8박자 |
| 한 줄 박자 | 긴장을 위해 허용 — "문이 열렸다." 한 줄이 한 박자 |

- 작가는 YAML에서 `---`로 박자를 나눈다. 자동 분할은 문단 경계에서만 한다.
- 이전 박자는 위로 밀려 올라가며 흐려진다(불투명도 55%). 손가락으로 끌어올리면 다시 읽을 수 있다 (기록 스크롤).

### 2.2 글자 나타나기
| 설정 | 동작 |
|------|------|
| 즉시 (기본) | 박자 전체가 한 번에 나타난다. 페이드 인 180ms |
| 천천히 | 문장 단위로 나타난다 (문장당 300ms). 화면을 탭하면 즉시 전부 |
| 연출 박자 | 작가가 `{slow}`로 지정한 박자만 한 글자씩 (대사, 유언, 진명). 탭하면 건너뜀 |

> 원칙: **플레이어의 읽기 속도를 게임이 강제하지 않는다.** 느린 연출은 언제나 탭으로 건너뛸 수 있다.

### 2.3 화면 타이포그래피 (모바일 세로 기준)
| 요소 | 규칙 |
|------|------|
| 본문 서체 | 명조 계열 (Gowun Batang 등) 17px, 줄간격 1.75 |
| 한 줄 길이 | 28~34자 (좌우 여백 20px) |
| 대사 | 들여쓰기 없이 따옴표, 화자 이름은 첫 등장 시만 굵게 |
| 내면의 목소리 | 목소리마다 다른 서체·색 (15 문서) |
| 체감 확률·태그 | 고딕 계열 13px, 본문과 분리된 칩 |
| 다크 모드 | 기본값. 종이 모드 선택 가능 (07 지도와 같은 팔레트) |

## 3. 몸의 상태가 문장을 바꾼다

### 3.1 파이프라인

```
작가 원문 (태그 포함)
  → ① 작가 변형 선택   : 상태별로 작가가 쓴 대체 문장이 있으면 그것을 쓴다 ({fear_alt|…})
  → ② 언어·문해 필터    : 모르는 언어·글자 가림 (§4)
  → ③ 문장 필터         : 상태에 따른 알고리즘 변형 (아래 표)
  → ④ 끼어들기 삽입     : 통증·허기·목소리 줄을 박자 사이에 끼워 넣음
  → ⑤ 시각 효과         : 흔들림·번짐·색 (CSS 클래스)
  → 화면
```

- **①이 언제나 ③보다 우선한다.** 핵심 장면은 작가가 상태별 문장을 직접 쓰고, 알고리즘은 나머지를 메운다.
- 스크린 리더용 텍스트는 ③·⑤를 건너뛰고 상태를 대괄호로 알려준다: `[공포] 문이 열렸다.`

### 3.2 상태별 규칙

| 상태 | 문장 필터 (③) | 끼어들기 (④) | 시각 효과 (⑤) | 진동 |
|------|---------------|--------------|----------------|------|
| **불안** (공포 1) | 없음 | 낮은 확률로 "숨이 얕아진다." | 없음 | 없음 |
| **공포** (공포 2) | 쉼표 뒤에서 줄바꿈 → 문장이 끊겨 보인다 | 박자마다 1줄: 심장 소리, 시야 좁아짐 | 글자 미세 떨림 (0.4px, 6Hz) | 심장 박동 (§8) |
| **공황** (공포 3) | 형용사·부사 30% 제거, 마지막 문장 반복 | 박자마다 2줄 | 떨림 0.8px + 화면 가장자리 어두워짐 | 빠른 심장 박동 |
| **통증** (0~100) | 없음 | 통증 ÷ 25 확률로 박자 사이에 `(왼손이 욱신거린다)` — 부위는 실제 부상 부위 | 끼어든 줄만 붉은 기 | 짧은 맥박 1회 |
| **취기** (1~3단계) | 어절 순서 교환 (단계별 5/12/25%), 받침 중복 (2단계부터) | "세상이 기울어진다." | 줄마다 좌우 흔들림, 3단계는 번짐 | 없음 |
| **굶주림** | 음식 관련 단어를 **굵게** | 굶주림 2단계부터 박자마다 30%: 냄새·환상 | 음식 단어 강조 색 | 없음 |
| **피로** (탈진) | 10% 확률로 문장 끝 몇 어절을 `…`로 | "눈꺼풀이 무겁다." | 박자 나타나기 느려짐 (자동 '천천히') | 없음 |
| **추위** | 대사 첫 음절 더듬기 (`ㄱ, 그러니까`) 20% | "손가락이 말을 듣지 않는다." | 푸른 기 | 짧은 떨림 2회 |
| **스트레스 70+** | 없음 | 트라우마 연상 줄 (트라우마 종류별 작가 문장) | 없음 | 없음 |

### 3.3 강도와 겹침
- 동시에 적용하는 **시각 효과는 최대 2개** (우선순위: 공황 > 공포 > 취기 > 통증 > 추위 > 피로).
- 문장 필터는 최대 2개, 끼어들기는 박자당 최대 2줄.
- **선택지 문장에는 필터를 적용하지 않는다.** 플레이어가 무엇을 고르는지는 언제나 명확해야 한다. 대신 공포 상태에서 잠긴 선택지는 01 문서대로 회색 + 이유.
- 설정: 효과 강도 (끔 / 약 / 기본 / 강), 흔들림 끔, 색 효과 끔 — 접근성.

### 3.4 예시 — 같은 박자, 다른 몸

**원문**
> 지하실 계단 아래에서 발소리가 멈췄다. 브람이 등잔을 낮추며 속삭였다. "숨 쉬지 마."

**공포 (공포 2, 통증 40, 왼손 부상)**
> 지하실 계단 아래에서,
> 발소리가 멈췄다.
> *쿵. 쿵.* 심장이 귀에서 뛴다.
> 브람이 등잔을 낮추며 속삭였다. "숨 쉬지 마."
> (왼손이 욱신거린다)

**취기 2단계**
> 지하실 계단 아래에서 멈췄다 발소리가. 브람이 등잔을 낮추며 속삭였다. "숨 쉬지 마ㅏ."
> 세상이 기울어진다.

## 4. 언어와 문맹 — 읽을 수 없는 것은 읽을 수 없다

### 4.1 모르는 언어 (말)
- 대사에 `{lang:용언|…}` 태그가 붙으면, 플레이어의 해당 언어 스킬로 이해도를 정한다.

| 언어 스킬 | 보이는 것 |
|-----------|-----------|
| 0 | 전부 `■■ ■■■ ■■.` + "(용언이다. 알아들을 수 없다)" |
| 1~19 | 아는 단어만 보인다 (단어 사전에 있는 것) |
| 20~49 | 70% 보이고 나머지 `■` |
| 50+ | 전부 보인다. 작은 표시로 "(용언)" |

- **단어 사전은 영구적이다.** 한 번 뜻을 알게 된 단어(대화에서 반복되거나, 누가 가르쳐주거나, 전생 기억으로 떠오른 단어)는 이후 모든 장면에서 풀려 보인다.
  → 같은 감독관의 욕설이 첫날에는 `■■■!`이고, 석 달 뒤에는 "짐승 같은 것!"으로 보인다. **배움이 화면에서 보인다.**
- 1.0 기준 언어별 핵심 어휘 200~400개를 사전으로 관리 (`content/base/lexicon/*.yaml`).

### 4.2 문맹 (글)
- 게시판·편지·장부·계약서는 `{read|…}` 태그. 읽고쓰기 스킬에 따라:

| 읽고쓰기 | 보이는 것 |
|----------|-----------|
| 0 | 글자 모양만: `▯▯▯ ▯▯ ▯▯▯▯ ▯▯` |
| 1~9 | 숫자만 읽힌다: `▯▯▯ ▯▯ 31 ▯▯` |
| 10~29 | 아는 글자로 된 짧은 단어 (이름, 숫자, 자주 본 단어) |
| 30+ | 전부 |

- 비밀 학교에서 글을 배우는 과정이 이 화면 변화로 체감된다.
- 남작의 매각 명단을 훔쳤는데 읽지 못하면, 거기 사라의 이름이 있는지 알 수 없다 — **글을 아는 누군가에게 보여줘야 한다** (오스릭, 오웬). 관계 시스템과의 연결.

### 4.3 진명 (고대 진명어)
- 진명은 특수 서체로, 화면에 쓰일 때 글자 주위가 열기로 일렁인다 (`{true_name|…}`).
- 진명을 말하는 선택을 하면 대가(체력·체온·기억)가 화면 가장자리에 붉게 새겨진다.
- 진명을 모르는 상태에서 진명이 적힌 유물을 보면: 글자가 보이지만 **눈이 아프다** (통증 +5, 끼어들기 "눈 뒤가 탄다").

## 5. 세계의 기괴함을 글로

| 현상 | 연출 | 태그 |
|------|------|------|
| **시간 뒤틀림** (재의 황무지, 시간의 상처) | 같은 박자가 미세하게 바뀐 채 반복된다 / 문단 순서가 거꾸로 / 이미 고른 선택지가 다시 나온다 (고르면 "이미 했다"는 문장) / 시각 표시가 앞뒤로 흔들린다 | `{time_loop}` `{time_reverse}` |
| **시간 잔상** | 다른 서체(흐린 회색)로 312년 전 사람들의 말이 겹쳐 나온다 | `{echo_ghost|…}` |
| **재오염** | 재오염도에 비례해 글자 위로 회색 재 입자가 천천히 내려앉는다. 높아지면 일부 단어가 회색으로 바래 읽기 어렵다 | 자동 (상태) |
| **페이의 환영** | 문장 하나가 화면에 있다가, 다시 보면 다른 말로 바뀌어 있다 (박자를 되감아 읽을 때) | `{fae_shift|원문|바뀐문}` |
| **잔향 각성 순간** | 2인칭 서술("당신은")이 한 문장 동안 1인칭("나는")으로 바뀌고, 그 문장은 전생의 서체 | `{echo_wake|…}` |
| **용의 출현** | 화면 전체가 0.6초 어두워지고, 본문이 한 줄로 줄어든다. 공포 판정 전에 이미 문장이 짧아져 있다 | `{dragon}` |

> 이런 연출은 **드물어야** 강하다. 1.0 기준 시간 뒤틀림은 황무지 안에서만, 용의 출현은 한 생애에 0~3회.

## 6. 화면 구성 (모바일 세로)

```
┌────────────────────────────┐
│ ☁ 비 · 저녁 7시   회색여울   ≡ │  ← 상단 띠: 날씨·시간·장소 (탭: 지도)
├────────────────────────────┤
│                            │
│  (이전 박자, 흐리게)          │
│                            │
│  지하실 계단 아래에서,        │  ← 현재 박자
│  발소리가 멈췄다.             │
│  *쿵. 쿵.*                  │
│                            │
│  ⟨다라⟩ 칼은 왼쪽 부츠에 있어.  │  ← 전생의 목소리 (15 문서 서체)
│                            │
├────────────────────────────┤
│ ▸ 숨을 죽인다     [은신] 해볼 만하다 │  ← 선택지 (엄지 영역)
│ ▸ 칼을 꺼낸다 🗡  [단검] 운이 따라야 │
│ ▸ 브람의 손을 잡는다            │
│ ⋯ 다른 행동                    │
├────────────────────────────┤
│ ♥ ▮▮▮▯  허기 ▮▮▯  통증 ▮▮▯      │  ← 하단 띠: 몸 상태 (숫자 없음)
└────────────────────────────┘
```

| 동작 | 결과 |
|------|------|
| 탭 | 다음 박자 / 천천히 나타나기 건너뛰기 |
| 선택지 길게 누르기 | 판정 근거 미리보기 (01 문서 §4.3) |
| 목소리 줄 길게 누르기 | 그 목소리에게 묻기 (15 문서) |
| 왼쪽으로 밀기 | 인물 수첩 (08 문서) |
| 오른쪽으로 밀기 | 지도 (07 문서) |
| 아래로 끌기 | 기록 스크롤 |
| 메아리 줄 탭 | 원인의 실 펼치기 (16 문서) |

- 하단 몸 상태 띠는 **숫자를 보여주지 않는다.** 칸과 색만. 정확한 수치는 설정에서 켤 수 있다.
- 선택지에 쓰이는 아이템은 작은 아이콘으로 붙는다 (02 문서): 무엇을 써서 하는지 보인다.

## 7. 소리

### 7.1 층(Layer) 구조
| 층 | 내용 | 바뀌는 조건 |
|----|------|-------------|
| 바탕 | 장소의 기본음 (마을 웅성임, 숲, 갱도의 물방울, 원형장 함성) | 장소 노드 (07) |
| 날씨 | 비, 바람, 눈, 재 폭풍 | 날씨 |
| 활동 | 대장간 망치, 방앗간, 배급 줄, 예배 종 | NPC 일정 (08) — 장소에서 실제로 그 일이 일어나고 있을 때만 |
| 긴장 | 낮은 현악 드론, 심장 박동 | 이야기 연출가의 긴장도 (18 문서) |
| 단발 효과 | 사슬, 채찍, 문, 개 짖음, 먼 곳의 용 울음 | 사건 |

- 층은 서로 교차 페이드(1.5초). 장면 전환에 맞춰 바뀌고, 박자마다 바뀌지 않는다.
- **침묵을 도구로 쓴다**: 처형 직전, 용의 출현 직후, 재의 날(불 금지)에는 모든 층을 끈다. 다시 소리가 돌아오는 순간이 연출이다.
- 음악은 최소화. **생애마다 짧은 주제 선율 하나**, 그리고 전생 목소리별 주제 (15 문서). 같은 선율이 다음 생애에 다른 악기로 돌아온다.
- 무음으로도 모든 정보가 전달되어야 한다 (모바일 대부분이 무음으로 플레이).

### 7.2 분량

|------|-------------|-----------|-----------|
| 수직 슬라이스 (회색여울) | 12 | 40 | 3 |
| 1.0 | 40~60 | 150~200 | 12~16 |

## 8. 진동 (햅틱)

| 패턴 | 언제 | 모양 |
|------|------|------|
| 심장 박동 | 공포 2 | 두 번 짧게(40ms, 120ms 간격), 0.9초마다. 장면 끝까지 |
| 빠른 심장 | 공황 | 같은 패턴 0.5초마다 |
| 채찍 | 채찍질 당함 | 날카로운 1회 (20ms 강) |
| 맥박 | 통증 끼어들기 | 약한 1회 |
| 용의 울림 | 진룡 출현·포효 | 길고 낮게 600ms |
| 꺼지는 심장 | 죽음 | 심장 박동이 점점 느려지다 멈춤 (5회, 간격 0.9→2.4초) |
| 깨어남 | 다른 몸에서 각성 | 멈춘 뒤 3초 무음 → 다른 박자의 심장 박동 1회 |

- 캐릭터 몸의 감각만 진동으로 준다. UI 버튼 진동은 쓰지 않는다 (의미가 흐려짐).
- 분당 최대 진동 횟수 상한 (심장 박동 제외 6회). 설정에서 끌 수 있다.
- 구현: Capacitor Haptics / 웹은 `navigator.vibrate` (지원 시).

## 9. 삽화

### 9.1 화풍
- **흑백 목판화·동판화풍**, 잉크의 번짐과 칼자국. 색은 오직 하나 — 핏빛 녹 — 을 드물게.
- 얼굴을 정밀하게 그리지 않는다. 실루엣, 손, 사슬, 불빛 — 상상력이 채울 자리를 남긴다.

### 9.2 언제 쓰나
| 순간 | 빈도 |
|------|------|
| 첫 죽음, 첫 각성 | 고정 |
| 진룡을 처음 봄 | 고정 |
| 처형·학살·봉기의 순간 | 사건당 1장 |
| 재회 (20 문서) | 고정 |
| 지역 첫 도착 | 지역당 1장 |
| 연대기 표지 | 생애당 1장 (그 생애의 핵심 사건으로 선택) |

> 평균 **플레이 1시간에 1~2장.** 흔하면 무뎌진다.

### 9.3 인물
- 초상화는 S등급 인물만, 목판화 흉상 실루엣. B·C 등급은 그림 없음.
- 주인공의 현재 몸도 흉상 하나 — 영혼이 옮겨가면 **그림이 바뀌는 순간**이 각성 연출의 일부가 된다.

### 9.4 제작 분량
| 단계 | 장면 삽화 | 인물 흉상 | 지역 |
|------|-----------|-----------|------|
| 수직 슬라이스 | 15 | 8 | 1 |
| 1.0 | 120~160 | 40 | 16 |

- 1인 개발 현실: 핵심 장면은 외주(화풍 가이드 고정), 나머지는 같은 화풍 가이드로 AI 보조 초안 + 사람이 다듬기. 사용하는 생성 도구의 상업 이용 조건을 반드시 확인한다.
- 날씨·시간 오버레이(비, 재, 밤)를 그림 위에 합성해 같은 그림을 여러 장면에 재사용한다.

## 10. 작가용 마크업

```yaml
- id: greyford_cellar_footsteps
  beats:
    - |
      지하실 계단 아래에서 발소리가 멈췄다.
      {fear_alt|계단 아래에서,\n발소리가 멈췄다.}
      브람이 등잔을 낮추며 속삭였다. "숨 쉬지 마."
    - |
      {lang:용언|"■■ 여기 냄새가 난다."|"짐승 냄새가 난다, 여기."}
      {voice:dara|칼은 왼쪽 부츠에 있어.}
    - "{slow}문이 열렸다."
  sound: { bed: cellar, tension: 2, sfx_on_beat3: door_creak }
  haptic_on_beat3: heartbeat_start
  illustration: null
```

| 태그 | 의미 |
|------|------|
| `{fear_alt|…}` `{drunk_alt|…}` `{pain_alt|…}` | 상태별 작가 대체 문장 (해당 상태일 때 원문 대신) |
| `{lang:언어|원문|번역}` | 언어 필터. 원문은 화면용 표기, 번역은 이해했을 때 보이는 문장 |
| `{read|…}` | 문해 필터 |
| `{true_name|…}` | 진명 서체·열기 효과 |
| `{voice:id|…}` | 전생의 목소리 줄 (15 문서 — 발동 규칙에 따라 표시 여부 결정) |
| `{slow}` | 이 박자는 한 글자씩 |
| `{time_loop}` `{time_reverse}` `{echo_ghost|…}` `{fae_shift|a|b}` `{echo_wake|…}` `{dragon}` | §5 |

- 05 문서의 대사 규칙 `lines`에도 같은 태그를 쓴다.
- 검증 도구(05 §7.4)가 태그 문법을 검사한다 (닫히지 않은 태그, 없는 언어·목소리 id).

## 13. 수직 슬라이스 범위

**반드시**
- 박자 시스템, 2인칭 서술, 기록 스크롤
- 상태 효과: 공포·공황·통증·굶주림·피로 (취기·추위는 나중)
- 문맹 필터 (매각 명단, 게시판) + 용언 언어 필터 + 단어 사전
- 잔향 각성 연출 `{echo_wake}`, 죽음·깨어남 진동
- 환경음 12 루프, 단발 40, 침묵 연출
- 삽화 15장 (첫 죽음, 첫 각성 포함)

**나중으로**
- 시간 뒤틀림·페이 환영 (해당 지역이 생길 때)
- 진명 서체 효과 (마법 계통이 열릴 때)
- 생애별 주제 선율 변주
- 날씨 오버레이 합성
