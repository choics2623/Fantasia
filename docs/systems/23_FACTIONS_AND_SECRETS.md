# 23. 세력의 몸과 세계의 비밀 — 통치 형태, 조직도, 관습, 비밀 결사, 은자

> 세력은 이름만 있는 덩어리가 아니라 **몸**을 가진다. 누가 결정하고, 누가 물려받고, 무엇이 죄이고, 어떻게 들어가고, 어떻게 배신하는지.
> 그리고 세계에는 **진실**이 있고, 그 진실을 아는 사람은 드물다. 누가 어디까지 아는지가 데이터로 정해진다.
> 이 둘은 NPC 카드(22)와 **연결**되어 움직인다. 세력의 자리가 바뀌면 그 자리에 앉은 사람의 카드가 달라 보이고, 진실의 조각은 사람을 따라 옮겨 다닌다.

- 세력 데이터: `content/base/factions/<세력id>.yaml`
- 진실 목록: `content/base/lore/truths.yaml`
- 정본: WORLD_BIBLE > HOUSES_AND_FACTIONS(이야기) > 세력 데이터(조직·운영 상세). 어긋나면 데이터를 고친다.

## 1. 통치 형태 — 세력마다 결정하는 방식이 다르다

| 형태 | 결정 | 계승 | 약점 (플레이어의 지렛대) | 예 (후보) |
|------|------|------|--------------------------|-----------|
| **제국·전제** | 한 존재의 뜻. 궁정은 해석을 다툰다 | 혈통 + 시험(용족 '불의 계승') | 계승 위기, 측근의 해석 독점 | 드라크마르 용제국 |
| **봉건 위계** | 주군 → 가신. 영지 안에서는 영주가 법 | 장자·혈통, 상위 승인 필요 | 빚, 서임권, 가신의 야심 | 용인 대가문, 레이번 남작가 |
| **과두 의회** | 의석 다수결, 의석은 돈으로 산다 | 의석 매매·상속 | 표 매수, 의석 간 경쟁 | 세렌 열두 의석 |
| **삼두·합의제** | 셋(또는 소수)이 만장일치 | 결원 시 남은 자들이 지명 | 한 명만 흔들면 전체가 멈춘다 | (후보) 녹테른 밤의 가문, 잿빛 탑 |
| **신정** | 경전 해석권을 가진 사제단 | 서품·선출 | 교리 논쟁, 이단 고발, 성물 | 순종의 빛 |
| **정신 공유·군체** | 개체가 아닌 전체가 결정. "우리는"으로 말한다 | 없음 — 전체가 계속된다 | 공유가 끊긴 개체(고아), 공유를 오염시키는 것 | (후보) 크릭 집단, 엘다르 기억 가지, 페이 궁정 |
| **씨족 연합** | 씨족장 회합, 명예와 혈채 | 씨족장은 씨족이 뽑는다 | 혈채, 오래된 원한 | 요툰 서리 씨족, 하르칸 초원 부족, 두르강 씨족 |
| **힘의 서열** | 가장 강한 자. 도전으로 바뀐다 | 결투 | 도전 시점을 조작하기 | 그롬 전쟁무리, 원형장 |
| **계약 공화국** | 계약서가 법. 맹세를 어긴 자는 돌이 된다 | 계약 승계 | 계약의 빈틈, 문구 | 두르강 (일부) |
| **세포 결사** | 위에서 아래로 한 줄. 서로의 얼굴을 모른다 | 위가 아래를 지명 | 한 세포가 잡히면 위로 한 줄이 드러난다 | 이름 없는 자들, 잿빛 실 |
| **장인·학회** | 지식의 위계. 논문과 실험 | 시험과 지명 | 연구 경쟁, 금지된 주제 | 잿빛 탑 |

> 위 '예'는 후보다. 각 세력의 형태는 세력 데이터에서 확정한다. 종족의 본성(WORLD_BIBLE §1.2 혈명과 굴레)이 통치 형태를 만든다 — 엘다르는 변하지 못하므로 결정이 느리고, 용은 소유하려 하므로 모든 것이 위계다.

## 2. 세력 데이터 형식

```yaml
id: fac_drakmar_empire
name: 드라크마르 용제국
kind: polity            # polity(국가·영지) | house(가문) | org(공개 조직) | secret(비밀 결사) | faith(신앙)
race: [용족, 용인, ...]
governance: 제국·전제    # §1의 형태
motto: "..."
seat: 바알카르 불꽃 홀  # 본거지 (REGIONS의 장소 id가 있으면 그 id)
size: {members: ..., territory: ..., wealth: ..., force: ...}

offices:                # 조직도 — 자리(office)와 그 자리에 앉은 사람(holder)
  - id: off_emperor
    title: 용황
    holder: npc_varskar          # 비어 있으면 null (공석이 곧 이야기)
    reports_to: null
    powers: ["모든 칙령", "진룡 소집"]
    chosen_by: "불의 계승 — 혈족 중 불을 견딘 자"
    perks: [...]
  - id: off_flame_steward
    title: 불꽃 홀의 집사
    holder: npc_...
    reports_to: off_emperor
    ...
ranks:                  # 구성원 계급 (위→아래). 플레이어가 오를 수 있는 사다리라면 open_to_player
  - {id: rank_x, title: "...", duties: "...", privileges: "...", open_to_player: false}
decision: "누가 무엇을 어떻게 결정하는가 — 회의 주기, 표결, 거부권"
succession: "자리가 비면 어떻게 채우는가"
law:                    # 이 세력의 영역·구성원에게 적용되는 법 (10, 13)
  crimes: [{act: "...", punishment: "...", note: "인간에게만 다름 등"}]
customs:                # 관습·예법·금기 — LLM 카드에 장면별로 들어간다
  greeting: "..."
  taboos: ["..."]
  rites: [{name: "...", when: "달력", what: "..."}]
  speech: "말투의 공통 결 (경어 체계, 금지어)"
membership:
  join: "어떻게 들어가나 (입문 의식, 시험, 피의 서약…)"
  leave: "어떻게 나가나 / 나갈 수 없나"
  signs: ["알아보는 표식, 암호"]
internal_factions:      # 안의 파벌
  - {name: "...", leader: npc_..., aim: "...", strength: 0-100}
assets: ["재산, 병력, 유물, 정보망"]
secrets:                # 이 세력이 숨기는 것 — 사실(22 facts) 또는 진실(§3)
  - {fact: fact_..., known_by_rank: rank_x}
  - {truth: T06, level: 전모, holders: [npc_...]}
relations: [{to: fac_..., stance: -100..100, note: "..."}]   # HOUSES §6.1 행렬과 같은 값
toward_echo: "잔향(주인공)에 대한 태도 — 태우기/붙잡기/기다리기/이용하기 (HOUSES §6.2)"
player_paths: ["플레이어가 이 세력과 엮이는 길: 가입, 이용, 침투, 무너뜨리기"]
regression: {fixed: [...], flow: [...], drift: [...]}   # 03 표류 등급
```

### 2.1 조직도는 자리와 사람을 나눈다
- **자리(office)** 는 세력의 것, **사람(holder)** 은 NPC의 것. 자리가 바뀌는 사건(죽음, 실각, 승진, 암살)이 일어나면 엔진은 `holder`만 바꾼다.
- NPC 카드에는 `affiliations`(§5)만 두고, 그 사람이 지금 앉은 자리는 세력 데이터에서 **계산**한다. 그래서 오웬이 남작이 되면 오웬의 카드는 그대로인데, 프롬프트에 들어가는 "지금의 오웬"은 남작의 권한과 무게를 갖는다.
- 공석(`holder: null`)은 그 자체로 이야기다. 공석이 오래가면 내부 파벌의 긴장이 오른다.

## 3. 세계의 진실 — 누가 어디까지 아는가

### 3.1 진실 목록 (`truths.yaml`)
WORLD_BIBLE의 숨은 진실을 번호로 쪼갠다. 진실마다 **세 단계**가 있다.

| 단계 | 뜻 | 예 (T06 대붕괴) |
|------|----|-----------------|
| **소문** | 왜곡되거나 반쪽인 이야기 | "아스테리온이 세계를 찢은 게 아니라던데" |
| **조각** | 사실이지만 맥락이 없다 | "그날 바르스카르가 의식 한가운데에 불을 뿜었다" |
| **전모** | 이유와 결과까지 | 의식은 성공 직전이었고, 회귀를 모든 인간에게 돌려주려 했으며, 두 힘이 시간을 찢었다 |

```yaml
- id: T06
  name: 대붕괴의 진실
  bible: "WORLD_BIBLE §2.1"
  levels:
    rumor: "..."
    fragment: "..."
    whole: "..."
  holders:                       # 누가 어느 단계까지 아는가
    - {who: npc_aurax, level: whole}
    - {who: fac_ashen_tower, level: fragment, rank: rank_archivist}
  danger: 5                      # 퍼지면 일어날 일
  proof: ["증거가 되는 물건·장소 — ITEMS/REGIONS id"]
  unlocks: ["이 진실을 알면 열리는 것 — 스토리렛, 진명, 엔딩 조건"]
```

- 플레이어가 진실을 알게 되는 것은 **지식 카드**(03)다. 회귀해도 남는다. 단계는 오를 수만 있다.
- 진실을 가진 NPC는 카드의 `hides`에 진실을 갖고, 공개 조건(`reveal_when`)이 더 엄격하다. 진실은 거래·고문으로 쉽게 나오지 않는다 — 대개 **시험**이나 **증명**이 필요하다 (§4).
- 주인공이 진실을 남에게 말하면: 엔진이 그 NPC의 지식에 `소문` 또는 `조각`으로 더한다 (주인공은 증거 없이 전모를 옮기지 못한다). 진실의 소문은 21 §8의 규칙으로 퍼지고, 진실을 지키려는 세력(정화청, 아우락스)의 사냥을 부른다.

### 3.2 회귀와 진실
- 세계는 진실을 잊지 않는다 — 회귀점에서 진실을 아는 사람은 매 회차 같다 (`fixed`).
- 주인공이 지난 회차에 퍼뜨린 진실은 사라진다. 다시 퍼뜨려야 한다.
- 시간 민감 존재(엘다르, 바르스카르, 잿빛 탑)는 회차가 쌓일수록 **자기가 모르는 것을 아는 듯한** 기시감을 갖는다 — 그들은 진실 쪽으로 조금씩 미끄러진다.

## 4. 비밀 결사와 은자

### 4.1 비밀 결사 — 위에서 아래로 한 줄
- 세포 구조: 각 단원은 `knows_members`(아는 동료)와 `knows_up`(한 단계 위로 가는 길)만 안다. 엔진은 결사를 **그래프**로 갖고, 한 사람이 잡히면 그 사람이 아는 간선만큼 드러난다.
- 알아보는 법: 암호, 표식, 수신호 (`membership.signs`). 플레이어가 표식을 알면 결사원을 알아볼 수 있고(지식 카드), 잘못 쓰면 정체가 탄로 난다.
- 침투: 플레이어는 가입하거나, 가입한 척하거나, 한 세포를 잡아 위로 올라갈 수 있다. 결사는 **시험**으로 가짜를 거른다 — 이름 없는 자들은 '돌아오는 이'의 증명을 요구한다(가짜에게 두 번 속았다).

### 4.2 은자·기인 — 진실을 가진 외톨이
세계의 진실은 궁정보다 **변두리**에 있다. 은자는 다음을 가진다.

| 항목 | 뜻 |
|------|----|
| `hidden_location` | 찾는 길 자체가 퀘스트. 소문(21 §8) → 단서 → 장소 |
| `test` | 진실을 주기 전에 거는 시험. 힘이 아니라 **사람을 보는** 시험 (질문, 기다림, 희생, 진명 한 마디) |
| `truths` | 가진 진실과 단계 |
| `price` | 진실의 값. 기억, 수명, 약속, 누군가의 이름 |
| `lies` | 은자도 틀린다 — 반쯤 틀린 믿음 하나씩 (진실 단계 `rumor`를 확신하는 것) |
| `deja_vu` | 시간 민감 은자는 회차가 쌓이면 주인공을 "기다리고 있었다" |

은자는 NPC 카드(22)를 그대로 쓰고, 위 필드를 카드의 `hermit:` 묶음에 더한다.

## 5. 연결 — NPC 카드와 세력

NPC 카드에 더하는 필드:

```yaml
affiliations:
  - faction: fac_raven_house
    rank: rank_heir              # 세력의 ranks id
    office: off_raven_heir       # 앉은 자리 (세력 데이터의 holder와 일치해야 한다)
    since: 290
    loyalty: 40                  # -100..100 — 세력에 대한 충성 (성향의 충성과 별개)
    public: true                 # 비밀 가입이면 false
    cell: null                   # 세포 결사면 세포 id
truths:                          # 아는 진실 (§3) — 진실 쪽 holders와 일치해야 한다
  - {id: T06, level: fragment}
```

### 5.1 엔진이 연결해서 하는 일
| 일 | 어떻게 |
|----|--------|
| **말투** | 두 NPC의 계급 차이 → 경어(05 §5.2). 카드의 `register`를 계급에서 고른다 |
| **관습을 프롬프트에** | 장면이 그 세력의 영역이면 `customs`의 인사·금기·말투 결을 21 §5.1 카드에 덧붙인다 |
| **법** | 그 영역의 `law.crimes`가 플레이어 행동의 결과(10 평판, 수배)를 정한다 |
| **승진·실각** | 자리가 바뀌면 `holder` 갱신 → 관계·권한·일정(§24 문서)이 따라 바뀐다 |
| **세력 반응** | 10 문서의 대응 사다리가 `toward_echo`와 `relations`를 읽는다 |
| **내부 파벌** | `internal_factions.strength`가 월드 클락에 따라 움직이고, 일정 문턱에서 분열·쿠데타 사건 |
| **진실 전파** | 진실을 아는 NPC가 죽으면 그 진실은 그 사람이 남긴 물건·제자에게 넘어가거나, 사라진다 |

### 5.2 검증 (`tools/validate_factions.py`)
- 세력의 `holder`와 NPC 카드의 `affiliations.office`가 서로 맞는가
- `reports_to`가 순환하지 않는가, 모든 자리가 최상위로 이어지는가
- 진실의 `holders`와 카드의 `truths`가 일치하는가
- `relations` 값이 HOUSES §6.1 행렬과 같은가
