# 02. 인벤토리·장비와 선택지 생성

> 원칙: **"가진 것이 곧 할 수 있는 것이다."**
> 선택지는 미리 정해진 목록이 아니라, 지금 상황 × 캐릭터가 가진 것(아이템·스킬·지식·관계)으로 매번 새로 만든다.

---

## 1. 아이템 데이터 모델

모든 아이템은 **태그(Tag)** 를 가진다. 선택지는 아이템 이름이 아니라 **태그를 조회**한다.
그래서 "밧줄"이든 "엮은 덩굴"이든 "찢어 묶은 침대 시트"든 `밧줄` 태그만 있으면 같은 선택지가 열린다.

```yaml
id: iron_shortsword
name: 철제 단검
tags: [무기, 날붙이, 한손, 찌르기, 숨길수있음:부츠]
slot: 무기_주
weight: 0.8          # kg
bulk: 1              # 부피 (배낭 칸)
quality: 보통         # 조악 / 보통 / 좋음 / 명품 / 걸작   → 장비보정 -5/0/+3/+6/+10
condition: 85        # 내구도 0~100. 녹, 이 빠짐 → 품질 단계 하락
value: { 발톱: 6 }
visibility: 보임      # 장착 시 남에게 보이는가 (보임 / 눈에 띄지 않음 / 숨김)
provenance:          # 소유 이력
  - { owner: npc_bran, how: 제작, year: 309 }
  - { owner: player, how: 훔침, year: 312, witnessed: false }
legal: { 용제국: 불법:인간, 세렌: 계약민_한뼘이하, 루멘: 금지, 그롬마르: 투사_허용 }
```

### 1.1 주요 태그 분류

| 분류 | 태그 예시 | 여는 선택지 |
|------|-----------|-------------|
| 도구 | `밧줄`, `갈고리`, `지렛대`, `자물쇠따개`, `삽`, `도끼`, `망치`, `부싯돌` | 등반, 문 부수기, 자물쇠 따기, 땅파기, 나무 베기, 불 피우기 |
| 광원 | `횃불`, `등불`, `양초` | 어두운 장소 탐색, 동굴 진입, 불 지르기 |
| 무기 | `날붙이`, `둔기`, `장병기`, `원거리`, `투척` + `한손`/`양손` | 공격 방식, 위협, 베어내기(덩굴·밧줄), 사냥 |
| 방어구 | `경갑`, `중갑`, `판금`, `방패`, `투구` | 화살비 돌파, 돌격, (그러나 은신·수영 불가) |
| 문서 | `통행증`, `소개장`, `증서`, `지도`, `편지`, `위조` | 검문 통과, 신분 주장, 협박, 길 찾기 |
| 신분 | `성표:순종의빛`, `문장:가문명`, `길드인장`, `노예낙인`, `죄수문신` | NPC 반응 변화, 출입 허가·거부 |
| 의복 | `귀족복`, `상인복`, `누더기`, `성직자복`, `제복:경비대`, `피묻음` | 변장, 사회 판정 보정, 의심 |
| 소모품 | `치료`, `독`, `해독`, `술`, `음식`, `미끼`, `연막`, `기름` | 치료, 독살, 회유, 유인, 도주 |
| 거래 | `화폐`, `보석`, `귀금속`, `장물`, `교역품` | 뇌물, 구매, 몸값 |
| 신비 | `촉매:원소`, `룬석`, `유물`, `재오염` | 마법, 의식, 위험한 거래 |
| 악기·놀이 | `악기`, `주사위`, `카드` | 공연, 도박, 사기 도박 |
| 동물 | `말`, `개`, `매` | 빠른 이동, 추적, 전령 |

## 2. 장착 슬롯 — "어디에 있느냐"가 중요하다

같은 단검도 **허리에 찼는지, 배낭 속에 있는지, 부츠에 숨겼는지**에 따라 다른 결과가 나온다.

```
머리 ─── 투구 / 두건 / 모자
목 ───── 성표 / 부적 / 목걸이
몸통 ─── [속옷층] → [갑옷층] → [겉옷층]     겉옷이 갑옷을 가릴 수 있음
망토 ─── 망토 (비·추위 보호, 무기 가림)
손 ───── 장갑 / 반지(2)
허리띠 ─ 빠른 접근 2칸 (무기·물약·주머니)    → 즉시 사용, 그러나 보임
무기 ─── 주무기 / 보조무기(방패)
다리·발 ─ 바지 / 장화
숨김 ─── 소매 1칸, 부츠 1칸 (소형·`숨길수있음` 태그만)
등 ───── 배낭 (부피 한도) / 화살통 / 등에 멘 대검
```

| 위치 | 꺼내는 데 걸리는 시간 | 남에게 보이는가 | 검문 시 |
|------|-----------------------|-----------------|---------|
| 손에 듦 | 0 | 매우 잘 보임 | 즉시 제지 |
| 허리띠·무기 슬롯 | 0 (전투 첫 합 가능) | 보임 | 무기 휴대 규칙 적용 |
| 숨김 칸 | 1 행동 | 숨김 (수색 판정) | 몸수색 시 [은신+손재주] vs [수색] |
| 배낭 | 2 행동 (전투 중 큰 불리) | 안 보임 | 짐 검사 시 발각 |
| 말 안장 | 말에게 가야 함 | 안 보임 | 짐 검사 |

## 3. 아이템이 선택지에 영향을 주는 7가지 방식

### ① 선택지를 연다 (태그 조건)
```yaml
- text: 밧줄을 타고 창문으로 내려간다
  requires: { has_tag: 밧줄, location_has: 창문 }
```

### ② 확률을 바꾼다 (장비보정)
- 좋은 자물쇠따개 `손재주 +6`, 조악한 쇠꼬챙이 `손재주 −5`
- 귀족복: 귀족 상대 `화술·예법 +8`, 빈민 상대 `화술 −6`, 소매치기의 표적이 됨
- 중갑: 전투 방어 `+15`, 은신 `−20`, 수영 불가, 피로 2배

### ③ 보이는 장비가 NPC 반응을 바꾼다 (첫인상)
| 보이는 것 | 반응 |
|-----------|------|
| 순종의 빛 성표 (쇠사슬 고리) | 신도·감독관이 덜 의심, 인간 저항 조직은 경계, 늪 마녀 적대 |
| 은화·금화 (인간이 소지) | 절도 의심 — 수색 확률 상승 (인간은 법적으로 돈을 가질 수 없다) |
| 뽑아 든 무기 | 모든 NPC 경계, 상점 거래 거부, 위압 +10 |
| 피 묻은 옷 | 의심 +20, 경비가 심문 |
| 비싼 반지 | 상인 가격 +15%, 도적의 표적 |
| 경비대 제복 (훔친 것) | 평민 복종, 진짜 경비에게는 대조 판정 |
| 노예 낙인 / 죄수 문신 | 세렌에서 체포 위험, 일부 지역 고용 거부 — **지울 수 없음** (가리는 것만 가능) |

### ④ 상태가 사용을 막는다 (조건·환경)
- 비 → `활` 시위가 젖으면 궁술 −15, 횃불 꺼짐
- 내구도 20 이하 → "칼날이 이가 빠져 있다" (품질 한 단계 하락), 0 → 부러짐
- 녹슨 자물쇠따개, 썩은 식량, 깨진 물약병

### ⑤ 무게와 부피가 행동을 바꾼다
```
적재율 = 총무게 / (근력 × 3 + 10) kg
  ~50%   : 정상
  ~75%   : 이동 시간 +20%, 은신 −5
  ~100%  : 이동 +50%, 은신 −15, 도주 −20, 피로 증가 2배
  100%+  : 이동 불가 → "무언가를 버려야 한다"
```
- 도주 선택지에 **"짐을 버리고 달린다"** 가 자동 추가된다 (배낭 손실, 도주 +25).

### ⑥ 아이템의 출처가 문제를 만든다 (소유 이력)
- 훔친 물건을 원래 마을에서 팔면 → 상인이 알아볼 확률 (특이한 물건일수록 높음)
- 죽은 용인 기사의 문장 검을 차고 다니면 → 그 가문 사람이 피의 복수를 하러 온다 (인간이 귀족의 검을 가졌다는 것 자체가 사형감)
- 장물은 장물아비에게만 제값의 30~50%로 판다

### ⑦ 조합하면 새 선택지가 생긴다
| 조합 | 결과 태그 | 선택지 |
|------|-----------|--------|
| 밧줄 + 갈고리 | `등반도구` | 성벽 오르기 |
| 기름 + 천 + 병 | `화염병` | 투척, 방화 |
| 독 + 음식/술 | `독이든음식` | 독살 (매우 위험한 선택지) |
| 약초 + 끓는 물 | `치료:약함` | 상처 소독 |
| 빈 종이 + 잉크 + 인장 사본 + [위조 스킬] | `위조:통행증` | 검문 통과 (경비 통찰과 대항) |

## 4. 선택지 생성 파이프라인

```
① 장면 컨텍스트 수집
   장소, 시간, 날씨, 등장 NPC, 상호작용 가능한 대상(문·창문·우물·말…)

② 후보 생성
   ├─ 시스템 선택지: 대상별 가능 동사 × 방식(approach) 전개
   └─ 스토리렛 선택지: 조건을 만족하는 작성된 선택지

③ 조건 필터 (각 선택지마다)
   ├─ 아이템 태그 / 장착 위치
   ├─ 스킬 최소치
   ├─ 지식 (모르면 숨김)
   ├─ 성향·상태 (공포 시 공격 잠김)
   ├─ 관계 (낯선 사람에게 부탁 불가)
   └─ 법·사회 맥락 (교회 안에서 무기 뽑기 = 가능하지만 결과 심각)

④ 분류
   ├─ 가능          → 체감 확률과 함께 표시
   ├─ 잠김(알 수 있음) → 회색 + 이유
   └─ 숨김(알 수 없음) → 표시 안 함

⑤ 정렬·압축 (모바일 화면 대응)
   상위 6~8개만 표시 + "다른 행동…" 메뉴로 나머지 묶음
   우선순위: 스토리렛 > 상황 핵심 동사 > 아이템 고유 행동 > 일반 행동
```

### 4.1 동사 목록 (초기 45개 예시)

| 범주 | 동사 |
|------|------|
| 이동 | 가다, 숨다, 몰래가다, 오르다, 뛰어내리다, 헤엄치다, 도망치다, 따라가다 |
| 관찰 | 살펴보다, 엿듣다, 수색하다, 기다리다 |
| 사회 | 말걸다, 묻다, 설득하다, 속이다, 위협하다, 흥정하다, 뇌물주다, 부탁하다, 모욕하다, 유혹하다, 사과하다 |
| 거래 | 사다, 팔다, 훔치다, 주다, 빌리다 |
| 물리 | 열다, 부수다, 자물쇠따다, 불지르다, 파다, 묶다, 풀다 |
| 전투 | 공격하다, 기습하다, 제압하다, 항복하다, 무장해제하다 |
| 생활 | 먹다, 자다, 일하다, 치료하다, 기도하다, 제작하다, 공부하다 |
| 신비 | 시전하다, 의식하다 |

## 5. 같은 장면, 다른 소지품 → 다른 선택지

**장면**: 밤. 레이번 남작(용인) 성채의 창고에 갇혔다. 문은 밖에서 빗장이 걸렸고, 높은 곳에 작은 창이 있다.
밖에서 경비 한 명의 발소리가 들린다.

### 소지품 A: 빈손 (몸수색 당함)
```
1. 문을 두드려 경비를 부른다
2. 창고 안을 뒤진다 (0.5시간)
3. 높은 창까지 기어오른다           [운동] 운이 따라야 한다
4. 경비에게 말을 건다 (문 너머로)
5. 기다린다
```

### 소지품 B: 부츠에 숨긴 단검 + 허리띠에 술병
```
1. 문을 두드려 경비를 부른다
2. 창고 안을 뒤진다
3. 높은 창까지 기어오른다           [운동] 운이 따라야 한다
4. 경비에게 말을 건다
5. 단검으로 문틈의 빗장을 들어 올린다   [손재주] 해볼 만하다      ← 단검(날붙이)
6. 경비를 불러 들어오게 한 뒤 기습한다  [단검술] 반반이다         ← 숨긴 무기
7. 문틈으로 술을 건네며 말을 붙인다    [화술] 해볼 만하다        ← 술(회유)
8. 기다린다
```

### 소지품 C: 마법 재능 (불 근원 룬 2개) + 부싯돌
```
...
5. 빗장을 열로 태워 끊는다           [불 마법] 확실해 보인다
   ⚠ 불빛과 탄내가 날 것이다 — 목격되면 '마녀' 소문
6. 창고의 건초에 불을 지른다         혼란을 틈타 탈출 / 성채 전체가 위험해진다
...
```

### 지식 D: 이 성채에서 하인으로 일한 적이 있음 (지식: `레이번성채_구조`)
```
...
5. 바닥의 배수용 철창을 들어 올린다   [근력] 해볼 만하다  ← 지식이 있어야 보임
   (예전에 하인들이 술을 몰래 숨기던 곳이다)
```

> 같은 감옥이지만 4명의 캐릭터에게 4개의 다른 탈출극이 생긴다.

## 6. 인벤토리 UI (모바일)

```
┌──────────────────────────────┐
│  [인물상]  체력 ■■■□□  피로 ■■□  │
│  배고픔 ■■■□  적재 62% (보통)    │
├──────────────────────────────┤
│ 장착                           │
│  주무기  철제 단검 (85%) ⓗ      │  ⓗ = 허리띠, 보임
│  몸통    누빈 갑옷 + 모직 외투   │
│  목      순종의 빛 성표 (보임)   │
│  숨김    자물쇠따개 (부츠)       │
├──────────────────────────────┤
│ 배낭 (7/12)                    │
│  밧줄 10m · 횃불×2 · 빵×3      │
│  말린 고기×2 · 붕대 · 편지(봉인) │
├──────────────────────────────┤
│ 돈주머니  은 4 · 동 17          │
└──────────────────────────────┘
```

- 아이템을 길게 누르면: 설명, 상태, 가치(흥정 스킬이 높을수록 정확), 출처(아는 범위), 사용 가능한 행동.
- **빠른 사용**은 선택지 화면에서 직접: 선택지에 아이템 아이콘이 붙어 "무엇을 써서 하는지" 알 수 있게.

## 7. 엔진 구현 메모

```ts
// 선택지 조건은 순수 함수로 평가 (테스트 쉬움)
interface ChoiceRequirement {
  hasTag?: string | { tag: string; slot?: SlotKind; visible?: boolean };
  skillMin?: { skill: SkillId; value: number };
  knows?: KnowledgeId;
  notCondition?: ConditionId;       // 예: 'fear' 상태면 잠김
  relationMin?: { npc: NpcRef; trust?: number; affection?: number };
  showWhenLocked?: boolean;         // 잠겼을 때 회색으로 보일지
  lockedHint?: string;              // "다리가 말을 듣지 않는다"
}
```

- 아이템 태그 인덱스: `Map<Tag, ItemInstance[]>` 를 인벤토리 변경 시에만 재계산 → 선택지 생성은 조회만.
- 장비보정은 `ModifierSource[]` 로 모아 판정 근거 미리보기(01 문서 4.3)에 그대로 사용.
