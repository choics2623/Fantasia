# 10. 명성·악명과 세계의 반응

> 질문: "주인공의 행보에 따라 세계 정세나 주인공의 대우가 달라지는 건 어떻게? 명성? 악명?"
> 답: **명성/악명을 하나의 수치로 만들지 않는다.** 같은 행동도 **누가 보느냐에 따라** 영웅담이 되고 범죄가 된다.
> 탈주 노예 서른 명을 구하면 인간들에게는 전설이 되고, 용제국에는 현상금이 걸리고, 목줄단에게는 위협이 된다.

---

## 1. 평판의 네 겹

| 겹 | 질문 | 범위 | 비고 |
|----|------|------|------|
| **① 인지도** | 얼마나 많은 사람이 나를 아는가 | 지역별 0~100 | 소문 시스템이 퍼뜨린다. 인지도가 낮으면 다른 수치는 거의 작동하지 않는다 |
| **② 시선** | 각 집단이 나를 어떻게 보는가 | 집단별 −100~+100 | 같은 행동을 집단마다 다르게 평가한다 (§2) |
| **③ 칭호** | 사람들이 나를 뭐라고 부르는가 | 소문으로 생기는 별칭 | "회색여울의 송곳니", "노예 도둑", "불타는 손" — 과장되고 왜곡된다 |
| **④ 위협도** | 권력이 나를 얼마나 위험하게 보는가 | 세력별 0~5 단계 | 세력의 **대응 단계**를 결정한다 (§5) |

> 개별 NPC와의 관계(08 문서)는 이것과 별개다. 평판은 "모르는 사람이 나를 처음 볼 때"를 결정하고,
> 관계는 "아는 사람이 나를 어떻게 대하는가"를 결정한다.

## 2. 시선 — 같은 행동, 다른 평가

### 2.1 집단 (예)

| 범주 | 집단 |
|------|------|
| 인간 | 노예·농노 일반, 북방 탈주자, 이름 없는 자들, 목줄단, 순종의 빛 신도, 순종의 빛 사제단, 늪 마녀, 원형장 투사 |
| 용 계통 | 진룡, 비늘 원로회(왕관 와이번), 순혈 용인 대가문, 비늘혈 용인, 각 후계자 파벌(아우락스·멜리산드·카스파르) |
| 그 외 | 엘다르(존속파/순혈파), 녹테른, 두르강, 세렌 상인 의회, 그롬, 바르그 노예사냥 조합, 잿빛 탑, 요툰, 하르칸 … |

### 2.2 평가표 (예)

| 행동 | 인간 노예 | 이름 없는 자들 | 목줄단 | 순종의 빛 | 용인 귀족 | 카스파르파 | 두르강 | 세렌 | 바르그 조합 |
|------|-----------|----------------|--------|-----------|-----------|------------|--------|------|-------------|
| 탈주 노예 30명 구출 | +15 | +20 | −15 | −5 | −20 | +3 | 0 | −5 (재산 손실) | −25 |
| 감독관 살해 | +10 | +5 | −25 | −10 | −25 | 0 | −3 | −3 | −10 |
| 감독관 살해 후 마을 전체가 본보기 처형당함 | **−20** | −5 | +5 | 0 | +5 | −5 | 0 | 0 | 0 |
| 비밀 학교 운영 | +8 | +25 | −10 | −15 | −15 | +5 | +2 | 0 | 0 |
| 두르강 계약을 끝까지 지킴 | +3 | 0 | 0 | 0 | 0 | 0 | **+20** | +5 | 0 |
| 계승 전쟁에서 카스파르를 도움 | +5 | +10 | −5 | 0 | −30 | **+30** | 0 | +5 | 0 |
| 굶주린 마을에 곡식 분배 | +20 | +10 | 0 | +5 | −5 | +3 | 0 | 0 | 0 |
| 순종의 빛 사제 앞에서 진명 사용 | +5 (경외·공포) | +15 | −20 | **−40** | −30 | 0 | 0 | 0 | −10 |
| 동료 인간을 팔아넘김 | −30 | −50 | +10 | 0 | +5 | −5 | −10 | +3 | +10 |

- 같은 행동이라도 **결과**가 평가를 바꾼다. 감독관을 죽인 대가로 마을이 본보기 처형을 당하면, 인간들은 주인공을 원망한다.
- **목격되지 않은 행동은 평판에 반영되지 않는다.** 대신 '사실(Fact)'로 남아 언젠가 드러날 수 있다.

## 3. 정체(Identity) — 평판은 '누구'에게 붙는가

주인공은 몸을 바꿔 다시 태어나는 유일한 존재다. 그래서 평판이 붙는 대상이 세 가지다.

| 정체 | 설명 | 몸이 죽으면 |
|------|------|-------------|
| **몸의 이름** | 지금 몸의 이름 (예: 회색여울의 리사) | 그 이름의 평판은 **죽은 사람의 것**으로 남는다. 사람들은 "리사"를 기억하고 무덤을 찾는다 |
| **가면·별칭** | 얼굴을 가리고 행동할 때 쓰는 이름 (예: '잿빛 송곳니') | 별칭은 살아남는다. 다음 몸이 같은 가면을 쓰면 **전설이 이어진다** ("송곳니는 죽지 않는다") |
| **돌아오는 이** | 잔향으로서의 정체 | 가장 큰 전설이자 가장 큰 표적. **스스로 밝히기 전까지** 대부분 모른다 |

### 3.1 정체를 연결하는 것
- **목격자**가 가면 아래 얼굴을 보면 → 별칭의 평판과 위협도가 몸의 이름으로 **합쳐진다.**
- 외모 식별: 흉터, 문신, 낙인, 신체 특질(은빛 눈, 거인의 체격), 특이한 장비, 말투.
- 주인공은 **목격자를 어떻게 할지** 선택해야 한다: 매수, 협박, 설득, 도주, 그리고 (그림다크) 침묵시키기.

### 3.2 "나는 돌아왔다" — 정체 공개
- 전생의 기억과 증거(전생만 아는 비밀 장소, 가보, 이름)를 보여 **"돌아오는 이"임을 밝힐 수 있다.**
- 효과: 인간·이름 없는 자들의 시선 **폭등**, 추종자 대량 유입, 찬가 단계 가속.
- 대가: 모든 고대 세력의 위협도 즉시 최고 단계. 맹약회의 의제가 되고, 잔향 사냥이 대륙 전체에서 격화된다.
- 공개하지 않고 **소수에게만** 밝히는 선택도 있다 (이름 없는 자들의 핵심, 깊이 신뢰하는 동료).

## 4. 대우 — 시선 구간별 반응

| 구간 | 이름 | 처음 보는 그 집단의 사람이 하는 일 |
|------|------|-------------------------------------|
| +80 이상 | **숭배** | 목숨을 건다. 숨겨 주고, 따라나서고, 대신 죽는다. 자식 이름을 주인공 별칭으로 짓는다 |
| +50 | **존경** | 공짜로 먹이고 재운다. 정보를 준다. 추종자로 합류할 수 있다 |
| +20 | **호의** | 가격 할인, 길 안내, 작은 부탁을 들어준다 |
| 0 | **무관심** | 기본 반응 |
| −20 | **경계** | 가격 인상, 거래 거부, 경비를 부를 수 있다 |
| −50 | **적대** | 밀고, 공격, 문을 닫는다 |
| −80 이하 | **증오** | 현상금 사냥, 복수, 보는 즉시 죽이려 한다 |

- **인지도 보정**: 실제 반응 = 시선 × (인지도 / 100). 무명이면 아무도 반응하지 않는다.
- **알아보는가**: 그 사람이 주인공을 알아보는지 먼저 판정한다 (인지도 + 외모 특징 + 변장 vs 상대의 감각·통찰).
- 대사 시스템(05 문서)은 `player.standing.<집단>`, `player.title`, `player.renown.<지역>`을 조건으로 쓴다.
  → "네가 그 잿빛 송곳니라고? 웃기지 마." / "…아이들이 당신 노래를 불러요."

### 4.1 칭호가 바꾸는 것
| 칭호 (예) | 생기는 조건 | 효과 |
|-----------|-------------|------|
| 회색여울의 송곳니 | 회색여울 근처에서 감독관·사냥꾼 다수 처치 | 인간 투사·탈주자 존경, 바르그 사냥꾼이 표적으로 삼음 |
| 노예 도둑 | 탈주 노예를 반복 구출 | 세렌·용인 귀족 경계, 탈주자들이 먼저 찾아옴 |
| 불타는 손 | 공개적으로 불 진명 사용 | 순종의 빛·용인 공포, 위협도 +1 |
| 빵을 나누는 이 | 기근 때 곡식 분배 | 인간 노예 호의, 사기 + |
| 개목걸이 | 동족을 팔아넘김 | 인간 증오, 목줄단 호의 |
| 계약을 지키는 무혈자 | 두르강 계약 이행 | 두르강 존중, 계약 조건 개선 |

> 칭호는 **소문으로 왜곡**된다. 도적 둘을 쫓아낸 일이 두 지방 건너면 "용인 기사 쉰을 혼자 벤 괴물"이 된다.
> 과장된 칭호는 기대도 부른다 — 사람들이 그 괴물에게 도움을 청하러 온다.

## 5. 세계의 반응 — 세력별 대응 단계

각 세력은 주인공에 대해 **인식 상태**와 **대응 단계**를 가진다. 위협도·시선·인지도·사건이 대응 단계를 올리고 내린다.

### 5.1 적대 대응 사다리 (용제국 예)

| 단계 | 대응 | 플레이어가 겪는 것 |
|------|------|--------------------|
| 0 | 무관심 | 아무 일도 없다 |
| 1 | **지역 현상금** | 수배 전단, 목줄단 밀고자 증가, 검문 강화 |
| 2 | **바르그 사냥대** | 냄새로 추적하는 노예사냥꾼 무리. 은신처가 위험해짐 |
| 3 | **수색령과 본보기** | 지역군의 집집 수색, 숨긴 자 공개 처형 — **인간들이 주인공 때문에 죽기 시작한다** |
| 4 | **와이번 기사단** | 하늘에서 수색. 영역(09 문서)이 공중 습격당함 |
| 5 | **진룡** | 진룡 한 마리가 직접 움직인다. 숨은 마을 하나가 하룻밤에 재가 된다. 맹약회의 의제 |

### 5.2 세력마다 다른 사다리
| 세력 | 2~3단계의 모습 | 최고 단계 |
|------|----------------|-----------|
| 엘다르 존속파 | 납치조('정원사들')가 잔향 징후자를 수집 | 영원 여왕의 예지로 위치가 드러남 |
| 멜리산드 | 이식 실험체 회수조, 잿빛 탑 시험관 | 주인공 생포 작전 (죽이지 않는다 — 그릇이 필요하다) |
| 아우락스 | 잔향 사냥 강화령 | 대숙청 (징후 있는 인간 일제 처형) |
| 녹테른 | 그림자 사냥꾼 | 첫 갈증의 군주가 깨어난다 |
| 순종의 빛 | 파문, 신도들의 밀고 | 이단 성전 선포 — 신도 인간들이 주인공을 사냥 |
| 세렌 | 계약 무효, 상관 동결 | 해군 봉쇄, 용병 고용 |

### 5.3 우호 사다리 (협력 가능 세력)
| 단계 | 내용 |
|------|------|
| 0 | 무관심 |
| 1 | **접촉** — 밀사가 은밀히 찾아온다 |
| 2 | **거래 제안** — 정보·물자 교환, 서로를 이용 |
| 3 | **비밀 동맹** — 공동 작전, 은신처 제공 |
| 4 | **공개 동맹 / 칙허** — 인간 영역의 법적 인정 (09 문서 §3 '하사받는다') |

- 카스파르파, 두르강 일부 씨족, 레이디 세실(녹테른 이단), 드라우르, 세렌 일부 상가가 우호 사다리를 가질 수 있다.
- **같은 세력이 두 사다리를 동시에 가질 수 있다** — 이용하면서 경계한다. 비늘 원로회는 주인공을 도구로 쓰면서 죽일 준비도 한다.

## 6. 세계 정세는 어떻게 바뀌는가

### 6.1 월드 클락에 들어가는 "주인공 변수"

월드 클락(WORLD_BIBLE §10)의 분기 가중치에 주인공의 행보가 직접 들어간다.

| 클락 | 주인공 변수 | 예 |
|------|-------------|-----|
| 용황의 죽음 | 각 후계자에 대한 기여도, 후계자 암살·구출 | 카스파르 기여도 60 이상 → 카스파르 즉위 가중치 ×2 |
| 맹약회의 313 | 최고 위협도, '돌아오는 이' 공개 여부, 각 종족 대표와의 관계 | 위협도 5 + 정체 공개 → 대숙청 가중치 ×3 / 두르강·녹테른 대표 설득 → 맹약 균열 |
| 북방 대탈주 | 탈주자 수용 규모, 서리왕과의 접촉 | 회색여울 숨은 마을이 탈주자 500명 수용 → '정착' 분기 |
| 끊어진 고리 | 알베릭 구출 여부 | 알베릭 생존 → 순종의 빛 개혁 가능 |
| 무혈자의 찬가 | 영역, 학교, 추종자, 정체 공개 | 09 문서 §7 |

### 6.2 반작용 — 크게 움직이면 세계도 크게 움직인다
- 주인공의 위협도가 오르면 **고대 세력끼리 다투던 것을 멈추고 손을 잡을 수도 있다** (공동의 적).
- 반대로 주인공이 조용히 움직이면 고대 세력들은 서로의 전쟁에 몰두한다 → 그 틈이 인간의 기회.
- 주인공이 활동한 지역에는 **본보기 처형·재의 법 강화** 같은 탄압이 온다. 인간들의 시선은 희망과 원망 사이를 오간다.
- 플레이어는 늘 선택한다: **크게 외칠 것인가, 숨어서 쌓을 것인가.**

### 6.3 시간이 지나면
- 인지도는 활동이 없으면 서서히 줄어든다 (전설은 남는다 — 칭호는 노래가 되어 오래간다).
- 위협도는 낮아지지만 **기록은 남는다.** 잿빛 탑과 엘다르는 잊지 않는다.
- 15년 공백(아기로 다시 태어남) 뒤에는 세상이 주인공을 "죽은 전설"로 기억한다. 다시 나타나면 극적인 효과가 있다.

## 7. 플레이어가 평판을 다루는 수단

| 수단 | 효과 |
|------|------|
| 가면·변장 | 행동의 평판을 별칭에 묶는다 |
| 소문 퍼뜨리기 (음유시인 요한 등) | 특정 지역·집단에 이야기를 퍼뜨린다. 거짓 소문도 가능 |
| 노래 | 인간 집단 시선을 천천히, 오래 올린다 |
| 증거 숨기기·목격자 처리 | 사실이 소문이 되지 않게 막는다 |
| 공개 연설 (지휘의 목소리) | 인지도와 시선을 한 번에 크게 움직인다. 위협도도 |
| 누명 씌우기 | 다른 사람·세력에게 행동을 돌린다 (그 사람이 대신 죽을 수도 있다) |
| 속죄 행동 | 원망하는 집단에 대한 보상 (본보기 처형당한 마을의 가족 돌보기 등) |

## 8. 화면 — "세상이 나를 보는 눈"

## 9. 구현 메모

```ts
interface Reputation {
  renown: Record<RegionId, number>;                       // 0~100
  standing: Record<AudienceId, number>;                   // -100~100
  titles: { id: string; text: string; regions: RegionId[]; strength: number; identity: IdentityId }[];
  threat: Record<FactionId, { aware: 0|1|2|3; hostileTier: 0|1|2|3|4|5; friendlyTier: 0|1|2|3|4 }>;
  identities: { id: IdentityId; kind: 'body'|'alias'|'returner'; name: string; linkedTo?: IdentityId[] }[];
}
// 행동 → Fact(목격자 포함) → 소문 전파(시간·거리) → 도달한 지역에서 집단별 평가표 적용 → standing/renown/titles 갱신
// 세력 AI는 매주 threat를 보고 대응 단계를 올리거나 내린다 (임계값 + 무작위 + 세력 성향)
```

- 평가표(§2.2)는 데이터 파일(`content/base/reputation/deeds.yaml`)로 관리 — 새 행동 유형을 추가할 때 집단별 반응을 한 줄씩 적는다.
- 반응 계산은 **소문이 도착했을 때** 일어난다. 그래서 멀리 있는 지역일수록 늦게, 더 과장되어 반응한다.
