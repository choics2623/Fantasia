# 10. 명성·악명과 세계의 반응

> 질문: "주인공의 행보에 따라 세계 정세나 주인공의 대우가 달라지는 건 어떻게? 명성? 악명?"
> 답: **명성/악명을 하나의 수치로 만들지 않는다.** 같은 행동도 **누가 보느냐에 따라** 영웅담이 되고 범죄가 된다.
> 탈주 노예 서른 명을 구하면 인간들에게는 전설이 되고, 용제국에는 현상금이 걸리고, 목줄단에게는 위협이 된다.
> 그리고 평판은 **한 회차 안의 것**이다. 주인공이 죽으면 세계는 회귀점으로 돌아가고, 노래도 현상금도 함께 지워진다.
> 회차를 넘어 남는 것은 둘뿐이다: **주인공의 기억**, 그리고 **시간에 민감한 존재들의 기시감** (§3.3).

---

## 1. 평판의 네 겹

| 겹 | 질문 | 범위 | 비고 |
|----|------|------|------|
| **① 인지도** | 얼마나 많은 사람이 나를 아는가 | 지역별 0~100 | 소문 시스템이 퍼뜨린다. 인지도가 낮으면 다른 수치는 거의 작동하지 않는다 |
| **② 시선** | 각 집단이 나를 어떻게 보는가 | 집단별 −100~+100 | 같은 행동을 집단마다 다르게 평가한다 (§2) |
| **③ 칭호** | 사람들이 나를 뭐라고 부르는가 | 소문으로 생기는 별칭 | "회색여울의 송곳니", "노예 도둑", "불타는 손" — 과장되고 왜곡된다 |
| **④ 위협도** | 권력이 나를 얼마나 위험하게 보는가 | 세력별 0~5 단계 | 세력의 **대응 단계**를 결정한다 (§5) |

> 개별 NPC와의 관계(08 문서)는 이것과 별개다. 평판은 "모르는 사람이 나를 처음 볼 때"를 결정하고,
> 관계는 "아는 사람이 나를 어떻게 대하는가"를 결정한다.
> 네 겹 모두 회귀하면 회귀점 값(거의 0)으로 돌아간다.

## 2. 시선 — 같은 행동, 다른 평가

### 2.1 집단 (예)

| 범주 | 집단 |
|------|------|
| 인간 | 노예·농노 일반, 북방 탈주자, 이름 없는 자들, 목줄단, 순종의 빛 신도, 순종의 빛 사제단, 늪 마녀, 원형장 투사 |
| 용 계통 | 진룡, 비늘 원로회(왕관 와이번), 순혈 용인 대가문, 비늘혈 용인, 각 후계자 파벌(아우락스·멜리산드·카스파르) |
| 그 외 | 엘다르(존속파/순혈파), 녹테른, 두르강, 세렌 상인 의회, 그롬, 바르그 노예사냥 조합, 잿빛 탑, 요툰, 하르칸 … |

### 2.2 평가표 (예)

| 행동 | 인간 노예 | 이름 없는 자들 | 목줄단 | 순종의 빛 | 용인 귀족 | 카스파르파 | 두르강 | 세렌 | 바르그 조합 |
|------|-----------|----------------|--------|-----------|-----------|------------|--------|------|-------------|
| 탈주 노예 30명 구출 | +15 | +20 | −15 | −5 | −20 | +3 | 0 | −5 (재산 손실) | −25 |
| 감독관 살해 | +10 | +5 | −25 | −10 | −25 | 0 | −3 | −3 | −10 |
| 감독관 살해 후 마을 전체가 본보기 처형당함 | **−20** | −5 | +5 | 0 | +5 | −5 | 0 | 0 | 0 |
| 비밀 학교 운영 | +8 | +25 | −10 | −15 | −15 | +5 | +2 | 0 | 0 |
| 두르강 계약을 끝까지 지킴 | +3 | 0 | 0 | 0 | 0 | 0 | **+20** | +5 | 0 |
| 계승 전쟁에서 카스파르를 도움 | +5 | +10 | −5 | 0 | −30 | **+30** | 0 | +5 | 0 |
| 굶주린 마을에 곡식 분배 | +20 | +10 | 0 | +5 | −5 | +3 | 0 | 0 | 0 |
| 순종의 빛 사제 앞에서 진명 사용 | +5 (경외·공포) | +15 | −20 | **−40** | −30 | 0 | 0 | 0 | −10 |
| 동료 인간을 팔아넘김 | −30 | −50 | +10 | 0 | +5 | −5 | −10 | +3 | +10 |
| **일어나기 전에 수색을 경고함** (그리고 맞음) | +10 | +15 | −10 | −10 (이단의 예지) | −5 | 0 | 0 | 0 | −5 |

- 같은 행동이라도 **결과**가 평가를 바꾼다. 감독관을 죽인 대가로 마을이 본보기 처형을 당하면, 인간들은 주인공을 원망한다.
- **목격되지 않은 행동은 평판에 반영되지 않는다.** 대신 '사실(Fact)'로 남아 언젠가 드러날 수 있다.
- **평가표는 회차를 넘어 배운다.** 첫 회차의 플레이어는 감독관을 죽이면 마을이 처형당한다는 것을 모른다. 둘째 회차의 플레이어는 안다. 회귀자의 평판 쌓기는 빠르다 — 누구를 먼저 도와야 소문이 어디로 가는지 알기 때문이다.

## 3. 정체(Identity) — 평판은 '누구'에게 붙는가

주인공은 몸을 바꾸지 않는다. 한 시대 내내 같은 몸으로, 같은 저녁에서 다시 시작한다. 평판이 붙는 대상은 세 가지다.

| 정체 | 설명 | 주인공이 죽으면 |
|------|------|-----------------|
| **이름** | 공개된 노예 이름 (예: 회색여울의 '셋째'), 그리고 소수만 아는 진짜 이름 | 회귀한다. 그 이름은 다시 아무도 모르는 농노의 이름이다 |
| **가면·별칭** | 얼굴을 가리고 행동할 때 쓰는 이름 (예: '잿빛 송곳니') | 회귀한다. 별칭은 아무도 들어 본 적 없는 말이 된다. **같은 별칭을 다시 쓸 수는 있다** — 처음부터 다시 노래가 된다 |
| **돌아오는 이** | 회귀자로서의 정체 — 죽어도 같은 저녁으로 돌아오는 자 | 가장 큰 전설이자 가장 큰 표적. **스스로 밝히기 전까지** 대부분 모른다. 그리고 시간에 민감한 존재들만이, 밝히지 않아도 **낌새를 느낀다** (§3.3) |

### 3.1 정체를 연결하는 것
- **목격자**가 가면 아래 얼굴을 보면 → 별칭의 평판과 위협도가 이름으로 **합쳐진다.**
- 외모 식별: 흉터, 문신, 낙인, 신체 특질(은빛 눈, 거인의 체격), 특이한 장비, 말투.
- 회귀하면 흉터는 사라진다 (03 §4.1). 지난 회차에 얼굴을 기억하게 만든 흉터가 이번 몸에는 없다. 그러나 목소리·말투·버릇은 영혼의 것이다 — 숙적(17 문서)이 회차 안에서 붙잡는 것은 대개 이쪽이다.
- 주인공은 **목격자를 어떻게 할지** 선택해야 한다: 매수, 협박, 설득, 도주, 그리고 (그림다크) 침묵시키기.

### 3.2 "나는 돌아왔다" — 정체 공개
- 회귀자임을 증명하는 방법은 하나다: **아직 일어나지 않은 일을 맞히는 것.** 〔고정〕 사건(03 §4.4)을 고르면 증명은 확실하다. 〔표류〕 사건을 고르면 틀릴 수 있다 — 틀린 예언자는 미친 사람이다.
- 소수에게 밝히기: 신뢰 70 이상 + 예언 하나. 믿으면 관계 태그 `knows_regressor` (12 §2.2).
- 공개 선언 (광장, 설교단, 맹약회의 앞): 인간·이름 없는 자들의 시선 **폭등**, 추종자 대량 유입, 찬가 '이름' 단계 조건 일부 충족. 칭호 「돌아오는 이」.
- 대가: 모든 고대 세력의 위협도 즉시 최고 단계. 맹약회의 의제가 되고, 잔향 사냥이 대륙 전체에서 격화된다. 그리고 **시간에 민감한 존재들은 이제 확신한다** — 그들은 회귀자를 죽이지 않는다. 회귀를 끊을 수단을 가지고 온다 (03 §4.5).
- 공개는 그 회차의 것이다. 회귀하면 아무도 들은 적이 없다. 그래서 회귀자는 **공개를 여러 번 시험해 볼 수 있다** — 누구에게 밝히면 무엇이 오는지. 그 시험의 값은 `loop.count`다.

### 3.3 기시감 — 회차를 넘는 유일한 평판
시간에 민감한 존재들 — 엘다르(시간의 혈명), 용황 바르스카르, 잿빛 탑 — 은 회귀를 **기억하지 못하지만 낌새를 느낀다.** 이것은 평판이 아니다. 그들은 주인공이 무엇을 했는지 모른다. 다만 **주인공이 있다는 것**을, 회차가 쌓일수록 더 일찍, 더 강하게 안다. 공식은 03 §7.2.

| 존재 | 기시감이 낮을 때 | 기시감이 높을 때 |
|------|------------------|------------------|
| 엘다르 존속파·영원 여왕 | 첫 만남 대사가 조금 길다. "낯설지 않구나." | 정원사들이 일찍 찾아온다. 영원 여왕의 예지가 회색여울을 가리킨다. 그물(클락 5)이 앞당겨진다 |
| 엘다르 개인 (정원지기 감독관 등) | 이유 없이 오래 쳐다본다 | 이유 없이 마음을 연다 — 또는 이유 없이 두려워한다. 둘 다 보고서가 된다 |
| 용황 바르스카르 | 꿈에서 인간의 냄새를 맡는다 | 잠결에 이름을 부른다. 궁정에 소문이 돈다. 아우락스가 그 소문을 듣는다 |
| 잿빛 탑 | 시간 측정값에 설명 못 할 떨림 | '시간 측정관'이 회색여울로 온다. 유리 칼이 움직인다 |

- 기시감에는 **접촉 보정**이 있다. 지난 회차들에서 그 존재를 자주 만났을수록 그 존재의 기시감이 크다. 영원 여왕과 일곱 회차 동안 거래한 주인공은, 여덟째 회차에 여왕이 처음 보는 얼굴이 아니다 — 여왕은 이유를 모르고, 그래서 더 위험하다.
- 이것은 **기회**이기도 하다. 기시감이 높은 엘다르는 주인공의 말을 이상하게 믿는다. 11 문서 §2.3의 회차를 넘는 작전 가운데 몇은 이것을 쓴다.
- 평범한 인간과 다른 고대 종족(시간에 닿지 않은 자들)은 아무것도 느끼지 못한다. 바르그 같은 코 좋은 사냥꾼은 기시감이 아니라 **냄새**로 안다 (03 §7.1) — 볼크는 주인공을 모르지만, 젖은 재 냄새는 안다.

## 4. 대우 — 시선 구간별 반응

| 구간 | 이름 | 처음 보는 그 집단의 사람이 하는 일 |
|------|------|-------------------------------------|
| +80 이상 | **숭배** | 목숨을 건다. 숨겨 주고, 따라나서고, 대신 죽는다. 자식 이름을 주인공 별칭으로 짓는다 |
| +50 | **존경** | 공짜로 먹이고 재운다. 정보를 준다. 추종자로 합류할 수 있다 |
| +20 | **호의** | 가격 할인, 길 안내, 작은 부탁을 들어준다 |
| 0 | **무관심** | 기본 반응 |
| −20 | **경계** | 가격 인상, 거래 거부, 경비를 부를 수 있다 |
| −50 | **적대** | 밀고, 공격, 문을 닫는다 |
| −80 이하 | **증오** | 현상금 사냥, 복수, 보는 즉시 죽이려 한다 |

- **인지도 보정**: 실제 반응 = 시선 × (인지도 / 100). 무명이면 아무도 반응하지 않는다.
- **알아보는가**: 그 사람이 주인공을 알아보는지 먼저 판정한다 (인지도 + 외모 특징 + 변장 vs 상대의 감각·통찰).
- 대사 시스템(05 문서)은 `player.standing.<집단>`, `player.title`, `player.renown.<지역>`, `loop.count`, `dejavu.<존재>`를 조건으로 쓴다.
  → "네가 그 잿빛 송곳니라고? 웃기지 마." / "…아이들이 당신 노래를 불러요." / (엘다르) "우리가 만난 적이 있던가. 없지. 없을 텐데."

### 4.1 칭호가 바꾸는 것
| 칭호 (예) | 생기는 조건 | 효과 |
|-----------|-------------|------|
| 회색여울의 송곳니 | 회색여울 근처에서 감독관·사냥꾼 다수 처치 | 인간 투사·탈주자 존경, 바르그 사냥꾼이 표적으로 삼음 |
| 노예 도둑 | 탈주 노예를 반복 구출 | 세렌·용인 귀족 경계, 탈주자들이 먼저 찾아옴 |
| 불타는 손 | 공개적으로 불 진명 사용 | 순종의 빛·용인 공포, 위협도 +1 |
| 빵을 나누는 이 | 기근 때 곡식 분배 | 인간 노예 호의, 사기 + |
| 개목걸이 | 동족을 팔아넘김 | 인간 증오, 목줄단 호의 |
| 계약을 지키는 무혈자 | 두르강 계약 이행 | 두르강 존중, 계약 조건 개선 |
| 날을 아는 자 | 아직 오지 않은 수색·징발을 여러 번 맞힘 | 인간·이름 없는 자들 경외, 순종의 빛 이단 지목, 잿빛 탑 관심 (잔향 징후 소문) |
| 돌아오는 이 | 정체 공개 (§3.2) | §3.2 |

> 칭호는 **소문으로 왜곡**된다. 도적 둘을 쫓아낸 일이 두 지방 건너면 "용인 기사 쉰을 혼자 벤 괴물"이 된다.
> 과장된 칭호는 기대도 부른다 — 사람들이 그 괴물에게 도움을 청하러 온다.
> 회귀하면 칭호는 사라진다. 그러나 주인공은 **어떤 행동이 어떤 칭호가 되었는지** 안다. 원하는 칭호를 노리고 움직일 수 있다.

## 5. 세계의 반응 — 세력별 대응 단계

각 세력은 주인공에 대해 **인식 상태**와 **대응 단계**를 가진다. 위협도·시선·인지도·사건이 대응 단계를 올리고 내린다. 회귀하면 모든 세력의 대응 단계는 회귀점 값(0)으로 돌아간다. **단, 기시감이 높은 세력의 출발점은 다르다** (§5.2 마지막 열).

### 5.1 적대 대응 사다리 (용제국 예)

| 단계 | 대응 | 플레이어가 겪는 것 |
|------|------|--------------------|
| 0 | 무관심 | 아무 일도 없다 |
| 1 | **지역 현상금** | 수배 전단, 목줄단 밀고자 증가, 검문 강화 |
| 2 | **바르그 사냥대** | 냄새로 추적하는 노예사냥꾼 무리. 은신처가 위험해짐 (냄새 보정, 03 §7.1) |
| 3 | **수색령과 본보기** | 지역군의 집집 수색, 숨긴 자 공개 처형 — **인간들이 주인공 때문에 죽기 시작한다** |
| 4 | **와이번 기사단** | 하늘에서 수색. 영역(09 문서)이 공중 습격당함 |
| 5 | **진룡** | 진룡 한 마리가 직접 움직인다. 숨은 마을 하나가 하룻밤에 재가 된다. 맹약회의 의제 |

### 5.2 세력마다 다른 사다리
| 세력 | 2~3단계의 모습 | 최고 단계 | 기시감이 높을 때 (회차를 넘어) |
|------|----------------|-----------|-------------------------------|
| 엘다르 존속파 | 납치조('정원사들')가 잔향 징후자를 수집 | 영원 여왕의 예지로 위치가 드러남 → 시간의 그물 | 회차 시작부터 인식 상태 1 (낌새). 정원사들이 일찍 온다 |
| 멜리산드 | 이식 실험체 회수조, 잿빛 탑 시험관 | 주인공 생포 작전 (죽이지 않는다 — 그릇이 필요하다) | 없음 (시간에 닿지 않았다) — 다만 잿빛 탑을 통해 간접적으로 |
| 아우락스 | 잔향 사냥 강화령 | 대숙청 (징후 있는 인간 일제 처형). 아버지의 불 | 바르스카르의 잠꼬대 소문을 듣고 움직인다 (03 §7.2 기시감 25+) |
| 녹테른 | 그림자 사냥꾼 | 첫 갈증의 군주가 깨어난다 | 없음 |
| 순종의 빛 | 파문, 신도들의 밀고 | 이단 성전 선포 — 신도 인간들이 주인공을 사냥 | 없음 |
| 세렌 | 계약 무효, 상관 동결 | 해군 봉쇄, 용병 고용 | 없음 |
| 잿빛 탑 | 밀정, 시간 측정관 | 시간 유리 칼 | 회차 시작부터 인식 상태 1~2. 측정관이 일찍 온다 |

### 5.3 우호 사다리 (협력 가능 세력)
| 단계 | 내용 |
|------|------|
| 0 | 무관심 |
| 1 | **접촉** — 밀사가 은밀히 찾아온다 |
| 2 | **거래 제안** — 정보·물자 교환, 서로를 이용 |
| 3 | **비밀 동맹** — 공동 작전, 은신처 제공 |
| 4 | **공개 동맹 / 칙허** — 인간 영역의 법적 인정 (09 문서 §3 '하사받는다') |

- 카스파르파, 두르강 일부 씨족, 레이디 세실(녹테른 이단), 드라우르, 세렌 일부 상가가 우호 사다리를 가질 수 있다.
- **같은 세력이 두 사다리를 동시에 가질 수 있다** — 이용하면서 경계한다. 비늘 원로회는 주인공을 도구로 쓰면서 죽일 준비도 한다.
- 우호 사다리도 회귀하면 0이다. 다만 **어느 밀사가 무엇을 원하는지** 아는 주인공은 1→3을 첫 회차보다 훨씬 빨리 오른다. 카스파르가 무엇에 마음이 움직이는지 아는 것은 칙허까지의 지름길이다.

## 6. 세계 정세는 어떻게 바뀌는가

### 6.1 월드 클락에 들어가는 "주인공 변수"

월드 클락(WORLD_BIBLE §10)의 분기 가중치에 주인공의 행보가 직접 들어간다. 모두 **그 회차 안의 값**이다.

| 클락 | 주인공 변수 | 예 |
|------|-------------|-----|
| 용황의 죽음 | 각 후계자에 대한 기여도, 후계자 암살·구출 | 카스파르 기여도 60 이상 → 카스파르 즉위 가중치 ×2 |
| 맹약회의 313 | 최고 위협도, '돌아오는 이' 공개 여부, 각 종족 대표와의 관계, 잔향 징후 수 | 위협도 5 + 정체 공개 → 대숙청 가중치 ×3 / 두르강·녹테른 대표 설득 → 맹약 균열 |
| 북방 대탈주 | 탈주자 수용 규모, 서리왕과의 접촉 | 회색여울 숨은 마을이 탈주자 500명 수용 → '정착' 분기 |
| 영혼 정원 | 엘다르 존속파의 기시감 (회차를 넘음), 잔향 징후 | 기시감 45+ → 의식이 312년 안에 준비됨 |
| 끊어진 고리 | 알베릭 구출 여부 | 알베릭 생존 → 순종의 빛 개혁 가능 |
| 무혈자의 찬가 | 영역, 학교, 추종자, 정체 공개 | 09 문서 §7 |

### 6.2 반작용 — 크게 움직이면 세계도 크게 움직인다
- 주인공의 위협도가 오르면 **고대 세력끼리 다투던 것을 멈추고 손을 잡을 수도 있다** (공동의 적).
- 반대로 주인공이 조용히 움직이면 고대 세력들은 서로의 전쟁에 몰두한다 → 그 틈이 인간의 기회.
- 주인공이 활동한 지역에는 **본보기 처형·재의 법 강화** 같은 탄압이 온다. 인간들의 시선은 희망과 원망 사이를 오간다.
- 플레이어는 늘 선택한다: **크게 외칠 것인가, 숨어서 쌓을 것인가.** 회귀자는 하나 더 고른다: **이번 회차에 외치고 배울 것인가, 이번 회차는 숨어서 끝까지 갈 것인가.**

### 6.3 시간이 지나면 — 그리고 회귀하면
- **회차 안에서**: 인지도는 활동이 없으면 서서히 줄어든다 (전설은 남는다 — 칭호는 노래가 되어 오래간다). 위협도는 낮아지지만 **기록은 남는다.** 잿빛 탑과 엘다르는 잊지 않는다.
- **회귀하면**: 네 겹 모두 회귀점 값으로. 노래는 아무도 부른 적이 없다. 현상금 전단은 아직 인쇄되지 않았다. 주인공 때문에 본보기로 처형된 사람들은 살아 있다 — 그리고 주인공을 모른다.
- **기억만 남는다.** 주인공은 지난 회차의 노래를 기억한다. 그 노래를 이번 회차의 가수(찬송 순례자 요한 등)에게 가르칠 수 있다 — 아무도 지은 사람을 모르는 노래가 된다. 처음보다 빨리 퍼지지만(인간 집단 시선 성장 ×1.5), 노래가 가리키는 사람은 아직 아무것도 하지 않았다.
- 시간에 민감한 존재들의 기시감(§3.3)만이 회차를 넘어 쌓인다.

## 7. 플레이어가 평판을 다루는 수단

| 수단 | 효과 |
|------|------|
| 가면·변장 | 행동의 평판을 별칭에 묶는다 |
| 소문 퍼뜨리기 (찬송 순례자 요한 등) | 특정 지역·집단에 이야기를 퍼뜨린다. 거짓 소문도 가능 |
| 노래 | 인간 집단 시선을 천천히, 오래 올린다. 지난 회차의 노래를 다시 가르치면 더 빠르다 (§6.3) |
| 증거 숨기기·목격자 처리 | 사실이 소문이 되지 않게 막는다 |
| 공개 연설 (군중의 목소리, 06 §5.5) | 인지도와 시선을 한 번에 크게 움직인다. 위협도도 |
| 누명 씌우기 | 다른 사람·세력에게 행동을 돌린다 (그 사람이 대신 죽을 수도 있다) |
| 속죄 행동 | 원망하는 집단에 대한 보상 (본보기 처형당한 마을의 가족 돌보기 등) |
| 예언 | 아직 오지 않은 일을 말한다. 맞으면 경외, 틀리면 조롱. 어느 쪽이든 앎의 흔적 (03 §4.3) |
| 냄새 덮기·접촉 피하기 | 회차를 넘는 노출(냄새·기시감)을 늦춘다 (03 §7) |

## 9. 구현 메모

```ts
interface Reputation {                                    // 회차에 속한다 — 회귀하면 회귀점 값으로
  loop: number;
  renown: Record<RegionId, number>;                       // 0~100
  standing: Record<AudienceId, number>;                   // -100~100
  titles: { id: string; text: string; regions: RegionId[]; strength: number; identity: IdentityId }[];
  threat: Record<FactionId, { aware: 0|1|2|3; hostileTier: 0|1|2|3|4|5; friendlyTier: 0|1|2|3|4 }>;
  identities: { id: IdentityId; kind: 'name'|'alias'|'regressor'; name: string; linkedTo?: IdentityId[]; revealedTo?: NpcId[] }[];
}
// 영혼 쪽 (03 Soul) — 회귀해도 남는다
interface CrossLoopExposure {
  scent: number;                                          // 03 §7.1 계산값
  dejaVuContact: Record<BeingId, number>;                 // 접촉한 회차 수
  pastTitles: { loop: number; text: string; peak: number }[];   // 화면용 기억
  pastSongs: SongId[];                                    // 다시 가르칠 수 있는 노래
}
// 회귀 시: threat[f].aware = baseAware(f, dejaVu(f))  — 시간에 민감한 세력만 0이 아닐 수 있다
// 행동 → Fact(목격자 포함) → 소문 전파(시간·거리) → 도달한 지역에서 집단별 평가표 적용 → standing/renown/titles 갱신
// 세력 AI는 매주 threat를 보고 대응 단계를 올리거나 내린다 (임계값 + 무작위 + 세력 성향)
```

- 평가표(§2.2)는 데이터 파일(`content/base/reputation/deeds.yaml`)로 관리 — 새 행동 유형을 추가할 때 집단별 반응을 한 줄씩 적는다.
- 반응 계산은 **소문이 도착했을 때** 일어난다. 그래서 멀리 있는 지역일수록 늦게, 더 과장되어 반응한다. 소문 도착 시각은 〔표류〕다 (03 §4.4).
