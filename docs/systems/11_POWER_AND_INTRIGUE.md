# 11. 권력과 음모 — 땅 없는 힘, 인정받는 힘, 그리고 암살

> 질문 ①: "인간이 영지를 가지면 주변 세력이 인정하지 않고 짓밟으려 하지 않을까? 그래서 일부러 힘이 생기기 전까지 영지를 갖지 않는 전략도?"
> 질문 ②: "혼자서 아주 강해지면 주요 인물 암살도 시도할 수 있게?"
> 답: 둘 다 **정해진 길이 아니라 시뮬레이션의 결과**로 가능하게 만든다.
> 세계는 "인간이 땅을 가졌다"는 사실에 반응하고, 플레이어는 그 반응을 예측해 **언제 드러낼지**를 고른다.
> 그리고 이 세계의 모든 인물은 — 진룡조차 — **충분한 정보·수단·대가가 있으면** 죽을 수 있다.

---

## 1. 땅은 표적이다 — "인정"의 문제

09 문서의 영역은 노출도가 오르면 진압을 부른다. 그런데 그보다 근본적인 문제가 있다.
**어느 고대 세력도 인간의 땅을 "정당하다"고 여기지 않는다.** 땅을 가진 순간, 사슬의 맹약 자체에 대한 도전이 된다.

### 1.1 세력별 반응 (인간 영역이 드러났을 때)

| 세력 | 기본 반응 | 바뀔 수 있는 조건 |
|------|-----------|-------------------|
| 용제국 (아우락스파) | 즉시 말살. "본보기" | 바뀌지 않는다 |
| 용제국 (멜리산드파) | 포위 후 '회수' — 사람을 실험 재료로 | 주인공을 넘기면 공동체는 살려주겠다는 거래 |
| 용제국 (카스파르파) | 겉으로는 침묵, 속으로는 관망 | 계승 전쟁 기여 → **칙허** 가능 |
| 비늘 원로회 | 쓸모를 따진다 | 세금·병력을 바치면 "관리되는 자치령"으로 묵인 |
| 엘다르 | 무관심 → 잔향 징후가 보이면 납치조 | 엘다르에게 줄 것이 있을 때 (기억, 예지의 단서) |
| 두르강 | 계약이 있으면 존중, 없으면 무관심 | **계약**을 맺으면 그 조건 안에서 법적 보호 |
| 세렌 | 돈이 되면 거래, 안 되면 팔아넘김 | 교역 이익 > 몰수 이익일 때 |
| 그롬 | "강하면 존중한다" | 원형장에서 증명하거나 그롬 전사를 꺾으면 |
| 요툰 | 굶주리면 약탈 | 식량 거래 |
| 순종의 빛 | 이단 공동체로 규정 | 내부 개혁(알베릭) 성공 시 |
| 맹약회의 | 100년 주기 의제 | 여러 종족이 갈라지면 결의 불가 → 사실상 방치 |

### 1.2 인정을 얻는 다섯 가지 지렛대

| 지렛대 | 내용 | 예 |
|--------|------|-----|
| **억지력** | 공격하면 대가가 너무 크다는 것을 보여준다 | 진압군을 한 번 크게 꺾는다 / 공격하면 광산을 무너뜨린다는 위협 |
| **필수성** | 없으면 손해인 존재가 된다 | 두르강이 의존하는 광석 공급, 세렌의 교역로, 그롬의 투사 공급 |
| **후견** | 강한 누군가의 이름 아래 들어간다 | 카스파르의 칙허, 두르강 계약, 레이디 세실의 비호 |
| **약점** | 상대가 공개되면 곤란한 비밀을 쥔다 | 대붕괴의 진실, 멜리산드의 실험 기록, 원로회의 '용 이후의 제국' 계획 |
| **분열** | 적들이 서로 싸우게 만든다 | 계승 전쟁의 틈, 맹약회의에서 종족끼리 대립시키기 |

> 인정은 영원하지 않다. 후견인이 죽거나, 필수성이 사라지거나, 약점이 공개되면 다시 표적이 된다.

## 2. 땅 없는 힘 — "보이지 않는 왕국" 전략

땅은 눈에 보이고, 보이는 것은 짓밟힌다. 그래서 **땅 없이 힘을 쌓는** 길을 정식 전략으로 설계한다.

| 힘의 형태 | 내용 | 노출도 | 약점 |
|-----------|------|--------|------|
| **사람의 망** | 여러 마을에 흩어진 신뢰하는 사람들 (세포 조직) | 낮음 | 한 명이 잡히면 연쇄 발각 |
| **빚과 은혜** | 많은 사람이 주인공에게 빚지고 있다 | 매우 낮음 | 은혜는 잊히고, 빚은 원한이 된다 |
| **비밀** | 권력자들의 약점을 쥐고 있다 | 없음 | 쓰는 순간 적이 생긴다 |
| **이동하는 무리** | 정착하지 않는 무장 집단 (탈주자 전사단) | 중간 | 보급, 피로, 추격 |
| **숨긴 재화** | 여러 곳에 나눠 숨긴 돈·물자 | 없음 | 위치를 아는 자가 배신하면 |
| **명성** | 이름만으로 사람이 움직인다 (10 문서) | 높음 (평판은 숨길 수 없다) | 표적이 된다 |
| **개인의 힘** | 주인공 자신의 실력·마법·이식 특질 | 쓰기 전까지 낮음 | 한 사람은 한 곳에만 있을 수 있다 |

### 2.1 전략 유형 (플레이어가 정하는 것이지 게임이 정하지 않는다)

| 유형 | 설명 | 장점 | 위험 |
|------|------|------|------|
| **외로운 늑대** | 주인공 개인의 힘을 극한까지 키운다 | 노출도 최소, 빠르다 | 한 명으로는 사슬을 끊을 수 없다. 찬가는 정체된다 |
| **그림자 망** | 땅 없이 사람·빚·비밀로 대륙에 망을 친다 | 짓밟을 대상이 없다 | 느리다. 배신 한 번에 무너진다 |
| **숨은 마을** | 작은 영역을 숨겨 키운다 (09 문서) | 사람을 실제로 구한다 | 노출도 관리 실패 = 학살 |
| **후견 아래** | 강자의 이름 아래 들어가 영지를 얻는다 | 법적 보호 | 후견인의 운명에 묶인다 |
| **왕을 만드는 자** | 계승 전쟁의 판을 움직인다 (카스파르 옹립 등) | 성공하면 가장 큰 보상 | 실패하면 모두 죽는다 |
| **공개 봉기** | 드러내고 싸운다 | 찬가가 빠르게 진행 | 진룡까지 온다 |

> 대부분의 플레이어는 이것들을 **섞고, 바꾼다.** 외로운 늑대로 시작해 그림자 망을 치고, 때가 되면 숨은 마을을 드러내 후견을 얻는다.
> 생애가 바뀌면 전략도 바뀐다 — 앞 생애의 망과 빚과 비밀은 남는다.

### 2.2 "드러낼 때"를 고르는 장치
- **정세 창(窓)**: 월드 클락의 특정 단계(용황 사망 직후, 맹약회의 결렬, 북방 남침)에는 고대 세력이 서로에게 묶여 **대응 단계 상승이 느려진다.**
- 플레이어는 소문·첩보로 이 창이 열리는 것을 미리 알 수 있다 → "지금 드러내면 3개월은 아무도 못 온다."
- 창이 닫히면 밀린 대응이 한꺼번에 온다.

## 3. 음모 작전 — 암살, 납치, 누명, 파괴, 쿠데타

### 3.1 원칙
- **누구든 표적이 될 수 있다.** 마을 감독관부터 진룡까지.
- 난이도는 대본이 아니라 **표적의 데이터**에서 계산된다: 표적의 힘, 경비, 습관, 거처, 알려진 약점.
- 작전은 한 번의 주사위가 아니라 **여러 단계의 계획**이다. 각 단계에서 준비가 쌓인다.
- 성공이든 실패든 **결과는 세계 전체로 퍼진다** (평판, 클락, 관계, 탄압).

### 3.2 작전 단계

```
① 정보 수집  →  ② 접근 경로  →  ③ 수단  →  ④ 실행  →  ⑤ 탈출  →  ⑥ 은폐·누명
```

| 단계 | 하는 일 | 쓰이는 시스템 |
|------|---------|---------------|
| ① 정보 | 표적의 일정, 거처 구조, 경비 교대, 약점, 진명 | 소문, 인물 수첩(08), 지식 카드, 밀정, 매수 |
| ② 접근 | 하인으로 잠입, 변장, 비밀 통로, 초대, 표적의 연인을 통해 | 아이템(변장·문서), 지도(07), 관계 |
| ③ 수단 | 칼, 독, 마법, 사고 위장, 다른 세력의 손 | 아이템(02), 마법(01), 이식 특질(06) |
| ④ 실행 | 판정 연쇄 (은신·무술·마법·기만) | 판정(01), 전투 |
| ⑤ 탈출 | 추격 따돌리기, 미리 준비한 퇴로 | 지도, 동료, 영역(은신처) |
| ⑥ 은폐 | 목격자 처리, 증거 조작, 누명 씌우기 | 사실·인식(08), 평판(10) |

- 준비가 잘 될수록 ④의 난이도가 떨어진다. **준비 없이 들이받는 것도 가능하지만**, 그 결과는 대개 죽음이다 (그리고 영혼은 다음 몸으로).

### 3.3 표적의 보안 등급

| 등급 | 예 | 기본 난이도 (D) | 필수 조건 |
|------|----|-----------------|-----------|
| 1 | 마을 감독관, 밀수꾼 | 25 | 없음 |
| 2 | 용인 하급 귀족, 징세관 | 40 | 일정 정보 |
| 3 | 영주(레이번 남작), 노예사냥 조합장 | 55 | 일정 + 접근 경로 |
| 4 | 대가문 가주, 원로회 와이번, 녹테른 귀족 | 70 | 일정 + 접근 + 약점 |
| 5 | 후계자 용(아우락스·멜리산드), 첫 갈증의 군주 | 90 | 위 전부 + **특수 수단** |
| 6 | 용황, 영원 여왕 | 사실상 불가능 | 위 전부 + **특수 수단 둘 이상** + 정세 창 |

### 3.4 진룡을 죽이는 법 — "매우매우매우 어렵지만 길은 있다"

진룡은 칼로 죽지 않는다. 비늘은 강철을 튕겨내고, 숨결은 성을 녹인다. 그러나 길이 없지는 않다.

| 특수 수단 | 얻는 법 (예) | 효과 |
|-----------|--------------|------|
| **그 용의 진명** | 잿빛 탑 금서고, 대붕괴 잔상, 전생(아스테리온)의 기억 | 이름을 아는 자의 마법은 용의 저항을 무시한다. 단 한 번의 말이 몸을 태울 수 있다 |
| **신살의 창 조각** | 전설의 유물 (ITEMS_AND_ARTIFACTS) | 신을 찌른 쇠. 혈명을 끊는다 |
| **잠든 용** | 용은 수십~수백 년 잠든다. 은거지·잠의 주기를 알아낸다 | 깨기 전 단 한 번의 기회 |
| **오래된 상처** | 바르스카르의 '시간의 상처' 같은 약점 | 상처에 닿는 공격만 통한다 |
| **용의 적** | 다른 진룡, 비늘 원로회, 녹테른의 피 독 | 용을 죽이는 것은 대개 다른 용이다 |
| **용심 이식** | 주인공이 용의 심장을 품었다면 | 용의 불에 버티고, 용의 피 냄새로 접근할 수 있다 |

- 진룡 암살은 **한 생애의 목표가 아니라 여러 생애의 프로젝트**가 될 수 있다: 한 생애는 진명을 찾고, 다음 생애는 창 조각을 찾고, 그다음 생애에 실행한다.
- 성공하면 세계가 뒤집힌다: 23마리 중 하나의 죽음은 3,400년 동안 거의 없던 일이다.

### 3.5 결과 — 성공도 대가를 부른다

| 결과 | 세계의 반응 |
|------|-------------|
| 감독관 암살 성공 | 지역 수색, 본보기 처형 위험 (10 문서 §2.2) |
| 영주 암살 성공 | 후계자·친척의 상속 다툼, 새 영주가 더 가혹할 수 있다 |
| 후계자 용 암살 성공 | 계승 클락 급변. 남은 후계자들의 균형 붕괴. **누가 했는지가 밝혀지면** 인간 전체에 대숙청 |
| 누명 성공 (다른 세력에게) | 그 세력끼리 전쟁 → 인간에게 틈. 단, 누명 쓴 쪽의 무고한 이들이 죽는다 |
| 실패 (도주) | 표적의 보안 등급 +1, 위협도 급상승, 정체 노출 위험 |
| 실패 (붙잡힘) | 심문 → 동료·은신처 노출 위험 → 처형 → 영혼은 다음 몸으로. **남은 사람들이 대가를 치른다** |

### 3.6 그 밖의 음모
| 작전 | 효과 |
|------|------|
| **납치** | 인질로 협상 (원로회 와이번의 새끼, 남작의 아들 오웬) |
| **협박** | 비밀(사실 데이터)로 사람을 움직인다. 쓸수록 원한 |
| **이간** | 두 인물·세력의 관계를 깎는 소문·위조 문서 |
| **매수·포섭** | 적의 측근을 내 편으로 (레아 같은 이중 첩자) |
| **파괴** | 광산·창고·다리·노예 장부 소각 |
| **쿠데타 지원** | 한 인물을 권좌에 올리기 (오웬이 아버지를 밀어내게 돕는다) |
| **구출** | 알베릭, 영혼 정원의 실험체, 원형장의 투사 |

## 4. 거꾸로 — 세계도 주인공에게 음모를 꾸민다

주인공이 강해질수록 세력 AI는 주인공을 표적으로 삼는다 (10 문서 대응 단계와 연동).

| 세력의 수단 | 주인공이 겪는 것 |
|-------------|------------------|
| 암살자 | 바르그 사냥꾼, 녹테른 그림자 사냥꾼, 라미아 밀정 |
| 회유 | "인간들을 버리면 너만은 살려주마" / 원로회의 동맹 제안 |
| 인질 | 주인공의 가족·연인·제자를 붙잡는다 (12 문서) |
| 이간 | 주인공의 동료에게 거짓 소문, 관리자 매수 (09 문서) |
| 함정 | 거짓 의뢰, 거짓 구출 요청 |
| 생포 | 멜리산드·엘다르 존속파는 죽이지 않고 붙잡으려 한다 |

> 주인공은 개인적으로 강해질 수 있지만, **주인공이 사랑하는 모든 것은 약하다.** 그것이 그림다크의 저울이다.

## 5. 구현 메모

```ts
interface Operation {
  kind: 'assassinate'|'kidnap'|'blackmail'|'sabotage'|'frame'|'rescue'|'coup'|'subvert';
  target: NpcId | SiteId;
  stages: { intel: number; access: number; means: MeansId[]; exit?: RouteId; cover?: FrameTarget }; // 0~100 준비도
  securityTier: 1|2|3|4|5|6;            // 표적 데이터에서 계산
  required: Requirement[];              // 등급별 필수 조건 (진명, 특수 유물 …)
}
// 실행: D = 기본 난이도(등급) − 준비 보정 + 상황(정세 창, 시간, 날씨) → 01 문서 판정 연쇄
// 결과: Fact 생성 → 목격자 → 소문 → 평판·위협도·클락·관계 갱신
```

- **"할 수 없다"는 선택지를 만들지 않는다.** 대신 "지금은 거의 확실히 죽는다"는 체감 확률(01 문서 §4)을 보여준다.
- 표적 보안 등급과 필수 조건은 인물 데이터에서 자동 계산 → NPC가 수천 명이어도 모두 표적이 될 수 있다.
