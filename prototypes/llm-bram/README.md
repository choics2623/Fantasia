# 브람 실험실 — LLM 하이브리드 실험 (21_LLM_HYBRID.md)

'첫 밤'의 배급 막사 장면 하나를 **LLM은 제안하고, 규칙이 판정하는** 방식으로 돌려 보는 실험용 프로토타입입니다.

- LLM이 하는 일: 선택지 문장, 브람의 반응 서술, 자유 입력 해석, 대화가 끝난 뒤 브람의 기억 후보 뽑기
- 규칙 엔진(`engine.mjs`)이 하는 일: 가능한 행동, 성공 확률(01 문서 공식), 결과 5단계, 호감·신뢰·두려움, 비밀 공개 여부, 기억 검증과 상한, 회귀

## 실행 (내 PC, Claude 구독으로)

준비물: **Node.js 20 이상**, **Claude Code 설치 + 로그인** (터미널에서 `claude`를 한 번 실행해 구독 계정으로 로그인).

```bash
cd prototypes/llm-bram
node server.mjs
# → 브라우저에서 http://localhost:5173
```

- 호출마다 헤드리스 Claude Code(`claude -p`)를 부르고, 사용량은 **내 구독 한도**에서 빠집니다.
- 혼자 테스트하는 용도입니다. 다른 사람이 플레이하게 하려면 API로 바꿔야 합니다 (아래).

## 공급자 바꾸기

| 환경 변수 | 뜻 |
|-----------|----|
| `LLM_PROVIDER=cli` (기본) | 구독 — 내 PC의 Claude Code 로그인 |
| `LLM_PROVIDER=offline` | LLM 없이 규칙 대체 문장만. 게임이 LLM 없이도 도는지 확인 |
| `LLM_PROVIDER=api` | Claude API (종량제). `npm i @anthropic-ai/sdk` 후 `ANTHROPIC_API_KEY` 설정 |
| `LLM_MODEL=haiku` | 모델. cli는 `haiku`/`sonnet` 같은 별칭, api는 `claude-haiku-4-5` 같은 전체 ID |
| `PORT=5173` | 포트 |

윈도우 PowerShell: `$env:LLM_PROVIDER="offline"; node server.mjs`

## 해 볼 것

1. 빵을 나눠 주고, 하겐에 대해 묻고, 지하실을 떠본다 → 오른쪽 **브람의 속**에서 수치와 기억이 쌓이는 것을 본다.
2. 아래 입력칸에 직접 말해 본다 — 예: `술을 한 잔 따라 주며 하겐 얘기를 슬쩍 꺼낸다`. 엔진이 가장 가까운 행동으로 판정한다.
3. **대화를 끝낸다** → LLM이 뽑은 기억 후보가 검증을 거쳐 받아들여지거나(금색) 버려진다(빨강).
4. **죽고 회귀한다** → 브람은 당신을 처음 본다. 인물 수첩(◇)에는 지난 회차가 남는다. 첫 밤에서 알게 된 에길 이야기를 꺼내면 브람은 "네가 그걸 어떻게 알아?" — 의심 기억이 남는다.
5. **엔진·LLM 기록**을 펼치면 프롬프트, LLM 원본 출력, 판정 계산(S·D), 검증에서 걸린 문제가 다 보인다.

## 측정 (이 환경, Haiku 4.5, 2026-10)

| 설정 | 한 번 호출 | 출력 토큰 |
|------|-----------|-----------|
| 생각(thinking) 켜짐 — Claude Code 기본 | 36~80초 | 약 4,700 (그중 생각 4,100) |
| **생각 꺼짐** — 이 서버의 설정 | **5~8초** | 약 580 |

→ 서버는 `alwaysThinkingEnabled: false` 설정과 `MAX_THINKING_TOKENS=0`으로 생각을 끈다. 문장 품질 차이는 거의 없었다.
