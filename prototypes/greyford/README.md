## 실행
```bash
python3 tools/build_content.py          # 콘텐츠 묶음 (처음 한 번, 콘텐츠를 고친 뒤에도)
node prototypes/greyford/server.mjs     # 기본: 이 PC의 Claude Code 로그인(구독)으로 LLM을 부른다
```
- PC: `http://localhost:5174`
- 폰(같은 와이파이): 서버 창에 나오는 `http://<PC IP>:5174/?key=…` 를 한 번 열면 기억된다.
- `LLM_PROVIDER=api` (ANTHROPIC_API_KEY 필요, 종량제) / `LLM_PROVIDER=mock` (테스트 전용 가짜 LLM)

## 저장
- `prototypes/greyford/saves/auto.json` 에 자동 저장 — 내용은 **시드 + 행동 기록**뿐이다. 불러오면 처음부터 다시 재생한다.
- 수첩(오른쪽 위) → 칸 이름으로 저장·불러오기, 새 판.

## LLM이 응답하지 않으면
그 턴은 일어나지 않은 것으로 되돌린다 (판정도 시간도 흐르지 않는다). "다시 시도"를 누르면 **같은 주사위로** 이어진다.

## LLM 호출을 아끼는 규칙
아무도 없는 곳으로 걷거나 아무 일 없이 기다리면 엔진이 짧은 문장을 쓰고 LLM을 부르지 않는다.
대화·싸움·사람이 있는 새 장면·주변에서 일이 생겼을 때만 부른다. 엔진 기록(수첩 → 맨 아래)에 호출 수가 나온다.
